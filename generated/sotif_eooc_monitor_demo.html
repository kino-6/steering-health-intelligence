SOTIF-EooC 運用フェーズ監視デモ

部品サプライヤが差し出す仮定を宣言し、公開走行logを流して、仮定の範囲内かを判定する。 対象 FORD_MAVERICK_1ST_GEN、806 台分(60秒記録)。

1宣言— EooCで差し出す仮定
機能不足窓長判定則90%検出下限観測された逸脱率
応答遅れ15 s2/40.3 s0.12%
ゲイン(効き)変化60 s1/10.104.59%
応答バイアス15 s3/40.10 m/s²0.25%

設計則は車種不変(4車種で優劣が一致、docs/155)。下限値はprogram固有で較正が要る(docs/147)。 左右非対称・drift・hf_noiseは宣言しない——この方式では90%検出に届かないため。

2較正— この program の母集団基準を取る

窓長ごとに中央値とMADを取り直す。手法は移るが閾値は移らないため、この工程が車種ごとに必要になる。 これが診断コンテンツNREの実体である。

3観測— 宣言した範囲を出た台数

4.96% （40 / 806 台）

ここはOEMが埋める欄（EOOC011）
機能不足の許容発生率の目標値は、車両レベルの安全目標からの配分であり、部品側では決められない。 公開情報では原理的に届かない。
部品側が差し出せるのは観測された 4.96% という実測値までで、 これが目標以下かを判定するのはOEMの領域である。この空欄そのものが責任境界の記録である。
4報告— 逸脱した1台に対する部品側payload 
component        : steering / EPS
observed_context : 宣言した観測範囲の外れ(ゲイン(効き)変化)
event_relation   : assist制限の確定fault未満。機能影響の有無は本payloadでは断定しない
severity_language: context observed / below hard fault threshold
recurrence       : 応答遅れ 0/4窓、ゲイン(効き)変化 1/1窓、応答バイアス 0/4窓
confidence       : medium(宣言済みの設計則と較正済み母集団に基づく)
recommended_read : EPS DTC status / reset context / supply voltage context / assist mode / recurrence
boundary         : not a root cause, not a failure prediction, not a replacement timing,
                   not a safety guarantee, not a SOTIF conformity claim
unit             : 00009

このデモが言っていないこと

  • 故障を検出した / 予測した — 言っていない。走行logは健全車両のもので、実故障の波形は公開されていない
  • 逸脱した台が異常である — 言っていない。母集団基準からの統計的な外れであり、路面・積載・運転操作でも起きる
  • SOTIF適合を証明した / 安全を保証した — 言っていない。適合判断の主語はOEMである
  • この逸脱率が妥当である — 言っていない。妥当性の基準(許容発生率)は上の空欄のままである
