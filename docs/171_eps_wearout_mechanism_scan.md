# 171. EPSに接合部の摩耗故障は現れるか(ギャップTの検証)

## 判断

**支持されなかった。そして公開のリコール記録では、この問いは原理的に決着しない。**

[docs/170](170_thermal_headroom_translation.md) は限界5として「EPSインバータでdie-attach型の熱劣化が起きることは示していない(類推である)」と書いた。
NHTSAリコール全文(2010年以降、13,461キャンペーン)で調べた結果:

| 機構グループ | EPS(168件) | 操舵全般(644件) | 全車両(13,461件) | EPS/全車両 |
|---|---|---|---|---|
| **接合部の摩耗故障**(die attach / solder / bond wire) | **1.2%** | 0.3% | 0.1% | **8.0倍** |
| **熱による駆動**(thermal cycling / fatigue / overheat) | **1.8%** | 0.6% | 3.3% | **0.54倍** |
| 割れ・剥離 | 6.0% | 23.0% | 11.3% | 0.53倍 |
| 接点の劣化(fretting / corrosion) | 3.6% | 1.4% | 2.2% | 1.63倍 |
| **電気的症状**(intermittent / open / short) | **7.7%** | 2.0% | 2.8% | **2.81倍** |

数表: [data/eps_wearout_mechanism_scan.tsv](../data/eps_wearout_mechanism_scan.tsv) / 実行: `python3 scripts/eps_wearout_mechanism_scan.py`

## 読み方

### 1. 接合部の摩耗故障は「8倍」だが、実体は2件しかない

EPSキャンペーン168件のうち `solder` を含むのは**2件だけ**である。しかも**両方とも製造起因**であって、熱サイクルによる摩耗故障ではない。

- **Nissan Rogue(2011)**: 「回路基板が正しい位置に取り付けられていない可能性 → 端子のはんだに追加応力 → はんだ割れと分離」——**組立不良**
- **Mercedes-Benz(2016、複数車種)**: EPSシステムのはんだ付け不良——**製造不良**

8倍という数字は、母数(全車両0.1%)が小さいことによる。**「EPSでは接合部の摩耗故障が起きている」の根拠にはならない。**

### 2. 熱による駆動はむしろ低い(0.54倍)

もしdie-attach熱疲労がEPSの主要なフィールド機構なら、熱関連の語が全車両平均より**高く**出るはずである。
実際は **0.54倍で平均以下**だった。**docs/170 の類推は、公開記録では支持されない。**

### 3. 一方、断続的な電気症状は明確に高い(2.81倍)

`intermittent` は EPS キャンペーンの最頻語(4.8%)であり、`corrosion` (3.6%)、`short circuit` (3.6%) が続く。
**本研究が標的にしてきた故障族(断続的な電気接続不良、[docs/127](127_steering_predictive_diagnostics_target_case_public_evidence.md), [docs/129](129_steering_predictive_diagnostics_public_case_crosscheck.md))が、EPSに特有であることが定量で裏づけられた。**

つまり **EPSの弱点は熱疲労ではなく接点・接続である**、と公開記録は言っている。

## 決定的な限界: リコール記録は摩耗故障を見られない

上の「熱が低い」を「熱疲労は起きていない」と読んではいけない。

**リコールは系統的な欠陥に対する制度である。** 保証期間後に母集団全体でゆっくり進む摩耗故障は、
リコールにならず**サービス交換として処理される**。したがって**リコール記録は構造的に摩耗故障を見られない**。

これは本研究がこれまでに特定した観測の盲点の**4つ目**である。

| 観測手段 | 見えないもの | 出典 |
|---|---|---|
| 苦情 | ユーザが気づいて書かない壊れ方 | [docs/156](156_train_era_miss_structure.md) |
| 車検 | 検査日に目視で分からない状態 | [docs/157](157_mode_split_and_corsa_correction.md) |
| **リコール** | **系統的欠陥でない摩耗故障** | **本ドキュメント** |
| 制御器の外側 | 制御器が打ち消す内部の変化 | [docs/162](162_pmsm_model_validation_results.md) |

**4つの独立した公開観測手段のすべてが、狙っている対象を構造的に見られない。** これは本研究の主張(部品内部観測が要る)の、これ以上ない裏づけである——**同時に、公開情報だけでは対象の実在を確認できないという限界の確定でもある。**

## 自分の集計の誤り(記録)

最初の実行は**キャンペーンではなく車種行を数えていた**。1つのリコールが数十行に展開されるため、
`solder` が14件あるように見えていた(実体は2件)。接合部グループのliftも13.3倍と出ていた(正しくは8.0倍)。

**単位を campaign に直して再実行した。** 数え方の誤りが結論を2倍以上動かしていた。

## ギャップTの結論

> **T: EPSインバータでdie-attach型の熱劣化が起きるか → 公開情報では確認できない。**
> リコール記録は摩耗故障を構造的に見られないため、「記録に無い」は「起きていない」を意味しない。
> **ここで問いを閉じる。** [docs/170](170_thermal_headroom_translation.md) の熱経路は、**EPSでの実在を仮定した推論**であることを明記したまま維持する。

代わりに、公開記録が積極的に支持しているのは**接点・接続の断続故障**である(2.81倍)。
[docs/168](168_transfer_reduces_to_spec.md) が立てた **A''(frettingが単調な発生率上昇として観測できるか)** の方が、
市場実態に沿った問いである。**熱経路より接点経路を優先する。**

## Rule Check

- 公開データのみ(NHTSA、パブリックドメイン)。検索語は機構名として実行前に固定した
- **8倍という有利な数字を、実体2件・製造起因と確認して否定した**
- 熱経路(自分が直前に構築した [docs/170](170_thermal_headroom_translation.md))を支持しない結果を、そのまま記録した
- **自分の集計単位の誤り(行 vs キャンペーン)を発見し、訂正して再実行した**
- 「記録に無い＝起きていない」ではないことを明記し、限界を限界として閉じた
