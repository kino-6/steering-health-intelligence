# 365. 事前登録 — NASA の劣化モデルを 6 素子に当て、その母数から仮想個体群を作る

2026-09-14 ユーザ提案: **「パワー電子は劣化推定式があるのでは？ そこから NASA のデータからモデル構築して、それを元に作業してみては？」**

そのとおりである。今の仮想パワーモジュール（[docs/343](343_virtual_module_detection_protocol.md)）は
「ランダムウォーク + 始点からの直線」という**私が置いた形**で劣化を作っていた。
NASA データの著者自身が劣化の形を公開している（[SOURCES.md](../SOURCES.md) S16）。
**その形を 6 素子に当て、母数の散らばりから仮想個体を作り直す。**模型であることは変わらないが、形と散らばりが測ったものになる。

## 使う劣化モデル（NASA、RAMS 2012）

> ΔR_DS(on) は時間に対して指数関数的に増え、その始まりは素子ごとに違う。

これを次の形で当てる。`t` は通電時間（データ自身のタイムスタンプ、[docs/341](341_lifetime_simulation_results.md)）:

```
ΔR(t) / R0 = 0                         t < t0
           = a · (exp(b · (t − t0)) − 1)   t ≥ t0
```

母数は素子ごとに `a`（無次元）、`b`（1/時間）、`t0`（時間）の 3 つ。7 run の R_on（基準温度で読んだ値、[docs/331](331_assist_capability_results.md)）に最小二乗で当てる。

**故障の判定**: NASA の ΔR = 0.05 Ω を IRF520N の R_DS(on) max 0.20 Ω で割った **+25%**。能力に直すと `C = 1/√1.25 = 0.894`。
6 素子の run 7 の能力は 0.82〜0.93 で、この線と整合する。

## 仮想個体群の作り方（実行前に固定する）

| 項目 | どう決めるか | 出所 |
|---|---|---|
| 劣化の形 | 上の指数モデル | NASA RAMS 2012 |
| `a`, `b` の散らばり | 6 素子の当てはめ値の対数正規（中央値と対数の標準偏差） | 6 素子（実測） |
| `t0` | 走行区間の中で一様 | 置いた値 |
| 測定ノイズ σ、信号対雑音 S | **40 テストの経験分布**からそのまま引く | [docs/363](363_population_results.md)（実測） |
| 健全期の漂流の総量 | 6 素子の中央値 0.351 × 3σ | [docs/343](343_virtual_module_detection_protocol.md)（実測） |
| 漂流の形 | ランダムウォーク | **置いた形。**実素子は傾向（α = 1.32）。前と同じ限界 |
| 時間の刻み | 5 秒窓を 1 単位（720 窓/時）。窓の平均を直接生成する | 記録器の判定単位 |
| 出荷時の掃引 | 1 時間（720 窓） | [docs/321](321_enrolment_length_results.md) |
| 誤検知の線 | 2.7 件/時（32 KB の線、[docs/356](356_nvm_budget_line_results.md)） | 導出 |
| 個体数 | 1,000（半分が劣化） | 置いた値 |
| 走行の長さ | 各個体の故障時刻 + 1 時間、上限 200 時間 | 模型から |

**何もしない基準**（T34）: 従来の仮想モジュール（直線の劣化）。docs/344 では検知 95〜100%、誤検知 12〜39 件/時。

## 事前登録する予想（手計算で決まらない量だけ）

| | 予想 | 外れる条件 |
|---|---|---|
| **M1** | 当てはめた `b` の最大/最小は 6 素子で **5 倍以内** | 5 倍超 |
| **M2** | 1,000 個体のうち劣化する 500 で、記録器が **C = 0.894 に達する前に警報を出す割合 ≥ 90%** | 90% 未満 |
| **M3** | 最初の警報から故障までの猶予の中央値は、その個体の時定数 `1/b` の **0.5 倍以上** | 0.5 倍未満 |
| **M4** | 健全な 500 のうち、誤検知率が線（2.7 件/時）の **2 倍を超える個体は 10% 以下** | 10% 超 |

## これで言えないこと

- **N が増えたのは模型の中である。**実素子は 6 のまま。M2 の「90%」は模型の性質であって、実素子の検知率ではない
- `a`, `b` の散らばりは 6 点から推定した対数正規で、6 点で分布の形は決まらない
- 漂流の形はウォークで置いたままで、実素子の傾向より易しい

## やらないこと

- 当てはめが悪い素子を外さない。6 素子全部を使う
- 外れた予想を層別で救わない（T17）
