# 374. 事前登録 — 較正した Wiener 個体群に、同じ種類のチャネルの差分を与えると、追い越し時刻と誤検知はどうなるか

[docs/373](373_wiener_path_results.md) は「差分が σ_B を共有分だけ減らすなら (σ_B/μ)² は縮む」と書いて、**測っていない**と明記した。ここで測る。
**追加取得はしない。**母数は docs/373（μ の対数正規 m = −1.65、s = 0.25、σ_B = 0.555）、共有率は [docs/352](352_shared_drift_results.md) の実測（半ブリッジ温度 92.6%、相電流 31.8%）、ノイズと S は 40 テストの経験分布。

## 式で先に決まること（予想ではない）

2 本の同じ種類のチャネルの漂流を、共有部分（分散の割合 s）と固有部分に分けると、差分の漂流の分散は `2(1 − s)σ_B²`。
追い越し時刻は `2(1 − s)(σ_B/μ)²` で、s = 0.926 なら **0.148 倍**（docs/373 の「1/13」は係数 2 を落としていた。正しくは約 1/6.8）。
劣化が 1 本だけに出るなら差分に残り、**両方に同じ速さで出るなら差分から消える。**

## 模型（実行前に固定する）

- 個体 = チャネル 3 本の組（半ブリッジ温度を想定）。各チャネルの漂流 = 共有ウォーク × √s + 固有ウォーク × √(1 − s)、σ_B は docs/373
- 劣化は **1 本だけ**に μ·t で入る（μ は対数正規から）。始点は健全期の中で一様
- 記録器は、各チャネルから**残り 2 本の中央値**を引いた系列で判定する（現行の実装、[docs/286](286_common_mode_results.md)）。閾値は 1 時間の登録区間の分位点、線は 2.7 件/時
- 共有率 s ∈ {0（差分なしと等価）, 0.318（相電流）, 0.926（半ブリッジ温度）, 1.0}
- 個体 1,000（半分が劣化）、健全期 2.3 時間、故障は劣化したチャネルの逸脱が D = S × 0.25 に達した時刻

## 事前登録する予想（手計算で決まらない量だけ）

| | 予想 | 外れる条件 |
|---|---|---|
| **X1** | s = 0.926 で、健全個体の誤検知率の中央値は線の **2 倍（5.4 件/時）以下** | 2 倍超 |
| **X2** | s = 0.926 で、劣化個体が故障前に鳴る割合は **90% 以上**、かつ最初の警報から故障までの猶予の中央値は **2 時間以上** | どちらか外 |
| **X3** | s = 0.318（相電流）では、誤検知の中央値は線の **2 倍を超える** | 2 倍以下 |
| **X4** | 劣化が 3 本すべてに同じ速さで入る場合、s = 0.926 でも故障前に鳴る割合は **50% 未満** | 50% 以上 |

**何もしない基準**（T34）: 差分なし（docs/373 の W4: 231 件/時、追い越し 4〜11 時間）。

## これで言えないこと

- 共有率は実インバータの正常運転 28 分で測った値で、劣化中も同じとは限らない
- 劣化が 1 本だけに出るという仮定は、三相ブリッジで 1 素子が先に劣化する場合に当たる。全部同時なら X4 が示すとおり見えない

## やらないこと

- s の値を後から動かさない。実測の 2 値と両端だけ
- 予想が外れても層別で救わない（T17）
