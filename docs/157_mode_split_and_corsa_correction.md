# 157. 故障モードによる4例目の照合と、Corsa答え合わせの訂正

## 判断

**1. 未照合だった Fiat 500X / Jeep Renegade は、バン(用途摩耗型)ではなく Corsa と同じ型だった。**

**2. ただしその「Corsaと同じ型」は、[docs/151](151_high_rate_model_crosscheck.md) が言った①欠陥ファミリー型ではない。3車種に共通するのは、ボールジョイントの<ruby>防塵<rt>ぼうじん</rt></ruby>カバー(ダストカバー)の劣化である。**

**3. したがって [docs/151](151_high_rate_model_crosscheck.md) の Corsa 答え合わせは、モードの水準では誤帰属だった。** 公開記録が示す Corsa の EPS コラム故障は実在するが、**Corsa の車検不合格率の高さを説明していない**。

推測で埋めず、車検の**不合格項目そのもの**を集計して判定した。

## 数字(車齢3-10年、2025年、乗用車クラス・通常検査)

| モデル | 検査数 | 操舵不合格率 | **カバー系 / ガタ系** | 判定 |
|---|---|---|---|---|
| **Fiat 500X** | 32,633 | 8.22% | 2,151 / 653 = **3.29** | カバー型 |
| **Jeep Renegade** | 26,014 | 7.89% | 1,558 / 584 = **2.67** | カバー型 |
| Vauxhall Corsa(参照) | 392,071 | 6.53% | 22,988 / 3,351 = **6.86** | カバー型 |
| Vauxhall Vivaro(参照・バン) | 93,861 | 8.62% | 562 / 7,768 = **0.07** | ガタ型 |
| Renault Trafic(参照・バン) | 55,093 | 9.87% | 396 / 5,208 = **0.08** | ガタ型 |

- **カバー系** = ボールジョイントのダストカバーが破損/脱落("dust cover excessively damaged"、"dust cover insecure")
- **ガタ系** = ボールジョイントに過大なガタ、または摩耗("has excessive play"、"worn to the extent...")

**比で40〜100倍の開きがある。** 乗用車3車種はカバー破損が主、バン2車種はガタが主。これは連続的な差ではなく、別の壊れ方である。

実行: `python3 scripts/dvsa_mot_mode_split.py`

## 読み方

- **バン(Vivaro / Trafic)**: 荷重と縁石・段差の累積で**ジョイントそのものが摩耗してガタが出る**。[docs/151](151_high_rate_model_crosscheck.md) の②用途起因の摩耗という判定は**正しかった**。今回、機序まで確定した
- **乗用車(Corsa / 500X / Renegade)**: ジョイントは摩耗していない。**ゴムカバーが先に劣化して不合格になる**。用途負荷ではなく材料・耐久の問題である

500X と Renegade は同一プラットフォーム(FCA)の対であり、両方が同じ比率(3.29 / 2.67)を示した。**同一プラットフォームのペアが同じ壊れ方を示す**という点は、Vivaro / Trafic(0.07 / 0.08)でも同様に成立している。群シグナルがプラットフォームの実体を指していることの、4例目・5例目の確認になる。

## [docs/151](151_high_rate_model_crosscheck.md) の訂正

[docs/151](151_high_rate_model_crosscheck.md) は Corsa を「①公知の欠陥ファミリー」に分類し、根拠として Corsa D 世代の EPS コラム故障(トルクセンサ/舵角センサ、断続的なアシスト喪失)が公知であることを挙げた。

**その公開記録自体は正しい。しかし、それは Corsa の車検不合格率を説明していない。**

| Corsa の操舵不合格 26,366件の内訳 | 件数 | 比率 |
|---|---|---|
| リンケージ(ボールジョイント等) | 26,366 | **99.0%** |
| ステアリングコラム/シャフト/継手 | 13 | **0.0%** |
| パワーステアリング | 15 | **0.1%** |

**EPS コラム系は13件、0.0%である。** つまり答え合わせは「高率モデルの上位に、たまたま別件で公知の欠陥があった」という対応であり、**同じ故障を指していなかった**。

[docs/151](151_high_rate_model_crosscheck.md) は「群シグナル上位は公開不具合記録と対応した(3例成立)」と書いたが、Corsa については**モードの水準で成立していない**。Ford / GM の2例(いずれもリコール文書との突き合わせ)は影響を受けない。

## 本研究への含意(重要)

**英国車検の群シグナルは、EPS の健全性の代理指標になっていない。**

操舵系不合格の99%はリンケージであり、EPS 内部に起因する項目は0.0〜0.1%しか現れない。[docs/148](148_dvsa_mot_denominator_verification.md) が「電動パワステ固有項目は絶対値が極小」と記録した現象を、モード内訳から裏づけた形である。

これは3つの帰結を持つ。

1. **[docs/149](149_concentration_ev_and_japan.md) / [docs/151](151_high_rate_model_crosscheck.md) の群集中の議論は、「操舵系の」集中であって「EPS の」集中ではない。** 以後この区別を落とさない
2. **[docs/150](150_advisory_precedence_verification.md) の24.1倍は影響を受けないが、意味はさらに限定される。** [docs/150](150_advisory_precedence_verification.md) は既に「検査員の目視観察の予測力であって、ECU内部信号の予測力ではない」と書いていた。今回それが具体化した——観察されていたのは主にボールジョイントのダストカバーである。「閾値未満の観察に予測情報が乗る」という一般命題の実証としては有効なまま
3. **部品内部観測の必要性が、また別の経路から裏づけられた。** 外部の全数検査データですら、EPS 内部の状態はほぼ観測していない。[docs/143](143_recall_detection_results_v2.md)(苦情)、[docs/156](156_train_era_miss_structure.md)(見逃し構造)に続き、3つ目の独立した経路から同じ結論に到達した

## 限界

1. **車検は「その日に検査員が見て分かる状態」しか記録しない。** EPS のアシスト喪失は断続的で、検査時に再現しなければ記録されない。したがって「車検にEPS項目が出ない」は「EPSが壊れていない」を意味しない——**観測できていない**という意味である
2. モデル名は前方一致で集計した(`CORSA` は `CORSA SE` 等の仕様違いを含む)。バン派生の `CORSAVAN` は用途が異なるため除外した
3. Corsa の検査数(392,071)は [docs/151](151_high_rate_model_crosscheck.md) の集計(310,887)と一致しない。モデル名の照合方法が異なるためで、不合格率も6.53%と9.35%で差がある。**本ドキュメントの結論は不合格の内訳比であり、母集団の取り方に対して頑健**だが、率の絶対値を [docs/151](151_high_rate_model_crosscheck.md) と比較しないこと
4. カバー系/ガタ系の分類は不合格理由の文言に基づく。中間的な記述の扱いは判定者(検査員)の裁量に依存する

## Rule Check

- 公開データのみ(DVSA MOT、OGL v3.0)。推測で埋めず、不合格項目の集計で判定した
- **自分たちの過去の結論(docs/151の3例目)を否定する結果を、そのまま記録した**
- モデル名の前方一致がバン派生を巻き込んでいたことを発見し、除外して再実行した(結果はほぼ不変だが、混入したまま報告しない)
- 設計優劣の断定をしていない。カバー劣化が「欠陥」かどうかは本データでは判定できず、判定していない
- 「車検にEPS項目が出ない=EPSは健全」という誤読を明示的に否定した
