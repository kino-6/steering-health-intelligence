# 201. 巻線の故障は2種類あり、電流はそのうち1つしか見ていない

**予想は外れた。**capability の規則はコイル間短絡へ転移しなかった。
そして**電流だけでは巻線の故障を覆いきれない**ことが分かった。

実行: `python3 scripts/motor_fault_types_and_vibration.py` /
数表: [data/motor_fault_types_and_vibration.tsv](../data/motor_fault_types_and_vibration.tsv)

## 事前登録([docs/200](200_motor_second_fault_and_vibration_protocol.md))の判定

| # | 問い | 結果 |
|---|---|---|
| **W1** 規則は第2の故障種へ転移するか | **不成立**(ρ = −0.024、必要 ≤ −0.80) |
| **W2** 電流は振動に対して十分か | **成立。ただしこの成立は信用できない**(後述) |
| **W3** 電流だけで故障種を区別できるか | **不成立**(値域が重なる) |

## 判定を汚していたもの — セッションの段差

全記録のうち、C相の極性が反転している側は **severityに関係なく** C1 ≒ 0.93、振動 ≒ 0.09 に張り付いていた。
健全記録側は C1 ≒ 0.98〜1.00、振動 ≒ 0.7〜1.6 である。

**これは故障の signature ではなく、測定セッションの違いである。**
[docs/162](162_pmsm_model_validation_results.md) が層間短絡で見つけた2セッション構造が、
**コイル間短絡にも同じように入っていた。**

W2が「電流で足りる」と出たのは、**両チャネルとも故障ではなくセッションの段差を検出していたから**である。
**この成立は取り下げる。**

## 事後の層別(健全記録を含むセッションのみ)

[docs/195](195_capability_rule_second_mechanism_results.md) と同じ処置を当てる。**判定の後に行った事後の層別である。W1は救われない。**

### 層間短絡

| severity | 電流 C1 | 粒度 | 振動 V1 | 粒度 |
|---|---|---|---|---|
| 0.00% | 1.0000 | 0.0014 | 1.000 | 0.078 |
| 3.35% | 0.9811 | 0.0023 | 0.667 | 0.096 |
| 6.48% | 0.9766 | 0.0038 | 0.683 | 0.051 |
| 21.69% | 0.9518 | 0.0101 | 0.281 | 0.074 |

**電流 ρ = −1.000(単調)** / 振動 ρ = −0.800(境界)

### コイル間短絡

| severity | 電流 C1 | 粒度 | 振動 V1 | 粒度 |
|---|---|---|---|---|
| 0.00% | 1.0000 | 0.0014 | 1.000 | 0.078 |
| 1.01% | 0.9949 | 0.0021 | 1.182 | 0.046 |
| 2.00% | 0.9898 | 0.0050 | 1.201 | 0.076 |
| 7.56% | 0.9952 | 0.0021 | **1.583** | 0.043 |

**電流 ρ = −0.400(不成立)** / **振動 ρ = +1.000(単調)**

## いちばん重要な結果

> **巻線の故障は2種類あり、どちらのチャネルも両方は覆わない。**

| 故障種 | 電流(ECUが既に持つ) | 振動(加速度計が要る) |
|---|---|---|
| **層間短絡** | **単調に効く** | 境界 |
| **コイル間短絡** | **効かない** | **単調に効く** |

**EPSのECUが既に測っている相電流は、巻線の故障のうち片方しか見ていない。**
もう片方を覆うには加速度計の追加が要る。

**これは商品として不利な結論である。**[docs/200](200_motor_second_fault_and_vibration_protocol.md) で
「不利でもそう書く」と先に決めたとおりに書く。

## 主張がどう動くか

| 主張 | 変化 |
|---|---|
| [docs/195](195_capability_rule_second_mechanism_results.md)「規則は巻線機構へ転移した」 | **範囲を狭める。**転移したのは**層間短絡**であって「巻線」一般ではない |
| 「センサ追加ゼロで成立する」 | **層間短絡に限れば成立。**巻線の故障全体では**成立しない** |
| 「劣化の次に故障種まで言える」 | **不成立。**電流だけでは2種を区別できない(W3) |
| 個体・セッション基準の必要性 | **さらに強くなった。**3例目のセッション段差。基準を持たない監視は毎回これに騙される |

## 記録するが、ここでは検証しないこと

事後の層別で、振動の向きが**故障種によって逆**になっていた——層間短絡では下がり(1.000→0.281)、
コイル間短絡では上がる(1.000→1.583)。**故障種の区別に使えるかもしれない。**

**しかしここでは検証しない。**[docs/200](200_motor_second_fault_and_vibration_protocol.md) で
「W3が落ちても別の特徴量を後から探さない」と先に縛った。**観察として記録し、別の事前登録に回す。**

## 限界(緩めない)

- **機体1台、各severity 1記録、層別後は各故障種4点。**ρ=1.000も4点では弱い。統計ではない
- **事後の層別である。**事前登録の判定はW1不成立・W3不成立で確定している
- **振動は1ch。**設置位置による差は評価できない
- **severityの範囲が揃っていない。**層間0〜21.69%、コイル間0〜7.56%
- **人工的に作られた故障である。**自然劣化ではない
- **これはEPSではなく同型のPMSMである**(1.0 kW、3000 rpm)

## Rule Check

- **W1不成立を冒頭に置いた。**基準を動かしていない
- **W2の「成立」を自分で取り下げた。**セッションの段差を検出していただけだと書いた
- 事後の層別を判定の後ろに置き、**W1は救われないと明記した**
- **不利な結論(加速度計が要る)を、先に決めたとおり書いた**
- 有望に見える観察(振動の向きの逆転)を、**先の縛りに従って検証しなかった**
