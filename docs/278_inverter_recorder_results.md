# 278. 8つ全部で鳴った。ただし黙るべきところで鳴るチャネルを除くと3つに落ちる

[docs/277](277_inverter_recorder_protocol.md) の事前登録を実行した。**追加取得ゼロ。**

> **V1 成立(8/8)。V2 不成立(最悪27,231倍)。**
> **誤報が基準内のチャネルだけで数え直すと 3/8 になる。**
>
> **[docs/277](277_inverter_recorder_protocol.md) が実行前に書いたとおりである——
> 「V2が落ちれば、V1は『何にでも鳴る』ことの言い換えにすぎない」。**

実行: `python3 scripts/inverter_recorder.py` / 数表: [data/inverter_recorder.tsv](../data/inverter_recorder.tsv)

装置: 三相インバータ(MOSFET IRF540N)+ **自動車用オルタネータを改造したPMSM**。
正常運転4,295点の前半で指紋を採り、後半と8つの故障条件に記録器を通した。

## 判定

| # | 基準 | 結果 |
|---|---|---|
| **V1** | 8つの故障のうち7つ以上で発火 | **8/8。PASS** |
| **V2** | 正常の後半で誤報が設計値の3倍以内 | **最悪 27,231倍。FAIL** |
| **V1かつV2** | 誤報が基準内のチャネルだけで数える | **3/8。FAIL** |

## チャネルごとの内訳

| チャネル | 正常後半での誤報(設計比) | 発火した故障 |
|---|---|---|
| **T1**(半ブリッジ1の温度) | **27,231倍** | 8/8 |
| **T2** | **1,683倍** | 8/8 |
| **Vdc**(DCバス電圧) | **16.8倍** | 3/8 |
| Ia(相電流) | **0.0倍** | 1/8 |
| Ib | 0.0倍 | 0/8 |
| Idc(DCバス電流) | **0.0倍** | 2/8 |
| T3 | **0.0倍** | 2/8 |
| Vd(ドライバ電圧) | 0.0倍 | 0/8 |

**8/8を出していたのは T1・T2 である。その2つは正常データの76%と4.7%でも鳴る。**
**検出器ではなく、温度が単調に上がっていることを見ているだけである。**

## なぜT1・T2が壊れたのか

**記録は正常運転を約5分続けたものであり、その間に半ブリッジの温度が上がり続ける。**
前半で採った指紋は後半を説明しない。**[docs/215](215_inverter_dataset_acquisition.md) が
「正常クラスだけが非定常」と書いた性質が、そのまま出た。**

**T3だけが誤報0である。**同じ試験機の同じ種類のセンサでありながら、
**3つのうち2つが使えず1つが使える。**理由はこのデータからは決まらない。

## 残ったもの — 3/8

誤報が基準内の5チャネル(Ia, Ib, Idc, T3, Vd)だけで数えると:

| 故障 | 発火したチャネル |
|---|---|
| HB1 下側 短絡 | **Ia, Idc** |
| HB3 上側 短絡 | **T3** |
| HB3 過温度 | **Idc, T3** |
| 他5件(開放2件、過温度2件、短絡1件) | **なし** |

**短絡と過温度の一部は捕まる。開放は1件も捕まらない。**

## 現在の答えへの影響

**現在の答えは「報告すべきは観測量の逸脱」である。本検定はそれを裏付けなかった。**

| | 検証の状態 |
|---|---|
| 相電流 | **1/8。**ほとんど鳴らない |
| DCバス | 2/8(電圧は誤報過多で除外) |
| 温度 | **3チャネル中2つが誤報で使えない。**1つで2/8 |
| ドライバ電圧 | **0/8** |

> **仕様が挙げる4つの観測量のうち、実インバータの導入故障を誤報なく捕まえたのは、
> 相電流1件・DCバス電流2件・温度1チャネル2件である。**
> **「観測量の逸脱を報告すれば足りる」は、この装置では支持されなかった。**

## この結果が示していないこと

- **故障は人為的に導入されたものである。**開放・短絡・過温度を実験者が作った。**劣化ではない**
- **EPSではない。**オルタネータ改造のPMSMである
- **1台のみ。**機体をまたぐ検証はできない
- **10 Hzである。**スイッチング周期は見えない
- **「記録器が使えない」とは言えない。**指紋を非定常な区間で採ったことが効いている可能性がある。
  **ただし、それを言い訳にして基準を緩めない**

## 次にやること(この不成立が指すもの)

**指紋を採る区間の選び方が、結果を支配している。**
[docs/225](225_recorder_specification.md) は「出荷時に採る」と書いているが、
**「その区間が定常であることをどう確かめるか」を書いていない。**
**T1・T2の失敗は、その欠落が実データで顕在化したものである。**
