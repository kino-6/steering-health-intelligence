## 事前登録の書き落とし — 指紋のスライス

**[docs/308](308_slow_refusal_protocol.md) は較正区間・誤報評価区間・探索区間を書いたが、
「直線をどのスライスで当てるか」を書かなかった。**
私は較正区間（約 7,000 標本）に当てた。[docs/299](299_bank_results.md) は run 1 前半（約 800 標本）だった。

**その差だけで、誤報 3 倍以内の素子が 3/6 → 1/6 に落ちる。**

> **標本を 9 倍にすると悪くなる。**
> 較正区間は run 1〜3 にまたがり、その間に観測量が漂流する（[docs/299](299_bank_results.md)）。
> **動作点だけの直線でその漂流を吸うと、線が傾き、run 4 の残差が丸ごとずれる。**
> **短い区間で当てた方が、漂流を吸わないぶん良い。**

## F1 と F2 が効かなかった理由

**F1（遅い側の宣言しない）**: Test_10 の暖機を狙ったが、誤報 3 倍以内の素子数は変わらない（1/6 → 1/6）。
Test_10 の run 4 判定数が 2,437 → 2,325 に減っており、**範囲外の窓は確かに落としているが、残った窓でも鳴っている。**
暖機は原因の一部でしかなかった。

**F2（漂流項）**: Test_9 と Test_11 が 0 になる一方、**Test_8 が 0 → 41,528 倍に悪化する。**
較正区間 7,000 標本で当てた時間の係数を、運用 50,000 標本に外挿している。
**係数のわずかな誤差が、外挿の先で大きなずれになる。**

> **これは [docs/306](306_capacitor_regression_results.md) の R2 と同じ型である**——
> **当てはめた範囲の外に出した瞬間に壊れる。**
> 動作点でも、応力水準でも、時間でも、同じことが起きている。

## 言えるようになったこと

**3 つの検証（[299](299_bank_results.md)・[306](306_capacitor_regression_results.md)・本文書）が、同じ 1 つのことを別の軸で示した。**

| 軸 | 外挿したもの | 壊れ方 |
|---|---|---|
| 動作点 | 指紋の掃引範囲の外 | 「宣言しない」で回避（仕様） |
| **応力水準** | 10 V 群を学習せずに予測 | 誤差 **12.6 倍**（[306](306_capacitor_regression_results.md)） |
| **時間** | 較正 7,000 標本の漂流係数を 50,000 標本へ | 誤報 **0 → 41,528 倍**（本文書） |

> **この要素の設計原則は 1 つに縮む——当てはめた範囲の外では宣言しない。**
> **動作点だけでなく、時間と応力水準についても同じ規則が要る。**

## 次の候補

**漂流を外挿しないやり方。**指紋を時間で更新する（走行ごとに再当てはめ）か、
**漂流項を持たずに、漂流が入る前の短い区間だけで当てる**（F0' がそれに近い）。
**どちらも設計判断であり、次の事前登録で比べる。**

## 答えないこと
- ヒーター動作の 1 試験機・6 素子。**率ではなく存在証明**
- F-B の 6/6 は誤報が万単位のままで意味を持たない
- F2 の漂流項は線形。非線形の漂流は扱っていない

## Rule Check
- F-C 不成立を冒頭に置いた。F-B の 6/6 を成立と読み替えていない
- **事前登録が指紋のスライスを書き落としていたことを、自分の欠陥として書いた**
- **書き落としの効果（3/6 → 1/6）を、修正の効果より大きいと明示した**
- F2 が 2 素子を救い 1 素子を壊したことを両方書いた
