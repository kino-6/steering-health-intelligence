# 314. 事前登録 — 範囲外で黙るか、指紋を採り直すか

> [docs/312](312_stress_axis_results.md) が軸を累積ストレスに決めた。**残るのは、その軸で何をするかである。**
>
> | 案 | やること | 危険 |
> |---|---|---|
> | **A 境界** | 累積ストレスが指紋の有効範囲を超えたら**宣言をやめる** | **遅い劣化は、範囲を超えた先で起きる。**そこで黙れば永久に見えない |
> | **B 採り直し** | 一定の累積ストレスごとに**指紋を採り直す** | **基準が劣化を追いかける。**ゆっくりした劣化が基準に吸われて見えなくなる |
>
> **どちらも「見えなくなる」危険を持つ。**危険の出方が違うだけである。**どちらがましかを測る。**

**追加取得ゼロ。** NASA MOSFET 6 素子、7 run 全部。**区間は [docs/297](297_bank_protocol.md) 改訂どおり。**

## 実装（実行前に固定）

**A 境界**: 指紋は run 1 前半（[docs/309](309_slow_refusal_results.md) の F0' と同じ、最も誤報の少なかった取り方）。
較正区間の累積ストレス範囲を有効範囲とし、**その上限を超えた標本では宣言しない。**
**累積ストレスは [docs/312](312_stress_axis_results.md) の「累積熱負荷」**（パッケージ温度の上昇分の積算。C1 で最良が 3/6 と最多）。

**B 採り直し**: 累積ストレスが **K** 進むごとに、**直前の K ぶんの標本**で指紋を採り直す。
**未来の標本は使わない。**K は較正区間の累積ストレス幅の **0.5 / 1 / 2 倍**の 3 通り。

**両案とも、閾値・バンク {100,200,500}・誤報 1 件/時 ÷ 3・clamp の規則は不変。**

## 判定基準（実行前に固定）

| # | 基準 | 閾値 |
|---|---|---|
| **V1** | **A** で、run 4 の誤報が設計値の 3 倍以内 かつ run 5〜7 で発火する素子 | 6 中 5 |
| **V2** | **A** の有効範囲が run 5 の開始より前に尽きる素子数 | 記述。**尽きれば「黙って見逃す」** |
| **V3** | **B**（K の 3 通りそれぞれ）で、run 4 の誤報 3 倍以内 かつ run 5〜7 で発火する素子 | 6 中 5 |
| **V4** | A と B のどちらが V1/V3 で多いか | **多い方を仕様に採る。両方 5 未満なら、どちらも採らない** |

**両方 5 未満なら、この二択では解けないと書き、次の候補を 1 つ挙げる。**

## 答えないこと
- ヒーター動作の 1 試験機・6 素子。**率ではなく存在証明**
- 累積熱負荷はパッケージ温度から作った量で、名前どおりの物理量ではない（[docs/312](312_stress_axis_results.md)）
- **B が通っても、実車の採り直し工程（いつ、どの動作点で）は決まらない**
