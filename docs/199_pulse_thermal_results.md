[docs/198](198_pulse_thermal_protocol.md) の事前登録を無修正で実行した。

|---|---|---|
| **T1 単調増加**(ρ ≥ 0.8) | 6中4以上 | **0/6 — 不成立** |
| **T2 run 4での先行**(基準ばらつきの3倍超) | 6中4以上 | **0/6 — 不成立** |

## 素子近傍の熱経路は劣化していない

| 個体 | ρ | 最終/基準 |
|---|---|---|
| Test_8 | −0.750 | 0.976 |
| Test_9 | −0.571 | 0.909 |
| Test_10 | +0.107 | 0.916 |
| Test_11 | +0.393 | 0.996 |
| Test_12 | −0.429 | 0.960 |
| Test_14 | −0.786 | 0.945 |

**増えるどころか、わずかに下がっている。**熱時定数は全個体・全runで **69〜72 µs** とほぼ一定だった。

### これが [docs/197](197_what_limits_the_declaration.md) をどう動かすか

docs/197 は「正規化後R_onの上昇が**全部**熱由来だったら接合部は30〜76°C高い」という上限を出した。

> **その極端は、データに支持されない。**素子近傍(時定数約70 µs)の熱経路は平坦である。
> つまり **k ≒ 1 の側に寄っており、仮定Bの状況は docs/197 が恐れたほど悪くない。**

**ただし閉じてはいない。** 400 µsのパルスが見るのはダイ本体までである。
ダイアタッチの熱時定数はこれより長い側にあり、**この窓では触れていない可能性がある**
([docs/198](198_pulse_thermal_protocol.md) で先に認めた限界)。

**「ダイ本体の熱経路は劣化していない」まで。「ダイアタッチも無事」とは言わない。**

## 探索で見つかった、こちらの方が大きい問題

事前登録の判定とは別に、`transient` と `pwmTempControllerState` を読んだことで
**docs/165以降がずっと使ってきた観測量の正体が変わった。**

### 1. 試験機の温度設定は意図的に下げられていた

設定は run毎に 250→240→230→220→210→210→210 と10°Cずつ下げられている。
**「素子の温度が下がっていく」と扱っていたものは、実験計画による操作点の掃引である。**

> **これは [docs/197](197_what_limits_the_declaration.md) (A) の訂正を要求する。**
> 「動作点は指紋の幅の1.7〜3.0倍を動く」は**この試験機の手順の性質**であって、
> 実車のEPSの動作点分布の性質ではない。**要求の向き(1点では足りない)は残るが、3.0倍という数値は移植できない。**

### 2. `Vds/Id` はオン抵抗ではなかった

| | |
|---|---|
| 供給電圧 | 5.61 V |
| 外部直列抵抗 | 約0.22〜0.28 Ω |
| **素子が負担する電圧** | **約4.9 V** |
| 電流 | 約2.6 A |
| 素子の消費 | **約13 W** |

**素子は供給のほぼ全部を負担している。これは能動領域であって、スイッチではない。**
`Vds/Id = 1.88 Ω` は導通抵抗ではなく、能動領域での動作点抵抗である。
過渡波形でも Vds は 2〜3 V(25〜30 W)であり、**この試験機は一度もスイッチとして動かしていない。**

run間で実際に動いているのは**電圧ではなく電流**である。Vdsはほぼ一定(4.87→4.99 V)で、
**電流が 2.6→2.8→2.1 A と動く。**同じゲート駆動で電流が落ちるのは、
導通抵抗ではなく**しきい値電圧の上昇または相互コンダクタンスの低下**である。

## 何が生き残り、何が生き残らないか

**先に生き残らない方を書く。**

| 主張 | 判定 |
|---|---|
| `C = √(R_base/R_on)` が MOSFETデータで**実現できるトルク比を計算している** | **成り立たない。**式は導通損(I²R、スイッチ動作)から導いたが、データは能動領域であり導通抵抗を測っていない |
| MOSFET側の `C = 0.832〜0.930` は**能力比である** | **格下げ。劣化指標であって、能力比ではない** |
| [docs/197](197_what_limits_the_declaration.md) の「指紋幅の1.7〜3.0倍」 | **試験機の手順の性質。**実車へ移植しない |

生き残るもの:

| 主張 | 根拠 |
|---|---|
| **個体基準＋動作点正規化で、劣化はノイズの20〜300倍の余裕で見える** | [docs/167](167_precursor_results_v2.md)。**観測量が何であるかに依存しない経験的結果** |
| **母集団基準は個体ばらつきを異常と誤読する** | [docs/193](193_str_capability_rule_results.md) Test_10、[docs/195](195_capability_rule_second_mechanism_results.md) セッション段差 |
| **巻線側の `H = mean\|I\|/max\|I\|`** | [docs/195](195_capability_rule_second_mechanism_results.md)。**これは名乗っているものを実際に測っている**(相電流の不平衡)。影響なし |
| **規則の形**(拘束下の出力 ÷ 自身の基準) | 形は残る。**MOSFETデータでの物理的裏付けだけが外れた** |
| **問2: 故障が立たないまま能力が縮む窓** | **巻線側で残る**(severity 21.69% で C=0.952)。MOSFET側は指標の低下であって能力比ではない |

## データ品質: Test_10 の過渡データは他と比較できない

Test_10 の過渡波形のドレイン電流は **0.31 A** で、他5個体の **6.4〜8.2 A** の25分の1である。
電力が小さすぎるため V/W が桁で違う(0.42〜0.65 対 0.024〜0.032)。
**この個体の過渡チャネルは他と同じ条件で取られていない。**判定には影響しない(5個体でも全部落ちている)。
