## 何が分かったか

| | 前 | 今 |
|---|---|---|
| 劣化の形 | 直線（観測範囲でデータが支持） | **直線 + 変量ドリフト。**μ の散らばりが 2.1 倍と測れ、故障時刻の分布（逆ガウス）が出る |
| 個体群を作る道 | 指数の母数（同定できず） | **μ の対数正規 (m = −1.65, s = 0.25) と σ_B = 0.555 から作れる** |
| 単独チャネルで検知できない理由 | 「健全期も傾向を持つ」（docs/348、定性的） | **(σ_B/μ)² = 4〜11 時間 に対して故障が 5〜11 時間。**壊れるころに分かれる |
| 同じ種類のチャネルの差分が要る理由 | 誤検知が 4〜6 分の 1 になる（実測） | 差分は σ_B を共有分だけ減らす。共有率 92.6% なら `(σ_B/μ)²` は 1/13 に縮む（docs/352 の機構を式にしたもの、**未検証**） |

## 残る限界

- σ_B は健全期を Wiener 過程と見て推定したが、実素子の健全期は傾向（α = 1.32）。σ_B は過大に出ている可能性がある
- 組 A の N は 6、故障を観測できたのは 4。逆ガウスの検証は 4 点
- 組 B は量も方式も違い、母集団としてまとまらない
- 最後の行（差分で 1/13）は式の帰結で、測っていない
