# 270. 事前登録 — 遅い時間尺度を足せば、本物の劣化で鳴るか

> [docs/269](269_real_degradation_results.md) は、記録器が本物の劣化で**6素子中0素子**しか鳴らないことを示した。
> **原因は構造の欠落である。**[docs/225](225_recorder_specification.md) は5秒窓で武装し、
> **発火したら**窓を伸ばすと定めている。**発火しなければ伸びない。**
> したがって、**分の尺度の平均でしか見えない劣化には原理的に到達できない。**

**追加取得ゼロ。** NASA MOSFET と KAIST PMSM(いずれも取得済み)。

---

## 何を足すのか

**速い側は変えない。**5秒窓の平均と最大は [docs/244](244_intermittent_injection_results.md) のまま。

**遅い側を、独立に走らせる。**

```
遅い側 = 直近 N 標本の連続平均を、同じ個体基準に対して評価する
        速い側の発火を待たない。常に走る
```

**N は 100, 200, 500, 1000, 2000, 5000 標本。**
**この格子は私が決めた仮定である**([TROUBLES.md](../TROUBLES.md) T2)。
[docs/167](167_precursor_results_v2.md) が使った平均長(1 run ≒ 5,200標本)を含む範囲に取った。

**閾値は速い側と同じ手順で決める。**誤報 **1件/時**に揃え、**健全区間の分位点から求める。**
**[docs/269](269_real_degradation_results.md) の閾値10を持ち込まない。**遅い側は標本数が違うため、
**同じ運用条件から改めて求めるのが正しい。閾値の後付け調整ではない。**

---

## 判定基準(実行前に固定)

| # | 基準 | 閾値 |
|---|---|---|
| **D1** | 本物の劣化で、故障前に発火する素子が **6中5以上**。どのNで達成できるか | 6中5 |
| **D2** | そのNでの健全区間の誤報が、**1件/時の設計値の3倍以内** | 3倍 |
| **D3** | 同じNで、**モータ3機体のうち2機体以上**が実故障重症度で発火する | 3中2 |

**D1が落ちれば、遅い側を足しても本物の劣化では鳴らない。**
そのとき **[docs/225](225_recorder_specification.md) の記録器は、注入事象と断続故障には使えるが、
遅い劣化には使えない**と書く。**仕様の適用範囲を狭める。**

**D3が落ちれば、遅い側も機体をまたがない**([docs/203](203_cross_machine_replication_results.md) と同じ)。
そのとき **1機体でしか成立しない**と書く。

---

## この検定が答えないこと(先に書く)

- **素子は能動領域のヒーターである**([docs/199](199_pulse_thermal_results.md))。EPSのスイッチ動作ではない
- **加速試験の故障であり、市場の故障ではない**
- **断続故障ではない。**R12は依然として未達
- **N の格子は仮定である。**実測値を必ず併記する
- **遅い側が鳴っても「予測できる」ではない。**[docs/225](225_recorder_specification.md) の
  「壊れる前に教えます」を主張しないは維持する。**鳴った時点で既に劣化は進んでいる**
