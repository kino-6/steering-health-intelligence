## 何を間違えたか

[docs/231](231_igbt_reading_and_protocol.md) はこう書いた。

**Readmeの警告は、コレクタ電流と定常測定に向けられている。**
**過渡波形(オシロスコープ側)には向けられていない。**私は警告の範囲を勝手に広げ、フォルダごと捨てた。

そしてもう一つ。「多くの過渡測定が欠落」という記述を根拠に**良質なスイッチ動作データは1個体だけ**と書いた。

## 事前登録

**観測量は電圧と時間だけに限る。**電流とスケールの問題を避けるためである。

各過渡波形について、ゲート信号の立ち上がり(振幅の50%交差)を起点に:

| 記号 | 観測量 | なぜこれか |
|---|---|---|
| **A. ターンON遅れ** | ゲート信号50%交差から、コレクタ-エミッタ電圧がスイングの50%まで落ちるまでの時間 | **しきい値電圧が上がると遅れる。**配布論文が V_gth を前駆と名指ししている。**時間測定なので電圧スケールの誤差に影響されない** |
| **B. 導通時のV_ce** | ON区間(エッジから十分離れた区間)の中央値 | 導通損に対応。電圧のみで求まる |
| **C. ゲートのミラー段** | ターンON中の gateEmitterVoltage の平坦部の水準 | しきい値と相互コンダクタンスに依存 |

**個体基準**: 各個体の**最初の20%**の過渡波形から、各観測量の中央値と散らばり(3×1.4826×MAD)を採る。
時間順は `date` フィールドで決め、main → b の順に連結する。

## 事前に認めておくこと

- **温度が測定できない。**保持されていた証拠は制御器の設定値のみで、実測が無い。
  **温度ドリフトが観測量に混入していても分離できない**
- **コレクタ電流を使わない。**Readmeが600 mAのドリフトを明記している
- **4個体、1日の試験(2008-12-24)。**ロット差・日差は評価できない
- **これらの個体が故障まで至ったかは未確認。**「check」ファイルの意味を Readme は説明していない
- **これはIGBTであってEPSのMOSFETではない。**動作モードは近いが素子が違う
- **[docs/232](232_pristine_unit_spread_results.md) の40個体とは別の実験である。**繋げて論じない
