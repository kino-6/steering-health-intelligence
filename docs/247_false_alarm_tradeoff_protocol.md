# 247. 誤検出を実用水準まで下げたら何が要るか — 事前登録

**追加取得ゼロ。**

## なぜ

[docs/244](244_intermittent_injection_results.md) は誤検出率を **1.0%/5秒窓** に固定して検出限界を測り、
**それが約7回/時間に相当し実用水準ではない**と自分で書いた。

**仕様([docs/225](225_recorder_specification.md))は、この1点しか持っていない。**
**実用の動作点で何が要るかを測っていない。**

> **7回/時間で鳴る記録器は配備できない。**
> **1回/時間、0.1回/時間まで下げたとき、検出限界がどこまで上がるかを測る。**

## 誤検出率の水準(実行前に固定)

10 Hz・5秒窓なので **720窓/走行時間**。

| 水準 | 走行時間あたり | 窓あたり | 窓の数(実車34,982窓) |
|---|---|---|---|
| **L0** | 7.2回 | 1.0e-2 | 350窓 |
| **L1** | **1回** | 1.39e-3 | 49窓 |
| **L2** | **0.1回**(約10時間に1回) | 1.39e-4 | **5窓** |
| L3 | 0.01回 | 1.39e-5 | **0.5窓 — 標本の外** |

**L3は標本の外である。**先に認めておき、**推定しない。**
L2も5窓しかなく、**分位点の推定として弱い。**そう書く。

## 手順([docs/243](243_intermittent_injection_protocol.md) と同一)

- 土台: 実車ログ(車両レベル)と、NASA健全区間(部品内部)
- 注入: 矩形、振幅は床の {1,2,3,5,10,20,50} 倍、継続 {1,2,5,10,20} 標本
- 検出器: **平均型**と**事象型**の両方([docs/244](244_intermittent_injection_results.md) で両方要ると分かった)
- **各水準で両検出器の閾値を合わせ、検出率90%に達する最小振幅を報告する**

## 判定基準(いま固定する)

| # | 報告するもの | 規則 |
|---|---|---|
| **P1** | 水準×継続ごとの最小振幅(床の倍数)、車両レベル | **全組を出す** |
| **P2** | 同、部品内部(NASA 6デバイスの中央値) | **同上。窓数が足りない水準は「標本の外」と書く** |
| **P3** | L0からL2へ下げたときに検出限界が何倍になるか | **これが実用化の代償である** |

- **標本の外の水準を外挿しない。**「測れない」と書く
- **v2は作らない**

## 事前に認めておくこと

- **1走行時間あたりという換算は、制御が有効な時間についてである。**実走行時間ではない
- **L2は5窓での分位点であり、推定として弱い**
- **部品内部は窓数が少ない**(デバイスあたり数百〜数千)。**L1・L2は測れない可能性が高い**
- **矩形という波形は仮定である**
- **これは検出器の性能であって現象の実在ではない**

## Rule Check

- **L3が標本の外であることを、実行前に表に書いた**
- **L2が5窓で弱いこと**を先に認めた
- 「実用化の代償」を報告項目として先に置いた。良い方向だけ測らない
