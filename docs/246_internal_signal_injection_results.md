# 246. 部品内部では床の2〜3倍で足りる — 前駆は20〜300倍。余裕がある

[docs/245](245_internal_signal_injection_protocol.md) の事前登録を実行した。**追加取得ゼロ。**

> **部品内部の信号では、床の 2〜3倍 で検出できる。**
> **車両レベルは 10倍 だった**([docs/244](244_intermittent_injection_results.md))。**3〜5倍 鋭い。**
> **そして [docs/167](167_precursor_results_v2.md) が測った前駆は床の 20〜300倍 である。**

## Test_10 だけが10倍 — この個体は3回目の異常である

| 検証 | Test_10 の挙動 |
|---|---|
| [docs/193](193_str_capability_rule_results.md) | **母集団閾値が run 1(健全)で誤警報した唯一の個体** |
| [docs/234](234_igbt_switching_results.md) 相当の確認 | 過渡電流が他の25分の1(別データセットだが同種の外れ) |
| **本文書** | **検出限界が他の3〜5倍悪い** |

**この個体は一貫して外れている。**外れ値として扱うが、**除外しない。**6個体中1個体は現実の割合である。

## N2 — 前駆と検出限界を同じ単位で並べる

| | 床の倍数 |
|---|---|
| **検出に必要な大きさ**(部品内部、本文書) | **2〜10倍** |
| **実際に観測された前駆の大きさ**([docs/167](167_precursor_results_v2.md)、6/6) | **20〜300倍** |

> **前駆は検出限界を 2倍〜150倍 上回る。**

**車両レベルとの対比:**

| 位置 | 検出に必要な大きさ |
|---|---|
| 車両レベル(横加速度残差) | **床の10倍**([docs/244](244_intermittent_injection_results.md)) |
| **部品内部**(本文書、6中5) | **床の2〜3倍** |

**部品の中で見ることの利得が、初めて数値になった。**
「見えるものが増える」だけでなく、**同じ事象を捕まえるのに必要な信号が3〜5分の1で済む。**

## これが何を意味しないか

**比べたのは大きさだけである。**

- [docs/167](167_precursor_results_v2.md) の前駆は**恒久劣化の逸脱**であり、**断続事象ではない**
  ([docs/245](245_internal_signal_injection_protocol.md) で先に認めた)
- **「前駆が検出限界を上回る」は「断続故障が捕まる」を意味しない**
- 注入した事象は本物ではない。**測ったのは検出器であって現象ではない**

## KAISTの数値は信用しない

KAISTの健全記録は**小窓が200個しかなく、窓は4個**である。
**4個の窓で1%分位点を取るのは、最大値を取るのと同じである。**閾値が意味を持たない。

**信用できるのはNASAの6デバイスである**(窓が数百〜数千)。KAISTは参考にとどめる。

## 限界(緩めない)

- **窓も継続も「標本」であって秒ではない。**NASAとKAISTでサンプリングが違う。
  **[docs/244](244_intermittent_injection_results.md) の秒表記と直接比べない**
- **KAISTは窓4個。**上記のとおり信用しない
- **矩形という波形は仮定である**
- **[docs/199](199_pulse_thermal_results.md) のとおり、NASAの観測量はオン抵抗ではなく能動領域の動作点抵抗。**
  床の推定には使えるが物理的な意味づけはしない
- **どちらもEPS実機ではない**
- **健全区間のみ。**劣化区間での検出は測っていない

## Rule Check

- **Test_10 が10倍であることを、6中5の「2〜3倍」と同じ表に置いた。**都合の良い方だけ書かない
- **KAISTの数値を自分で「信用しない」と書いた**(窓4個)
- **「大きさの比較であって断続故障が捕まる証明ではない」**を独立の節にした
- Test_10が3回目の異常であることを、過去の文書と突き合わせて書いた
