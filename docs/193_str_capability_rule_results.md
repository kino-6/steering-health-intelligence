## P1が落ちた理由と、それが意味すること

個体基準(M2)は run 4〜5 で宣言した。母集団閾値＋温度補償(M1)は run 5〜6 で鳴った。
**差は0〜1 run しかない。**

| デバイス | M1が鳴る | M2が宣言 | 差 |
|---|---|---|---|
| Test_8 | run 5 | run 4 | +1 |
| Test_9 | run 6 | run 5 | +1 |
| Test_10 | **run 1** | run 4 | **−3** |
| Test_11 | run 6 | run 5 | +1 |
| Test_12 | run 5 | run 5 | 0 |
| Test_14 | run 5 | run 5 | 0 |

理由は明快である。**この試験の劣化は大きく急である**(終端で能力7〜17%喪失)。
そこまで大きく動けば、個体基準を持たない監視でも捕まる。
**個体基準が買っているのは「警報の早さ」ではなかった。**

> **これは [docs/188](188_the_line.md) と矛盾しない。むしろ独立に裏付けた。**
> docs/188 は売るものから ×「壊れる前に教えます」を既に外していた
> ([docs/175](175_close_contact_question.md) 接点系に先行時間が無いため)。
> **P1の不成立は、その判断が別の機構でも正しかったことを示している。**

### 付記(事後の観察。P1の採点は動かさない)

Test_10 で M1 が **run 1** に鳴っている。劣化が始まる前の健全な個体に対する**誤警報**である。
この個体は元々 R_on が高く、母集団閾値がそれを異常と読んだ。
事前登録の P1 はこれを「M1の勝ち」と数えるが、**早く鳴ったのではなく間違って鳴っている。**
事後に気づいたので基準は動かさない。**母集団閾値は個体ばらつきを異常と誤認する**という性質の記録として残す。

## 個体基準が実際に買っているもの — 値の解像度

| | M1(母集団閾値) | **M2(個体基準)** |
|---|---|---|
| 出せる出力 | **鳴った / 鳴らない**の2値 | **連続量 C** |
| 宣言できる分解能 | 無い(閾値の位置のみ) | **0.081% 〜 0.641%** |
| 個体ばらつきの扱い | 異常と誤認する(Test_10) | 各個体の基準に吸収される |

**SOTIFが要求するのは警報ではなく値である。**
AUTOSAR の `STR capability` は「指定時間内に実現できる値」であり、フラグではない([docs/183](183_autosar_capability_channel.md))。
M1 はこの欄を埋められない。**埋められるのは M2 だけである。**

P2 が6/6で成立したのは、この解像度が実際に効いているという意味である——
宣言時点の低下量は粒度の **3.5倍 〜 23.9倍** あった。

## 問1・問2への回答

### 問2. DTC未到達の通知はSOTIFか — 窓は実在した

各デバイスの終端(run 7)における capability:

| Test_8 | Test_9 | Test_10 | Test_11 | Test_12 | Test_14 |
|---|---|---|---|---|---|
| 0.832 | 0.895 | 0.890 | 0.921 | 0.930 | 0.876 |

**動作したまま、実現できる能力が自身の基準比で 7.0% 〜 16.8% 失われている。**
そしてこの縮小は run 4〜5 の時点で既に粒度の3.5〜23.9倍あり、**測定可能だった。**

> **故障が立たないまま能力が縮む状態は実在し、連続量として測定でき、宣言できる。**
> これが [docs/191](191_degradation_demand_and_sotif.md) が SOTIF の領域と特定した場所である。
> **その領域は空ではないことが、実部品・実劣化で確認された。**

### 問1. 入庫時に劣化状態が分かることに需要があるか — 第3の答えは作れる

[docs/190](190_assembly_replacement_meaning.md) が示した既存の運用は2値である。

| 今の答え | 処置 |
|---|---|
| コードあり | Assy交換 |
| コードなし | ソフト更新して返す |

本規則は、この「コードなし」に対して **C = 0.93 / 0.89 / 0.83** という**第3の答えを返す。**
**134万台の決定点に差し込める形の値が、実データで生成できた。**

**ただし証明したのはここまでである。** 「その値に金を払うか」は依然として未証明であり、
本規則は支払意思について何も示していない。

## 限界(事前登録で認めたものを再掲、緩めない)

- **run は粗い。**窓の存在は言えるが、**長さを時間では言えない**
- **デバイスは6個。**母集団閾値は区間を持たない点推定である
- **これはMOSFETであってEPSではない。**同型機構(パワー段の導通抵抗上昇)が根拠であり、EPS実機での確認ではない
- **仮定Bは楽観側。**ダイアタッチ劣化を含めた実測は [docs/189](189_five_limits_tested.md) ② で失敗しており、埋まっていない
