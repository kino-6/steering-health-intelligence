# 351. 事前登録 — 同種チャネルの差分は、本物の劣化にも効くのか

## 何が未検証か

いまの答えは「**同種チャネルがあれば検知できる。EPS はそちら側**」である。根拠は 2 つに分かれている。

| 根拠 | データ | 故障の種類 |
|---|---|---|
| 検知 8/8、遅い側の誤検知 0（[docs/286](286_common_mode_results.md)） | 実インバータ | **人為的に導入した開放・短絡・過温度** |
| 2〜5/6（[docs/299](299_bank_results.md)・[docs/315](315_boundary_vs_refresh_results.md)） | NASA MOSFET | **本物の劣化。ただし 1 素子で同種チャネルが無い** |

> **「同種チャネルがある状態で、本物の劣化を検知できるか」は、一度も測っていない。**
> 手元のデータでは測れない。NASA は 1 試験 1 素子である。

## 何が効き目を決めるのか

同種チャネルの差分が効くのは、**健全期の傾向が同種チャネルで共有されている**ときだけである。
共有されていなければ、差分は雑音を 2 倍にするだけになる。

> **決めるのは「健全期の傾向のうち、同種チャネルで共有される割合」である。**
> **これは実インバータで測れる。**半ブリッジ温度 3 つが同種チャネルである。

## 手順

### 第 1 部 実測: 共有される割合

1. 実インバータの正常運転で、半ブリッジ温度 3 つの残差を出す（動作点の直線を引いた後）
2. 移動平均で傾向を取り出す（[docs/348](348_drift_shape_results.md) と同じ 500 標本）
3. **3 本の傾向の共通成分の割合を出す。**
   共通成分は 3 本の中央値とし、各チャネルの分散に占める割合で表す
4. 相電流 2 本でも同じことをする

### 第 2 部 仮想: 共有の割合を振って、差分が効くかを見る

1. 同種チャネル 3 本を持つモジュールを作る。
   各チャネルの傾向 = **共通の傾向 × s + 独立な傾向 × (1−s)**
2. **s を 0.0 / 0.25 / 0.5 / 0.75 / 1.0 で振る**
3. 1 本だけを劣化させる（速度は実素子の実測 D = 9.6、[docs/344](344_virtual_module_detection_results.md)）
4. 差分あり・差分なしの両方で、検知率と健全群の誤検知を出す
5. **第 1 部で測った s を、この曲線の上に置く**

## 事前に決める判定

| | 基準 |
|---|---|
| **P1** | 実インバータの半ブリッジ温度で、共有される割合 s の実測値を出す |
| **P2** | 仮想で、差分ありが誤検知 1 件/時 以下・検知 90% 以上を満たす**最小の s** |
| **P3** | **実測の s が P2 の最小値を超えているか。**超えていれば「本物の劣化にも効く見込みがある」、下回れば「効かない」 |

**P3 が「効かない」なら、いまの答え（EPS は同種チャネルがある側だから検知できる）を弱める。**

## この事前登録が外れる条件

- **実インバータの正常運転は 28 分・10 Hz である。**傾向を測るには短い。
  **s の推定が不安定なら、その旨を書いて範囲で出す**
- **実インバータの半ブリッジ温度は、本物の劣化を経ていない。**共有の割合が劣化中も同じとは限らない
- 仮想の傾向は [docs/348](348_drift_shape_results.md) の α = 1.32 に合わせるが、**形が同じでも中身が同じとは限らない**
- s の刻み・個体数・劣化速度は私が置いた（[TROUBLES.md](../TROUBLES.md) T2・T35）
- **母集団基準ではなく、同じ個体の中の同種チャネルだけを使う**（[TROUBLES.md](../TROUBLES.md) T15）
