# 161. PMSM故障モデル検証プロトコル(実行前に固定)

**このドキュメントは、DS011の中身を見る前にコミットする。** [docs/140](140_recall_detection_protocol.md) / [docs/142](142_recall_detection_protocol_v2.md) と同じ作法である。

## T4の判定: 何が検証でき、何が循環のまま残るか

理想回路モデルの循環問題([docs/158](158_sotif_eooc_monitor_demo.md))——自作モデルの波形で自作検出器を検証すると循環する——は、**一部だけ断てる**。

| 層 | 内容 | DS011で外部検証できるか |
|---|---|---|
| **電気層** | 三相PMSMの巻線間短絡 → 相電流のsignature | **できる**。DS011が同型モータ・同出力帯で、severityを段階的に振った実測を持つ |
| 電磁-機械層 | 巻線故障 → トルクリップル → アシストトルクの異常 | **できない**。DS011にトルク計測がない(振動はあるが機構が違う) |
| 車両層 | アシストトルク異常 → 操舵応答(遅れ・ゲイン・バイアス) | **できない**。DS011に操舵系も車両もない |
| **標的故障族** | コネクタfretting / 電源dip起因の断続的アシスト制限 | **できない**。DS011は巻線故障のみで、標的故障族を含まない |

**したがって主張できるのは電気層まで**である。「モデルが実車のアシスト喪失を再現する」とは言えない。言えるのは「**このモデルの巻線故障モードは、同型モータの実測signatureと整合する(または整合しない)**」までである。

それでも価値がある。電気層が実測に接続されれば、モデルの残りの層は「根拠のない仮定」から「**1点で校正された外挿**」に変わる。今は根拠が1つもない。

## 事前登録: 比較の設計

### 対象

- モデル: 三相PMSM、巻線間短絡(inter-turn short)。短絡巻数比 μ を 0 から振る
- 実測: DS011 の 1.0 kW 機(EPSアシストモータと同出力帯)、正常 + 巻線間短絡、severity 8段階
- 比較する物理量: **相電流のみ**(振動は使わない。機構が違うため)

### 主指標(実行前に固定、2つ)

1. **相電流RMSの不平衡率** `U = (max_p RMS_p - min_p RMS_p) / mean_p RMS_p`
2. **逆相電流比** `I2/I1`(対称座標法。巻線間短絡の古典的指標)

### 判定基準(実行前に固定)

**整合と判定する条件(3つすべて)**:

1. **単調性**: モデル・実測とも、severity増加に対し指標が単調増加(Spearman順位相関 ρ ≥ 0.8)
2. **桁の一致**: severity範囲全体で、実測値とモデル値の比が **0.1 〜 10 の範囲**に収まる
3. **感度の一致**: 指標が健全時の3倍に達するseverityが、モデルと実測で **2倍以内**にある

**不整合と判定した場合の扱い**: モデルを実測に合わせて調整**しない**。不整合をそのまま記録し、
「このモデルは電気層でも実測に接続できない」と結論する。パラメータを合うまで叩くのは、
[docs/143](143_recall_detection_results_v2.md) の教訓(テストeraを叩かない)と同じ理由で禁止する。

**調整してよいもの(1回だけ、実測を見る前に決める)**: モータ定数(R, L, Ke, 極対数)は
DS011の公開仕様に合わせる。これは校正ではなく、対象を同じにする作業である。

### やらないこと

- モデルの層を増やして「合った」と言うこと(自由度を増やせば必ず合う)
- 振動データの併用(機構依存で、EPSへの転用根拠がない)
- severityごとに別パラメータを使うこと
- 実測を見てから指標を差し替えること

## 成立した場合に何が言えるようになるか

> EPSアシストモータおよびSbW road wheel actuatorの巻線劣化について、
> **物理モデルが実測されたseverity-signature関係を再現する範囲で**、
> 段階的な劣化が相電流にどう現れるかを、部品内部の観測量として宣言できる。

これは [docs/153](153_sotif_eooc_assumption_sheet.md) のEooC仮定シートに、
**合成注入([docs/144](144_synthetic_sensitivity_results.md))ではなく実測に接続された行**を1つ加えることを意味する。

## 不成立の場合に何が言えるようになるか

> 三相PMSMの標準的な故障モデルは、同型・同出力帯の実測signatureを再現しない。
> したがって理想回路モデルによる劣化signature生成は、本研究では根拠として使えない。

これも成果である。[docs/158](158_sotif_eooc_monitor_demo.md) が「循環する」と書いた懸念に、
実測での答えが付く。

## Rule Check

- 実測を見る前に指標・判定基準・禁止事項を固定し、コミットしてから実行する
- 不整合時にモデルを叩かないことを明記した
- 主張できる層(電気層のみ)と、できない層(機械・車両・標的故障族)を先に分けた
- 故障予測([docs/143](143_recall_detection_results_v2.md))へは戻らない。severityは実験で振られた既知量であり、予測対象ではない
