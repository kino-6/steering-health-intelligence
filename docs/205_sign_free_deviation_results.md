# 205. 機体をまたぐ逸脱指標は1つだけあった — ただし電流ではない

[docs/204](204_sign_free_deviation_protocol.md) の事前登録を実行した。

> **4特徴量のうち1つだけが、3機体5セルすべてで単調かつ検出可能だった。
> それは「電気周波数2倍の振動振幅」であり、EPSのECUが持っていないセンサを要する。
> 相電流ベースの2つは両方とも落ちた。**

実行: `python3 scripts/sign_free_deviation.py` / 数表: [data/sign_free_deviation.tsv](../data/sign_free_deviation.tsv)

## 先に: 判定を変えた修正を1つ入れた

**初回実行では V1 も落ちていた(単調 4/5)。浮動小数点の表現誤差だった。**

4点のSpearman相関は厳密な有理数しか取らない: 1、**4/5**、3/5、2/5。
隣接1つの逆転は **Σd² = 2 → ρ = 1 − 12/60 = 4/5 = 0.8 ちょうど**である。
事前登録の基準は「ρ ≥ 0.8」なのでこれは**通る**。しかし計算値は `0.7999999999999999` で返り、
素の `>= 0.8` が弾いていた。誤差は 1.1e-16 である。

**この修正で V1 は 4/5 → 5/5(不成立 → 成立)、C2 は 2/5 → 4/5 に変わった。**

- 修正したのは**表現誤差であって閾値ではない。**基準 0.8 は動かしていない
- **落ちるのを見た後に気づいた。**その事実を書く
- 厳密な有理数計算で 4/5 であることを確認したうえで直した

## 結果

| 特徴量 | 単調(ρ≥0.8) | Dmax>3 | 判定 | 盲検性 |
|---|---|---|---|---|
| C1 相電流の平衡 | 3/5 | 2/5 | 不成立 | 既に見ていた |
| C2 逆相/正相比 | **4/5** | **4/5** | **不成立(惜しい)** | **盲検** |
| **V1 振動 2f0** | **5/5** | **5/5** | **成立** | 既に見ていた |
| V2 振動 広帯域RMS | 3/5 | 5/5 | 不成立 | 盲検 |

D は「自分の健全記録の測定ノイズの何倍離れたか」である。

| 機体・故障種 | C1 | C2 | **V1** | V2 |
|---|---|---|---|---|
| 1.0 kW 層間 | ρ+1.00 D=33.3 | ρ+1.00 D=25.7 | **ρ+0.80 D=8.9** | ρ+0.80 D=26.6 |
| 1.0 kW コイル間 | ρ+0.40 D=7.1 | ρ+0.40 D=5.2 | **ρ+1.00 D=7.2** | ρ+0.40 D=48.1 |
| 1.5 kW 層間 | ρ+1.00 D=**2.5** | ρ+0.80 D=4.1 | **ρ+1.00 D=17.7** | ρ+0.80 D=18.6 |
| 1.5 kW コイル間 | ρ+1.00 D=**0.8** | ρ+1.00 D=**1.5** | **ρ+1.00 D=15.6** | ρ+0.40 D=8.1 |
| 3.0 kW 層間 | ρ+0.40 D=2.8 | ρ+0.80 D=3.7 | **ρ+1.00 D=220.4** | ρ+0.80 D=25.7 |

**C1 は1.5 kW で検出限界に届かない**(D = 2.5 / 0.8)。**符号を捨てても、電流の平衡指標は機体をまたがない。**

## 通ったが、素直に喜べない3点

### 1. V1 は既に見ていた特徴量である

[docs/201](201_motor_second_fault_and_vibration_results.md) と [docs/203](203_cross_machine_replication_results.md) で
全機体の V1 を表示している。**指標 D の定義は事前に固定したが、入力の値は見ていた。**
**盲検の確認より弱く、事後の探索より強い**という位置である。

**盲検だったのは C2 と V2 で、どちらも落ちた。**C2 は 4/5 と惜しいが、事前登録は 5/5 である。

### 2. 「検出できる最小severity」は機体をまたがない

D が初めて3を超える severity:

| 機体・故障種 | 最小検出severity | それ未満での D |
|---|---|---|
| 1.0 kW 層間 | **3.35%** | — |
| 1.5 kW 層間 | **4.57%** | 2.34% で D=0.9 |
| 1.0 kW コイル間 | **7.56%** | 2.00% で D=2.5 |
| 1.5 kW コイル間 | **7.02%** | — |
| **3.0 kW 層間** | **17.86%** | **5.16% で D=0.7、2.65% で D=0.1** |

**3.35% 〜 17.86%、5倍以上ひらく。**3.0 kW では 5.16% の層間短絡がほぼ見えず(D=0.7)、
17.86% で突然 220 倍に跳ぶ。**単調ではあるが、閾値的な応答であって段階的ではない。**

> **「検出できる」は機体をまたぐ。「どこから検出できる」はまたがない。**

### 3. 通った指標は、ECUが持っていないセンサを要する

EPSのECUは制御のために**相電流を必ず測る**。**加速度計は積んでいない。**

**その相電流ベースの2つ(C1・C2)が、両方とも落ちた。**
通ったのは振動である。**センサ追加ゼロでは成立しない。**

[docs/201](201_motor_second_fault_and_vibration_results.md) で同じ向きの結論を出し、
[docs/203](203_cross_machine_replication_results.md) で取り下げた。
**今回は3機体・事前登録・符号なしで、同じ向きに戻った。**根拠の強さが違う。

## 主張の現在地

| 主張 | 状態 |
|---|---|
| capability **値**を宣言する | **降ろした**([docs/203](203_cross_machine_replication_results.md))。符号が機体で揃わない |
| 自分の基準からの**逸脱を検知**する | **1指標で成立**。3機体5セル、ただし振動 |
| 相電流だけで成立する | **不成立。**C1・C2とも落ちた |
| 検出の**早さ**を宣言する | **不成立。**最小検出severityが5倍ひらく |
| SOTIF EooC の「値」欄 | **埋まらない。**[docs/204](204_sign_free_deviation_protocol.md) で先に認めたとおり |
| 個体・セッション基準の必要性 | **無傷。**本文書も全セルで健全記録と同一測定日に限定して成立している |

## 限界(緩めない)

- **各セル4点。**ρ=1.000 も4点では弱い
- **3機体は同一設備・同一グループ。**独立性は機体まで
- **V1は盲検でない**(上記)
- **人工的に作られた故障。**自然劣化ではない
- **これはEPSではなく同型のPMSM**
- **3.0 kW のコイル間短絡は評価できていない**(健全記録が単独の測定日)
- **振動は1ch。**設置位置の影響は評価できない

## Rule Check

- **判定を変えた修正を冒頭に置いた。**「落ちるのを見た後に気づいた」と明記した
- 通った指標が**盲検でなかった**ことを、通った事実と同じ節に書いた
- **盲検だった2つが落ちたこと**を書いた
- 「検出できる」と「どこから検出できる」を分け、後者が不成立であると書いた
- **不利な結論(センサ追加が要る)を、通った結論より強調して書いた**
