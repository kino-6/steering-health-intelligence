# PVC001 使用負荷classの先読み 深掘り

## 結論

PVC001は、現時点で最も残す価値がある。

理由は、EPSがいつ壊れるかを言わなくても、EPSに厳しい使われ方を先に分類する価値は、EPSサプライヤ内の製品企画、診断企画、品質改善、評価企画へ転記できる可能性があるためである。

ただし、これはまだ外販商品ではない。
最初の提供物は、使用負荷classの仮説表である。
その表を使い、EPSサプライヤ内の部署が「これは自分たちの業務判断に使える」と言えるかを確認する。

## 何を先読みするのか

先読みするのは、EPS故障、残寿命、交換時期ではない。

先読みするのは、車両や用途が次のような使われ方に入りそうかである。

- 低速で大きな操舵を繰り返す
- 駐車場や市街地でstop-startと操舵が重なる
- 荒れた路面や段差で操舵入力が重なる
- 連続振動路で操舵が続く
- 荒い運転スタイルと荒れた路面が重なる
- 長時間都市走行で反復操舵が続く

これらはEPS内部状態を示さない。
しかし、EPSにとって厳しい使用条件を分類する入口にはなり得る。

## なぜEPSサプライヤに残る可能性があるか

EPSサプライヤは、OEM保証DBやfleet dataを持たない前提では、個車の故障予測を主張できない。
一方で、EPS製品がどのような使用条件にさらされるか、どの使用条件で顧客説明や診断説明が難しくなるかは、component supplierとして関心を持てる。

PVC001が価値になり得るのは、次のような場合である。

- 製品企画が、用途別の操舵負荷profileを価値説明に使える
- 診断企画が、DTCだけでは説明しにくい使用contextを補助説明に使える
- 品質改善が、field issueを使用条件別に見直す入口にできる
- 評価企画が、既存評価がどのusage classを代表しているかを確認できる
- 顧客技術説明が、故障原因を断定せずに「このような使用条件では体感差が出る可能性がある」と説明できる

## 買い手 / 利用者

最初の利用者は外部顧客ではない。
EPSサプライヤ内の以下の部署に見せる。

1. 製品企画: 用途別にEPSの価値や注意点を説明できるか
2. 診断企画: DTCやfreeze frameだけで説明しにくい使用contextを補助できるか
3. 品質改善: field issueを使用条件別に見直す入口になるか
4. 評価企画: 既存HILS/bench/vehicle評価がどのusage classを代表しているか確認できるか

この4部署のどこにも刺さらない場合、PVC001は止める。

## 既存業務との差分候補

既存評価や診断は、試験条件、DTC、freeze frame、extended data、顧客症状、再現試験を扱う。
PVC001の差分候補は、それらを置き換えることではない。

差分があるとすれば、公開proxyを使って、使用条件を自然言語のclassとして先に整理する点である。
これにより、部署間で次のような会話ができる可能性がある。

> この問題はEPS故障予測ではない。まず、この車両用途が低速高操舵や荒れた路面での操舵に偏っているかを見たい。そのclassが分かると、既存評価、診断説明、顧客説明のどこに接続できるかを確認できる。

## 現時点のProceed条件

PVC001を続けてよいのは、次の3つのうち2つ以上が満たせる場合である。

1. 製品企画が、用途別のEPS価値説明に使えると言える
2. 診断企画が、DTCやfreeze frameの補助contextとして使えると言える
3. 品質改善または評価企画が、既存評価やfield issue整理の切り口として使えると言える

## Kill条件

次のどれかに当たれば止める。

- 使用負荷classが、既存評価scenario名の言い換えにしかならない
- 診断企画から見ると、DTC / freeze frame / extended dataの既存項目で十分である
- 製品企画から見ると、用途別価値説明に使えない
- 品質改善から見ると、OEM保証DBやfleet dataがないと意味がない
- 顧客説明に使うと、故障原因や残寿命の断定に見えてしまう

## EPSサプライヤとして言えること

言ってよいこと:

> 公開proxyからEPS内部状態は分からない。ただし、低速高操舵、荒れた路面での操舵、stop-startと反復操舵など、EPSに厳しい使用負荷classを先に整理することはできる。このclassが、製品企画、診断企画、品質改善、評価企画に使えるかを確認する。

まだ言ってはいけないこと:

> 使用負荷classからEPS故障を予測できる。

> 使用負荷classから交換時期や残寿命が分かる。

> 低速高操舵や荒れた路面が故障原因である。

> 公開Kaggle proxyでEPS内部stressやthermal limitを推定できる。

## 次にやること

次は、ULC001、ULC003、ULC004、ULC008の4件だけを使い、1枚のsampleにする。
そのsampleで、製品企画、診断企画、品質改善、評価企画のどこに転記できるかを見る。
4件で刺さらなければ、9件に増やしても価値は出にくい。
