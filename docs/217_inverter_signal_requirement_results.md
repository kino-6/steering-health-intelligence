# 217. 向きは出たが、場所は特定できなかった — そして基準にした正常データが不平衡だった

[docs/216](216_inverter_signal_requirement_protocol.md) の事前登録を実行した。

| # | 基準 | 結果 |
|---|---|---|
| **P1 予測した向きが出るか** | **2/2 — 成立** |
| **P2 影響相が3相中で最大の偏りか** | **1/2 — 不成立** |

**両方が必要だったので、判定は「相電流だけでは切り分けられない」である。**

実行: `python3 scripts/inverter_signal_requirement.py` / 数表: [data/inverter_signal_requirement.tsv](../data/inverter_signal_requirement.tsv)

## 結果

`R_p = |90パーセンタイル| / |10パーセンタイル|`(平衡なら1)、`d_p = log R_p − log R_p,正常`

| 条件 | R_A | R_B | R_C | d_A | d_B | d_C | 最大 |
|---|---|---|---|---|---|---|---|
| 正常 | 0.657 | **3.017** | 0.429 | — | — | — | — |
| **HB2_HIGH_SIDE_OC** | 1.254 | **0.205** | 3.897 | +0.647 | **−2.688** | +2.207 | **B ✓** |
| **HB3_LOW_SIDE_OC** | 1.304 | 1.434 | 0.656 | +0.686 | −0.744 | **+0.426** | **B ✗**(Cが正解) |

**HB2の上側開放は明瞭に出た。**B相の正側が潰れ、`R_B` が 3.017 → 0.205 に落ちている。
予測した向きそのものである。

**HB3の下側開放は向きだけ合った。**C相の `d_C = +0.426` は予測どおり正だが、
**B相の `d_B = −0.744` の方が大きく、特定はB相を指してしまう。**

## 基準にした正常データが平衡していない

**正常ファイルの `R_B` が 3.017 である。**平衡なら1に近いはずのものが3倍ずれている。

[docs/215](215_inverter_dataset_acquisition.md) が見つけたとおり、
**正常ファイルは Ib が439秒で118カウント漂動している。**
中央値をゼロ点に取ると、漂動した分布は片側に偏る。**`R_B = 3.017` はその偏りである。**

> **すべての `d_p` は、この汚染された基準からの差である。**
> **P2が落ちた最も有力な説明はこれである。**

**続き([docs/219](219_inverter_settled_baseline_results.md))**: 整定後を基準に取り直したところ**基準は平衡化したが判定はさらに落ちた**(向き 2/2 → 1/2)。
**汚染が偶然に正しい向きを作っていた。**

**ただしここでは基準を取り替えない。**
落ちた結果を見た後に基準を選び直せば、それは調整である。
**正常ファイルの定常部分を基準にする案は、別の事前登録に回す。**

## 温度は救わなかった(副次、報告のみ)

ECUが普通持たないハーフブリッジ個別温度が、開放故障の特定を救うかを見た。

| 条件 | 最も動く温度 | 変化量 |
|---|---|---|
| **HB2_HIGH_SIDE_OC** | **T1** | −14.0 |
| **HB3_LOW_SIDE_OC** | **T1** | −12.0 |
| HB1_LOW_SIDE_SC | T2 | −28.0(**HB1が正解。外れ**) |
| HB2_HIGH_SIDE_SC | T2 | −20.0 ✓ |
| HB3_HIGH_SIDE_SC | T3 | +23.0 ✓ |
| HB1_OVER_TEMP | T1 | **−192.5** ✓ |
| HB1&2_OVER_TEMP | T1 | −143.0 ✓ |
| HB3_OVER_TEMP | T3 | −97.0 ✓ |

**開放故障2件とも T1 が最も動いており、ハーフブリッジを区別していない。**

> **温度を足しても開放故障の場所は分からない。**
> 温度が効くのは過熱条件(定義上当然)と短絡3件中2件である。

**したがって「センサを足せば解決する」という結論にはならない。**
[docs/205](205_sign_free_deviation_results.md) の巻線側(振動を足せば覆える)とは**逆の形**である。

## 主張がどう動くか

| 主張 | 変化 |
|---|---|
| 開放故障の**存在**は相電流で分かるか | **向きは2/2で出た。**ただし「どこか」は別 |
| 開放故障の**場所**は相電流で分かるか | **不成立(1/2)** |
| 温度を足せば場所が分かるか | **分からない。**開放2件ともT1が最大 |
| [docs/190](190_assembly_replacement_meaning.md)「どこが悪いか分からないからAssy交換」 | **この経路では答えられなかった** |
| [docs/215](215_inverter_dataset_acquisition.md) 正常クラスの非定常 | **実害が出た。**基準が汚染され、P2の失敗を説明する |

## 限界(緩めない)

- **10 Hz。**電流波形は折り返している可能性が高く、分布のみを使った
- **Ic は計算値**(Ia, Ib と三相平衡から)。**開放されたHB3はそのC相にあたり、最も弱い量で判定している**
- **1条件1記録。**再現性を評価できない
- **正常クラスが非定常で、基準が汚染されている**(上記)
- **自作装置であり車載品ではない**
- **恒久故障である。**前駆でも断続でもない

## Rule Check

- **P2の不成立を冒頭に置き、「両方必要」という事前登録の定めどおり判定した**
- **基準の汚染を見つけたが、基準を取り替えなかった。**別の事前登録に回すと書いた
- 温度が救わなかったことを、**「センサを足せば解決」という期待より先に書いた**
- Ic が計算値であり、外した方(HB3)がまさにその相であることを明記した
