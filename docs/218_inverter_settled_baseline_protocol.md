# 218. 整定後を基準にして開放故障の特定をやり直す — 事前登録

**結果を1つも見る前に書き、単独でコミットする。**

## なぜやり直すか

[docs/217](217_inverter_signal_requirement_results.md) は P2(影響相の特定)を 1/2 で落とした。
最も有力な説明は**基準の汚染**である——正常ファイルの相電流非対称比 `R_B` が **3.017**(平衡なら1)。

原因は [docs/215](215_inverter_dataset_acquisition.md) が見つけた漂動である。
**正常記録の Ib は439秒で118カウント動き、後半で整定している。**
中央値をゼロ点に取ると、漂動した分布は片側に偏る。

**基準を整定後に取り直せば、この汚染は消えるはずである。**

## 「落ちた後に基準を選び直す」ことについて

**これは調整になりうる操作である。**したがって縛りを先に置く。

1. **区間の選び方を、結果と無関係な規則で固定する**——**全ファイルの末尾60%**を使う。
   正常だけを特別扱いしない。**5等分の後半3区間**であり、[docs/215](215_inverter_dataset_acquisition.md) が
   **本検証より前に**公表した区分をそのまま使う
2. **60%という数字は、この文書で固定し、以後動かさない。**50%や70%を試して良い方を採らない
3. **判定基準は [docs/216](216_inverter_signal_requirement_protocol.md) と完全に同一にする。**
   予測の向き・相も変えない
4. **落ちたら落ちたと書く。**docs/217 の結論(相電流だけでは切り分けられない)がそのまま残る

## 手順(固定)

[docs/216](216_inverter_signal_requirement_protocol.md) と同一。**違いは1点だけ**である。

> **各ファイルの末尾60%のサンプルのみを使う。**ゼロ点(中央値)もその範囲で取る。

```
R_p = |90パーセンタイル| / |10パーセンタイル|      平衡なら 1
d_p = log R_p − log R_p,正常
```

予測([docs/216](216_inverter_signal_requirement_protocol.md) から変更なし):

| 条件 | 影響相 | 予測される向き |
|---|---|---|
| HB2_HIGH_SIDE_OC | B相 | 負(正側が抑制) |
| HB3_LOW_SIDE_OC | C相 | 正(負側が抑制) |

## 判定基準(いま固定する)

| # | 基準 | 閾値 |
|---|---|---|
| **Q0 基準は健全化したか** | 整定後の正常 `R_p` が3相とも `1/2 〜 2` の範囲に入る | **報告。落ちても Q1/Q2 は実施する** |
| **Q1 向き** | 影響相の `d_p` が予測した符号 | **2条件の両方** |
| **Q2 相の特定** | 影響相の `\|d_p\|` が3相中で最大 | **2条件の両方** |

**Q1とQ2の両方が2条件とも成立したときのみ「整定後の基準なら相電流だけで切り分けられる」と判定する。**

**Q0が落ちたまま Q1/Q2 が通った場合は、「基準は健全化していないが判定は通った」と正確に書く。**
都合よく「基準を直したから通った」と読み替えない。

## 事前に認めておくこと

- **[docs/217](217_inverter_signal_requirement_results.md) の判定は取り消さない。**
  登録どおり不成立であり、本検証はその後に行う別の検証である
- **末尾60%という選択は、漂動を見た後に決めている。**規則は結果と無関係だが、
  **区間を選ぶという発想自体が事後である。**この点は消えない
- **Ic は計算値である。**HB3はそのC相にあたり、最も弱い量で判定する([docs/217](217_inverter_signal_requirement_results.md))
- **10 Hz、1条件1記録、自作装置、恒久故障。**すべて [docs/216](216_inverter_signal_requirement_protocol.md) と同じ
- **サンプル数が減る。**最短の HB2_HIGH_SIDE_SC は 340 → 204 になる

## Rule Check

- **「落ちた後の選び直し」であることを冒頭近くに書いた**
- 区間の規則を**結果と無関係な形(全ファイル一律・既公表の区分)で固定し、他の割合を試さないと明記した**
- Q0が落ちたまま通った場合の書き方を**先に決めた**
- docs/217 の判定を取り消さないと明記した
