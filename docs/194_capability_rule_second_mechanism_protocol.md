# 194. capability 決定則 — 第2機構での検証(事前登録)

**結果を1つも見る前に書き、単独でコミットする。**

## なぜ第2機構が要るか

[docs/193](193_str_capability_rule_results.md) は NASA MOSFET 6個で capability 指標を出した。
しかし**1つの機構(パワー段の導通抵抗上昇)で成立しただけでは、規則ではなく1つの計器である。**

規則であるための条件は、**同じ形が、設計時に想定していない別の機構でも成立すること**である。

第2機構: **モータ巻線の層間短絡**(KAIST 1.0kW PMSM、[docs/162](162_pmsm_model_validation_results.md) で扱ったデータ)。
機構が違う(電気抵抗の増加ではなく相間の不平衡)、拘束条件が違う(パワー段の接合部温度ではなく巻線の最悪相)、
データの型が違う(run-to-failure ではなく段階的severity)。

## capability の定義(同じ形を当てる)

規則の形は [docs/192](192_str_capability_rule_protocol.md) と同じである:

> **capability = 拘束条件下で実現できる出力を、その個体自身の基準で割ったもの。**

層間短絡では拘束は熱であり、**最も電流の大きい相**が先に上限に達する。
トルクは3相の平均電流にほぼ比例するので:

```
熱拘束:  I_max_phase <= I_limit
トルク  ∝ I_mean
  =>  実現できるトルク ∝ I_limit * (I_mean / I_max_phase)
```

個体自身の健全記録に対する比として:

> **C(sev) = H(sev) / H(0),   H = I_mean / I_max_phase**

I_limit は比で消える。[docs/192](192_str_capability_rule_protocol.md) で Rth が消えたのと同じ構造である。

**H は「不平衡でどれだけ余裕を捨てているか」を表す。** 完全平衡なら H = 1。

## 対象データと層別の宣言

[docs/162](162_pmsm_model_validation_results.md) が実行中に発見したとおり、実測8ファイルは**2つの測定セッションに分かれ、ベースラインが違う。**

| セッション | severity | 極性 | 健全記録 |
|---|---|---|---|
| **S2** | 0.00 / 3.35 / 6.48 / 21.69% | 正常 | **あり(0.00%)** |
| S1 | 2.26 / 2.70 / 4.41 / 12.17% | C相反転 | **なし** |

**本検証は S2 のみを対象とする。**
理由は結果ではなく**規則の前提**である——個体基準の規則は同一個体・同一セッションの健全記録を必要とし、S1にはそれが無い。
S1 は基準を持たないため、**自身の最小severityを仮基準とした参考値として別掲する。規則の検証には使わない。**

> **これは docs/162 で事後に見つかった層別である。**その事実をここで宣言したうえで使う。隠して使わない。

## 手順(固定)

- 各記録の中央20秒。[docs/161](161_pmsm_model_validation_protocol.md) と同じ窓。運転点は全記録で 3000 rpm・負荷15% で共通
- 相電流を基本波(100 Hz)で複素振幅に落とし、3相の振幅 |I_a|, |I_b|, |I_c| を得る
- `H = mean(|I|) / max(|I|)`、`C(sev) = H(sev) / H(0)`
- **宣言粒度 g**: 20秒窓を2秒×10に分割し、各小窓で C を計算した標準偏差の3倍。
  [docs/192](192_str_capability_rule_protocol.md) と同じ「3σ」の定義を使う

## 合否基準(いま固定する)

| # | 基準 | 閾値 |
|---|---|---|
| **R1 単調性** | C が severity に対して単調減少 | **Spearman ρ ≤ −0.8** |
| **R2 粒度超え** | 最大severity(21.69%)での C が `1 − g` を下回る | **成立/不成立** |
| **R3 分解能** | ΔC が g を超える最小の severity 段差を報告 | **閾値なし。EooCシートに載る数値** |

**R1とR2の両方が成立したときのみ「規則の形が第2機構へ転移した」と判定する。**
片方でも落ちれば**転移しなかった**と書く。

## 事前に認めておくこと

- **機体は1台、severityは4点である。**統計ではない。示せるのは**規則の形が当たるかどうか**だけである
- **run-to-failure ではない。**severity 21.69% でも故障には至っていない。**先行時間については何も言えない**
- **S2の4点のうち健全は1点である。**基準の安定性は評価できない。g は測定内変動であって個体間変動ではない
- **層間短絡は人工的に作られている。**自然劣化ではない
- **v2は作らない。**落ちたら落ちたと書く
