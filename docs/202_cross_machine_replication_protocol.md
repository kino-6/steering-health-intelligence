# 202. 別機体2台での再現 — 事前登録

**結果を1つも見る前に書き、単独でコミットする。**
**1.5 kW と 3.0 kW のファイルは、この文書を書いている時点で一度も開いていない。**

## なぜ書けるようになったか

[docs/201](201_motor_second_fault_and_vibration_results.md) までの巻線側の結論はすべて
**1機体(1.0 kW)**に依存しており、全ドキュメントで「統計ではない」と断ってきた。

Mendeley の配布物を確認したところ、同一データセットに**3機体**あった。

| 機体 | 状態 |
|---|---|
| 1.0 kW | 使用済み。**ここまでの結論はすべてこれ1台** |
| **1.5 kW** | **未取得・未開封** |
| **3.0 kW** | **未取得・未開封** |

**したがって、1.0 kW で見つけた仮説を、見ていない2機体で確かめられる。**
探索と確認が別のデータに分かれる——これまでできなかった形である。

## 確かめる3つ

### X1. capability の規則は別機体で再現するか

[docs/195](195_capability_rule_second_mechanism_results.md) の `C1 = H(sev)/H(0)`、`H = mean|I| / max|I|` を、
**層間短絡**に当てる。1.0 kW では ρ = −1.000 だった。

### X2. 「電流はコイル間短絡に効かない」は別機体でも成り立つか

[docs/201](201_motor_second_fault_and_vibration_results.md) は 1.0 kW で ρ = −0.400(不成立)だった。
**これは「効かない」という主張なので、証明はできない。反証されるかどうかを見る。**

### X3. 振動の向きは故障種で逆になるか — 1.0 kWで見つけた仮説の確認

docs/201 の事後観察: 電気周波数2倍の振動振幅が、**層間短絡では下がり(1.000→0.281)、コイル間短絡では上がった(1.000→1.583)。**

**この仮説は 1.0 kW のデータから作った。同じデータで確かめても意味がない。**
**だから確認は 1.5 kW と 3.0 kW だけで行い、1.0 kW は確認に使わない。**

## 手順(固定)

[docs/200](200_motor_second_fault_and_vibration_protocol.md) と同一。中央20秒、極性の幾何補正、
粒度は2秒×10小窓の標準偏差の3倍。

**セッションの層別を、今回は事前登録する。**
docs/201 で、C相極性が反転している記録は severity と無関係に別の水準へ張り付くことが確定した。
したがって**健全記録(0.00%)を含むセッションのみを解析対象とする。**これは事後の処置ではなく前提である。
**新機体でセッション構造が違った場合は、その事実を報告して該当する問いを不成立とする。**

## 判定基準(いま固定する)

| # | 基準 | 閾値 |
|---|---|---|
| **X1 規則の再現** | 層間短絡で C1 が単調減少 | **2機体の両方で Spearman ρ ≤ −0.8** |
| **X2 反証されるか** | コイル間短絡で C1 が単調 | **2機体の両方で \|ρ\| ≥ 0.8 なら docs/201 は反証される** |
| **X3 向きの確認** | 2f0 の振動が 層間で減少・コイル間で増加 | **2機体 × 2故障種 = 4件すべてで向きが一致** |

- X1が落ちたら、規則は1.0 kW固有だったと書く
- X3が**1件でも**向きを外したら、**確認できなかったと書く。**3/4は成功ではない
- **v2は作らない**

## 事前に認めておくこと

- **新機体のseverity一覧を知らない。**1.0 kWと同じ点である保証はない
- **各機体・各severityは1記録である。**繰り返しは無い
- **3機体はいずれも同一の試験設備・同一の研究グループ由来である。**独立性は「機体が違う」までであり、設備・手法の系統誤差は共有する
- **人工的に作られた故障である。**自然劣化ではない
- **これはEPSではなく同型のPMSMである**
- **X2は「効かない」の確認ではない。**反証されなかった、までしか言えない

## Rule Check

- **1.5 kW / 3.0 kW を開く前に書いた。**このコミットが download より先であることを履歴に残す
- X3の仮説が 1.0 kW 由来であることを明記し、**確認に 1.0 kW を使わないと先に決めた**
- X3を「4件すべて」と縛った。**3/4を成功と読み替える余地を消した**
- X2が原理的に証明できないこと(反証のみ可能)を先に書いた
- 3機体が独立でない範囲(同一設備・同一グループ)を先に書いた
