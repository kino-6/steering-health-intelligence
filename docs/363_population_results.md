# 363. 40 テストで測ると、信号対雑音は 6 倍ばらつく。6 素子が揃っていたのは母集団の性質ではなかった

[docs/362](362_population_protocol.md) の事前登録を実行した。**追加取得ゼロ。**42 テストのうち run 1 が 400 点以上ある **40 テスト**を使った。

> **P3・P4 成立、P1 外れ、P2 は判定できない（測定の定義を取り違えた）。**
>
> **信号対雑音 S は 40 テストで 1.63〜9.52、最大/最小 5.83 倍。**6 素子では 1.14 倍だった。
> **6 素子が揃っていたのは母集団の性質ではない。**[docs/354](354_capability_threshold_results.md) の
> 「能力の閾値を逸脱の閾値に翻訳しても失うものが小さい」は、**同じ能力の閾値が個体によって 6 倍違う逸脱の閾値になる**、に弱まる。
>
> **測定ノイズ σ は 6 素子の中央値 0.0736 が 40 の中央値 0.0748 と一致し、6 素子は 40 の 10〜90% の中にいる。**
> 出荷時の当てはめの傾きが負になる（採否で落ちる）テストは **4/40 = 10%**。

実行: `python3 scripts/population.py` / 数表: [data/population.tsv](../data/population.tsv)

## 結果

| 量 | 40 テストの中央値 | 10% | 90% | 6 素子の中央値 | 6 素子の位置 |
|---|---|---|---|---|---|
| σ（ノイズ） | 0.0748 | 0.0661 | 0.2949 | 0.0736 | 45 パーセンタイル |
| **S（信号対雑音）** | 8.52 | **3.07** | 9.21 | 8.51 | 50 パーセンタイル |
| 傾き（温度係数） | 0.0104 | 0.0043 | 0.0125 | 0.0082 | 22 パーセンタイル |

**S の分布は上に詰まり、下に長い。**中央値 8.5 の近くに多く、1.6 まで下がるテストがある。
6 素子は分布の真ん中にいるが、**幅を代表していない。**

## 判定

| | 予想 | 結果 |
|---|---|---|
| **P1** | S の最大/最小 ≤ 3 倍 | **外れ。5.83 倍** |
| **P2** | α の中央値 1.1〜1.5 | **判定できない。**下記 |
| **P3** | 傾きが負のテスト ≤ 6 個 | **成立。4/40** |
| **P4** | 6 素子が 10〜90% の中 | **成立**（σ、S、α とも） |

### P2 を判定できない理由

事前登録は「α は [docs/348](348_drift_shape_results.md) と同じ定義」と書いた。
実装は run 1 だけを対象に、50 点で平滑した走行平均の n 点差分（n = 25〜400）の分散の伸び方を取った。
**docs/348 は run 1〜4 を対象に、別の窓で測っている。**同じ 6 素子で、本件の α は 0.20、docs/348 は 1.32 になる。
**同じ名前で別の量を測った**（[TROUBLES.md](../TROUBLES.md) T4 の 4 回目）。
本件の α の値そのもの（40 の中央値 0.68）は run 1 の中の漂流の形を表すが、docs/348 の 1.32 とは比べられない。

## 答えがどう変わるか

| | 6 素子 | 40 テスト |
|---|---|---|
| S のばらつき | 1.14 倍 | **5.83 倍** |
| 能力 0.95 を課したときの逸脱の閾値 | 0.79〜0.90 × 3σ | **S × (1/0.95² − 1) = 0.18〜1.03 × 3σ** |
| 「翻訳で失うものが小さい」 | 成立 | **弱まる。**同じ能力の閾値が、個体によって 6 倍違う逸脱の閾値になる |
| ノイズ σ の代表性 | — | **6 素子は代表している**（中央値が一致） |
| 採否で落ちる割合 | 1/6 | **4/40 = 10%** |

**能力の閾値は依然として置ける**（翻訳の式は変わらない）。変わるのは、**S が小さい個体では逸脱の閾値が 0.18 × 3σ まで下がり、
ノイズに近づく**ことである。そういう個体は「5% 落ちたら」を検知できる保証が無い。

## 残る限界

- **劣化の側の N は 6 のまま。**検知率・警報時点の能力は増えていない
- 40 テストは同じ型番・同じ試験機である
- 基準温度を run 1 の中央値に置いたので、6 素子の S は docs/354 の 7.3〜8.3 とは少し違う（8.5）
- run 1 の長さがテストごとに違う（数表に載せた）
- 2 テストは run 1 が 400 点未満で除いた
