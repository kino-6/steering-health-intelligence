# 228. 仕様を実車ログの上で動かす — 事前登録

**結果を1つも見る前に書き、単独でコミットする。**

## なぜやるか

[docs/225](225_recorder_specification.md) は記録器の仕様を書き、[docs/227](227_filling_spec_blanks_results.md) は
**1回の走行で採った指紋が、その車の速度範囲の 1/7 〜 1/35 しか覆わない**ことを示した。

**では、指紋が狭いと実際に何が起きるのか。**

仕様は「正規化できない条件では値を出さず**宣言しない**を返す」と定めた([docs/196](196_eps_health_element.md))。
**指紋が狭ければ、宣言しない割合が増える。**その割合を測っていない。

> **測るのは「記録器がどれだけ黙るか」である。**

これは配備できるかどうかを直接決める。**大半の時間で黙る記録器は、あっても意味がない。**

## 手順(固定)

commaSteeringControl 4車種2,495ログ。制御が有効で運転者が介入していない標本のみ
([docs/220](220_real_vehicle_granularity_protocol.md) と同一)。

**出荷時指紋は存在しないので、各ログの前半30%を指紋の代用とする。**

- 指紋: そのログの**先頭30%**の標本から、速度と操舵角の範囲(5〜95パーセンタイル)と、
  残差のノイズ床(3×1.4826×MAD)を採る
- 評価: **残り70%**の標本について、動作点が指紋の範囲内かを判定する
- **範囲外なら「宣言しない」**([docs/225](225_recorder_specification.md) の有効性規則)

**この代用は既知の欠陥を持つ。**指紋を同じ走行から採るので、
[docs/227](227_filling_spec_blanks_results.md) が測った 1/7〜1/35 の不足がそのまま入る。
**したがって本検証は「指紋が狭いときに何が起きるか」を測るものであり、良い指紋の性能ではない。**

## 指紋を広げたらどうなるか

指紋の範囲を中心から **×1(そのまま) / ×2 / ×5 / ×10 / ×20** に広げ、
**宣言しない割合がどう下がるか**を測る。

> **「宣言しない割合を10%未満に抑えるには、指紋を何倍に広げる必要があるか」を報告する。**

## 判定基準(いま固定する)

**記述統計であり合否判定を置かない。**報告の規則を固定する。

| # | 報告するもの | 規則 |
|---|---|---|
| **E1** | 車種ごとの「宣言しない」割合(×1) | 分母(標本数・ログ数)を必ず併記 |
| **E2** | 指紋倍率を変えたときの割合の変化 | ×1/×2/×5/×10/×20 の全部を出す。良い倍率だけを出さない |
| **E3** | **宣言しない割合を10%未満・1%未満にする最小倍率** | **10%と1%の両方を先に決める。**結果を見て閾値を選ばない |
| **E4** | 1走行あたりの出力件数と概算データ量 | 1件のサイズは仕様の項目数から算出し、内訳を書く |

- **E1が高い(たとえば半分以上黙る)場合でも、そのまま報告する。**仕様に不利でも書く
- **v2は作らない**

## 事前に認めておくこと

- **指紋の代用は既知の欠陥を持つ**(上記)。**良い指紋の性能を測っていない**
- **温度軸を評価していない。**commaSteeringControlに温度が無い([docs/227](227_filling_spec_blanks_results.md))。
  **実機では温度が範囲外の主因になりうるが、本検証はそれを含まない**
- **残差はEPSの測定量ではない**([docs/220](220_real_vehicle_granularity_protocol.md))
- **openpilot搭載4車種。**一般の分布ではない
- **制御が有効な区間のみ。**据え切り・駐車が入っていないため、
  **動作点の範囲を過小評価している**([docs/227](227_filling_spec_blanks_results.md))
- **前半30%という分割は任意である。**別の分割なら結果が変わりうる。**他の分割を試さない**

## Rule Check

- **指紋の代用が既知の欠陥を持つことを、手順の中に書いた**
- **E3の閾値(10%と1%)を結果を見る前に両方固定した**
- E2で「全倍率を出す。良い倍率だけを出さない」と縛った
- E1が不利でもそのまま報告すると先に決めた
- 30%という分割が任意であり、**他を試さない**と明記した
