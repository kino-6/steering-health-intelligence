# 204. 符号を捨てた逸脱指標は機体をまたぐか — 事前登録

**結果を1つも見る前に書き、単独でコミットする。**

## なぜ符号を捨てるか

[docs/203](203_cross_machine_replication_results.md) で、層間短絡に対する相電流の平衡指標が
**機体によって向きが逆**になることが分かった(1.0 kW で −1.000、1.5 kW で **+1.000**)。

**変化量はどの機体でも粒度を超えている。動いてはいる。向きが揃わないだけである。**

ここで分かれる。

| 出したいもの | 符号 |
|---|---|
| **capability 値**(「本来の95%が出せる」) | **要る** |
| **逸脱検知**(「自分の基準から外れている」) | **要らない** |

capability 値の宣言は降ろす([docs/203](203_cross_machine_replication_results.md) の帰結)。
残る問いは**逸脱検知の方が機体をまたぐか**である。

これは [docs/167](167_precursor_results_v2.md) が NASA で示した形(自分の基準からの逸脱がノイズの20〜300倍)そのものであり、
**この研究で唯一、機構・データセットをまたいで成立し続けている形**である。

## 既に見てしまったものの宣言

**公正さのため、どの特徴量をどの機体で既に見たかを全部書く。**

| 特徴量 | 1.0 kW | 1.5 kW | 3.0 kW |
|---|---|---|---|
| C1 相電流の平衡 | 見た | **見た** | **見た** |
| V1 電気周波数2倍の振動 | 見た | **見た** | **見た** |
| **C2 逆相/正相比** | 見た | **未見** | **未見** |
| **V2 振動の広帯域RMS** | 見た | **未見** | **未見** |

**したがって C2・V2 の新機体での結果だけが盲検である。**
C1・V1 は既に見ているので、それらが通っても証拠としては弱い。**両方を報告し、区別する。**

## 逸脱指標の定義

各特徴量 F について、**その個体の健全記録における測定ノイズ**を単位にした距離:

```
g0 = 健全記録の20秒を2秒×10に割った小窓での F の標準偏差 × 3
D(sev) = | F(sev) − F(0) | / g0
```

**D は「自分の健全時のノイズの何倍離れたか」である。符号を持たない。**
[docs/167](167_precursor_results_v2.md) の「20〜300倍」と同じ量である。

## 対象セル

[docs/203](203_cross_machine_replication_results.md) の日付層別を適用し、**健全記録と同じ測定日の記録のみ**を使う。
評価できるのは5セル(3.0 kW のコイル間短絡は健全記録が単独の測定日にあり評価不能)。

| 機体 | 層間短絡 | コイル間短絡 |
|---|---|---|
| 1.0 kW | 可 | 可 |
| 1.5 kW | 可 | 可 |
| 3.0 kW | 可 | **不可** |

## 判定基準(いま固定する)

| # | 基準 | 閾値 |
|---|---|---|
| **Y1 携帯性** | ある特徴量の D が severity に対して単調増加 | **5セルすべてで Spearman ρ ≥ 0.8** |
| **Y2 検出力** | その特徴量の最大 D | **5セルすべてで 3 を超える** |
| **Y3 報告** | 全4特徴量 × 全5セルの ρ と最大 D | **閾値なし** |

> **Y1 と Y2 の両方を満たす特徴量が1つでもあれば「機体をまたぐ逸脱指標がある」と判定する。
> 1つも無ければ「無い」と書く。**

- 4セルで通っても**成功と読まない。**5セルすべてである
- **通った特徴量が C1 か V1 だった場合は、「既に見ていた特徴量である」と併記する**
- **v2は作らない**

## 事前に認めておくこと

- **各セル4点である。**ρ = 1.000 も4点では弱い
- **3機体は同一設備・同一グループ由来。**独立性は機体までである
- **severity の定義が機体間で同じ物理量を指すかは確認していない**
- **人工的に作られた故障である。**自然劣化ではない
- **これは検知であって能力値ではない。**通っても「本来の何%か」は言えない
- **Y1が通っても、SOTIFのEooCが要求する「値」は埋まらない**([docs/193](193_str_capability_rule_results.md))。
  SOTIFは二次的な位置に戻る

## Rule Check

- **既に見た特徴量と未見の特徴量を、表にして先に区別した**
- Y1を「5セルすべて」と縛った。**4/5を成功と読み替える余地を消した**
- capability値の宣言を降ろすことを、通った場合の利得より先に書いた
- 通っても SOTIF の欄が埋まらないことを先に書いた
