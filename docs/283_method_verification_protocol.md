## 検証の対象を分ける

**2つの主張が混ざっていた。分ける。**

| 主張 | 検証に要るもの |
|---|---|
| **(a) 記録器という手法が、本物の劣化を、決めた誤報率で捕まえる** | **保持された動作点 + 十分な標本 + 実劣化。部品は問わない** |
| (b) EPSの劣化が捕まる | EPSまたは同型機構の実機データ |
|  |  |

**本Repoが立証できていないのは (a) である。**
[docs/278](278_inverter_recorder_results.md)/[docs/282](282_igbt_recorder_results.md) が落ちたのは、
**(b)の難しさではなく、(a)を測れる標本が無かったからである。**

> **(a)が落ちれば、(b)を議論する意味は無い。**
> **(a)が通れば、残るのは「EPSでどうか」だけになり、問いが1つに減る。**

## 判定基準(実行前に固定)

記録器は `scripts/element_v2.py` を**そのまま使う。書き換えない。**
指紋は各個体の**最初の1/3**。[docs/280](280_fingerprint_interval_results.md) の交差検証を通す。

| # | 基準 | 閾値 |
|---|---|---|
| **X1** | 指紋区間に**判定10,000回分以上**の標本がある個体が過半 | 過半。**36,000に届かなければ、届いた数を書く** |
| **X2** | 交差検証(残差水準のずれ < 床1つ)を通る個体が過半 | 過半 |
| **X3** | 通った個体のうち、**故障前に発火する割合** | **過半で成立** |
| **X4** | 指紋区間での誤報が**設計値の3倍以内** | 3倍 |

**X3とX4の両方が要る。**[TROUBLES.md](../TROUBLES.md) T28。
**X1が届かなければ、誤報の設計値を標本数で刻める水準まで下げ、その値を明記する。**
**これは閾値の後付け調整ではない——刻めない分位点を推定しないという既存の規則である。**
