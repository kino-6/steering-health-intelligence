# 302. 隠れた構造はある（6/6）。だが検出には効かない（0/4）。そして N=6 が許す言い方

[docs/301](301_multivariate_protocol.md) の事前登録を実行した。**追加取得ゼロ。**

> **M2 成立 6/6、M1 不成立 0/4。**
> **ユーザの指摘は半分当たっている**——run 5 で動く主成分には、6 素子すべてで Vds/Id 以外の量が 0.49〜0.79 の負荷で乗る。
> **1 要素の事象ではない。**しかし多変量にしても、単変量が取り逃した 4 素子は 1 つも拾えない。
> 理由は同じ——**健全期の漂流が run 4 で誤報になる**（T² が 3,478〜16,430 件/時）。

## M2 の読み方 — 「隠れた構造」の正体は 2 種類に分かれる

**供給電圧**（Test_8・12・14）と**フランジ−パッケージ温度差**（10・11）が、run 5 で Vds/Id と一緒に動く。

- **フランジ−パッケージ温度差**は、die-attach の熱経路そのもの。**これが動くのは劣化と整合する**（[docs/256](256_thermal_index_protocol.md) が狙って落ちた量が、多変量では立ち上がりの成分に乗った）
- **供給電圧**は素子の量ではない。**試験機が run ごとに供給を変えている**可能性があり（[docs/199](199_pulse_thermal_results.md)・[273](273_power_stage_observables_results.md) の T1 の型）、**温度補償では消えない。**「隠れた構造」の一部は試験機の操作である

> **したがって M2 の 6/6 は「1 要素では記述できない」までであり、「隠れた劣化モードがある」ではない。**
> 6 のうち 3 は供給電圧で、それは素子の外の量である。

## ユーザの第 2 の問い — N=6 で、これは報告なのか、所感なのか

**率としての主張はできない。**6 素子で「5/6」「2/6」と書いても、区間は 1 素子ぶんで動く。
**この Repo の数字は、存在証明として読むべきで、率として読んではならない。**

**N に依存しない発見はある。**それが報告として残る部分である。

| 発見 | N に依存するか |
|---|---|
| 較正できる誤報率は登録標本数 k の 1/k で頭打ち（[docs/282](282_igbt_recorder_results.md)） | **しない**。算術 |
| 束ねた検定の誤報は束ねる前の単位で報告してはならない（[docs/294](294_unit_level_false_alarm.md)） | **しない** |
| 同種チャネルの差分で共通原因が消える（[docs/286](286_common_mode_results.md)） | 1 台。**機構は一般的** |
| 健全期にも漂流があり、閾値を床の 0.2 倍まで下げると誤報になる（[docs/299](299_bank_results.md)） | 6 素子とも同方向。**方向は N=6 で言える、大きさは言えない** |
| 劣化が起きた素子は run 5 で床の +1.4 倍を越え、そこは 2 素子だけ | **存在証明** |

**N を上げる道は 1 つしかない。**手元で 20 個体を超えるのはコンデンサ 23 個体だけで、それは記録器の同時事象（[docs/300](300_eis_sync_results.md)）で止まっている。
**その事象を特定して除けば、N=23・3 群の検定になる。**それが出るまで、率の主張はしない。

## 答えないこと
- ヒーター動作の 1 試験機・1 型番。含まれていない劣化モードは多変量でも出ない
- PCA は線形
- 供給電圧が試験機の操作かどうかは、制御器記録との突き合わせが要る（未実施）

- Test_10 の run 4 欠損を「評価不能」とし、0 にも無限にも数えなかった
