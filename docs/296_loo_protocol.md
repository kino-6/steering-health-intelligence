# 296. 事前登録 — 5/6 は汎化するか。素子を 1 つ抜いて残りで決め、抜いた 1 つで試す

> **ユーザ指摘(2026-09-03): 「N が少ないのは気になる」「あんまり汎化できてない気がする」。**
>
> [docs/295](295_all_seven_runs.md) の 5/6 は、平均長 N を **{100, 200, 500, 1000, 2000, 5000} の 6 候補から
> 「6 中 5 以上が鳴る最初の N」として選んでいる。**選んだ N で選んだ素子を数えており、**同じ 6 素子で決めて同じ 6 素子で測っている。**
> これが汎化しないなら、5/6 は N の選び方が 6 素子に合わせ込まれた結果である。

**追加取得ゼロ。** NASA PCoE MOSFET、7 run 全部。

## 手順（実行前に固定）

Leave-one-out。6 素子それぞれについて:

1. その素子を抜く
2. **残り 5 素子だけで**、6 候補の N のうち「5 中 4 以上が故障前に鳴る最初の N」を選ぶ（無ければ最大の発火数の N）
3. 閾値は [docs/271](271_slow_channel_results.md) と同じく、**残り 5 素子の健全区間**から誤報 1 件/時で求める
4. **抜いた 1 素子**に、その N と閾値をそのまま当てる。鳴るか、誤報は何件か

**閾値も N も、抜いた素子の情報を一切使わない。**

## 判定基準（実行前に固定）

| # | 基準 | 閾値 |
|---|---|---|
| **G1** | 抜いた素子で故障前に鳴った数 | **6 中 4 以上なら「N の選び方は汎化する」** |
| **G2** | 選ばれた N が 6 回の LOO で一致するか | 記述。**ばらつけば、N は素子依存** |
| **G3** | 抜いた素子の健全区間での誤報 | 設計値の 3 倍以内 |

**G1 が 3 以下なら、[docs/295](295_all_seven_runs.md) の 5/6 は合わせ込みの産物と書き、標準の答えを「5/6」から「LOO で x/6」に置き換える。**

## この検定が答えないこと

- **同じ試験機・同じ型番の中での汎化**しか見ない。別の素子種・別の試験機・EPS への汎化は別問題
- 6 素子なので、G1 の 4/6 と 3/6 の差は素子 1 つ。**強い証拠にはならない**
- 素子はヒーター動作。R12 未達
