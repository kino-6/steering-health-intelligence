# 370. 事前登録 — 量の定義を直して当て直す（docs/369 の E2 は判定できない）

[docs/369](369_continuous_tests_protocol.md) を走らせると 12 本すべてで `t10 = 0`、`R0 ≈ 0.6 Ω` になり、同定 0/12 だった。
**物理ではなく量の定義の欠陥である。**Test_36 の波形を見ると:

| 事実 | 意味 |
|---|---|
| V_GS = 18.7 V で on、V_DS ≈ 4.1 V、I ≈ 7〜9.6 A → R ≈ 0.43〜0.6 Ω | **加速温度での R_DS(on)**。Si MOSFET は 200 °C で 25 °C の 2〜3 倍になる。0.19 Ω の記録 0 は冷えた開始時 |
| 3.5 時間で V_DS 4.21 → 4.30 V、I 9.65 → 9.09 A | **R が約 8% 上がる。**ΔR ≈ 0.036 Ω で NASA の 0.05 Ω に向かう |
| 4.0 時間で I が 0.4 A に落ち、V_GS が −0.4 V | **素子の死。**NASA の 2011 年論文の EOL 228 分と一致 |
| 500 点の波形の [0-49] と [200-249] は I 3.8 A・V_DS 4.9 V | 立ち上がり・立ち下がりの**斜面**。「I > p95 の 50%」の mask はこれを拾っていた |

docs/369 の欠陥は 2 つ。(1) on 状態の mask が斜面を含み、V/I の中央値が偏った。(2) 最初の 10% で I と T がほぼ動かず、2 変数回帰が悪条件で外へ外挿した。
**E1（12/12 が 0.10 に達した）は定義の欠陥による見かけで、判定に使わない。E2〜E4 は判定できない。**

## 直した定義（実行前に固定する）

- **on 状態 = V_GS > 15 V の点**（プラトー。斜面と off を除く）。20 点未満なら記録を捨てる
- **R_DS(on) = on 状態の V_DS / I_D の中央値**
- **ΔR/R0(t) = R(t) / R0 − 1、R0 = 最初の 10% の R の中央値。回帰しない。**連続試験は I と T を保持しているので、動作点の補正は要らない。I と T の変化は結果に添える
- **素子の死 = on 状態の I_D の中央値が R0 で決めた健全値の 20% を初めて割った記録。**それ以降は当てはめに使わない
- 50 記録の走行平均。軸は aging time
- 当てはめ、同定失敗の条件、直線の基準、予想 E1〜E4 は docs/369 と同じ。ただし E1 は「死の前に 0.10 に達する本数 ≥ 8」と読む

## やらないこと

- 定義を 3 度変えない。これで同定できなければ「NASA の量でも指数は同定できない」と書いて閉じる
- 死の後の記録（R が 15 Ω など）を劣化として数えない
