# 176. 訂正: 接点系にも劣化の窓は存在する

## 訂正の内容

2026-08-23、私は次のように述べた。**これは誤りである。**

> 接点fretting系は抵抗上昇が機能不全と同時に来るため、SOTIFが扱う「性能不足の窓」がそもそも存在しない。

**「公開データでは測れない」([docs/175](175_close_contact_question.md))を、「存在しない」にすり替えた飛躍である。**

## 一次証拠が否定している

公開リコール文書([data/eps_public_market_pain_cases.tsv](../data/eps_public_market_pain_cases.tsv))は、標的故障族をこう記述している。

| ケース | 記述 |
|---|---|
| MKT011〜014(Cadillac ATS/CTS, Camaro, Corvette) | "Assist may return after restart; **condition can recur**" |
| MKT015〜016(Cadillac CTS/ATS) | "Assist loss **may last ignition cycle and return after restart**" |

**アシストが失われ、再始動で戻り、また再発する。** これは「動作しているが機能が足りない」状態が
**繰り返し発生している**ということであり、劣化の窓そのものである。窓が無いどころか、**公開文書に明記されている**。

加えて [docs/150](150_advisory_precedence_verification.md) は、閾値未満の兆候が翌年の故障に最大24.1倍先行することを、
英国車検1,700万個体の実データで示している。**「兆候が先行する」こと自体は既に実証済みである。**

## 何を取り違えたか

文献([docs/172](172_contact_degradation_route.md))が述べているのは、次の1点に限られる。

> **DCの接触抵抗の「水準」**は、寿命の大部分で安定しており、機能不全とほぼ同時に上昇する。

これは**一つの指標についての記述**であって、劣化の窓についての記述ではない。
本研究が標的にしてきた観測量は、そもそも抵抗の水準ではない——
[docs/121](121_steering_predictive_diagnostics_power_monitor_case.md) の payload は
**短い電圧dip、near-reset、assist制限との同時性、key cycle recurrence(再発頻度)** である。

**指標の限界を、現象の限界と読み違えた。**

## 正しい状態

| 項目 | 状態 |
|---|---|
| 接点系に劣化の窓は存在するか | **存在する。公開リコール文書に明記**(断続・回復・再発) |
| その窓で抵抗の**水準**は上がるか | **上がらない**(文献、二次情報) |
| その窓を**発生率**として定量できるか | **未検証**。これが A'' であり、[docs/175](175_close_contact_question.md) で「公開データでは測れない」として閉じた |
| SOTIFの対象(動作するが性能不足)は主力族に存在するか | **存在する**。前言を撤回する |

**したがってSOTIF方向は、私が言ったようには弱まっていない。**
弱いのは「部品側がその窓の進行を**数値で宣言できるか**」であり、これは [docs/153](153_sotif_eooc_assumption_sheet.md) の
EooC仮定シートで**空欄として既に扱っている**箇所である。新しい壁ではない。

## なぜ飛んだか(手順への反映)

[AGENTS.md](../AGENTS.md) の「検証作業の作法」に7項目目を追加する。

> 7. **「測れない」を「無い」と書かない。** 指標の限界と現象の限界を分ける。
>    公開データで測れないことは、その現象が存在しないことを意味しない。
>    実例: 接触抵抗の水準が上がらないことを根拠に「劣化の窓が存在しない」と述べ、
>    公開リコール文書(断続・回復・再発の明記)に否定された(本ドキュメント)
