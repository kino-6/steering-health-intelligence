## 判定

| | 予想 | 結果 |

| **X1** | s = 0.926 で誤検知 ≤ 5.4 件/時 | **外れ。333** |
| **X2** | 故障前 ≥ 90% かつ猶予 ≥ 2 h | **成立。100%、11.7 h。ただし猶予が寿命と同じで、鳴っているのは漂流** |

## 式で分かること

差分の漂流の分散は `2(1 − s)σ_B²`。s = 0.926 でも 0.148 倍が残り、σ_B = 0.555 なら 2.3 時間で標準偏差 0.32（3σ 単位）。
1 時間の登録区間の分位点で決めた閾値は、その後も伸び続けるウォークを止められない。**残った漂流がウォークである限り、s → 1 以外では線に届かない。**
σ_B = 0.23 なら残りは 0.13 で、ノイズ（0.047）の 3 倍。届くかどうかは測り直しで決まる。
