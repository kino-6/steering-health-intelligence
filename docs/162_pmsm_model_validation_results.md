# 162. PMSM故障モデル検証の結果(事前登録[docs/161](161_pmsm_model_validation_protocol.md)の実行)

## 判定

**事前登録した3基準のうち、基準1(単調性)は不成立、基準3は評価不能。したがってプロトコルの定めにより「整合とは判定できない」。**

| 基準 | 内容 | 結果 |
|---|---|---|
| 1 | severityに対する単調性 ρ ≥ 0.8 | **不成立**(ρ = 0.381 / 0.333) |
| 2 | 実測とモデルの比が 0.1〜10 | **成立**(比 1.8〜6.2)。ずれは宣言済みの系統誤差の向き |
| 3 | 健全の3倍に達するseverityが2倍以内 | **評価不能**(プロトコルの設計欠陥、後述) |

**そしてモデルは調整していない。** [docs/161](161_pmsm_model_validation_protocol.md) の「不整合時にモデルを叩かない」を守った。

実行: `python3 scripts/pmsm_interturn_model.py` → `scripts/pmsm_measured_signature.py` → `scripts/pmsm_model_vs_measured.py`

## 不成立の原因は、モデルではなく測定側にあった

単調性が崩れた原因を特定した。**実測8ファイルは2つの測定セッションに分かれており、両者でベースラインが違う。**

### 発見1: C相電流センサの極性反転(4ファイル)

severity 2.26 / 2.70 / 4.41 / 12.17% の記録では、**C相がA相から+120°ではなく−66°の位置にある**。180°回すと+113°となり、他の記録(+112〜117°)と一致する。センサ配線の極性が逆である。

これは故障signatureではなく計測系の差である。幾何的に検出して補正した(`fix_polarity()`)。手作業でファイルを選んでいない。

### 発見2: 極性を直してもセッション間の段差が残る

| セッション | severity | U(基本波不平衡) |
|---|---|---|
| **S2**(極性正常、健全0%を含む) | 0.00 / 3.35 / 6.48 / 21.69% | 0.0275 → 0.0673 → 0.0754 → **0.1056** |
| **S1**(極性反転、健全なし) | 2.26 / 2.70 / 4.41 / 12.17% | 0.2311 → 0.2442 → 0.2559 → **0.2605** |

**S1はS2より一貫して2〜8倍不平衡が大きい。** severity 2.26%(S1)の不平衡が、severity 21.69%(S2)の2倍以上ある。これはseverityの効果ではありえない。

**各セッション内では完全に単調である**(S2: ρ=1.000/1.000、S1: ρ=1.000/0.800)。全体で崩れているのは段差のせいである。

> **この層別は事前登録していない。実行中に見つけた事後の層別である。** 事前登録どおりの(層別なしの)結果はρ=0.381/0.333で不成立であり、そちらが正式な判定である。両方を並べて記録する。

## 基準2は成立し、ずれは宣言どおりの向きだった

S2(健全0%を含む唯一のセッション)で、健全ベースラインを差し引いた増分を比較した。

| severity | ΔU 実測 | U モデル(帯) | モデル/実測 |
|---|---|---|---|
| 3.35% | 0.0398 | 0.0725〜0.0932 | **1.8〜2.3** |
| 6.48% | 0.0479 | 0.1501〜0.1699 | **3.1〜3.5** |
| 21.69% | 0.0782 | 0.4198〜0.4369 | **5.4〜5.6** |

I2/I1でも同様(比 1.9〜6.2)。**すべて0.1〜10の範囲内で、基準2は成立する。**

さらに、**ずれの向きと挙動が [docs/161](161_pmsm_model_validation_protocol.md) で事前に宣言した系統誤差と一致した**。

- 向き: モデルが実測を上回る(宣言どおり)
- 挙動: **ずれがseverityとともに拡大する**(1.8倍 → 5.6倍)

これは電流制御器の挙動として自然である。不平衡が大きくなるほど制御器が強く打ち消すため、実測の伸びが頭打ちになる。**モデルの過大評価は、モデルの誤りではなく開ループ仮定の帰結**であると読める。

ただし**これは後付けの説明である**。事前に向きは宣言したが、拡大することまでは宣言していない。整合の根拠としては弱く扱う。

## プロトコルの設計欠陥(基準3)

基準3「指標が健全時の3倍に達するseverityが、モデルと実測で2倍以内」は**評価できなかった**。

モデルは μ=0 で完全対称であり、**健全時の不平衡が0**である。したがって「健全時の3倍」が定義できない。一方、実測機は製造・配線に由来する**健全時不平衡 U=2.75%** を持つ。

事前登録時にこの非対称性を見落とした。基準を作るときは、**モデルと実測で同じ量が定義されるかを確認する**必要がある。記録して次回に持ち越す。

## それでも得られたもの: 実測に基づく1行

モデルは検証されなかった。しかし**実測そのものは残る**。

> **1.0 kW級三相PMSM(EPSアシストモータ・SbW road wheel actuatorと同型・同出力帯)において、
> 巻線間短絡のseverityが3.35% → 21.69% と進むとき、相電流の基本波不平衡は 0.040 → 0.078 と単調に増加する。
> 健全時の不平衡は 2.75% である。**(実測、CC BY 4.0)

これはモデルに依存しない。[docs/153](153_sotif_eooc_assumption_sheet.md) のEooC仮定シートに、
**合成注入([docs/144](144_synthetic_sensitivity_results.md))ではなく実測に基づく行**として追加できる。

同時に、**この量の小ささが重要である**。severityが21.69%(巻線の1/5が短絡)まで進んでも、
相電流不平衡は健全時2.75%から10.6%へ、**わずか4倍にしか増えない**。
制御器が打ち消すため、外から見える変化は小さい。**部品内部で、制御器の内側の量を見なければ観測できない**——
本研究の主張([docs/143](143_recall_detection_results_v2.md), [docs/156](156_train_era_miss_structure.md), [docs/157](157_mode_split_and_corsa_correction.md))が、
4つ目の独立した経路から裏づけられた。

## 次にやるなら

1. **セッション段差の除去**: S1に健全記録がないため、同一セッション内で健全から最大severityまで揃った測定が要る。DS011の1.5 kW / 3.0 kW機で同じ構造が出るかを確認すれば、段差がセッション固有か機種共通かが分かる
2. **閉ループモデル**: 電流制御器を含めれば過大評価が解消するはずである。ただし制御器の設計は公開されておらず、**仮定を1つ増やすことになる**。自由度を増やして合わせるのは [docs/161](161_pmsm_model_validation_protocol.md) が禁じた行為に近い。やるなら制御器パラメータも事前登録する
3. **基準3の作り直し**: モデルにも健全時不平衡(製造ばらつき)を入れる
