# 367. 事前登録 — NASA の指数モデルを、同定できる形で当て直す

[docs/366](366_calibrated_population_results.md) で、run ごとの 7 点への当てはめは縮退した（`a` が上限に張り付く）。
**形は変えず、当て方を変える。**

## 当て方（実行前に固定する）

1. **標本ごとに当てる。**各素子の全標本について、run 1 前半の直線（温度に対する R_on）からの残差を 3σ 単位で取り、
   `ΔR/R0 = 残差 / S`（S = R0 / 3σ、基準温度で）に直す。時間 `t` は標本ごとの通電時間（タイムスタンプの差分、1 分超の空白は除く）
2. **母数を縛る。**`ΔR/R0 = 0.10`（C = 0.953）を初めて越えた時刻 `t10` を、50 標本の走行平均でデータから測る。
   6 素子とも run 5〜7 でこれを越える（run 水準の C から確認済み）。
   モデルを `a = 0.10 / (exp(b (t10 − t0)) − 1)` で縛ると、自由な母数は **`b` と `t0` の 2 つ**になる
3. `b ∈ [0.001, 5] /h`、`t0 ∈ [0, t10)` の格子と最小二乗で当てる
4. **停止条件。**`b` が境界に張り付く、または `t0` が 0 か `t10` の端に張り付いた素子は「同定失敗」とし、その母数は個体群に使わない。
   **同定できた素子が 4 未満なら、個体群の段は走らせずに終える**

## 個体群（docs/365 との差だけ）

| 項目 | docs/365 | 本件 |
|---|---|---|
| `a`, `b` の散らばり | 縮退した当てはめの対数正規 | 同定できた素子の `b` の対数正規。`a` は `t_fail` から縛る |
| 故障 | C = 0.894（ΔR/R0 = 0.25） | 同じ。`t_fail = t0 + ln(0.25/a + 1)/b` |
| 健全個体の走行 | 20 時間 | **実素子の健全期（run 1〜4）の通電時間の中央値**。漂流の総量 0.351 はその長さに対して |
| 劣化個体の走行 | 故障 + 1 時間、上限 200 | 同じ |

## 事前登録する予想（手計算で決まらない量だけ）

| | 予想 | 外れる条件 |
|---|---|---|
| **V1** | 同定できる素子は **5 以上 / 6** | 4 以下 |
| **V2** | 同定できた素子の `b` の最大/最小は **10 倍以内** | 10 倍超 |
| **V3** | 劣化個体で、C = 0.894 の前に警報が出る割合 **≥ 90%** | 90% 未満 |
| **V4** | 健全個体の誤検知率の中央値は線（2.7 件/時）の **2 倍以下** | 2 倍超 |

V4 は docs/344・348 から見て外れる可能性が高い。**それでも置く。**外れれば「ウォークの漂流では 1 時間の登録では足りない」が
較正した個体群でも再現される、という結果になる。

## 何もしない基準（T34）

docs/366 の縮退した個体群（検知 88.4%、健全の誤検知 310 件/時）と、docs/344 の直線の劣化（検知 95〜100%、誤検知 12〜39 件/時）。

## やらないこと

- 同定失敗の素子を、境界の値のまま使わない
- 外れた予想を層別で救わない（T17）
