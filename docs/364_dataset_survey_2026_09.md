# 364. 公開データの再調査（2026-09-14）。劣化側の N を 6 から増やせる公開データは見つからなかった

前回の棚卸しは 2026-08-30〜31（[data/dataset_prospect.tsv](../data/dataset_prospect.tsv)、8 候補を評価して取得ゼロ）。
ユーザ指摘「数件程度しか扱ってないのが非常に気になる」「N が少なくていい理由はほぼない」を受けて、
**壊れるまで追った個体が数十あるパワー半導体の公開データ**を探し直した。

## 探した場所と、見つかったもの

| 場所 | 見つかったもの | 判断 |
|---|---|---|
| NASA PCoE ミラー（21 セット） | パワー電子は #8 IGBT、#12/#14 コンデンサ、#13 MOSFET の 4 つだけ。**全部使用済み** | 新規なし |
| IEEE DataPort | gEOL パワーサイクル（Aalborg、2023）: **8 個体、Vce のみ、購読制**。「IGBT」: GaN/SiC/IGBT 各 1 個体（オープン） | 購読制は公開データではない。N も増えない |
| Zenodo / Mendeley Data | パワー半導体の run-to-failure は無し。Mendeley の IGBT RUL は NASA IGBT の派生 | 新規なし |
| arXiv 2403.13694（劣化データセットの総覧、2024/2025） | ベアリング・電池・工具・エンジンが中心で、**パワー電子の項目なし** | 新規なし |
| 国内（パワーサイクル試験 公開データ） | 受託試験サービスの案内のみ | 新規なし |
| 論文の Data Availability（MDPI Energies 2024、SiC パワーサイクル） | 本文を取得できず（403） | 未確認 |

## 結論

**2026-09-14 時点で、劣化側の N を 6 から増やせるオープンな公開データは無い。**
健全期の統計だけは、同じ NASA データの 40 テストで測った（[docs/363](363_population_results.md)）。

## 成立に要るもの（[docs/363](363_population_results.md) と合わせて）

| 主張 | 今 | 成立に要るもの |
|---|---|---|
| 検知率 | 6/6（存在証明） | 30 個体で全検知なら「95% 信頼で 90% 以上」。100 個体なら 97% 以上（rule of three） |
| 誤検知率 ≤ 2.7 件/時 | 健全区間が最短 0.25 時間、4 件/時より細かく測れない | 個体あたり 1.1 時間以上の警報ゼロの健全区間（上限 λ を 95% で言うには 3/λ 時間） |
| 閾値の翻訳の実用性 | S が 1 ロットで 5.8 倍ばらつく | 複数ロット・複数ベンダの健全期データ |
| 同種チャネル差分が本物の劣化に効くか | 人為故障 8 件のみ | 同じ種類のチャネルを持つ実回路で本物の劣化を追ったデータ。**1 件も無い** |

## 限界

- MDPI の 1 本は本文を取れておらず、データ提供があるか未確認
- Aalborg の研究ポータル（データセット一覧）も 403 で見られていない
- 検索は英語と日本語で行い、中国語・ドイツ語は行っていない
