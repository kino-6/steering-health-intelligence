# 347. 事前登録 — 実素子の漂流は、どういう形をしているか

## なぜこれを次に置くか

[docs/346](346_drift_removal_results.md) が止まった場所は 1 つである。

> **仮想では 1.5 件/時 の手立てが、実素子では 4 万件/時 になる。**
> **漂流をランダムウォークで模したのが違っていた。どう違うかは測っていない。**

**模型を当てるまで試すのは事後の探索である**（[TROUBLES.md](../TROUBLES.md) T17）。
**先に実物の形を測り、それから模型を直す。**

## 測るもの（3 つ。実行前に固定する）

いずれも、健全区間（run 1〜4）の残差（動作点の直線を引いた後、床で割ったもの）に対して行う。

| | 何を測るか | 何が分かるか |
|---|---|---|
| **S1 分散の伸び方** | 窓長 n に対する「n 標本での変化量」の分散。両対数の傾き α | **α ≈ 1 ならランダムウォーク。α ≈ 0 なら定常。α ≈ 2 なら直線的な傾向** |
| **S2 増分の自己相関** | 1 次の自己相関 ρ₁ | **ρ₁ ≈ 0 なら独立増分（ウォーク）。ρ₁ < 0 なら平均回帰（戻る漂流）** |
| **S3 動作点との関係** | 残差と動作点（パッケージ温度）の相関、および残差と温度の 2 乗の相関 | **直線で引き切れていない温度依存が残っているか** |

**3 つとも記述である。合否の基準は置かない。**（[TROUBLES.md](../TROUBLES.md) T40——恒等式を基準にしない）

## 読み方は先に固定する

| | 読み方 |
|---|---|
| α が 0.8〜1.2 | ウォークの模型は妥当。**違いは別のところにある** |
| **α が 1.2 を超える** | 健全区間にも傾向がある。**「健全期の漂流」と呼んでいたものが、実は緩やかな傾向である** |
| α が 0.8 未満 | 定常に近い。**ウォークは実物より暴れている** |
| ρ₁ が負 | **戻る漂流。**採り直しが効きにくい理由になりうる |
| S3 に相関が残る | **温度で説明できる。**直線を 2 次にすれば消える可能性がある |

## 手順

1. 6 素子それぞれで、run 1〜4 の残差を出す
2. 窓長 n = 10, 30, 100, 300, 1000, 3000 で S1 を測り、両対数の傾き α を出す
3. 残差の 1 標本差分の 1 次自己相関 ρ₁ を出す
4. 残差と動作点、残差と動作点の 2 乗の相関を出す
5. **同じ 3 つを仮想モジュールの健全個体でも測り、並べる**

**仮想と実物を同じ物差しで並べることが、この文書の目的である。**

## この事前登録が外れる条件

- 窓長の刻みは私が置いた（[TROUBLES.md](../TROUBLES.md) T2）
- **run 1〜4 を健全とみなしている。**実際にいつから劣化しているかは分からない
- 6 素子・1 試験機。**率ではなく存在証明**
- **この文書は模型を直さない。**形を測るだけである。直すのは次の事前登録
