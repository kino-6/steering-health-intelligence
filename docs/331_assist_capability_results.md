# 331. アシストは検出時点で 7%、故障直前で 11% 落ちる。数字は出た

[docs/330](330_assist_capability_protocol.md) の事前登録を実行した。**追加取得ゼロ。**

> **「アシストが何 % 落ちるか」は計算できた。10 回以上「不可能」と書いてきたのは私の誤りである。**
>
> | | アシスト能力 C（中央値） | 落ちる分 |
> |---|---|---|
> | 健全期 | 1.000（散らばり **0.6%**） | — |
> | **検出器が最初に鳴った時点** | **0.932**（0.887〜0.980） | **約 7%** |
> | 故障直前の run | **0.892**（0.827〜0.924） | **約 11%** |
>
> **落ちる量は計算自身の雑音の 12 倍**なので、雑音ではない。
> **ただしこれは計算であって測定ではない。**導通損しか見ていない。

実行: `python3 scripts/assist_capability.py` / 数表: [data/assist_capability.tsv](../data/assist_capability.tsv)

## 何を計算したか

[docs/192](192_str_capability_rule_protocol.md) が既に導いていた式である。**新しい仮定は足していない。**

```
導通損で制限されるとき  I_max = √( (Tj_max − T_amb) / (Rth · R_on) )
  ⇒  アシストトルク ∝ 1/√(R_on)
  ⇒  C = √( R_on(健全期) / R_on(t) )        Tj_max と T_amb は約分で消える
```

**教師ラベルは要らない。**必要なのは R_on の時間変化だけで、それは 6 素子 × 7 run 分ある。

**健全期（run 1〜4）は 6 素子とも 1.000 の周りに収まる。**散らばりは中央値 **0.006**。
**これがこの計算自身の雑音である。**
Test_10 だけ 0.071（他の 12 倍）で、**run 1 の当てはめが壊れている**（傾きの符号が他の run と逆）。
**この素子の数字は他より信用できない。**

事前登録した読み方では **A2 = 0.932 は 0.80〜0.95 の間**なので、**数字のまま報告する。**

## 途中で 2 回、自分の規則に引っかかった

**1 回目——基準温度の取り方。**最初は重なる温度範囲の中点を基準にした。**測ったら各 run の下位 0.4〜3.6 パーセンタイルだった。**
標本の 96% 以上がその上にあり、**実質は冷側の裾への外挿**である。
**重なり内の標本の中央値**に直した（123〜140°C）。

**2 回目——物理範囲。**基準を run 1 単独に取ったため、健全期の当てはめ雑音がそのまま偏りになり、
**5 素子で C が 1 を超えた**（新品より抵抗が低い、という意味になる）。
**[docs/325](325_extrapolation_direction_results.md) で仕様に足したばかりの規則に、自分で引っかかった。**
基準を**健全期（run 1〜4）の中央値**に直すと、雑音は 1 の周りの散らばりとして見えるようになった。

## この数字が意味すること

**検出は機能低下に先行しない。**鳴った時点で既に約 7% 落ちている。
**しかし発火から故障までに追加で失うのは 4 百分点しかない。**

> **故障直前でも、導通損から計算されるアシストの低下は 11% にとどまる。**
> **素子は壊れかけているのに、この経路では 11% しか説明できない。**

**読み方は 2 つあり、このデータでは分けられない。**

| | |
|---|---|
| **(a)** | 実際にアシストは故障直前まで 11% しか落ちない。**機能への影響は小さいまま壊れる** |
| **(b)** | 故障の機構が導通損ではない（熱暴走・ゲート破壊など）。**式が見ていない経路で失われている** |

**(a) と (b) を分けるには、機能出力の実測が要る。**
[docs/303](303_ml_construction_plan.md) の目標 C は依然として埋まっていない。**この文書はそれを代替しない。**

## 仕様への影響

**ECU が実行時に能力値を名乗る話ではない。**そこは変わらず名乗らない（禁止語の筆頭）。
**変わるのは、SOTIF への説明で「この記録がどれだけの機能低下に対応するか」を数字で言えるようになったことである。**

> **逸脱がこの個体の床の N 倍のとき、導通損から計算されるアシスト能力は C である。**
> **換算は出荷時に固定でき、出荷時基準値に追加の情報は要らない**（R_on と動作点は既に記録している）。
> **ただしこれは計算であり、機能出力の実測ではない。**

## 残る限界

- **導通損しか見ていない。**スイッチング損・ゲート駆動・巻線・機械系は入っていない
- **Rth 一定を仮定している。**[docs/199](199_pulse_thermal_results.md) はダイ本体で k ≒ 1 を測ったが、**ダイアタッチは 400 µs の窓で触れていない**
- **Test_10 の run 1 の当てはめが壊れている**（散らばり 0.071）。原因は特定していない
- 対象は**単体 MOSFET であって EPS ではない**。6 素子・1 試験機。**率ではなく存在証明**
- **(a) と (b) を分けられない。**この計算だけでは、11% が実態なのか式の射程外なのか決まらない

## Rule Check

- **基準温度が裾に落ちていることを、結果を出す前に測って直した**（T1）
- **自分が仕様に足したばかりの物理範囲の規則に引っかかったことを、隠さず節にした**（T31 の逆）
- **11% を「機能低下は小さい」と読まず、(a)(b) を分けられないと書いた**（T27——消去法で残ったものを選んだものとして報告しない）
