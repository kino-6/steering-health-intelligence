## なぜこの 3 素子か — 閾値の問題ではない

[docs/299](299_bank_results.md) の診断が説明している。

| 素子 | run 1→4 の健全期の漂流 | 本物の立ち上がり | 大小関係 |
|---|---|---|---|
| Test_8 | −0.07 → −0.10 | **run 5 で +1.38** | **立ち上がりが漂流の 14 倍** |
| Test_14 | −0.04 → −0.01 | **run 5 で +1.48** | **同 100 倍以上** |
| Test_9 | −0.08 → −0.19 | run 6 で +1.04 | 漂流が 0.19、立ち上がりまで 2 run 遠い |
| Test_11 | −0.06 → −0.24 | run 6 で +0.69 | **漂流 0.24 と立ち上がり 0.69 が同じ桁** |
| Test_12 | −0.04 → −0.21 | run 6 で +0.71 | 同上 |

> **落ちる 3 素子は、健全期の漂流と劣化の立ち上がりが同じ桁である。**
> **水準に閾値を置くかぎり、この 2 つは分けられない。**
> **境界を足しても、指紋を採り直しても、水準を見ていることは変わらない。**

## 次の候補（[docs/314](314_boundary_vs_refresh_protocol.md) が求めた 1 つ）

**大きさではなく、形で分ける。**

- 健全期の漂流は**単調で遅い**（4 run かけて 0.2 床）
- 劣化の立ち上がりは**加速**である（1 run で 0.7〜1.5 床）

> **候補: 水準の閾値ではなく、遅い側の系列に対する変化点検出（傾きの変化）を見る。**
> **健全期の漂流は傾きが一定、立ち上がりは傾きが変わる。**
> これなら、漂流と立ち上がりが同じ「大きさ」でも分けられる可能性がある。
