# 332. 事前登録 — パワーモジュールの推定モデルを、ECU が実際に持つ数字だけから組む

## 何を作るのか

[docs/331](331_assist_capability_results.md) は **実験室の全精度データ**から C を計算した。
**ECU が持っているのはそれではない。**持っているのは 30 バイトの記録である
（[docs/319](319_unit_trace.md) の実バイト列）。

> **問い: 30 バイトの記録と 56 バイトの出荷時基準値だけから、アシスト能力 C を推定できるか。**

**これが「パワーモジュールの推定モデル」の実体である。**
モデルとは、逸脱（自分の床いくつぶん）から C への写像であり、**係数は出荷時に決まる。**

## 写像

出荷時基準値は `R_on ≒ a·T + b`（傾き・基準値）と床 `g` を持っている。記録は逸脱 `d`（床いくつ分）を持つ。

```
R_on(t)   = a·T + b + d·g          記録から復元
R_on(base) = a·T + b               出荷時基準値そのもの
C = √( R_on(base) / R_on(t) ) = √( 1 / (1 + d·g / (a·T + b)) )
```

**出荷時基準値に追加の情報は要らない。**`a`・`b`・`g` は既に 56 バイトに入っている。
**追加で要るのは何も無い。**

## 何を確かめるのか

**復元が、量子化と記録形式を通しても生き残るか。**

| 落ちる要素 | どこで効くか |
|---|---|
| 逸脱 `d` は float32 で記録される | 30 バイトの `deviation` |
| 動作点 `T` も float32 | 30 バイトの `operating_point` |
| **電流測定は 8 ビット**（[docs/261](261_no_data_decisions_results.md)） | R_on の推定そのもの |
| **バスに出るのは 8 ビット・0.1 床刻み・25.5 で飽和** | [docs/318](318_unit_ledger.md) の 2 バイトフレーム |

## 手順

データ: NASA MOSFET、6 素子 × 7 run。

1. [docs/331](331_assist_capability_results.md) の C を**真値**とする（全精度の R_on から計算したもの）
2. 各素子を [scripts/eps_health_recorder.py](../scripts/eps_health_recorder.py) に通し、**記録される 30 バイトを実際に作る**
3. その 30 バイトと 56 バイトの出荷時基準値**だけ**から上の式で C を復元する
4. 真値との差を、**run ごと・素子ごと**に出す
5. **バスの 2 バイト（0.1 床刻み、25.5 飽和）からも復元し、同じ差を出す**

## 事前に決める判定

| | 基準 |
|---|---|
| **M1 不揮発の記録から** | 復元した C と真値の差の中央値が **0.01 未満**（アシスト 1%）。健全期の散らばり 0.006 と同じ桁 |
| **M2 バスの 2 バイトから** | 同じく **0.02 未満**（アシスト 2%）。0.1 床刻みの量子化分だけ粗くなるはず |
| **M3 飽和** | 逸脱が 25.5 床を超える run があるか。**あるならバスからは復元できないと書く** |

**M1 が外れたら、30 バイトでは足りないということであり、何を足せば足りるかを数える。**
**当てて回るのではなく、足りない量を数える。**

## この事前登録が外れる条件

- **C の真値自体が計算であって測定ではない**（[docs/331](331_assist_capability_results.md)）。
  **ここで確かめるのは「ECU の数字から同じ計算ができるか」であって、その計算が正しいかではない**
- **8 ビット電流測定の効きは、このデータでは測れない。**NASA の記録は既に別の分解能で取られている。
  **量子化の影響として測れるのは、記録形式（float32、0.1 床刻み、25.5 飽和）の分だけである**
- 単体 MOSFET・6 素子・1 試験機。**EPS ではない。率ではなく存在証明**
- **モデルと呼ぶが、学習していない。**係数は出荷時基準値そのものである（[TROUBLES.md](../TROUBLES.md) T32——検出器をモデルと呼ばない）
