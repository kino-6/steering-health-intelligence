# 275. 事前登録 — 現場の苦情は、機構について何を言っているか

> [docs/274](274_why_windings_audit.md) が明らかにしたこと: **本研究がデータを持つ2機構は、
> どちらも現場記録がEPSの主要機構として挙げていない。**
> 挙げているのは**断続的な電気症状(2.81倍)と接点の劣化(1.63倍)**である([docs/171](171_eps_wearout_mechanism_scan.md))。
>
> **その機構の公開データを4つの軸で探して、見つからなかった。**

| 探索軸 | 結果 |
|---|---|
| 接点のフレッティング腐食の run-to-failure | **公開データセット無し。**論文はあるが生データが公開されていない |
| 自動車コネクタ・端子の劣化試験 | **同上** |
| はんだ接合の断続(IPC-9701 の事象検出器) | **同上。**手法は標準化されているが公開データが無い |
| NASA PCoE 全21件の一覧 | **接点・コネクタ・はんだ・断続のものは1件も無い**([PHM Society ミラー](https://data.phmsociety.org/nasa/)で全件確認) |

**接点劣化の公開データはSOReDDのみであり、それは既に閉じている**
([docs/174](174_contact_variance_results.md): 終端事象が固着で、漸進劣化の経路が無い)。
> **待たない。**軸を反転する。

**追加取得ゼロ。** NHTSA FLAT_CMPL(取得済み)。

## 問いの反転

| 旧い問い(待つ形) | 新しい問い(決める形) |
|---|---|
| 断続的な接続不良の計測データはあるか | **現場の記述は、その機構について何を言っているか** |

**[docs/251](251_field_timescale_results.md) は時間尺度と復帰方法を取り出した。**
**取り出していないのは「修理で何が見つかったか」である。**
**これは機構についての現場の証言であり、[docs/274](274_why_windings_audit.md) が空白だと指摘した
「なぜその機構を狙うのか」に直接答える。**

## 標本(実行前に固定)

[docs/250](250_field_timescale_protocol.md) と**同一の選別規則**を使う。変えない。

- `COMPDESC` に `STEERING`、本文に 電動・アシスト喪失・断続 の3語
- **油圧の語で除外**(ユーザ指示)、外力の語で除外

## 抽出する量(実行前に固定)

本文から、**修理・点検で何が見つかったか/交換されたか**を示す語を数える。

| 機構の分類 | 語 |
|---|---|
| **接続・配線** | `WIRING`, `HARNESS`, `CONNECTOR`, `TERMINAL`, `PLUG`, `PIN`, `GROUND`, `CORROSION`, `LOOSE` |
| **電子制御ユニット** | `ECU`, `MODULE`, `CONTROL UNIT`, `CIRCUIT BOARD`, `PCB`, `SOLDER` |
| **モータ** | `MOTOR`, `WINDING`, `ARMATURE`, `BRUSH`, `COMMUTATOR` |
| **センサ** | `TORQUE SENSOR`, `SENSOR`, `POSITION SENSOR` |
| **機械部** | `RACK`, `PINION`, `COLUMN`, `COUPLER`, `SHAFT`, `BEARING` |
| **電源** | `BATTERY`, `ALTERNATOR`, `FUSE`, `RELAY`, `VOLTAGE` |

**1件が複数に該当してよい。重複を隠さず報告する。**

## 判定基準(実行前に固定)

| # | 基準 | 閾値 |
|---|---|---|
| **F1** | 断続症状の苦情のうち、**接続・配線**に言及する割合 | 記述。**操舵系苦情全体との比(lift)を併記** |
| **F2** | 機構分類の順位が、[docs/171](171_eps_wearout_mechanism_scan.md) のリコール分析と**一致するか** | 上位2つが一致すれば一致とみなす |
| **F3** | **モータ・巻線**への言及割合 | 記述。**本研究が対象にしている機構が現場でどれだけ出るか** |

**F2が一致すれば、2つの独立な公開記録(リコール届出と消費者苦情)が同じ機構を指すことになる。**
**一致しなければ、どちらを信じるかを決められない。そう書く。**

---

## この検定が答えないこと(先に書く)

- **自己申告の自由記述である。**修理結果が書かれるとは限らず、**言及率であって発生率ではない**
- **語の照合であり、因果ではない。**「配線を交換した」と「配線が原因だった」は別
- **これはEPSの故障機構を決定しない。**決めるのは「現場の記述が何を挙げているか」だけである
- **機構が分かってもデータは生まれない。**R12・R13は未達のまま

## 失敗したときに何を言うか

**F2が一致しなければ**、「リコール届出と消費者苦情が別の機構を指す」と書き、
**本研究の対象機構の選定根拠は、依然として空白である**と記録する([TROUBLES.md](../TROUBLES.md) T27)。
