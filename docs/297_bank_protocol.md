# 297. 事前登録 — 平均長 N を「選ぶ値」から外す

> [docs/296](296_loo_results.md): N は素子により 100〜500 でばらつき、他個体から持ち込んだ閾値は 1 素子で誤報 1,817 倍。
> **N を選ばず、複数の N を並列に走らせ、閾値はその個体自身の健全区間から取る。**

**追加取得ゼロ。** NASA PCoE MOSFET、7 run 全部。

## 手順（実行前に固定）

1. 平均長の**バンク** {100, 200, 500} を同時に走らせる。**選ばない。3 本すべて常時**
2. 閾値は **その素子自身の**運用区間の最初の 1/4（健全区間）から、誤報 1 件/時で取る。**他素子を一切使わない**
3. **バンク 3 本を OR で束ねるので、要求率を 3 で割ってから較正する**（[docs/294](294_unit_level_false_alarm.md) T33）
4. 発火 = 3 本のどれかが閾値を越えた最初の点

## 判定基準（実行前に固定）

| # | 基準 | 閾値 |
|---|---|---|
| **B1** | 故障前に鳴る素子 | **6 中 5 以上** |
| **B2** | 健全区間（閾値を取った区間の外側、run 2〜4 相当）での誤報 | 設計値の 3 倍以内、**6 素子すべて** |
| **B3** | 初発火の run | 記述。[docs/295](295_all_seven_runs.md) の run 4〜5 と比べる |

**B2 は素子ごとに見る。**1 素子でも大きく外れれば不成立。
**B1 と B2 の両方が要る**（T28）。

## 答えないこと
- 同じ試験機・型番の中。EPS への汎化ではない
- 6 素子。B1 の 5/6 と 4/6 の差は 1 素子

---

## 追記（実行後に見つかった手順の欠陥。1 回限りの改訂）

**「運用区間の最初の 1/4 を健全区間とする」は、この記録では成り立たなかった。**
run 5〜7 は run 1〜4 の 5〜7 倍の標本を持つため、**標本数の 1/4 は run 5 の途中に落ちる。**
較正区間に run 5（[docs/295](295_all_seven_runs.md) が立ち上がりを置いた run）が 2,000〜6,000 標本入り、
B2 の評価区間は 6 素子とも空になった。**この定義のまま得た B1 5/6 は、閾値が劣化の立ち上がりを一部吸っており、採用しない。**

**改訂（区間を標本の割合ではなく run 境界で定義する）**

| 区間 | 定義 |
|---|---|
| 指紋 | run 1 の前半（不変） |
| 較正（閾値。素子・N ごと） | run 1 の後半 + run 2 + run 3 |
| B2 健全評価 | **run 4 のみ**（[docs/295](295_all_seven_runs.md) で 6 素子とも中央値が床の 0.24 倍以内。較正と重ならない） |
| 検出探索 | run 5 の先頭から終端まで |

バンク・要求率・clamp 規則・OR は不変。**較正が短くなる（約 5,000〜7,000 標本）ため clamp が強く効く。達成率はそのまま報告する。**

**教訓**: 「記録の何割」という区間定義は、記録の密度が一様でないと意味を変える。**区間は物理的な境界（run）で切る。**
