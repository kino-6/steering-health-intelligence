# 264. 事前登録 — 記録器を、今の答えのとおりに作り直す

> `scripts/eps_health_element.py`([docs/196](196_eps_health_element.md))は、**能力値を出す要素**として書かれている。
> その能力値は [docs/199](199_pulse_thermal_results.md) で物理が成立せず、
> [docs/203](203_cross_machine_replication_results.md) で機体をまたがず、**取り下げてある。**
>
> **コードと答えが食い違ったまま置いてある。**これを直すのが本作業である。

**追加取得ゼロ。** NASA MOSFET と KAIST PMSM(いずれも取得済み)。

---

## 何を作るか

[docs/225](225_recorder_specification.md) の仕様どおりの記録器。**能力値を出さない。**

**出荷時(1回)**
```
その個体の、観測量と動作点の関係(直線1本)、基準動作点、掃引した動作点範囲、出荷時の床
```

**運用時(常時)**
```
残差   = 実測 − (直線が予測する値)
逸脱   = |残差| / その個体の床
5秒窓で 平均と最大の両方。発火したら窓を事象の終わりまで伸ばす
動作点が掃引範囲の外なら「宣言しない」を返す
```

**出力1件**: 逸脱・粒度・妥当性・動作点・キーオンからの経過時間・キーオフまで持続したか

## 判定基準(実行前に固定)

| # | 基準 | 閾値 |
|---|---|---|
| **M1** | 実装が能力値を一切出さないこと。仕様の7つの禁止事項を出力に含まないこと | **機械で検査する。**出力の欄名を列挙して照合 |
| **M2** | 出荷時の指紋が **36バイト以内**に収まること。実際にバイト列へ詰めて測る | 36バイト |
| **M3** | 掃引範囲の外で「宣言しない」を返し、**範囲内では返さない**こと | **範囲外での沈黙率 100%、範囲内での沈黙率 0%** |
| **M4** | 入力を8ビットに量子化しても、**逸脱の判定が一致する**こと | **一致率 99%以上**(6素子+KAIST) |
| **M5** | 1事象の記録が **27バイト以内**に収まること。実際に詰めて測る | 27バイト |

**M2・M5は「計算上そうなる」ではなく、実際に `struct` で詰めて `len()` を測る。**
[docs/196](196_eps_health_element.md) の36バイトは float32×9 という**計算**であり、
**詰めて確かめていない。**

## この実装が示さないこと(先に書く)

- **EPS実機で動かしていない。**同型機構の公開データを入力にする
- **注入した事象は本物ではない。**M3・M4は注入で検査する
- **能力値を出さないことは、能力値が出せないことの証明ではない。**
  出せないと判断した根拠は [docs/203](203_cross_machine_replication_results.md) にある

## 失敗したときに何を言うか

- **M2かM5が落ちれば**、[docs/225](225_recorder_specification.md) のバイト数を改訂する。**丸めない**
- **M3が落ちれば**、「宣言しない」の判定規則が仕様どおりでない。規則を書き直す
- **M4が落ちれば**、[docs/261](261_no_data_decisions_results.md) の「8ビットで足りる」は
  **床の話としては正しくても、判定の話としては足りない**ことになる。8ビットという数字を改訂する
