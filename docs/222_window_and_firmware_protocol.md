# 222. 窓平均は実車でどれだけ効くか、firmwareは床を動かすか — 事前登録

**結果を1つも見る前に書き、単独でコミットする。**

## なぜやるか

[docs/221](221_real_vehicle_granularity_results.md) は実車の床を**標本あたり 0.19〜0.24 m/s²**と測った。
そして「窓で平均すれば床は下がる」と書いた——**が、どれだけ下がるかは測っていない。**

**これは既存の主張に直結する。**
[docs/144](144_synthetic_sensitivity_results.md) / [docs/155](155_window_recurrence_verification.md) は
合成注入で「**0.10 m/s² の定常オフセットを90%検出**」を示し、それが EooC仮定シートの
「観測できる機能不足の粒度」欄の根拠になっている([docs/153](153_sotif_eooc_assumption_sheet.md))。

**白色雑音なら床は 1/√N で下がる。しかし路面外乱は相関を持つ。**
相関があれば平均しても床は下がりきらず、**必要な窓は 1/√N の予想よりずっと長くなる。**

もう一点。commaSteeringControl で **AUDI Q3 のみ EPS firmware が2版**含まれている(745ログ / 255ログ)。
**firmwareが床を動かすなら、個体基準はfirmware更新のたびに取り直す必要がある。**

## データ

commaSteeringControl、4車種2,495ログ。**10 Hz、1ログ60秒(599標本)。**
残差は [docs/221](221_real_vehicle_granularity_results.md) と同一:

```
e = latAccelLocalizer − latAccelDesired      latActive かつ not steeringPressed の標本のみ
```

**動作点正規化は使わない。**[docs/221](221_real_vehicle_granularity_results.md) が実車では効かないことを示したため。

## 問いA: 窓平均の効き

各ログについて、重なりのない N標本ブロックの平均を取り、その散らばりを測る。

```
g(N) = 3 × 1.4826 × MAD( N標本ブロック平均 )
r(N) = g(N) / ( g(1) / sqrt(N) )        白色雑音なら 1
```

N = 1, 2, 5, 10, 20, 50, 100(= 0.1秒 〜 10秒)。

**併せて「g(N) が 0.10 m/s² を下回る最小の N」を報告する。**
docs/144 / docs/155 が検出できるとした量に、実車で必要な窓長を対応させる。

## 問いB: firmwareは床を動かすか

**AUDI Q3 のみ**が2版を持つ(他3車種は1版)。両群のログごとの `g(1)` 中央値を比べる。

## 判定基準(いま固定する)

| # | 基準 | 閾値 |
|---|---|---|
| **W1 相関の有無** | `r(100)` が **1.5以上** | **4車種すべてで成立すれば「平均は白色雑音の予想ほど効かない」と判定** |
| **W2 必要窓長** | `g(N) < 0.10 m/s²` となる最小 N | **報告のみ。到達しなければ「10秒では届かない」と書く** |
| **W3 firmware** | AUDI Q3 の2群の `g(1)` 中央値の比が **1.2以上** | **成立すれば「firmwareは床を動かす」と判定** |

- **W1が落ちたら、残差は白色雑音に近く、平均は予想どおり効くと書く。**その場合 docs/144 の主張は補強される
- **W3は1車種でしか検定できない。**成立しても「1車種で観測された」までとする
- **v2は作らない**

## 事前に認めておくこと

- **残差はEPSの測定量ではない**([docs/220](220_real_vehicle_granularity_protocol.md))。
  制御器の追従誤差・路面外乱・推定誤差を含む
- **1ログ60秒。**N=100(10秒)より長い窓は1ログ内で5ブロックしか取れない。**N の上限を100に固定する**
- **firmwareの比較は交絡する。**版が違えば車両個体・走行条件も違う可能性があり、分離できない
- **4車種のみ。**openpilot搭載車であり一般の分布ではない
- **故障ラベルが無い。**検出能力ではなく床を測っている

## Rule Check

- **W1が落ちた場合に docs/144 の主張が補強されることを先に書いた。**自分に不利な向きだけを想定しない
- N の上限を先に固定した(1ログ60秒という制約から)
- **firmwareの比較が交絡すること**を先に認めた
- W3が1車種のみであることを先に書いた
