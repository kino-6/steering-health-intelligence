# 362. 事前登録 — 健全期の統計を、6 素子ではなく 42 素子で測り直す

2026-09-13 ユーザ指摘: **「数件程度しか扱ってないのが非常に気になる」**

そのとおりで、これまでの結論は 6 素子と試験機 1 台の存在証明である。
NASA の MOSFET データ [SOURCES S8] には **42 テスト**があり、7 run 揃った run-to-failure が 6 だけなので 6 素子を使ってきた。
しかし **健全期の統計（測定ノイズ σ、漂流の形 α、信号対雑音 S）は run 1 だけあれば測れる。**
42 テストすべてに run 1 がある（走査 2026-09-13: run 数の分布は 1 run が 20、2 run が 11、3 run が 2、4 run が 1、5 run が 2、7 run が 6）。

**追加取得はしない。**すでにあるデータの、使っていなかった 36 テストを使う。

## 何を測るか

各テストの run 1 の前半で直線を当て（現行と同じ）、run 1 の残りで:

| 量 | 定義 | 6 素子での値 |
|---|---|---|
| σ | 残差のロバスト標準偏差（MAD × 1.4826） | 6 素子の中央値 0.2208（床 = 3σ で 0.351 の漂流） |
| S | R0 / (3σ)、基準温度で | 7.3〜8.3（最大/最小 1.14 倍） |
| α | 残差の走行平均の分散の伸び方（log-log 傾き） | 1.32（1.18〜1.48） |
| 傾き | R_on の温度係数 | 0.008244 |

基準温度は各テストの run 1 の動作点の中央値とする（run 間の重なりが無いテストがあるため）。

## 事前登録する予想（件数と範囲で書く）

| | 予想 | 外れる条件 |
|---|---|---|
| **P1** | 42 テストの S の最大/最小は **3 倍以内**に収まる（6 素子の 1.14 倍より広がるが、桁は変わらない） | 3 倍超 |
| **P2** | 42 テストの α の中央値は **1.1〜1.5** に入る（健全期も傾向を持つ、が 6 素子だけの性質ではない） | 範囲外 |
| **P3** | 42 テストのうち、傾きの符号が負になる（出荷時の当てはめが壊れる）ものは **6 個以下**（Test_10 の 1/6 = 17% を上限とみる） | 7 個以上 |
| **P4** | 6 素子の値は、42 テストの分布の **10〜90 パーセンタイルの中**に入る（σ、S、α とも中央値で） | どれか 1 つでも外 |

**何もしない基準**（T34）: 6 素子の値そのもの。42 で測って 6 と同じ幅なら「N を増やしても何も変わらない」が答えになる。

**手計算で決まらない量だけを予想にした**（[TROUBLES.md](../TROUBLES.md) T45）。

## これで答えられないこと

- **劣化の側の N は 6 のまま**である。run-to-failure が 6 しか無い。検知率・警報時点の能力は増えない
- 42 テストは同じ型番・同じ試験機で、母集団の代表ではない
- run 1 の長さがテストごとに違い、α の推定精度が揃わない。長さは結果に添える

## やらないこと

- 42 テストのうち都合の良い部分集合を選ばない。run 1 があるものは全部使う
- 外れた予想を層別で救わない（T17）
