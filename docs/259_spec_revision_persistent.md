# 259. 記録器仕様の改訂 — 現場の事象の形に合わせる

[docs/225](225_recorder_specification.md) を改訂した。**追加取得ゼロ。**

> **改訂の理由は、新しいデータではない。**
> **根拠は仕様書の中に最初からあったのに、設計がそれに従っていなかった。**

## 何が起きていたか

[docs/213](213_trigger_conditions_results.md)(2026-08-30)は苦情9,909件からこう書いた。

> **「瞬間的」より「再始動まで続く」の方が4倍以上多く書かれている。**(12.5% 対 2.8%)

[docs/225](225_recorder_specification.md) の「3-2. 記録の窓」は、**この行を根拠として引用した上で、
窓長を5秒に固定した。**そして [docs/243](243_intermittent_injection_protocol.md) は
**0.1〜2.0秒の事象**を注入して検出率を測った。

**手元の根拠が「キーサイクルまで続く」と言っているのに、設計と検証は「2秒以下」で組まれていた。**

[docs/251](251_field_timescale_results.md) が同じ苦情を別の切り口で数え直して、ようやく気づいた——
経過時間が読めた28件のうち**注入格子に入ったのは0件**、中央値**20分**、
**622件が明示的に「イグニッションを切るまで戻らなかった」と書いている。**

**新しい失敗の型として [TROUBLES.md](../TROUBLES.md) に T19 を立てた。**

## 改訂した4点

### 1. 窓 — 5秒は下限であって、上限が無かった

誤検出1件/時に揃えたときの、90%検出に要る最小振幅([docs/253](253_persistent_event_results.md)):

| 事象の長さ | 窓を事象に合わせる | **5秒固定** | 捨てている分 |
|---|---|---|---|
| 2秒 | 8.5床 | 11.5床 | 1.4倍 |
| 5秒 | 4.5床 | 4.5床 | — |
| 10秒 | 2.5床 | 4.5床 | 1.8倍 |
| **20秒** | **1.5床** | 4.5床 | **3.0倍** |

**5秒窓は、事象が5秒を超えると、それ以上長くなっても何も得しない。**

> **改訂: 5秒窓で常時見張り、発火したら事象の終わりまで窓を伸ばして測り直す。**

### 2. 記録項目 — 現場が報告している2つが無かった

> **追加: キーオンからの経過時間(2バイトで18時間、1秒刻み)。**
> **追加: キーオフまで持続したか(1ビット)。**

**1件あたり 24 → 27バイト。**[docs/229](229_recorder_simulation_results.md) の結論(容量は障害にならない)は変わらない。

### 3. 検出限界の表 — 測定条件を併記していなかった

[docs/248](248_false_alarm_tradeoff_results.md) の「床の20倍=約4.2 m/s²」は
**1秒未満の突発に対する値**だが、条件を書かずに引用していた。

| 事象の型 | 最小検出 | 実寸 |
|---|---|---|
| 1秒未満の突発 | 20床 | 4.2 m/s² |
| 5秒の逸脱 | 4.5床 | 0.94 m/s² |
| **20秒の持続** | **1.5床** | **0.31 m/s²** |
| 走行全体を覆うずれ | 3.0床 | 0.62 m/s² |

**持続型は突発型の 1/7〜1/14 で捕まる。**

### 4. 正規化 — 尺度と位置を分けていなかった

| | 尺度(床で割る) | 位置(平均を引く) |
|---|---|---|
| **車両レベルの横加速度残差** | **必要**(車種間1.3倍、車種内1.2倍) | **不要かつ有害。**残差は平均ゼロで、推定して引くと2倍損をする([docs/255](255_step_detector_results.md)) |
| **部品内部のしきい値電圧** | 必要 | **必須。**新品40個体で個体差が測定ノイズの159〜530倍([docs/232](232_pristine_unit_spread_results.md)) |

[docs/221](221_real_vehicle_granularity_results.md) が測ったばらつきは**床(尺度)**のものであり、
平均(位置)のものではなかった。**両者を混同していた。**

## 改訂で変わらなかったこと

- **主張してはならないこと7項目**([docs/225](225_recorder_specification.md) 5章)は**そのまま。**
  持続型が細かく捕まることは、予測・場所特定・能力値のいずれも支持しない
- **空欄**もそのまま。ECU内部信号の観測床、許容できる逸脱の下限、掃引すべき温度範囲
- **R12・R13は未達。**注入した事象は本物ではない

## Rule Check

- **改訂の理由が「新しいデータ」ではなく「手元の根拠に従っていなかった」ことを先頭に書いた**
- 新しい失敗の型(T19)を立て、登録簿に追加した
- [docs/248](248_false_alarm_tradeoff_results.md) を撤回せず、**測定条件を併記する形に直した**
- 主張してはならないこと7項目を**1つも緩めなかった**
