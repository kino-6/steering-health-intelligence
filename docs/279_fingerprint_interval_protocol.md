# 279. 事前登録 — 指紋を採ってよい区間の条件を決める

> [docs/278](278_inverter_recorder_results.md): 記録の前半をそのまま指紋にしたところ、
> **正常運転の後半の76%で誤報した。**温度が5分間上がり続けているためである。
> **[docs/225](225_recorder_specification.md) は指紋を「出荷時に採る」としか書いておらず、
> その区間が定常であることをどう確かめるかを書いていない。**

**追加取得ゼロ。** Bacha et al. inverter PMSM と NASA MOSFET(いずれも取得済み)。

---

## 規則(実行前に固定)

> **指紋を採ってよい区間の条件:**
> **その区間を通した観測量の漂流が、その区間の床の1倍未満であること。**

```
漂流 = |区間の直線当てはめの傾き| × 区間長
床   = その区間の残差から求めた robust な散らばり
条件 = 漂流 / 床 < 1.0
```

**この形にした理由**: 記録器は逸脱を床の倍数で測る([docs/225](225_recorder_specification.md))。
**指紋区間の中で観測量が床1つ分より大きく動いていれば、その動きは指紋自身に化けて入る。**
**しきい値1.0は「床1つ分」という自然な単位であり、後から調整しない。**

**区間の選び方**: 正常記録を等分割した候補区間(全体の 1/2, 1/3, 1/4, 1/6)を全位置で走査し、
**条件を満たすもののうち最も長いもの**を採る。**満たすものが無ければ、その観測量は指紋を採れないと判定する。**

---

## 判定基準(実行前に固定)

| # | 基準 | 閾値 |
|---|---|---|
| **W1** | 8チャネルのうち、条件を満たす区間が存在するチャネル数 | 記述 |
| **W2a** | 選び直した指紋で、**正常後半の誤報が設計値の3倍以内**になるチャネル数 | **[docs/278](278_inverter_recorder_results.md) の5より増えること** |
| **W2b** | 誤報基準内のチャネルだけで数えた検出が **3/8 より増えるか** | **増えること** |
| **W3** | 同じ規則をパワー段の実劣化に当てたとき、**6中1**が変わるか | 記述 |

**W2aとW2bの両方が増えて初めて成立とする。**
**誤報だけ減って検出が減るのは、閾値を上げたのと同じであり、成立ではない。**

**W2bが増えなければ、指紋の区間は律速ではない。**そう書いて次を探す。

## この検定が答えないこと(先に書く)

- **故障は人為的に導入されたものである。**劣化ではない。R12は未達のまま
- **EPSではない。**オルタネータ改造のPMSM、1台のみ
- **条件を満たす区間が見つかっても、それが出荷時に確保できるとは限らない。**
  **実際の生産ラインでその区間を作れるかは、部品側では決まらない**——
  ただしそれは**待つ理由にしない。**規則を書き、必要な区間長を数値で出す
