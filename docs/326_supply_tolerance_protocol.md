# 326. 事前登録 — 6 時間の構成は、どれだけの電源変動まで持つか

## なぜこれを次に置くか

[docs/323](323_test_count_results.md) はライン時間を 16 → 6 時間にしたが、**選ばれた 3 本がすべて DC 側だった**
（Vdc・Vd・Idc）。**そこは実車で最も動く。**

**暖機は心配しなくてよいことが分かっている。**[docs/317](317_changepoint_results.md) の実劣化 6/6 は
**同相除去なしの単一チャネル**で、run ごとに冷間始動があるデータで得た。
**動作点に対する直線が、暖機を吸っている。**

**残るのは電源変動である。**この試験機の Vdc は中央値の **4.5%** しか振れない（実測）。実験室電源だからである。

| ch | 幅 / 中央値 |
|---|---|
| Vdc | **4.5%** |
| Idc | 5.7% |
| Vd | 5.5% |
| T1〜T3 | 15.5〜24.9% |
| Ia・Ib | 52.5〜64.7% |

**実車の電源変動を測った公開記録は持っていない。**

## データが無い中での判断 — 問いを裏返す

**「実車ではどれだけ動くか」は公開データでは決まらない。決まらないので、部品側で決まる形に置き換える。**

> **どれだけの電源変動まで持つか。**

答えは観測量自身の単位（中央値に対する %）で出す。**実車の値と突き合わせるのは読み手の仕事である**
（[docs/261](261_no_data_decisions_results.md)・[docs/263](263_temperature_span_results.md) と同じ形）。

## 手順

データ: 実インバータ（[docs/286](286_common_mode_results.md) と同じ。正常前半で登録、正常後半で誤報、故障 8 件で検出）。

1. **登録は乱さない。**出荷ラインは安定した電源で行うので、指紋は無摂動の前半から採る
2. **運用時にだけ摂動を入れる。**DC 側の 3 本（Vdc・Vd・Idc）に、**共通の**緩やかな変動を加える。
   電源が動けば 3 本は一緒に動くからである
3. 形は**記録長を 1 周期とする正弦**、振幅 A は各チャネルの中央値に対する割合。
   **形も周期も私が決めた**（[TROUBLES.md](../TROUBLES.md) T2・T35）
4. A = **0, 1%, 2%, 5%, 10%, 20%, 30%**
5. **3 本の構成と 8 本の構成の両方**で、保留正常の誤報と故障 8 件の検出を数える

**注意すべき仕掛けが 1 つある。**Vdc の動作点は Idc、Idc の動作点は Vdc である。
**共通の摂動は、観測量とその動作点を同時に動かす。**直線がどれだけ吸うかは、やってみないと分からない。

## 事前に決める判定

| | 基準 |
|---|---|
| **S1 耐性** | 3 本構成の誤報が、A = 0 のときの **3 倍以内**に収まる最大の A。**これが「持つ電源変動」である** |
| **S2 検出** | その A で検出が **8/8 のまま** |
| **S3 比較** | 同じ A で 8 本構成はどうか。**3 本が 8 本より先に壊れるなら、6 時間はその分だけ危うい** |

**S1 が 5% 未満なら**、この試験機の 4.5% とほぼ同じであり、
**「実験室電源の範囲でしか確かめていない」と書いて 6 時間の主張を弱める。**

**S1 が 20% 以上なら**、6 時間の構成は電源変動に対して丈夫であり、
**[docs/323](323_test_count_results.md) の懸念のうち電源の分は晴れる**（暖機の分は [docs/317](317_changepoint_results.md) で既に晴れている）。

**その間（5〜20%）なら、数字をそのまま書く。**どちらにも寄せない。

## この事前登録が外れる条件

- **摂動の形（正弦、記録長 1 周期）は根拠なく置いた。**実車の電源変動の形は知らない
- 故障は**人為的に導入したもので劣化ではない**（R12 未達）
- 実インバータ 1 台・10 Hz・28 分。**率ではなく存在証明**
- **摂動を DC 側 3 本だけに入れる。**実車では温度や相電流にも波及しうるが、その経路は測っていない
