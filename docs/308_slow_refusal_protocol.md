# 308. 事前登録 — 遅い側に「宣言しない」を入れ、指紋に漂流を許す

> [docs/299](299_bank_results.md) が名指しした 2 つの原因を潰す。
> **原因 1**: 健全期にも漂流がある（run 1→4 で −0.05 → −0.24 床）。閾値を床の 0.2 倍まで下げると誤報になる。
> **原因 2**: 遅い側が動作点範囲を見ない。run 開始の暖機で 3.7〜4.5 床の偽の逸脱（Test_10）。

**追加取得ゼロ。** NASA MOSFET 6 素子、7 run 全部。**区間定義は [docs/297](297_bank_protocol.md) の改訂どおり**（較正 = run 1 後半〜3、誤報 = run 4、探索 = run 5〜）。

## 直す 2 点（実行前に固定）

**修正 F1 — 遅い側の「宣言しない」**
遅い側の連続平均を取る窓の中に、**動作点が指紋の掃引範囲の外にある標本が 1 つでもあれば、その窓は宣言しない。**
速い側（`element_v2.Recorder`）と同じ規則を、同じ形で適用する。

**修正 F2 — 指紋の漂流項**
指紋の直線を `観測量 = a×動作点 + b` から **`観測量 = a×動作点 + c×経過時間 + b`** にする。
係数は較正区間（run 1 後半〜3）で当てる。**経過時間は較正区間の開始からの標本数。**

## 判定基準（実行前に固定）

素子ごとに、F0（現状）／F1 のみ／F2 のみ／F1+F2 の 4 通りを回す。

| # | 基準 | 閾値 |
|---|---|---|
| **F-A** | F1+F2 で、run 4 の誤報が設計値の 3 倍以内の素子 | **6 中 5 以上** |
| **F-B** | F1+F2 で、故障前（run 5〜7）に鳴る素子 | **6 中 5 以上** |
| **F-C** | F-A と F-B の**両方**を満たすか | **両方でなければ不成立**（T28） |
| **F-D** | F1 だけ／F2 だけの寄与 | 記述。**どちらが効いたか** |

**F-C が成立すれば、[docs/299](299_bank_results.md) の「正味 2/6」は 5/6 以上に変わる。**
**不成立なら、原因はこの 2 つではなかったと書き、次の候補を 1 つ挙げる。**

## 答えないこと
- ヒーター動作の 1 試験機・6 素子。**率ではなく存在証明**
- F2 の漂流項は線形。非線形の漂流は扱わない
- **修正後に閾値や平均長を動かさない。**[docs/297](297_bank_protocol.md) 改訂のバンク {100,200,500} をそのまま使う
