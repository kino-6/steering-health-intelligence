# 244. 空欄が1つ埋まった — 検出には床の10倍が要る。そして検出器は2つ要る

[docs/243](243_intermittent_injection_protocol.md) の事前登録を実行した。**追加取得ゼロ。**

> **[docs/225](225_recorder_specification.md) の空欄「検出確率・誤検出率」が埋まった。**
> **ただし埋まったのは車両レベルの数値であり、ECU内部信号のものではない。**

実行: `python3 scripts/intermittent_injection.py` /
数表: [data/intermittent_injection.tsv](../data/intermittent_injection.tsv)

## 結果

実車3,471ログ、床の中央値 0.2083 m/s²、5秒窓34,982個。
**両検出器の閾値を、注入なしでの誤検出率 1.0%/窓 に揃えた。**

| 検出器 | 閾値(床の倍数) |
|---|---|
| 平均型 | **1.80** |
| 事象型(窓内の最大) | **7.73** |

**事象型は閾値が4.3倍高い。**50標本の最大値は、雑音だけでも大きくなるからである。
**「最大を取る」は信号と一緒に雑音の床も持ち上げる。**

検出率(振幅は床の倍数、継続は秒):

| 振幅 | 0.1s | 0.2s | 0.5s | 1.0s | 2.0s |
|---|---|---|---|---|---|
| | 平均 / 事象 | 平均 / 事象 | 平均 / 事象 | 平均 / 事象 | 平均 / 事象 |
| 1〜3倍 | 1% / 1% | 1% / 1% | 1% / 1% | 1% / 1% | 2% / 1% |
| **5倍** | 1% / 1% | 1% / 1% | 1% / 1% | 1% / 1% | **91% / 1%** |
| **10倍** | 1% / **99.9%** | 1% / **99.8%** | 1% / **99.9%** | **90%** / **99.9%** | 99% / **100%** |

## 検出器は2つ要る — どちらか一方では足りない

| 事象の長さ | 有効な検出器 | 必要な振幅 |
|---|---|---|
| **1秒未満** | **事象型のみ** | **床の10倍** |
| **2秒** | **平均型の方が鋭い** | **床の5倍**(事象型は10倍) |

**短い事象では平均型が完全に無力である**(0.1〜0.5秒で1%=偶然)。
窓の平均が、短い逸脱を50標本で割って薄めてしまう。

**長い事象では平均型が2倍鋭い。**事象型は閾値が高い分、損をする。

> **[docs/240](240_excursion_event_protocol.md) の「突発事象は数えるもので平均するものではない」は、半分だけ正しかった。**
> **短い事象については正しい。長い事象については逆である。**
> **仕様は両方を持たなければならない。**

## 仕様に載る数値

| 項目 | 値 |
|---|---|
| 誤検出率 | **1.0% / 5秒窓**(= 約7回/時間) |
| **1秒未満の事象の検出限界** | **床の10倍** = 実車で約 **2.1 m/s²** |
| **2秒の事象の検出限界** | **床の5倍** = 約 **1.0 m/s²** |
| 床の中央値 | 0.2083 m/s²(3,471ログ) |

**2.1 m/s² は大きい。**車両レベルでは、**相当大きな断続事象しか捕まらない。**
これは [docs/220](220_real_vehicle_granularity_protocol.md) が先に認めたこと——
**残差は制御器・路面・推定誤差の合成であり、EPSの測定量ではない**——の量的な帰結である。

**誤検出率1.0%/窓は実用の水準ではない。**5秒窓で1時間に約7回鳴る。
実用にはもっと低い誤検出率が要り、そのぶん検出限界は上がる。

## 何が埋まって、何が埋まっていないか

| [docs/225](225_recorder_specification.md) の空欄 | 状態 |
|---|---|
| **検出確率・誤検出率** | **埋まった(車両レベル)。**上表 |
| ECU内部信号の観測床 | **空欄のまま。**R12/R13を満たすデータが要る |
| 掃引すべき温度範囲 | 空欄のまま |
| 許容できる逸脱の下限 | 空欄のまま(OEMが埋める) |

**4欄が3欄になった。**

## 限界(緩めない)

- **これは検出器の性能であって、現象の実在ではない。**注入した事象は本物ではない
- **矩形という波形は仮定である**([docs/243](243_intermittent_injection_protocol.md) で先に認めた)。
  実際の断続アシスト喪失の形は公開データに無い
- **車両レベルの残差である。**EPS内部信号なら床も検出限界も変わる。**この数値を内部信号に移さない**
- **1ログに1事象。**重なりは扱っていない
- **誤検出率1.0%/窓は実用水準ではない**(上記)
- **openpilot搭載4車種**

## Rule Check

- **自分の見立て([docs/240](240_excursion_event_protocol.md))が半分外れたことを、節を立てて書いた**
- **事象型の閾値が4.3倍高いこと**(不利な事実)を、検出率より先に書いた
- 埋まったのが**車両レベルであって内部信号ではない**ことを、数値を出す節と限界の両方に書いた
- **誤検出率1.0%が実用水準でない**ことを自分で書いた。数字を良く見せない
- docs/225の空欄を「早すぎた」と認めた上で埋めた
