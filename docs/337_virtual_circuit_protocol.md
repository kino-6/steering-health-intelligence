# 337. 事前登録 — 仮想回路を定義し、導通損以外も入れて出力への影響を出す

## なぜ必要か

[docs/331](331_assist_capability_results.md) は「故障直前でもアシストの低下は 11%」と出した。
**この 11% は導通損しか見ていない。**回路を定義していないので、他の損失を入れようがなかった。

**回路を先に決める。**そのうえで、測った R_on の上昇が出力に何をするかを計算する。

## 定義する仮想回路

**実製品ではない。**公開されている構成と、公開値の範囲だけで組む。

| 項目 | 値 | 出所 |
|---|---|---|
| 構成 | 三相インバータ、下側 3 素子 + 上側 3 素子 | 一般的な EPS パワー段 |
| 素子 | パワー MOSFET。**型番は固定しない**（下記の範囲で振る） | — |
| DC バス | 12 V 系（公称 13.5 V） | 車載 12 V 系 |
| PWM 周波数 `f_sw` | **10 / 20 / 40 kHz** を振る | 可聴域外にする一般的な範囲 |
| 相電流（実効） | **20 / 40 / 60 A** を振る | 12 V 系 EPS の出力域 |
| 熱経路 `Rth(j-a)` | **1 / 2 / 4 K/W** を振る | 基板実装〜ヒートシンク付きの範囲 |
| 接合部の上限 `Tj_max` | 150 °C | パワー MOSFET の一般値 |
| 周囲温度 `T_amb` | 85 °C | エンジンルーム側の一般値 |
| **R_on の劣化** | **NASA MOSFET 6 素子の実測**（[docs/331](331_assist_capability_results.md)） | **唯一の実測入力** |

**振る 3 つ（`f_sw`・電流・`Rth`）は私が置いた範囲である**（[TROUBLES.md](../TROUBLES.md) T2）。
**この文書は 1 つの答えを出すものではなく、答えがどの条件でどう変わるかを出すものである。**

## 損失モデル

```
導通損        P_cond = I² · R_on(t) · (デューティ分の係数)
スイッチング損 P_sw   = (E_on + E_off) · f_sw
   E_on + E_off は R_on と独立に扱う（劣化しても変わらないと仮定）
熱             Tj = T_amb + (P_cond + P_sw) · Rth
出力の制限     Tj ≤ Tj_max を満たす最大の I が、出せる電流
アシストトルク ∝ その電流
```

**スイッチング損は R_on の劣化で変わらないと仮定する。**
この仮定が効くので、**結果は「スイッチング損の割合」で整理する。**

## 事前に予想すること（外れたらそう書く）

> **スイッチング損の割合が大きいほど、R_on の劣化に対する出力の感度は下がる。**
> **したがって [docs/331](331_assist_capability_results.md) の 11% は、導通損だけを見た上限であり、
> 回路によってはもっと小さくなる。**

| | 予想 |
|---|---|
| **W1** | スイッチング損の割合が 0% に近い条件では、出力低下が [docs/331](331_assist_capability_results.md) の 11% と **±2 ポイント以内**で一致する |
| **W2** | スイッチング損の割合が 50% を超える条件では、出力低下が **11% の半分以下**になる |
| **W3** | 振った 27 通り（3×3×3）のうち、出力低下が 11% を**超える**条件が存在するか。**存在するなら、その条件を書く** |

**W1 が外れたら、私の実装か docs/331 のどちらかが間違っている。**どちらかを特定する。
**W2 が外れたら、感度はスイッチング損の割合では説明できない。**そう書く。

## この事前登録が外れる条件

- **`f_sw`・電流・`Rth` の範囲は私が置いた**（T2・T35）。実 EPS の値ではない
- **E_on + E_off の絶対値を公開値から取っていない。**スイッチング損の割合を直接振ることで回避するが、
  **「割合」自体が私の設計変数であって、実素子の値ではない**
- **`Tj_max` と `T_amb` は一般値であり、特定の製品の値ではない**
- **熱は定常だけを見る。**過渡（短時間の大電流）は入れていない
- **劣化するのは R_on だけと仮定する。**閾値電圧・ゲート電荷・熱抵抗の劣化は入れていない
  （熱抵抗はダイ本体で変化なしを実測、[docs/199](199_pulse_thermal_results.md)）
- R_on の劣化は単体 MOSFET 6 素子・1 試験機の実測。**EPS ではない**
