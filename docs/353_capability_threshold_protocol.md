# 353. 事前登録 — 能力の閾値を「何 % 落ちたら鳴る」の形で置けるか

[docs/331](331_assist_capability_results.md) と本レポートで、**閾値は逸脱に置いてあり、
能力に直すと個体ごとに 0.887〜0.980 に散る**ことを測った（幅 0.09）。
そこで「能力を一定の割合で切る閾値に直すには、個体ごとのノイズの大きさと能力の傾きが要る。
**両方とも出荷時基準値に入っているので計算はできるが、まだ測っていない**」と書いた。

**測っていないと書いたまま置かない**（[TROUBLES.md](../TROUBLES.md) T38）。ここで測る。
**追加取得はしない。**

## 何を測るか

受け手が「能力が 5% 落ちたら知らせてほしい」と言ったとき、
要素はそれを自分の逸脱の閾値に翻訳できるか。翻訳できるとして、**何を失うか。**

## 翻訳の式（測る前に書く）

基準温度 `T` で、出荷時の直線が与えるオン抵抗を `R0 = slope·T + intercept`、
その個体のノイズを `g = floor` とする。逸脱 `d`（`g` の何倍か）のとき

```
R_on(d) = R0 + d·g
C(d)    = √( R0 / (R0 + d·g) )
```

これを `d` について解くと

```
d(C) = S · (1/C² − 1)        S = R0 / g
```

**`S` はその個体の信号対雑音である。**`slope`・`intercept`・`floor` は
出荷時基準値 56 バイトの中にあるので、**ECU は追加情報なしに `d(C)` を計算できる。**

## 事前登録する予想

| | 予想 | 外れる条件 |
|---|---|---|
| **Y1** | `S` は 6 素子で **最大/最小 ≥ 3 倍** ばらつく | 3 倍未満 |
| **Y2** | 共通の能力閾値 `C = 0.95` を課すと、誤検知件数/時 の **最大/最小 ≥ 10 倍** | 10 倍未満 |
| **Y3** | そのとき検出は **6/6** を保つ | 5/6 以下 |

**何もしない基準**（[TROUBLES.md](../TROUBLES.md) T34）: 全個体に同じ逸脱閾値を課す現行。
そのとき能力の閾値は 0.887〜0.980 に散る（幅 0.09、[data/assist_capability.tsv](../data/assist_capability.tsv) で測定済み）。
**Y2 が成立すれば、誤検知率と能力閾値は同時には揃えられない。**どちらを揃えるかを選ぶことになる。

## 手順

1. `series(dev)` で残差と動作点を取り、run 1 の前半で直線とノイズを決める（現行と同じ）
2. 基準温度は [data/assist_capability.tsv](../data/assist_capability.tsv) の `t_ref`（素子ごと）
3. `S = (slope·t_ref + intercept) / floor` を 6 素子ぶん出す
4. `C = 0.95` から `d(C)` を素子ごとに出す
5. 健全区間（run 1〜4、当てはめに使った前半を除く）の 5 秒窓で `|残差平均| > d(C)` を数え、件/時 に直す
6. run 5〜7 に 1 つでも超える窓があれば検出とする

## 測定の床

健全区間の長さで決まる。**その長さより細かい誤検知率は区別できない**
（[docs/321](321_enrolment_length_results.md)）。**床は結果と一緒に書く。**

## やらないこと

- **`C = 0.95` という値に根拠は無い。**受け手が言いそうな値として私が置いた（[TROUBLES.md](../TROUBLES.md) T35）
- 当てはまりの良さで判定しない
- 外れた予想を、後から層別して救わない（[TROUBLES.md](../TROUBLES.md) T17）
