# 376. 事前登録 — 健全期の拡散 σ_B を、標本ノイズに埋もれない方法で測り直す

[docs/373](373_wiener_path_results.md) の σ_B = 0.555（3σ 単位/√時）は、50 標本の走行平均の**隣接する増分**の分散を時間刻みで割って出した。
刻みが数秒なので、増分は走行平均に残る標本ノイズで支配され、拡散が膨らむ。
[docs/343](343_virtual_module_detection_protocol.md) の直接測定（健全期の走行平均の最大−最小 = 0.351、約 2.3 時間）は σ_B ≈ 0.23 を示す。

## 測り方（実行前に固定する）

各素子の健全期（run 1〜4、通電時間 t）で、走行平均 m(t) の **ラグ Δ の増分** `m(t + Δ) − m(t)` の分散 `V(Δ)` を、Δ = 0.05, 0.1, 0.2, 0.4 時間で測る。

- ウォークなら `V(Δ) = σ_B² · Δ`（原点を通る直線）。傾向なら Δ に対して上に凸（α > 1）
- **σ_B² は V(Δ) を Δ に回帰した傾き**（切片は標本ノイズの寄与として別に出す）
- 併せて docs/343 の直接測定（最大−最小 / √T）も出し、2 つを並べる

## 事前登録する予想（手計算で決まらない量だけ）

| | 予想 | 外れる条件 |
|---|---|---|
| **B1** | ラグ法の σ_B の 6 素子中央値は **0.15〜0.35** に入る（直接測定の 0.23 の側） | 範囲外 |
| **B2** | `V(Δ)` の log-log 傾きは **1 より大きい**（傾向。docs/348 の α = 1.32 と同じ向き） | 1 以下 |
| **B3** | 直した σ_B で docs/374 の s = 0.926 を再実行すると、健全個体の誤検知の中央値は **50 件/時 未満**（0.555 では 333） | 50 以上 |
| **B4** | それでも線（5.4 件/時）には届かない | 届く（そのとき「差分で線に入る」が模型でも成立する） |

**何もしない基準**（T34）: σ_B = 0.555（docs/373）。

## やらないこと

- Δ の刻みを後から変えない
- B3・B4 のどちらに出ても、それを答えにする
