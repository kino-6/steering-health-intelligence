# 338. 出力への影響は 3.7〜10.8%。決めているのは損失の内訳ではなく、どちらの拘束が効くか

[docs/337](337_virtual_circuit_protocol.md) の事前登録を実行した。**追加取得ゼロ。**

> **W1 成立、W2 外れ、W3 は 0 件。**
>
> **測った R_on 劣化を定義した回路に通すと、出力（出せる電流）の低下は 3.7〜10.8% だった。**
> 振った 54 通りのどれも 11% を超えない。
>
> **スイッチング損の割合は、感度を変えない。**変えるのは**どちらの拘束が効くか**である。
> **熱が拘束するとき 10.8%、バス電圧が拘束するとき 3.7%。**

実行: `python3 scripts/virtual_circuit.py` / 数表: [data/virtual_circuit.tsv](../data/virtual_circuit.tsv)

## 定義した回路

三相インバータ、12 V 系（13.5 V）、`Tj_max` 150 °C、周囲 85 °C。
`f_sw` 10/20/40 kHz、設計電流 20/40/60 A、`Rth` 1/2/4 K/W、スイッチング損の割合 0/25/50/75%。
**実測入力は NASA 6 素子の R_on 劣化だけである。**他はすべて私が置いた（[docs/337](337_virtual_circuit_protocol.md)）。

```
熱       Tj = T_amb + (I² R_on k + P_sw) Rth ≤ Tj_max
バス電圧  V_bus = I (R_motor + 2 R_on)        （失速時、逆起電力なし）
出力      2 つの拘束のうち小さいほうが、出せる電流
```

## W2 は外れるべくして外れた

**登録する前に代数で分かることだった。**

```
熱が拘束するとき   I² R_on k = (Tj_max − T_amb)/Rth − P_sw
                  I = √( (A − P_sw) / (R_on k) )
劣化前後の比       I₁/I₀ = √( R_on0 / R_on1 )
```

**P_sw は分子で共通に引かれ、比の中で消える。**
スイッチング損が R_on と独立であるかぎり（[docs/337](337_virtual_circuit_protocol.md) の仮定）、
**感度はスイッチング損の割合に依存しない。**

**[TROUBLES.md](../TROUBLES.md) T40 と同じ検査を怠った。**
T40 は「必ず成立する基準」、今回は「必ず外れる基準」で、**向きが逆なだけである。**
どちらも「基準に出てくる量が、振る変数に依存しているか」を追えば書いた時点で分かった。
**T40 の 2 回目として登録した。**

## では何が感度を決めているのか

**拘束の種類である。**

| 拘束 | 感度 | 理由 |
|---|---|---|
| 熱 | `√(R_on0/R_on1)` → **10.8%** | 損失が電流の 2 乗なので、平方根で効く |
| バス電圧 | `(R_motor + 2R_on0)/(R_motor + 2R_on1)` → **3.7%** | **R_motor が支配的で、R_on の変化が薄まる** |

設計電流 40 A・13.5 V なら経路の合計抵抗は 0.34 Ω、そのうち素子 2 個分は 0.10 Ω である。
**R_on が 26% 上がっても、合計抵抗は 8% しか上がらない。**

**スイッチング損の割合が効くのは、どちらが拘束するかを動かすときだけである。**
割合が上がると熱の余裕が減り、熱が先に効くようになる（75% では 3 条件とも熱）。

## [docs/331](331_assist_capability_results.md) をどう動かすか

**11% は導通損だけを見た人為的な数字ではなかった。**
回路を定義し、スイッチング損と熱経路とバス電圧を入れても、**上限として 10.8% で一致した。**

> **出力への影響は 3.7〜10.8%。**
> **11% を超える条件は、振った範囲には無い。**

## 残る限界

- **`f_sw`・電流・`Rth`・損失割合・`R_on0`・`Tj_max`・`T_amb` はすべて私が置いた**（[TROUBLES.md](../TROUBLES.md) T2・T35）
- **失速時（逆起電力なし）だけを見た。**回転中は逆起電力が電圧の余裕を食うので、電圧が拘束する条件が増える
- **定常熱だけを見た。**過渡の大電流は入れていない
- **劣化するのは R_on だけと仮定した。**閾値電圧・ゲート電荷は入れていない
- **スイッチング損が R_on と独立という仮定が、結論の中心にある。**この仮定が崩れれば感度も変わる
- R_on の劣化は単体 MOSFET 6 素子・1 試験機の実測。**EPS ではない**
