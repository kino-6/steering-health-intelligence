# 243. 断続事象を注入して、仕様した記録器の検出力を測る — 事前登録

**追加取得ゼロ。**[docs/225](225_recorder_specification.md) の空欄「検出確率・誤検出率」を埋めにいく。

## なぜ今までやらなかったか、なぜ今できるか

[docs/225](225_recorder_specification.md) はこの欄を「**R13(正解時刻)が無いと埋まらない**」として空欄にした。
**これは早すぎた。**

[docs/144](144_synthetic_sensitivity_results.md) は**合成注入**で検出限界を測り、その結果が
EooC仮定シートの粒度欄の根拠になっている。**同じ手が使える。**
**やっていなかったのは、注入したのが定常オフセットだけで、断続事象を一度も注入していないことである。**

> **注入すれば正解時刻は構成上わかる。R13は満たされる。**
> **満たされないのは R12(現象が実在すること)であり、それは注入では埋まらない。**

**したがって本検証が測るのは「現象があるとして、仕様した記録器が捕まえるか」である。**
**現象の実在は測らない。**

## 何を注入するか

**土台**: commaSteeringControl の実車ログ(4車種2,495、10 Hz、60秒)。
残差 `e = latAccelLocalizer − latAccelDesired`、制御有効かつ運転者非介入の標本のみ
([docs/220](220_real_vehicle_granularity_protocol.md) と同一)。

**断続事象**: 矩形の加算。ログ内のランダムな時刻に、振幅 A、継続 D の逸脱を1回加える。

```
振幅 A = そのログ自身の床 g(1) の {1, 2, 3, 5, 10} 倍
継続 D = {1, 2, 5, 10, 20} 標本 = 0.1 / 0.2 / 0.5 / 1.0 / 2.0 秒
```

**矩形という形は仮定である。**実際のアシスト喪失の波形は分からない。先に認める。

## 何と比べるか — これが本題

[docs/240](240_excursion_event_protocol.md) で、突発事象は「平均するもの」ではなく「数えるもの」だと書いた。
**その差を、正解のある土台で初めて測る。**

| 検出器 | 窓の統計量 | 由来 |
|---|---|---|
| **平均型** | 窓内の残差の**平均** | [docs/144](144_synthetic_sensitivity_results.md) / [docs/223](223_window_and_firmware_results.md) の系列 |
| **事象型** | 窓内の残差の**最大絶対値** | [docs/240](240_excursion_event_protocol.md)、IPC-9701 の事象検出の考え方 |

窓は **50標本(5秒)**([docs/225](225_recorder_specification.md) の仕様)、重なりなし。

## 判定基準(いま固定する)

**誤検出率を先に固定し、そこでの検出率を比べる。**

- 各検出器の閾値は、**注入していないログでの窓あたり誤検出率が 1.0%** になる点に合わせる
- **この 1.0% を先に決める。**結果を見て動かさない

| # | 報告するもの | 規則 |
|---|---|---|
| **M1** | 振幅×継続ごとの検出率を、両検出器について報告 | **全組み合わせを出す。良い組だけ出さない** |
| **M2** | 検出率90%に達する最小振幅を、継続ごとに報告 | **これが仕様に載る数値** |
| **M3** | 事象型が平均型より優れるか | **90%到達の最小振幅の比で報告。閾値なし** |

- **事象型が優れなかったら、そう書く。**[docs/240](240_excursion_event_protocol.md) の見立てが外れたことになる
- **v2は作らない。**注入の形も窓長も変えない

## 事前に認めておくこと

- **これは検出器の性能であって、現象の実在ではない。**注入した事象は本物ではない
- **矩形という波形は仮定である。**実際の断続アシスト喪失の形は公開データに無い
- **残差はEPSの測定量ではない**([docs/220](220_real_vehicle_granularity_protocol.md))。
  制御器の追従誤差・路面外乱・推定誤差を含む
- **1ログに1事象。**複数事象の重なりは扱わない
- **openpilot搭載4車種。**一般の車両分布ではない
- **誤検出率1.0%は窓あたりである。**5秒窓なら1時間あたり約7回に相当する。実用の水準ではない

## Rule Check

- **「注入で埋まるのはR13だけ、R12は埋まらない」を冒頭に書いた**
- **誤検出率を先に固定してから検出率を比べる**と決めた。片方だけ良く見せない
- **事象型が優れなかった場合にどう書くかを先に決めた**
- 矩形という波形が仮定であることを、手順の中に書いた
- docs/225の空欄を「早すぎた」と自分で書いた
