# 209. 油圧を除いても先行性は残る — 22.0倍。中身は腐食である

[docs/208](208_mot_nonhydraulic_protocol.md) の事前登録を実行した。

| # | 基準 | 結果 |
|---|---|---|
| **N1 先行性が残るか** | **成立。22.0倍**(n = 14,029、必要 3.0倍以上・n ≥ 1,000) |
| **N2 族別** | **腐食のみが検定可能**(n = 14,490、23.3倍)。他4族は n < 1,000 で検定不能 |
| **N3 量** | 非油圧の兆候は 14,029台。**全PS兆候の25.8%** |

実行: `python3 scripts/mot_cause_breakdown.py` / 数表: [data/mot_cause_breakdown.tsv](../data/mot_cause_breakdown.tsv)

## 結果

作動油の漏れを兆候からも不合格からも除いた。

| 2024年の状態 | n | 2025年の非油圧PS不合格率 | 倍率 |
|---|---|---|---|
| clean | 16,994,497 | 0.031% | 1.0 |
| **非油圧の兆候のみ** | **14,029** | **0.677%** | **22.0** |

**[docs/207](207_mot_cause_breakdown_results.md) の33.9倍は油圧の性質ではなかった。**
油圧を全部落としても22.0倍が残る。

## ただし、残ったものの中身は腐食である

| 非油圧の族 | n | 非油圧不合格率 | 倍率 |
|---|---|---|---|
| **corrosion** | **14,490** | **0.718%** | **23.3** |
| damage | 588 | 0.850% | 検定不能(n<1,000) |
| geometry | 86 | 0.000% | 検定不能 |
| modification | 37 | 5.405% | 検定不能 |
| security / function | **0** | — | **記録が存在しない** |

非油圧の兆候群 14,029台に対し、腐食の兆候を持つ車両が 14,490台である。
**つまりこの22.0倍は、実質的に腐食の先行性である。**

> **油圧を外して残ったのは「腐食が進むと、その車は翌年パワーステアリングで落ちる」という一本の関係である。**

## 記録するが、ここでは検定しないこと

腐食の兆候が付いた車両の**翌年の不合格の内訳**を見ると、機能不全(function 族)が **0.179%** で、
clean 群の **0.026%** に対して約 **6.9倍**にあたる(n = 14,490)。

**腐食は接触不良を通じて断続故障を生む**機構であり、これは本研究の中心に最も近い形の観測である。

**しかしここでは検定しない。**
[docs/208](208_mot_nonhydraulic_protocol.md) が事前登録したのは「非油圧の不合格全体」であって、
「機能不全という特定の帰結」ではない。**結果を見た後に切り口を作らない。**
**観察として記録し、別の事前登録に回す。**

なお [docs/206](206_mot_cause_breakdown_protocol.md) の M3(配線の兆候→機能不全)は、
対象が **28台**で検定不能のままである。配線という細い項目ではなく、
**腐食という太い項目の側に量がある**ことがここで分かった。

## 限界(緩めない)

- **非油圧は電動EPSではない。**腐食・損傷・固定不良は油圧式のポンプやホースにも起きる。
  **言えるのは「作動油の漏れではない劣化」までである**([docs/208](208_mot_nonhydraulic_protocol.md) で先に認めた)
- **検査員の目視所見である。**部品内部の状態ではない
- **機能不全には兆候の区分が制度上存在しない**([docs/207](207_mot_cause_breakdown_results.md))。
  **本検証も機能不全の前駆には届かない**
- **兆候は放置され、不合格は修理される。**群間比較にこの非対称が入る
- **選択効果を除去できない。**腐食が進む車種・車齢・地域はもともと壊れやすい可能性がある
- **英国市場のデータである**
- **N2で検定できたのは1族のみ。**他4族はいずれも n < 1,000

## 主張がどう動くか

| 主張 | 変化 |
|---|---|
| [docs/207](207_mot_cause_breakdown_results.md) の33.9倍 | **油圧の性質ではなかった。**除いても22.0倍が残る |
| 先行性の中身 | **腐食に絞られた。**他族は量が足りない |
| [docs/175](175_close_contact_question.md) 接点系の問い | **実車側から量のある入口が見つかった。**ただし本文書では検定していない |
| 機能不全の前駆 | **依然として届かない。**制度に区分が無い |
