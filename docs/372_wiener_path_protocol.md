# 372. 事前登録 — 指数を同定する代わりに、変量ドリフト付き Wiener 過程（一般経路モデル）で劣化と個体差を表す

2026-09-14 ユーザ指摘: **「それでも指数は同定できない、では他の方法は？」「類似のアイテムないの？」**

ある。信頼性工学の標準は、**個体ごとの劣化経路に変量効果を置く一般経路モデル**（Lu & Meeker 1993）で、
その確率過程の形が **変量ドリフト付き Wiener 過程**である（[SOURCES.md](../SOURCES.md) S17）。
類似の公開データ（NASA IGBT、電池、C-MAPSS）の RUL でも主流の手法である。

**この研究の記録器が出す逸脱の系列は、まさに「健全期の漂流（拡散）＋ 劣化（ドリフト）」なので、この形がそのまま当たる。**

```
X_i(t) = μ_i · t + σ_B · B(t)        i は個体、B は標準ブラウン運動
μ_i ~ 対数正規(m, s)                  個体ごとの劣化速度（変量効果）
故障 = X_i(t) が閾値 D を初めて越える時刻。分布は逆ガウス IG(D/μ_i, D²/σ_B²)
```

指数のように曲がりを同定する必要が無く、**直線の傾き（ドリフト）とその散らばりだけを推定する。**docs/368・371 で直線が支持されたので、この形は観測と矛盾しない。

## 当てはめ（実行前に固定する）

対象は 2 組。**方式も量も違うので混ぜない。**

| 組 | 個体 | 量 | 軸 | 閾値 D |
|---|---|---|---|---|
| A | 7 run の 6 素子 | 逸脱（3σ 単位、steadyState の量、基準温度で読む） | 通電時間 | C = 0.894 に相当する逸脱（個体の S × 0.25） |
| B | 連続試験 5 本（35, 36, 37, 38, 41） | ΔR/R0（transient の R_DS(on)） | aging time | **0.08**（NASA の 0.05 Ω / 加速温度の R0 0.6 Ω） |

各個体で: 劣化が始まってからの区間（A は run 5〜7、B は死の前の後半 50%）で `X(t)` に直線を当て、傾き `μ_i`、
残差の増分の標準偏差から `σ_B`（増分の分散 ÷ 時間刻み）を出す。組ごとに `μ` の対数正規を推定する。

## 事前登録する予想（手計算で決まらない量だけ）

| | 予想 | 外れる条件 |
|---|---|---|
| **W1** | 各組の `μ_i` の対数の標準偏差 `s` は **0.8 以下**（最大/最小でおおむね 5 倍以内） | 0.8 超 |
| **W2** | 組 A で、推定した `(μ_i, σ_B)` から出る逆ガウス分布の 10〜90% 区間が、**観測した故障時刻を 6 素子中 4 以上で含む** | 3 以下 |
| **W3** | 組 A の母数で作った 1,000 個体で、記録器（32 KB の線、2.7 件/時）が **C = 0.894 の前に警報を出す割合 ≥ 90%** | 90% 未満 |
| **W4** | 健全個体の誤検知率の中央値は線の **2 倍以下** | 2 倍超 |

**何もしない基準**（T34）: 指数モデル（docs/366、368、371、同定できず）と、直線の劣化を置いた仮想モジュール（docs/344）。

## 個体群の作り方

docs/367 と同じ手順で、劣化を `μ_i · t`（μ_i は組 A の対数正規から）、健全期の漂流を `σ_B · B(t)`（σ_B は組 A の推定値）、
ノイズと S は 40 テストの経験分布から。健全個体の走行は組 A の健全期（run 1〜4）の通電時間の中央値。

## これで言えないこと

- 組 A と B の `μ` は量が違うので比べない。B は閾値到達時刻の分布を出すためだけに使う
- N は 6 と 5 のまま。模型で増えるのは母数を引いた個体であって、実素子ではない

## やらないこと

- 直線が悪い個体を外さない
- 予想が外れたら層別で救わない（T17）
