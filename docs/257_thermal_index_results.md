[docs/256](256_thermal_index_protocol.md) の事前登録を実行した。**追加取得ゼロ。**

> **落ちた理由は観測量の選び方ではなく、この試験機が劣化の分離を許さない構造だったことである。**

## モデルは何も足さなかった

生の温度差(2/6)より、モデルの量(1/6)の方が悪い。
**外部加熱の大きさを比で消すという発想は、この試験機では効かなかった。**

理由は実行後に分かった。**フランジ温度を合わせても、動作点は合っていない。**

各runは40→250 °Cを掃引するが、**上限がrunごとに 250 → 240 → 230 と下がる。**
したがって同じ200 °Cという点は、run1では掃引の途中、run3では掃引の終盤にあたる。
**同じ温度でも、そこに至る履歴と熱的な落ち着き具合が違う。**

> **温度を合わせることは、動作点を合わせることではなかった。**
> [AGENTS.md](../AGENTS.md) の「制御器の記録を先に確認する」は守ったが、
> **設定値の軌跡を確認するだけでは足りず、その軌跡上のどこにいるかまで合わせる必要があった。**

## 副産物 — 個体差が劣化変化を1桁上回る

失敗の中で1つだけ、はっきりした量が出た。フランジ200 °Cの帯で:

| | 値 |
|---|---|
| 6素子の指数のばらつき(run1) | 0.740 〜 0.857 = **0.117** |
| 同じ素子の run1→run3 の変化(中央値) | **0.014** |
| **比** | **8.4倍** |

フランジ100 °Cの帯では 0.205 対 0.044 = **4.7倍**。

**同じ型番・同じ試験機・同じ動作点でも、個体差が3runぶんの劣化変化を5〜8倍上回る。**
これは [docs/232](232_pristine_unit_spread_results.md) の新品40個体(159〜530倍)と同じ向きの証拠であり、
**別の観測量・別の試験機で再現した。個体基準法の必要性はこれで2つの独立な根拠を持つ。**

ただし **「3runぶんの劣化変化」が小さいのは、劣化が進んでいないためかもしれない。**
この比を「劣化は個体差より小さい」と読んではならない。

## この失敗が示していないこと

- **「モデル構築という approach が無効だ」とは言えない。**落ちたのは
  **このデータセットに対するこのモデル**である。動作点が保持される試験データがあれば、同じ形は成立しうる
- **「熱経路の劣化が存在しない」とは言えない。**この試験機では分離できないというだけである
- **3runは短い。**劣化がまだ現れていない可能性を排除できない
