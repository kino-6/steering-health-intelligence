# 175. A''を閉じる — 公開データの地図に接点劣化は存在しない

## 判断

**A''(接点界面の劣化で、抵抗の変動は水準の上昇に先行するか)は、公開情報では答えられない。問いを閉じる。**

**ただし「分からない」で止めない。** 公開の構造証拠から、事業判断に必要な結論は出せる(後述)。

## 探索の結果

3方向から探した。

| 経路 | 結果 |
|---|---|
| Zenodo API(`fretting contact resistance` ほか3クエリ) | 接点劣化の時系列データは**0件**。ヒットは無関係(森林劣化、楽器の腐食など) |
| Web検索(接点軸、[docs/172](172_contact_degradation_route.md) で追加) | 学術論文のみ。**生データの公開は見つからない** |
| **PHM公開劣化データセット総覧**([arXiv:2403.13694](https://arxiv.org/pdf/2403.13694)、v3 2026-02) | **決定的** |

### 総覧が示す公開データの地図

この論文は公開劣化データセット**110件**を11ドメイン・43アプリケーションに分類している。

| | 件数 |
|---|---|
| 機械部品ドメイン | 26 |
| 電気部品ドメイン | 25 |
| 駆動技術ドメイン | 12 |
| 最頻アプリケーション | **軸受 17件、電池 16件**、以下 航空機エンジン/濾過/生産ライン 各5件 |
| 3件以上のデータセットを持つアプリケーション | **わずか9個** |

そして本文全体で **`relay` `connector` `contact` `fretting` の出現は0回**である(`bearing` は45回、`motor` は10回)。

> **公開劣化データの地図に、電気接点というアプリケーションは存在しない。**

これは検索の不足ではなく、**分野の偏り**である。公開PHMデータは軸受と電池に集中しており、接点は空白である。

## それでも事業判断は出せる(AGENTS.md 7条)

自前の測定はできないが、文献が一貫して記述する軌跡から、必要な判断は構成できる。

複数の独立した研究が、fretting下の接触抵抗に**3段階**を報告している。

1. **初期のこぶ** — 接触の安定化に伴う一過性の上昇
2. **安定した低抵抗** — 正常動作期間。寿命の大部分を占める
3. **真の上昇** — 機能不全と故障に**同時**に起こる

**含意は明確である。**

> 段階2が寿命の大部分を占め、段階3が機能不全と同時に来るなら、
> **水準を見る監視は、fretting系の故障に対して実用的な先行時間を与えない。**

そして [docs/174](174_contact_variance_results.md) が示したとおり、変動が先行するかは**測れなかった**。
したがって**先行するという前提に立った設計をしない**。

### 事業判断への反映

これは [docs/146](146_business_framework_and_roadmap.md) 第1層を動かさない。理由は本研究が既にそこに立っていないからである。

- 故障予測・余寿命・交換時期は [docs/143](143_recall_detection_results_v2.md) で**Kill済み**
- SPD008 payload([docs/121](121_steering_predictive_diagnostics_power_monitor_case.md))は「**予告**」ではなく「**event時点の状態説明**」の設計である
- [docs/153](153_sotif_eooc_assumption_sheet.md) のEooC仮定も、発生率の**市場検証**であって予告ではない

**fretting系に対する価値は「早く知らせる」ではなく「起きた瞬間に、部品側からしか出せない文脈を添えて説明する」である。**
これは元の設計と一致する。**変えるべきものはない。**

ただし**言い方は変える**。「fault未満の兆候を早期に捉える」という言い方は、
熱劣化系([docs/167](167_precursor_results_v2.md)、先行1〜2段階を実測)には使えるが、
**fretting系には使えない**。故障族ごとに主張を分ける。

## 故障族ごとの整理(以後これを使う)

| 故障族 | 先行の実証 | 部品側の価値 |
|---|---|---|
| **熱・接合部の劣化** | **あり**。ノイズの20〜300倍の逸脱が故障の1〜2段階前([docs/167](167_precursor_results_v2.md)) | 早期の状態説明 |
| **接点のfretting** | **なし**。文献は段階2が大半・段階3は故障と同時。自前の測定は不可([docs/174](174_contact_variance_results.md), 本ドキュメント) | **event時点の文脈説明**(予告ではない) |
| **巻線の短絡** | 段階的severityは実測([docs/162](162_pmsm_model_validation_results.md))。故障までの追跡はなし | 状態説明 |

そして [docs/171](171_eps_wearout_mechanism_scan.md) は、**EPSの公開記録で優勢なのは接点・接続系(2.81倍)、熱系は平均以下(0.54倍)**と示した。
**つまり市場で最も多い故障族が、最も先行時間を取りにくい族である。** これは本研究にとって不利な事実であり、そのまま記録する。

## Rule Check

- 公開情報のみ。3方向から探し、**見つからないことを総覧(110件の分類)で裏づけた**——「探し方が足りない」で閉じ損ねていない
- **内部資料を代替として要求していない**([AGENTS.md](../AGENTS.md) 2条)
- 「分からない」で止めず、文献の構造から事業判断を構成した(7条)
- 自分に不利な事実(市場で最多の故障族が最も先行時間を取りにくい)を、結論として明記した
- 故障族ごとに主張を分け、**熱系の実証をfretting系に流用しない**ことを固定した
