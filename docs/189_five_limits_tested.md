## ① EPSでの兆候→故障 — 検証不能を確定した

> **範囲の訂正(2026-08-27, [docs/207](207_mot_cause_breakdown_results.md))**: **検証不能なのは `Electronic power steering` 配下の9項目についてである。**
> 一般の `Power steering` 59項目では、兆候のみの車両が **54,431台**あり、翌年のPS不合格が **33.9倍**である。
> **ただしその74.2%は油圧の漏れであり、電動EPSを代表しない。**また機能不全(inoperative/malfunctioning)には**兆候の区分が制度に存在しない。**

英国車検2024/2025を車両IDで連結し、**EPS固有の9項目に限定**して [docs/150](150_advisory_precedence_verification.md) と同じ解析を回した。

対象項目(`Vehicle > Steering > Electronic power steering` 配下):
警告灯の点灯、配線の腐食・損傷(**advisory版「slightly corroded」と fail版「excessively corroded」の両方を持つ**)、fly-by-wireの舵角、動作不良。

**結果: EPSの「兆候」記録が存在しない。**

| 2024の状態 | 車齢4-7 | 8-11 | 12-15 | 16-25 |
|---|---|---|---|---|
| 記録なし | 0.01%(6,376,229) | 0.02%(6,749,955) | 0.03%(4,119,215) | 0.04%(2,999,294) |
| **EPS兆候のみ** | **(1台)** | **(7台)** | **(11台)** | **(16台)** |
| EPS不合格 | 2.43% **[417倍]** (329) | 1.90% **[121倍]** (999) | 3.34% **[121倍]** (1,079) | 4.36% **[121倍]** (917) |

**両年受検2,177万台のうち、EPS兆候のみは64台。** 車齢帯あたり1〜16台であり、**統計にならない。**
(車齢8-11の「907倍」は7台中1台であり、意味を持たない)

**原因は [docs/148](148_dvsa_mot_denominator_verification.md) が既に特定していた**——
「整備現場は故障を汎用の操舵項目で記録しがちで、固有項目の使用は稀」。
2024年のEPS固有 sign相当は全国で99件しかない。

**限界①は「未証明」から「公開データでは検証不能」へ確定した。** これで**5つ目の観測手段が同じ族を見られない**ことになる
(苦情 / 車検の目視 / リコール / 制御器の外側 / **車検のEPS固有記録**)。

### 副産物: EPS不合格は極めて強く再発する

**2024年にEPS項目で不合格になった車は、翌年もEPS項目で不合格になる率が 121〜417倍**(1.90〜4.36% vs 0.01〜0.04%)。

車検は不合格なら是正しないと証明書が出ない。**にもかかわらず翌年また同じ系統で落ちている。**

**ただし解釈は一意に定まらない。** ①適切に直っていない ②その車種・車齢がEPS問題を起こしやすい(選択効果)——
本データでは区別できない。**「直っていない証拠」とは言わない。**

## ② 熱抵抗の直接測定 — 試みて失敗した

[docs/170](170_thermal_headroom_translation.md) は温度係数からの3段推論だった。NASAデータには `flangeTemperature` があるので、
**Rth = (T_package − T_flange) / (V_DS × I_D)** で直接測れると考えた。

**測ったら符号が逆だった。**

| | 実測(Test_11 run 1) |
|---|---|
| packageTemperature | 150.0 °C |
| **flangeTemperature** | **246.5 °C** |
| 差 | **−97.4 °C** |

**フランジの方が90〜100°C高い。** この試験機は熱過負荷をフランジ側から与えており、
熱は「ダイ→フランジ」ではなく「フランジ→パッケージ」へ流れている。
**素子自身の発熱(約13W)は外部加熱に埋もれており、この構成では die-attach の熱抵抗を分離できない。**

加えて、フランジ温度自体が run とともに 246→207°C と下がる。**試験条件が run 間で変わっている。**

**限界②は維持する。** [docs/170](170_thermal_headroom_translation.md) の13〜50%は**計算のままである。**
数表: [data/thermal_resistance_measured.tsv](../data/thermal_resistance_measured.tsv)

## ③④ 動かなかった2件

**③ 接点系の先行時間**: [docs/175](175_close_contact_question.md) で確定したとおり、公開劣化データセット110件の総覧に電気接点のアプリケーションが存在しない。
**新しいデータが出ない限り動かない。** 観測台帳の対象。

**④ 誤診の発生率**: 苦情は消費者の自己申告であり、販売店の診断結果が書かれるとは限らない。
「原因不明」は全体で1.15%しか書かれない稀な語であり、**これは言及率である。**
発生率を知るには修理記録が要るが、公開されていない。**問いを閉じる。**

## ⑤ 金額 — 台数は出た

NHTSAリコール(2010年以降、車両、操舵系)715キャンペーンの `POTAFF`(対象台数)を集計した。

| 母集団 | 件数 | 対象台数 |
|---|---|---|
| 操舵系リコール全体 | 715 | 24,590,365 |
| ギアAssy交換を含む是正 | 120 | 4,342,449 |
| EPS系(部品名) | 181 | 10,990,061 |
| ~~EPS系 かつ ギアAssy交換~~ | ~~23~~ | ~~1,398,556~~ |
| EPS系 かつ 断続/腐食の記述 | 16 | 335,686 |

> **【訂正】この行は誤りである。** 照合が緩く、是正が「4つのブルテンのいずれかを実施」でしかない
> 14V153000(137万台)を巻き込んでいた。正しくは **11キャンペーン / 223,159台**。
> 数え直した結果と、そこから出た強い結論は [docs/190](190_assembly_replacement_meaning.md) に書いた。

**これが示すのは規模であって、無駄の量ではない。** リコールの是正は欠陥が確認されたうえでの**正しい交換**である。
言えるのは「**交換の単位がAssy丸ごとである**」という粒度の粗さと、その適用規模までである。

**金額は依然として不明。** 保証費の内訳は公開されておらず、部品単価×台数を掛けることもしない
(リコール費用と誤診費用は別のものである)。**限界⑤は「台数は公開、金額は非公開」へ精密化した。**
