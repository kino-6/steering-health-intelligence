# 311. 事前登録 — 漂流の軸は暦時間か、累積ストレスか

> **ユーザ指摘(2026-09-04)**: 「負荷が定期的にかかるわけではないので、そこは縛らないほうがいいのでは。
> 実車は毎日決まった時間、時刻に運転しない。」
>
> **正しい。**[docs/309](309_slow_refusal_results.md) は漂流項を**標本番号（＝試験機では暦時間）**で入れた。
> **試験機では暦時間と累積ストレスが一致している**（連続運転）。**実車では分離する**——駐車中も暦時間は進むが、劣化は進まない。
> **暦時間で縛れば、長期駐車のあとに誤報が出る。**
>
> **どちらの軸なら漂流を説明できるかは、手元のデータで確かめられる。**

**追加取得ゼロ。** NASA MOSFET 6 素子、7 run 全部。

## 候補の軸（実行前に固定。3 つ）

| 記号なしの名前 | 定義 |
|---|---|
| **暦時間** | 標本番号（現状。[docs/309](309_slow_refusal_results.md) の F2 が使ったもの） |
| **累積消費エネルギー** | 導通している標本について `ドレイン・ソース間電圧 × ドレイン電流` を積算 |
| **累積熱負荷** | 導通している標本について `パッケージ温度 − 較正区間の中央値` を積算（負の側も加算） |

**実車での対応**: 暦時間はキーオフ中も進む。**残り 2 つはアシストが動いている間だけ進む。**

## 先に測ること（実行前に固定）

**3 軸の相関を先に出す。**試験機では連続運転のため強く相関しうる。
**相関が 0.99 を超えるなら、この試験機では区別できないと書き、判定を出さない。**

## 判定基準（実行前に固定）

| # | 基準 | 閾値 |
|---|---|---|
| **C0** | 3 軸の相関（較正区間 run 1〜3） | **0.99 超なら区別不能。以下の判定を出さない** |
| **C1** | 較正区間で各軸に対して直線を当てたとき、**健全期（run 4）の残差の中央値が最も小さい軸** | 素子ごとに数え、過半で決める |
| **C2** | 各軸の漂流項を入れたときの **run 4 の誤報**（[docs/308](308_slow_refusal_protocol.md) と同じ設定） | 設計値の 3 倍以内の素子数 |
| **C3** | [docs/309](309_slow_refusal_results.md) の F2（暦時間）より、累積軸の方が良い素子数 | 過半で「軸を替えるべき」 |

**C3 が過半を取れば、仕様の「時間」を「累積ストレス」に置き換える。**
**取らなければ、この試験機では軸の違いが出ないと書き、実車での議論は設計上の判断として別に記録する**
——**それは待つ理由にしない**（[AGENTS.md](../AGENTS.md) 0 条）。

## 設計上の判断（データに依らず、先に書く）

**試験機の結果がどうであれ、実車で暦時間を軸にしてはならない。**

- 駐車中に暦時間は進む。**劣化は進まない**
- 毎日 30 分の車と 4 時間の車で、同じ暦日数での劣化は違う
- **したがって漂流項・指紋の有効期限は、累積ストレス（アシスト稼働時間、または積算した電流・熱）で数える**

**この判断は、試験機のデータでは検証できない**（暦時間と累積ストレスが一致しているため）。
**検証できないことを理由に判断を保留しない。**判断として記録し、根拠が「応用の物理」であることを明記する。

## 答えないこと
- ヒーター動作の 1 試験機・6 素子
- 実車の駐車パターンのデータは持っていない。**累積ストレスの分布は測っていない**
