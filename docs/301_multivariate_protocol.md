# 301. 事前登録 — 多次元で見ると、単変量が取り逃した劣化に隠れた構造があるか

> **ユーザ指摘(2026-09-03)**: 「レポート上だと 1 要素の単純な閾値で処理可能なデータに見える。本当に?
> 1 つのモードの劣化しか取れておらず、出力側に直接影響がすぐ出るものでしかない。多次元を分析すると隠れていた特徴があるのでは」
>
> **検定できる。**[docs/299](299_bank_results.md) で単変量（温度補償した Vds/Id）が劣化そのもので鳴ったのは 2/6。
> 残り 4 素子（漂流で鳴りっぱなしの 3、暖機の 1）に、**複数の量を同時に見て初めて出る構造があるか。**

**追加取得ゼロ。** NASA PCoE MOSFET、7 run 全部。

## 特徴量（実行前に固定。7 つ。後から足さない）

定常記録から: Vds/Id（従来の 1 要素）、供給電圧、フランジ温度 − パッケージ温度。
過渡記録から（時刻で最寄りを対応付け）: ゲート立ち上がり時間、ゲート平坦部、導通時の電圧降下、ドレイン電流ピーク。

**動作点はパッケージ温度。**7 特徴すべてを、素子ごとに run 1〜3 でパッケージ温度に対する直線で補償し、残差を使う
（[docs/273](273_power_stage_observables_results.md) の教訓: 補償しないと試験機のランプを拾う）。

## 手法（実行前に固定。学習ではなく多変量管理図）

素子ごとに、run 1〜3 の残差 7 次元を標準化し PCA。**主成分数は累積寄与 90% で切る。**
統計量は 2 つ: **Hotelling T²**（主成分内の距離）と **SPE**（主成分外の残差）。
閾値は run 1〜3 の各統計量の分位点（1 件/時 ÷ 2、clamp して達成率を報告）。
**評価は [docs/297](297_bank_protocol.md) 改訂と同じ区間**: 誤報評価 = run 4、探索 = run 5 以降。連続平均 N=200 を T²・SPE に適用。

## 判定基準（実行前に固定）

| # | 基準 | 閾値 |
|---|---|---|
| **M1** | 単変量が劣化で鳴らなかった 4 素子（9・10・11・12）のうち、多変量が **run 4 の誤報 3 倍以内のまま** run 5〜7 で鳴る数 | **2 以上で「隠れた構造あり」** |
| **M2** | run 5 で最も動く主成分に、**Vds/Id 以外の特徴の寄与（絶対負荷）が 0.4 以上**あるか、素子ごと | 過半で「1 要素ではない」 |
| **M3** | 多変量の初発火が単変量（[docs/299](299_bank_results.md)）より早い素子数 | 記述 |

**M1 と M2 は別の問いである。**M1 は検出の話、M2 は「隠れた特徴があるか」の話。**M2 が過半で成立すれば、ユーザの指摘は当たり。**
**M1・M2 とも不成立なら、この 6 素子・この試験機では 1 要素で足りると書く——ただしそれは劣化モードが 1 つしか入っていない試験だからで、汎用の主張ではない。**

## 答えないこと
- ヒーター動作の 1 試験機・1 型番。**別の劣化モード（ゲート酸化膜、ボンドワイヤ）は含まれていない**——含まれていないことは、多変量でも出ない
- PCA は線形。非線形の構造は見えない
