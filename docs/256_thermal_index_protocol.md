# 256. 事前登録 — 生の観測量ではなくモデルの量なら、試験機の操作を跨げるか

> 本研究で落ちた解析4本([docs/199](199_pulse_thermal_results.md), [203](203_cross_machine_replication_results.md),
> [234](234_igbt_switching_results.md), [237](237_within_condition_results.md))は、**すべて同じ理由で落ちた**——
> **試験機自身が設定値を動かしており、その操作が観測量の最大の変動要因だった。**
>
> **生の観測量を統計で扱うかぎり、この交絡は消えない。**
> **動作点を入力として含むモデルの量なら、消える可能性がある。**これを検定する。

**追加取得ゼロ。** NASA PCoE MOSFET Thermal Overstress Aging(取得済み、public domain)。

---

| | 内容 |

| run数 | 各3 |
| 1 run の長さ | 約36分、定常記録 約5,190点 |
| **run内の設定温度** | **40 → 250 °C へ掃引**(保持ではない) |
| **run間の設定温度** | **上限が 250 → 240 → 230 °C と下がる** |

| 素子の消費電力 | 約 12.4〜13.5 W |

**フランジがパッケージより約95°C高い。**[docs/189](189_five_limits_tested.md) が見つけたとおり、
熱は素子からフランジへではなく、**外部加熱からフランジを経てパッケージへ流れている。**

## [docs/189](189_five_limits_tested.md) が落ちた理由の再解釈

[docs/189](189_five_limits_tested.md) は熱抵抗を `(パッケージ温度 − フランジ温度) / 素子の消費電力` で測り、
符号が逆になって落ちた。

**落ちた原因は「熱抵抗が測れない」ことではなく、分母に素子自身の13Wを置いたことである。**
実際に流れている熱の大半は外部加熱によるものであり、その量は記録されていない。

**分母の絶対量が要らない形にすれば、この障害は迂回できる。**

## モデルの量(実行前に固定)

導通している定常記録ごとに、次を計算する。

```
熱の非対称指数 = (フランジ温度 − パッケージ温度) / (パッケージ温度 − 周囲温度)
```

**周囲温度は記録されていないので、定数として仮定する。**基準は 25 °C とし、
**20 / 25 / 30 / 35 / 40 °C すべてで結果を示す**(M3)。

**この形が試験機の操作を跨げる理由:**
外部加熱の大きさは分子と分母の両方を同じ比率で押し上げるため、比では消える。
設定温度を250から230へ下げても、素子が変わっていなければ指数は動かない。

**動作点は合わせる。**runをまたぐ比較は、**測定されたフランジ温度が同じ帯**でのみ行う。
帯は 100, 150, 200, 220 °C(±5 °C)の4つ。**この4帯は3つのrun全部が通過する。**

## 判定基準(実行前に固定)

| # | 基準 | 閾値 | 向き |
|---|---|---|---|
| **M1** | 動作点を合わせたとき、指数が run1 より run3 で**大きい**素子の数 | **6中5以上** | 劣化で熱の通りが悪くなるなら指数は上がる |
| **M2** | 同じ比較を**生の温度差**(フランジ − パッケージ)で行ったときの素子数 | 記述 | **モデルが何を足したか**を示す対照 |
| **M3** | 仮定した周囲温度 20〜40 °C で M1 の判定が変わるか | 変わらないこと | 仮定への依存 |

**向きは実行前に固定する。**ダイの接合が劣化すればフランジからパッケージへの熱の通りが悪くなり、
温度差は開き、指数は**上がる**。**下がった場合はFAILとし、閾値を裏返さない。**

## この検定が主張できないこと(先に書く)

- **指数は熱抵抗ではない。**周囲温度が記録されておらず、外部加熱の熱流も記録されていない。
  **「熱抵抗を測った」とは書かない。**書けるのは「設定温度に依らない指数が劣化とともに動いたか」だけである
- **パッケージ温度がダイ温度の代理であるという仮定**は、このデータでは検証できない
- **素子は能動領域のヒーターとして使われている**([docs/199](199_pulse_thermal_results.md))。
  EPSインバータのスイッチ動作ではない。**R2は満たされていない**
- **runは3つしかない。**素子ごとの傾きは検定できない。できるのは run1 対 run3 の符号だけである
- **6素子の符号検定である。**6中5は、偶然でも 7/64 = 11% 起こる。**強い証拠ではない**

## 失敗したときに何を言うか

M1が通らなければ、**「モデルの量にしても試験機の操作は跨げなかった」**と書く。
そのとき、[docs/199](199_pulse_thermal_results.md) 以降の4本が落ちた理由は
**観測量の選び方ではなく、この試験機が劣化の分離を許さない構造だった**ことになり、
**このデータセットからは熱経路の劣化を取り出せない**と結論する。
