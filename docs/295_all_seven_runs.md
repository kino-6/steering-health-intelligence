# 295. パワー段は捕まる — 7 run のうち run 1〜3 しか通していなかった

> **ユーザに「劣化の決定的瞬間を可視化して」と求められ、可視化するために全記録を読み直したところ発覚した。**
>
> [docs/269](269_real_degradation_results.md)・[271](271_slow_channel_results.md)・[273](273_power_stage_observables_results.md) の
> 「パワー段の劣化は捕まらない（6 素子中 0〜1）」は、**7 run のうち run 1〜3 しか記録器に通していなかった**結果である。
> 前駆は run 4〜7 にある（[docs/167](167_precursor_results_v2.md) が測った「故障の 1〜2 run 前」）。
> **記録器は劣化した区間を一度も見ていなかった。**

**追加取得ゼロ。** NASA PCoE MOSFET（取得済み）。

## 何が起きていたか

`scripts/real_degradation.py` の `device_series()` が `for r in (1, 2, 3)` だった。
これは [docs/167](167_precursor_results_v2.md) が**指紋の当てはめ窓**として run 1〜3 を使った名残で、
[docs/265](265_element_v2_results.md) の `element_v2.nasa_units()` がそれを**データ全体**として写し、
`slow_channel.py`・`power_stage_observables.py` がそのまま継いだ。

**当てはめの窓が、いつの間にか記録の全体になっていた。**
[TROUBLES.md](../TROUBLES.md) **T3（標本の一部しか見ずに全体を語る）の 5 件目**。しかも 3 文書にまたがる。

## 7 run 全部で回し直した（事前登録した基準・閾値はそのまま）

| 検定 | run 1〜3 のみ（旧） | **run 1〜7（本文書）** |
|---|---|---|
| 5 秒窓（[docs/269](269_real_degradation_results.md) R1） | 0/6 | **2/6**（基準 6 中 5、不成立のまま） |
| 遅い側 N=500（[docs/271](271_slow_channel_results.md) D1） | 1/6 | **5/6、PASS**。誤報は設計値の 1.2 倍 |

**run 1〜3 は 6 素子とも床の 0.2 倍以内で、そこだけを見れば「何も起きていない」のは当然だった。**

> **確定する結論**: パワー段の劣化は、**分の尺度の平均でなら**故障の 2〜3 run 前に捕まる（5/6）。
> 5 秒窓では 2/6 に留まる——瞬間ではなく、ゆっくり進む劣化だからである。
> **加速試験の時間で 1〜1.5 時間の先行。**市場の時間には換算しない。

## この結果が示していないこと

- 素子は能動領域のヒーターとして動いている。**EPS のスイッチ動作ではない**
- 加速試験の故障であり市場の故障ではない。**断続故障でもない（R12 未達）**
- 「1〜1.5 時間の先行」は試験機の時間である
