# 184. 誤り条件4の点検 — ADSは西側で後退している

## 判断

**[docs/182](182_business_judgment_update.md) の誤り条件4(ADS普及が量として足りない)は、**
**西側市場では既に踏まれている。しかも「伸びが遅い」ではなく「撤退が始まっている」。**

これは本研究にとって**最も不利な観測**である。そのまま記録する。

## 事実

### 西側OEMはL3から撤退している(2026年前半)

| OEM | 状態 |
|---|---|
| **Mercedes-Benz** | **Drive Pilot を一時停止**(2026-01)。2021年から提供、独で95km/hまで認可されていた |
| **BMW** | **Personal Pilot L3 を終了**(2026-04の7シリーズ改良で廃止)。2024年導入 |
| **Honda** | 同様に終了 |

理由として報じられているのは **高コスト・限定的なユースケース・弱い需要**である。

**Mercedes は5年間提供して止め、BMW は2年で止めた。** これは立ち上がりの遅れではなく、撤退である。

### 中国だけが商用展開している。ただし範囲は狭い

| 項目 | 内容 |
|---|---|
| 初認可 | **2025年12月**、MIIT が2車種を認可 |
| 車種 | Changan Deepal SL03 / BAIC Arcfox Alpha S(いずれも Huawei Qiankun ADS) |
| 範囲 | **指定区間のみ**(北京・重慶) |
| 速度 | **最大50 km/h**(Changan、渋滞環境) / **80 km/h**(BAIC) |

**指定区間・低速に限定された商用パイロットであり、一般販売の全車展開ではない。**

(「2030年に10%」という予測もあるが、**これは予測であって事実ではない**。本研究は予測を根拠に使わない)

## 何が壊れて、何が残るか

### 壊れたもの: 「規制が需要を硬くした」の実効性

[docs/177](177_sotif_direction_update.md) は「需要は規制の義務へ格上げされた」と結論した。**規制の存在は事実であり、これは変わらない。**
しかし**その規制が適用される車両が、西側では減っている。**

> **規制の存在と、需要の量は別である。** 義務が課される対象車両が無ければ、義務は需要にならない。

私はこれを混同していた。[docs/177](177_sotif_direction_update.md) は「ADS限定」を限界として挙げたが、
**その限定の中身(実際に何台あるか)を確認していなかった。**

### 残るもの1: 中国市場と、そこに出ている競合

**Nexteer MotionIQ/Health が量産投入されたのは中国のNEVである**([docs/178](178_sotif_straight_answer.md))。
Nexteer の SbW 量産も中国。**動いているのは中国であり、競合はそこに出ている。**

これは整合的である。ADSが動いている市場に、ADS向けの部品機能が出ている。

### 残るもの2: 類型判断そのもの

[docs/182](182_business_judgment_update.md) の判断は「**この種類の機能は有償で残る側か**」であり、**量の話ではない。**
規制が結果のみを義務化し方法を開けている構造([docs/183](183_autosar_capability_channel.md)でAUTOSARも同型と確認)は変わらない。

**類型は生きている。市場が小さいだけである。** この2つを混ぜない。

## 価値の置き場所が動く

L3が西側で後退すると、**SOTIF/ADS規制を需要の駆動源にする話が弱くなる。** 残る駆動源は何か。

| 駆動源 | 状態 |
|---|---|
| SOTIF/ADS規制の義務 | **西側では対象車両が縮小。中国に限定的に存在** |
| **OEM自身の品質・保証の経済性**(誤診による無駄な交換、フリート稼働率、診断工数) | **車両区分を問わない。ADSに依存しない** |

そして**Nexteer が名乗っている顧客価値は、まさに後者である**——
「フリート稼働率、整備計画、診断時間・費用の削減」([docs/178](178_sotif_straight_answer.md))。**SOTIFを名乗っていない。**

**L3の後退は、価値の置き場所を「SOTIF適合の支援」から「品質・保証の経済性」へ押し戻す。**
そして後者は、[docs/145](145_final_conclusions_and_interpretations.md) が「誰が、なぜ払うのか」として既に挙げていたものである
(「誤診による無駄な交換の実費」)。

**つまり本研究の価値主張は、SOTIFに寄りかからない形へ戻すべきである。**
SOTIFは**乗れる枠**として維持するが、**需要の主たる根拠にはしない。**

## 判断への反映

| 項目 | 更新前 | 更新後 |
|---|---|---|
| SOTIF方向の需要 | 規制により確定 | **規制は実在。ただし対象車両が西側で縮小中。中国に限定的** |
| 需要の主たる根拠 | SOTIF/ADS規制 | **OEMの品質・保証の経済性**(ADS非依存)。SOTIFは乗れる枠として維持 |
| 類型判断([docs/182](182_business_judgment_update.md)) | 有償側 | **変わらず**(量の話とは別) |
| 「成立する」と主張するか | しない | **しない**(変わらず) |

## 観測台帳への追加

- **西側OEMのL3再開または新規参入** — 撤退が一時的か構造的かの判定
- **中国のL3認可拡大**(車種数・区間・速度上限) — 今回の認可は指定区間・50〜80km/h。ここが広がるか
- **AUTOSARの capability 決定則の規格化**([docs/183](183_autosar_capability_channel.md) の誤り条件1-2)

## Rule Check

- **自分が出した判断の誤り条件を点検し、踏まれていることを確認して記録した**
- **予測(2030年10%)を根拠に使っていない**。使ったのは認可・製品終了の事実のみ
- 「規制の存在」と「需要の量」を混同していたことを、自分の誤りとして明記した
- 壊れたもの(規制を需要の駆動源とする話)と残るもの(類型判断)を分けた。**都合の悪い方を丸めていない**
- 価値の置き場所が [docs/145](145_final_conclusions_and_interpretations.md) の元の位置へ戻ることを示した
