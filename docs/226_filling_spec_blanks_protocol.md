# 226. 仕様の空欄を2つ埋める — 事前登録

**結果を1つも見る前に書き、単独でコミットする。**

## 何を埋めるか

[docs/225](225_recorder_specification.md) は空欄を6つ残した。**うち2つは手元のデータで埋まる。**

| 空欄 | 埋まるか | 理由 |
|---|---|---|
| ECU内部信号の観測床 | **埋まらない** | 断続故障の公開データが無い |
| **指紋の掃引幅** | **埋まる** | 実車が実際に訪れる動作点の分布が commaSteeringControl にある |
| **保持期間** | **埋まる** | 次に整備工場へ確実に来るまでの間隔が英国車検データにある |
| 事前バッファ長 | **設計で消える**(後述) | — |
| 許容逸脱の下限 | 埋まらない | 車両レベル安全目標からの配分。部品側で決まらない |
| 検出確率・誤検出率 | 埋まらない | 故障データが無い |

## 事前バッファ長は設計で消える

[docs/225](225_recorder_specification.md) は「**アシストが有効な間は常に武装する**」と決めた。
常時武装なら記録は回り続けるバッファであり、**「トリガの何秒前から」という問いが立たない。**
**バッファ長 = 窓長 = 5秒以上**である。

**これは新しい根拠ではなく、既に決めた設計から出る帰結である。**そう明記して空欄から外す。

## 空欄A: 指紋の掃引幅

[docs/197](197_what_limits_the_declaration.md) の「1.7〜3.0倍」は試験機の手順の性質であり
実車に移せない([docs/199](199_pulse_thermal_results.md))。

**正しい問いは「実車はどれだけの動作点範囲を訪れるか」である。**
出荷時指紋はその範囲を覆っていなければ、運用中ずっと外挿になる。

commaSteeringControl 4車種2,495ログ、制御が有効で運転者が介入していない標本について:

- **速度**(`vEgo`)と**操舵角の大きさ**(`|steeringAngleDeg|`)の分布
- 各ログ内での範囲(そのログが訪れた幅)と、車種全体での範囲
- **報告する量**: 標本の 90% / 99% を覆う範囲、および1ログが典型的に覆う範囲

**「1ログが覆う範囲」と「車種全体の範囲」の比が、1回の走行で指紋を採った場合の不足倍率にあたる。**

## 空欄B: 保持期間

記録は**次に整備工場へ確実に来るまで**生きていなければならない。
英国では車検が法定であり、**連続する2回の受検間隔がその上限を与える。**

英国車検 2024→2025 を車両IDで連結した乗用車について:

- 連続する検査日の**間隔の分布**(中央値、90パーセンタイル、最大)
- 母集団は [docs/150](150_advisory_precedence_verification.md) と同一(乗用車・通常検査・両年受検)

## 判定基準(いま固定する)

**どちらも記述統計である。合否判定を置かない。**代わりに報告の規則を固定する。

| # | 報告するもの | 規則 |
|---|---|---|
| **A1** | 車種ごとの、標本90%/99%を覆う速度と操舵角の範囲 | 分母(標本数・ログ数)を必ず併記 |
| **A2** | 1ログが覆う範囲の中央値 と 車種全体の範囲 の比 | **これが「1回の走行では何倍足りないか」である** |
| **B1** | 車検間隔の中央値・90パーセンタイル・最大 | 分母(車両数)を必ず併記 |
| **B2** | 仕様に書く保持期間 | **90パーセンタイルを採る。**中央値でも最大でもない理由を書く |

- **B2で90パーセンタイルを採ると先に決める。**結果を見てから分位点を選ばない
- **v2は作らない**

## 事前に認めておくこと

- **A: openpilot搭載4車種の走行である。**一般の車両分布ではない。
  また**制御が有効な区間のみ**であり、駐車・低速の据え切りは含まれない可能性が高い
- **A: 動作点は速度と操舵角のみ。**温度は commaSteeringControl に無い。
  **指紋が本当に掃引すべき軸(温度)は、このデータでは決まらない**
- **B: 車検間隔は「確実に工場へ来る」上限であって「実際に来る」間隔ではない。**
  車検の間に整備で入庫する車両はこれより短い。**したがって保持期間の要求としては保守側**
- **B: 英国の制度である。**他国の法定間隔は異なる
- **B: 両年受検した車両のみ。**間隔が2年を超える車両は母集団から落ちている

## Rule Check

- **埋まらない4欄を先に列挙し、埋める2欄と区別した**
- 事前バッファ長が**新しい根拠ではなく設計の帰結**であることを明記した
- **B2の分位点を結果を見る前に固定した**
- Aで温度軸が決まらないこと(指紋にとって最も重要な軸)を先に認めた
- Bが保守側の値になることを先に書いた
