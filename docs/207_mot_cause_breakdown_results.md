# 207. パワーステアリングの兆候は33.9倍 — ただし中身は油圧の漏れで、機能不全には兆候の階層が存在しない

[docs/206](206_mot_cause_breakdown_protocol.md) の事前登録を実行した。

| # | 問い | 結果 |
|---|---|---|
| **M1** 原因別の先行率 | **兆候あり群は 2.333%、clean 0.069% = 33.9倍**(n = 54,431 / 16,994,497) |
| **M2** 原因特異性 | **形式上は成立(1/2)。ただし検定できた族が2つしかなく、根拠は薄い** |
| **M3** 配線の兆候→機能不全 | **検定不能**(該当車両28台 < 100)。**倍率を報告しない** |

## M1 — パワーステアリング固有で33.9倍

| 2024年の状態 | n | 2025年PS不合格率 | 倍率 |
|---|---|---|---|
| clean | 16,994,497 | 0.069% | 1.0 |
| **兆候のみ** | **54,431** | **2.333%** | **33.9** |
| 不合格あり | 11,830 | 4.235% | 61.6 |

**[docs/189](189_five_limits_tested.md) ① を訂正する必要がある。**
あちらは `Electronic power steering` 配下の**9項目**だけを見て「EPS兆候が2,177万台中64台」「検定不能」と結論した。
**一般の `Power steering` 59項目では、兆候のみの車両が 54,431 台あり、先行性が測れる。**

族別:

| 2024年の兆候 | n | 2025年PS不合格率 | 倍率 |
|---|---|---|---|
| leak(漏れ・油面) | **40,402** | 2.735% | 39.8 |
| corrosion(腐食) | 14,490 | 1.318% | 19.2 |
| damage(損傷) | 588 | 1.531% | 検定不能(n<1,000) |
| geometry | 86 | 0.000% | 検定不能 |
| modification | 37 | 8.108% | 検定不能 |
| **security / function** | **0** | — | **記録が存在しない(後述)** |

## いちばん重要な2点

### 1. この信号の中身は油圧である

**兆候54,431台のうち40,402台(74.2%)が leak 族**——`fluid level below minimum` / `leaking` / `has slight seepage` である。
**これらは作動油を持つ系の項目であり、電動のみのEPSには存在しない。**

> **33.9倍という数字は本物だが、その主成分は油圧系の漏れである。**
>
> **追記(2026-08-29, [docs/209](209_mot_nonhydraulic_results.md))**: 油圧を兆候からも不合格からも除いて測り直したところ、
> **22.0倍が残った**(n = 14,029)。**33.9倍は油圧の性質ではなかった。**ただし残った中身は実質的に腐食1族である。
> **電動パワーステアリングの劣化を代表する数字として使ってはならない。**

### 2. 機能不全には「兆候」の階層が存在しない

`function` 族(inoperative / malfunctioning / warning lamp indicates a failure)の**兆候記録は0件である。**
少ないのではない。**検査基準にその区分が無い。**

検査項目を確認すると、機能系の項目は不合格の文言しか持たない:

| 項目 | 兆候(advisory) |
|---|---|
| 7349 inoperative | **無し** |
| 7350 malfunctioning | **無し** |
| 1076 warning lamp indicates a failure in the system | **無し** |
| 30697 inoperative and steering adversely affected | **無し** |

一方、物理的な劣化を見る項目には対がある(slightly corroded / excessively corroded など)。

> **機能は「半分動く」を記録できない。動くか動かないかである。**
> したがって**車検制度は、機能不全の前駆を原理的に記録できない。**

これは [docs/189](189_five_limits_tested.md) ① の「記録が少なくて測れない」より強い結論である。
**少ないのではなく、そういう記録が制度に存在しない。**
そして本研究が扱う断続故障は、まさにこの `malfunctioning` の側にある。

## M2 — 形式上は成立するが根拠は薄い

```
S_X = P(2025に族Xで不合格 | 2024に族Xの兆候) / P(2025に族Xで不合格 | 何らかのPS兆候)
```

| 族 | n | 同族不合格率 | 全兆候での率 | S |
|---|---|---|---|---|
| corrosion | 14,490 | 0.524% | 0.169% | **3.10** |
| leak | 40,402 | 2.426% | 1.973% | **1.23** |
| その他5族 | いずれも n < 1,000 | | | **検定不能** |

事前登録の基準は「n≥1,000 の族の半数以上で S≥2.0」であり、**1/2 で形式的には満たす。**

> **しかし検定できた族が2つしかなく、うち1つは基準を割っている。**
> **「原因特異的である」と強く主張しない。**言えるのは
> **腐食の兆候は腐食の不合格を特異的に予告する(S=3.10)が、漏れはそうではない(S=1.23)**までである。

漏れが特異的でないのは解釈できる。作動油が減れば系全体に影響し、
特定の部位ではなく複数の項目で落ちるからである。

## M3 — 検定不能

配線の兆候(`wiring slightly corroded` / `wiring slightly damaged`)を持つ車両は、
両年受検の母集団で **28台**であった。事前登録の下限100台に届かない。

**倍率は報告しない。**28台で倍率を語れば、[docs/189](189_five_limits_tested.md) ① の「7台中1台で907倍」と同じ誤りになる。

配線の項目は存在するが、**2024年通年で兆候が99件しか記録されていない**(不合格側も同様に稀)。
[docs/148](148_dvsa_mot_denominator_verification.md) が指摘した「整備現場は電気系を汎用項目で記録する」構造と整合する。

## 主張がどう動くか

| 主張 | 変化 |
|---|---|
| [docs/189](189_five_limits_tested.md) ①「EPSの兆候→故障は検定不能」 | **範囲を訂正。**9項目では不能だが、**59項目では54,431台で測れる(33.9倍)** |
| その33.9倍がEPSを代表するか | **代表しない。**74.2%が油圧の漏れ |
| 機能不全の前駆を車検で捉えられるか | **原理的に不可能と確定。**兆候の区分が制度に無い |
| [docs/175](175_close_contact_question.md) 接点系の問い | **実車側からも届かなかった。**配線項目は28台 |
| 外部観測が部品内部を見られないこと | **さらに強くなった。**制度が機能の中間状態を持たない |

## 限界(緩めない)

- **検査員の目視所見である。**部品内部の状態ではない
- **兆候は放置され不合格は修理される**([docs/150](150_advisory_precedence_verification.md))。群間比較にこの非対称が入る
- **選択効果を除去できない。**兆候が付く車種・車齢はもともと壊れやすい可能性がある
- **英国市場のデータである**
- **M2は2族のみで判定した。**形式上の成立であり、根拠は薄い
- **族の分類は語による。**同一項目が複数の語を含む場合、先に一致した族に入る

## Rule Check

- **M3の28台で倍率を語らなかった。**事前登録の下限を守った
- **M2の形式的成立を、根拠が薄いと同じ節に書いた。**「原因特異的と判定」だけを書かない
- **33.9倍という有利な数字の主成分が油圧であることを、数字と同じ節に書いた**
- docs/189① の訂正範囲を「不能→可能」ではなく「9項目では不能、59項目では可能」と正確に書いた
