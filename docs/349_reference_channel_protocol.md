# 349. 事前登録 — 第 2 の温度を基準に使うと、単体素子でも劣化兆候が出るか

## ユーザ指摘(2026-09-09)

> 「回答になってない。**モデルで劣化兆候がわかるという話だったのでは？**」

**そのとおりで、報告の重心が狂っていた。**

| | 状態 |
|---|---|
| 同種チャネルがある実インバータ | **検出 8/8、遅い側の誤報 0**（[docs/286](286_common_mode_results.md)） |
| 換算モデル | **記録から誤差 0.003 で復元**（[docs/333](333_power_module_model_results.md)） |
| 劣化の推移 | **連続量として出る。健全期のばらつきの 15 倍**（[docs/334](334_capability_trace.md)） |
| **NASA 単体素子** | 2〜5/6。**この試験は 1 素子なので同種チャネルが無い** |

**「検出が載らない」と書いたのは、同種チャネルが無い場合の話である。**
EPS は半ブリッジ温度 3 つと相電流 3 つを持つので、**その場合には当たらない。**

## そして NASA にも第 2 の温度がある

記録には **`packageTemperature` と `flangeTemperature`** の 2 つがある。
[docs/302](302_multivariate_results.md) が「フランジ−パッケージ温度差」を候補として挙げたまま、**試していない。**

**この差は熱の流れを表す。**素子の発熱が増えれば差が広がる。
**つまり、動作点とは別の経路で劣化に反応しうる。**

## 問い

**基準値を採るときにこの温度差を入れると、健全期の傾向は減るか。減れば検出は改善するか。**

## 手順

1. いまの基準: `R_on = a·Tp + b`
2. **試す基準: `R_on = a·Tp + c·(Tf − Tp) + b`**（項が 1 つ増えるだけ）
3. 6 素子それぞれで、健全区間（run 1〜4）の残差について
   - **α（[docs/348](348_drift_shape_results.md) と同じ測り方）**
   - 残差の広がり（床いくつ分）
4. 水準の閾値で、run 4 の誤報と run 5〜7 の発火を数える（[docs/315](315_boundary_vs_refresh_results.md) と同じ）
5. **出荷時基準値は 56 → 60 バイト/チャネルになる。**その分も書く

## 事前に決める判定

| | 基準 |
|---|---|
| **R1** | 健全区間の α の中央値が **1.2 未満**に下がる（[docs/348](348_drift_shape_results.md) は 1.32） |
| **R2** | 誤報を run 4 で 3 倍以内に保ったまま、run 5〜7 で発火するのが **6 中 5 以上** |
| **R3** | R2 が満たされないとき、**いまの基準（2〜5/6）より良くなっているか悪くなっているか**を書く |

**R1 と R2 が両方外れたら、この温度差は使えないと結論する。**
**当たるまで別の項を足すのは事後の探索である**（[TROUBLES.md](../TROUBLES.md) T17）。**この 1 項だけを試す。**

## この事前登録が外れる条件

- **フランジ温度も試験機のヒーターが決めている可能性がある。**
  加えた項が劣化ではなく試験機の操作を写すなら、[TROUBLES.md](../TROUBLES.md) T1 の 7 回目になる。
  **実行前に、フランジ温度が run ごとにどう動くかを確認する**
- 項を 1 つ足せば当てはまりは必ず良くなる。**当てはまりではなく、健全期の α と誤報で判定する**
- 6 素子・1 試験機。**EPS ではない**
