# 280. 指紋の区間は律速ではなかった。失敗は2種類あり、別々の原因である

[docs/279](279_fingerprint_interval_protocol.md) の事前登録を実行した。**追加取得ゼロ。**

> **W2 不成立。改善しなかった。**誤報が基準内のチャネルは 5→4、検出は 3/8 のまま。
> **[docs/279](279_fingerprint_interval_protocol.md) の規則(漂流 < 床1つ)は、誤報するチャネルを1つも予測しなかった。**
>
> **したがって W4 が成立する——指紋を採る区間は律速ではない。**

実行: `python3 scripts/fingerprint_interval.py` / 数表: [data/fingerprint_interval.tsv](../data/fingerprint_interval.tsv)

## 判定

| # | 基準 | 結果 |
|---|---|---|
| **W1** | 条件を満たす区間があるチャネル数 | **8/8。**全チャネルで見つかる |
| **W2a** | 誤報が基準内のチャネルが5より増えるか | **4。減った。FAIL** |
| **W2b** | 検出が3/8より増えるか | **3/8。変わらず。FAIL** |
| **W3** | 同じ規則をパワー段に当てると | **6/6が交差検証を通る。**判定は変わらない |
| **W4** | 変わらなければ指紋の区間は律速ではない | **律速ではない** |

## 規則が外れた理由を3段階で追った

**① 漂流を動作点軸で測った。**T1 は漂流 0.02 で条件を通り、それでも**正常データの76%で誤報**した。

**② 時間軸で測り直した。**T1 は 0.86。**それでも条件内である。**漂流では説明できない。

**③ 水準のずれを測った。**指紋区間の前半で採った指紋が、後半をどれだけ外すか:

| チャネル | 水準のずれ(床) | 誤報(設計比) | 予測は当たったか |
|---|---|---|---|
| **T1** | **1.57** | 27,231倍 | **当たり** |
| Ib | 3.82 | 0.0倍 | 外れ(ずれるのに静か) |
| Vdc | 0.00 | 16.8倍 | 外れ(ずれないのに鳴る) |
| T2 | 0.57 | 1,683倍 | 外れ |
| Vd | 0.00 | 134.6倍 | 外れ |

**8チャネル中4つしか当たらない。水準のずれでも説明できない。**

## 実際に壊れているのは2チャネルだけである

**誤報の絶対値を見ると、話が変わる。**

| チャネル | 誤報の実数 | 設計比 |
|---|---|---|
| **T1** | **75.6%** | 27,231倍 |
| **T2** | **4.7%** | 1,683倍 |
| Vd | 0.37% | 134.6倍 |
| Vdc | 0.047% | 16.8倍 |
| 他4つ | **0%** | 0倍 |

**設計値(1件/時 = 0.0028%)に対する3倍という基準は、超過が数個しかないチャネルでは
統計として脆い。**Vdc の 0.047% は絶対値では小さい。

> **本当に壊れているのは T1 と T2 だけである。**
> **[docs/278](278_inverter_recorder_results.md) が「5チャネルが基準内」と書いたのは、
> 脆い基準で線を引いた結果であり、実態は「2チャネルが壊れ、6チャネルは概ね静か」である。**

**ただし判定は変えない。**[docs/279](279_fingerprint_interval_protocol.md) が置いた基準で W2 は不成立である。
**基準を後から緩めない。**

## W3 — パワー段の失敗は別の原因である

同じ交差検証(指紋区間を半分に割り、後半で水準がずれるか)をNASA MOSFETに当てた:

| 素子 | 水準のずれ(床) |
|---|---|
| Test_8 | 0.06 |
| Test_9 | 0.09 |
| Test_10 | 0.10 |
| Test_11 | 0.15 |
| Test_12 | 0.08 |
| Test_14 | 0.04 |

**6/6で通る。**パワー段の指紋は再現する。

> **失敗の型は2つあり、原因が違う。**
>
> | | 指紋は再現するか | 検出できないのはなぜか |
> |---|---|---|
> | **実インバータの温度2チャネル** | **しない**(1.57床ずれる) | **基準が信用できない** |
> | **パワー段6素子** | **する**(0.04〜0.15床) | **前駆が床に対して小さい**([docs/271](271_slow_channel_results.md)) |
>
> **どちらも「指紋を採る区間の選び方」では直らない。**

## 仕様に足すこと

**区間の選び方ではなく、チャネルの採否である。**

> **出荷時に、指紋を別の正常区間で検証する。**
> **その区間の残差水準が床1つ分を超えてずれるチャネルは、宣言に使わない。**
>
> これは [docs/225](225_recorder_specification.md) の「正規化できない条件では宣言しない」を、
> **運用時ではなく出荷時に、条件ではなくチャネルに対して適用したものである。**

**この規則で落ちるのは、実インバータでは T1 のみ(1.57床)。T2 は 0.57 で通ってしまう。**
**したがってこの規則も完全ではない。そう書く。**

## この結果が示していないこと

- **故障は人為的に導入されたものである。**劣化ではない。R12は未達
- **1台のみ、8チャネルのみ。**チャネル採否の規則を一般化できる標本数ではない
- **「記録器が使えない」とは言えない。**2種類の失敗の原因を分離しただけである
- **T2 が規則をすり抜けることを、規則を調整して直していない**

## Rule Check

- **事前登録した規則(漂流 < 床1つ)が、誤報するチャネルを1つも予測しなかったことを書いた**
- **3段階の診断を、当たった数(4/8)まで含めて書いた**
- **「実態は2チャネルだけが壊れている」と分かった後も、事前登録の基準で不成立と判定した**
- **新しい規則(チャネルの採否)が T2 を取りこぼすことを、隠さず書いた**
- **パワー段の失敗が別原因であることを、交差検証の数字で分離した**
