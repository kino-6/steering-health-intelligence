# 203. 別機体では再現しなかった

**1.0 kW で得た巻線側の結論は、1.5 kW と 3.0 kW で再現しなかった。**

[docs/202](202_cross_machine_replication_protocol.md) の事前登録を実行した結果である。
事前登録は**ダウンロード前にコミット済み**であり、確認用の2機体は登録時点で一度も開いていない。

実行: `python3 scripts/cross_machine_replication.py` /
数表: [data/cross_machine_replication.tsv](../data/cross_machine_replication.tsv)

## 判定

| # | 問い | 結果 |
|---|---|---|
| **X1** capability規則(層間短絡)は再現するか | **不成立**(ρ = +1.000 / +0.400、必要 ≤ −0.80) |
| **X2** 「電流はコイル間短絡に効かない」は反証されるか | **形式上は反証されず**。ただし評価できた1機体では **ρ = −1.000** で効いていた |
| **X3** 振動の向きは故障種で逆か | **確認できず**(4件中2件が逆向き、1件は評価不能) |

## 何が起きたか

### X1 — 電流の平衡指標は機体によって向きが違う

| 機体 | 層間短絡での C1 の動き | ρ |
|---|---|---|
| 1.0 kW([docs/195](195_capability_rule_second_mechanism_results.md)) | 1.0000 → 0.9518(**下がる**) | **−1.000** |
| **1.5 kW** | 1.0000 → **1.0126**(**上がる**) | **+1.000** |
| **3.0 kW** | 1.0000 → 1.0051(ほぼ動かない) | +0.400 |

**1.0 kW で見えた「severityが上がると相電流の平衡が崩れて capability が下がる」は、他の2機体では起きない。**
1.5 kW では逆向きに動く。

### X2 — こちらも1.0 kW と逆だった

| 機体 | コイル間短絡での ρ |
|---|---|
| 1.0 kW([docs/201](201_motor_second_fault_and_vibration_results.md)) | −0.400(**効かない**と書いた) |
| **1.5 kW** | **−1.000(効いている)** |
| 3.0 kW | **評価不能**(健全記録が単独の測定日にあり、同一セッションに比較対象が無い) |

事前登録の反証条件は「2機体の両方で|ρ|≥0.8」だったので、形式上は反証されない。
**しかし評価できた唯一の機体は docs/201 と逆の結果である。**「効かない」とは言えなくなった。

### X3 — 向きは逆にならなかった

| 機体・故障種 | 期待した向き | 実際 |
|---|---|---|
| 1.5 kW 層間 | 下がる | **上がる**(ρ = +1.000、1.000→4.470) |
| 1.5 kW コイル間 | 上がる | 上がる(+1.000) ✓ |
| 3.0 kW 層間 | 下がる | **上がる**(+0.400、17.86%で 8.302 へ跳ぶ) |
| 3.0 kW コイル間 | 上がる | **評価不能** |

**1.0 kW の層間短絡で振動が下がったこと(1.000→0.281)は、他機体では起きない。**
[docs/202](202_cross_machine_replication_protocol.md) で「1件でも外したら確認できなかったと書く」と縛った。**確認できなかった。**

## 実行中に直した欠陥(2つ。どちらも判定を変えていない)

### 1. ファイル名の不統一

3.0 kW のコイル間短絡の振動ファイルだけ `_coil` で、他は全部 `_intercoil` である。
初回実行では**8ファイルを黙って落としていた。**両方を受けるよう直した。

### 2. セッション識別子が新機体で機能しなかった

docs/202 は**意図**として「健全記録を含むセッションのみを解析する」と登録し、
**実装**として [docs/162](162_pmsm_model_validation_results.md) のC相極性反転を使った。
**1.5 / 3.0 kW ではこの反転が起きない。**しかし記録は明らかに2群に分かれていた。

**TDMSのメタデータに録音日時が入っていた。**

| 機体・故障種 | 2022-01-25 | 2022-03-08 | 2022-08-11 |
|---|---|---|---|
| 1.0 kW 層間 | **0, 3.35, 6.48, 21.69** | 2.26, 2.70, 4.41, 12.17 | |
| 1.0 kW コイル間 | 0, 1.01, 2.00, 7.56 | 0.68, 0.81, 1.34, 3.93 | |
| 1.5 kW 層間 | 0, 2.34, 4.57, 16.08 | 1.57, 1.88, 3.10, 8.74 | |
| 1.5 kW コイル間 | 0, 7.02, 13.12, 37.66 | 4.79, 5.70, 9.15, 23.20 | |
| 3.0 kW 層間 | 0, 2.65, 5.16, 17.86 | 1.78, 2.13, 3.50, 9.81 | |
| 3.0 kW コイル間 | **0 のみ** | | 2.49 〜 23.48 の7点 |

**このデータセットは3機体すべて、故障種ごとに、数か月離れた測定キャンペーンに分かれている。**
そして 1.0 kW 層間短絡の 2022-01-25 群は、**docs/195 が極性から求めた S2 と完全に一致する。**
古い識別子が機能した機体では、新しい識別子が同じ答えを出す。

日付は**閾値ではないので、判定に向けて調整できない。**この置き換えは、
**極性版の結果が落ちるのを見た後に行った。**その事実を書いたうえで、両方の結果を出す。

| 判定 | 極性版(登録どおり) | 日付版(欠陥修正後) |
|---|---|---|
| X1 | 不成立(+0.381 / −0.143) | **不成立**(+1.000 / +0.400) |
| X3 | 確認できず | **確認できず** |

**2つの欠陥を直しても、判定は1つも変わっていない。**

## 主張がどう動くか

| 主張 | 変化 |
|---|---|
| [docs/195](195_capability_rule_second_mechanism_results.md) 「規則の形は層間短絡へ転移した」 | **1.0 kW 限定に降格。**他2機体で再現しない |
| [docs/201](201_motor_second_fault_and_vibration_results.md) 「電流はコイル間短絡に効かない」 | **取り下げ。**1.5 kW では効いている |
| [docs/201](201_motor_second_fault_and_vibration_results.md) 「振動の向きが故障種で逆」 | **取り下げ。**確認できなかった |
| [docs/201](201_motor_second_fault_and_vibration_results.md) 「電流は巻線故障の片方しか見ない」 | **根拠を失う。**1機体の観察に依存していた |
| **測定キャンペーンの層別が必須であること** | **さらに強くなった。**3機体6セル全部に段差があり、**メタデータから一意に取れる** |

## 生き残っているもの

- **個体/セッション基準を持たない監視は、キャンペーンの段差を故障と誤読する。**
  3機体6セルすべてで確認された。これはこの研究の一貫した主張であり、今回最も強化された
- **キャンペーンはファイルのメタデータから復元できる。**
  このデータセットを使う解析はすべて日付で層別すべきである
- 車検・NHTSA側の結論([docs/148](148_dvsa_mot_denominator_verification.md), [docs/185](185_misdiagnosis_quantified.md), [docs/190](190_assembly_replacement_meaning.md))は、本件の影響を受けない

## 限界

- **各セル4点である。**ρ = ±1.000 も4点では弱い
- **3機体は同一設備・同一グループ由来。**独立性は機体までで、系統誤差は共有する
- **severity の定義が機体間で比較可能かは確認していない。**同じ%が同じ物理量とは限らない
- **3.0 kW のコイル間短絡は評価できていない。**健全記録が単独の測定日にある
- **人工的に作られた故障である**

## Rule Check

- **再現しなかったことを冒頭に置いた。**自分の過去の結論を降格・取り下げた
- **2つの欠陥修正を、判定が変わらないことと合わせて開示した**
- 日付への置き換えを「落ちるのを見た後に行った」と明記し、極性版の結果も残した
- X3を「4件中2件が逆」と正確に書いた。**「2件は合った」と書かない**
- X2が形式上反証されないことと、**唯一評価できた機体が逆だったこと**を両方書いた
