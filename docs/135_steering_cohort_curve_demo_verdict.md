# Steering Cohort Curve Demo: Verdict

## 結論

フェーズC(Demo構築 v2)を実装し、答え合わせに**成功**した。

> **公開苦情データだけで、車種×年式の群レベルの操舵系リスク傾向は読める。**
> 既知のリコール対象cohort(Ford Fusion MY2011–2012、EPASリコール15V-340)は、同一車種の比較cohort(MY2013–2014)に対して、操舵系苦情比率で**2倍以上**浮いた。盲検的な集計が、公式のリコール事実を正しく再現した。

| 年式cohort | 位置づけ(公開文書) | 全苦情 | 操舵系 | **操舵系比率** | 累積(車齢48ヶ月) |
|---|---|---:|---:|---:|---:|
| MY2010 | 調査対象(PE14-030) | 5,122 | 1,657 | 32.4% | 109 |

これにより、需要マップ([docs/133](133_failure_prediction_demand_map.md))の**空席(2)「群レベルの故障傾向」は、公開データで実際に埋められる**ことが実証された。

## 何を判断したか

docs/134の判定条件「車齢×操舵系不具合率の曲線が誠実に引けるか」に対する実装での回答である。

「誠実に」の3条件と、その充足:

1. **分母や偏りの問題を隠さない**: 分母(稼働台数)がないことをHTML内に明記し、比率(操舵系/全苦情)で販売規模差を部分補正。さらに**リコール公表(2015年7月)後の届出スパイクを第2チャートとして意図的に可視化**した——苦情データの社会的な歪みを、隠すのではなく成果物の一部にした
2. **個車の未来の予測に見せない**: HTML冒頭と末尾に「言ってよいこと/いけないこと」を明記
3. **既知の事実と突き合わせて検証**: リコールcohortが浮くかの盲検テストに合格

## 興味深い副次観測(過剰解釈しないこと)

- MY2010(調査対象)は比率32.4%で、リコールcohortと比較cohortの**中間**に位置する。PE14-030が調査で終わりリコールの主対象にならなかった事実と整合的な位置であり、曲線の解像度がリコール有無の二値より細かい可能性を示す。ただし1事例であり一般化しない
- 累積曲線の形も異なる: リコールcohortは車齢2〜4年で急伸、MY2010は後年に伸びる。故障モードの発現時期の違いを示唆するが、報告バイアス(2015年のリコール報道)と交絡しているため、発生日ベースでも慎重な解釈が要る

## Rule Check

今回の判断では、[AGENTS.md](../AGENTS.md) の次を適用する。

1. `Market Demand First`: 買い手はdocs/133で特定済み(EPSサプライヤ内部の品質改善・製品企画。次期設計の重点、評価計画、RFQ回答の裏付け)
2. `Natural Language First`: 結論を表と平文で先に示した
3. `EPS Supplier Lens`: この曲線はEPSサプライヤが自社搭載車種について公開データだけで引ける。内部保証データと重ねれば解像度が上がる(それは実行段階)
4. `Kaggle / Public Proxy Predictive Value Rule`: 個車RUL・交換時期・保証費削減を主張しない。群曲線は過去の記述である
5. 特定OEM批判の禁止: Ford Fusionは「リコールが公開されており答え合わせができる」事例として選んだ。設計優劣の主張には使わない(HTML内にも明記)

## 限界(正直に)

1. 苦情は自己申告であり、分母(稼働台数)がない。絶対率は出せない
2. 報告バイアスが大きい(第2チャートで可視化)。発生日ベースの集計でも、リコール報道後は過去の事象の掘り起こし届出が混ざる
3. STEERINGカテゴリはEPS以外(機械系)も含む
4. 1車種系列での検証である。他車種への一般化は追加検証が要る
5. 車齢起点は年式年1月1日の近似
6. 答え合わせが成功したのは「事後に」リコールを知っているから。この曲線が「事前に」異常を検知できたかは、時点を区切ったバックテスト(2013年時点のデータだけで2011-2012 cohortの浮きが見えたか)が必要——**これが次の自然な検証**
