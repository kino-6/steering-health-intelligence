# 236. ストレスランプを除いて劣化を測る — 事前登録

**結果を1つも見る前に書き、単独でコミットする。追加取得はゼロ。**

## なぜ

[docs/234](234_igbt_switching_results.md) は、観測量の変動が**試験機のストレスランプ**
(供給 2.5→6.0 V、設定 100→280 °C)で説明できることを示し、H1は不成立だった。

**同じ動作点に留まっている区間だけを取り出せば、ランプを除いた劣化が見える可能性がある。**
条件別に数えたところ、全4個体に18〜63回の過渡波形を持つ条件群があった。

**これは「落ちた後に条件を切り直す」操作である。**したがって規則を先に固定する。

## 縛り(先に置く)

1. **条件群の選び方を、結果と無関係な規則で固定する**——
   **各個体で、過渡波形の数が最も多い条件群**を選ぶ。値は見ない
2. **最小群サイズ 18** を先に決める。届かない個体は「評価不能」と書く
3. **観測量は [docs/233](233_igbt_exclusion_retracted_protocol.md) と同一。**新しい特徴量を足さない
4. **[docs/234](234_igbt_switching_results.md) の判定は取り消さない。**あれは全期間についての結果であり、本件は別の検証である

## 手順(固定)

- 各過渡波形の時刻に対して、直前の制御器記録から `(supplyVoltage, highTemp)` を割り当てる
- **個体ごとに、最も件数の多い `(supplyVoltage, highTemp)` の組を選ぶ**
- その群の波形を**時刻順**に並べる(群の中で時間が飛んでいてもよい。同一条件・異なる時刻の比較になる)
- 観測量([docs/233](233_igbt_exclusion_retracted_protocol.md) と同一):
  - **A. ターンON遅れ**、**B. 導通時 V_ce**、**C. ゲートのミラー段**
- **個体基準**: 群の**最初の30%**から中央値と散らばり(3×1.4826×MAD)

## 判定基準(いま固定する)

| # | 基準 | 閾値 |
|---|---|---|
| **J1 単調性** | いずれかの観測量が群内の時間に対して単調(\|ρ\| ≥ 0.8) | **評価できた個体の3以上** |
| **J2 余裕** | 群の最後30%での逸脱量 ÷ 基準の散らばり | **報告のみ** |
| **J3 群の条件** | 各個体で選ばれた `(供給, 設定温度)` と件数 | **報告のみ** |

- **J1が落ちたら、ストレスランプを除いても観測量は動かなかったと書く。**
  その場合、**このデータセットからは劣化の前駆は取り出せない**と結論する
- **比較は `lib_discipline.passes()` を使う**
- **v2は作らない。条件群の選び方も変えない**

## 事前に認めておくこと

- **設定値であって実測ではない。**`steadyState` は全チャネル NaN([docs/233](233_igbt_exclusion_retracted_protocol.md))。
  **同じ設定でも実温度が違っていた可能性を排除できない**
- **群の中で時間が飛ぶ。**その間に別の条件で運転されており、**その間の履歴が観測量に残る**
- **群が小さい**(18〜63)。単調性の検定として弱い
- **コレクタ電流は使わない**(600 mA のドリフト)
- **4個体、1日の試験。**故障に至ったかも未確認
- **IGBTであってEPSのMOSFETではない**

## Rule Check

- **「落ちた後の切り直し」であることを冒頭近くに書いた**
- 条件群の選び方を**結果と無関係な規則(最多件数)で固定した**
- 観測量を [docs/233](233_igbt_exclusion_retracted_protocol.md) から変えないと明記した
- **落ちた場合の結論(このデータからは取り出せない)を先に決めた**
- 設定値と実測の違いを限界の先頭に置いた
