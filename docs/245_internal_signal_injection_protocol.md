# 245. 部品内部の信号で同じ注入をする — 前駆の大きさと検出限界を突き合わせる。事前登録

**追加取得ゼロ。**

## 何を確かめるか

[docs/244](244_intermittent_injection_results.md) は**車両レベル**で検出限界を測った——
誤検出1.0%/窓で、**床の10倍**(1秒未満)、**床の5倍**(2秒)。

**部品内部の信号でも同じ倍率が要るのか、それとも違うのか。**これは測っていない。

そして突き合わせる相手がある。

> **[docs/167](167_precursor_results_v2.md) は、実部品の前駆が
> 健全時の床の 20〜300倍 の逸脱として現れることを測っている**(NASA MOSFET、6デバイス中6)。

**もし部品内部でも検出に10倍程度で足りるなら、前駆は十分な余裕をもって捕まることになる。**
**逆に部品内部では50倍必要なら、20倍の前駆は捕まらない。**

> **本検証は「前駆の大きさ」と「検出に必要な大きさ」を、同じ単位(その個体の床)で並べる。**

## 土台(すべて健全区間、既取得)

| データ | 使う区間 | 観測量 |
|---|---|---|
| **NASA MOSFET** | 各デバイスの **run 1〜3**([docs/166](166_precursor_results_v1.md) で固定した健全窓) | 温度正規化した導通抵抗の残差 |
| **KAIST PMSM** | **severity 0.00% の記録**(健全)、健全記録と同一測定日 | 相電流の平衡 `H = mean\|I\|/max\|I\|` の小窓系列 |

**劣化データは使わない。**健全区間に事象を注入し、検出器の性能だけを測る。

## 注入と検出器([docs/243](243_intermittent_injection_protocol.md) と同一)

- **矩形の加算**、振幅 A = その系列自身の床の {1, 2, 3, 5, 10, 20} 倍、
  継続 D = {1, 2, 5, 10, 20} 標本
- 窓 = **50標本**、重なりなし
- 検出器は **平均型**(窓の平均)と **事象型**(窓内の最大絶対値)の2つ
- **両検出器の閾値を、注入なしでの誤検出率 1.0%/窓 に揃える**

**窓と継続は「標本」であって秒ではない。**NASAとKAISTでサンプリングが違うため、
**秒に換算しない。**[docs/244](244_intermittent_injection_results.md) の秒表記とは直接比べない。

## 判定基準(いま固定する)

| # | 報告するもの | 規則 |
|---|---|---|
| **N1** | データ源ごと・検出器ごとに、検出率90%に達する最小振幅(床の倍数) | **全組み合わせを出す** |
| **N2** | その最小振幅と、[docs/167](167_precursor_results_v2.md) の前駆(床の20〜300倍)の比較 | **前駆が検出限界を上回れば「余裕がある」と書く** |
| **N3** | 車両レベル([docs/244](244_intermittent_injection_results.md))との比較 | **標本数の窓で揃えて比べる。秒では比べない** |

- **N2で前駆が検出限界を下回ったら、「前駆は捕まらない」と書く**
- **v2は作らない。**注入の形も窓長も検出器も変えない

## 事前に認めておくこと

- **これは検出器の性能であって、現象の実在ではない**([docs/243](243_intermittent_injection_protocol.md) と同じ)
- **[docs/167](167_precursor_results_v2.md) の前駆は恒久劣化の逸脱であり、断続事象ではない。**
  **「前駆が検出限界を上回る」は「断続故障が捕まる」を意味しない。**
  比べているのは大きさだけである
- **NASAの健全窓は run 1〜3 のみで、記録数が限られる**(デバイスあたり数千)
- **矩形という波形は仮定である**
- **どちらもEPS実機ではない**
- **[docs/199](199_pulse_thermal_results.md) のとおり、NASAの観測量はオン抵抗ではなく能動領域の動作点抵抗である。**
  床の推定には使えるが、物理的な意味づけはしない

## Rule Check

- **前駆と検出限界を同じ単位で並べるという目的を、冒頭に書いた**
- **N2が落ちた場合に何と書くかを先に決めた**
- **「大きさの比較であって、断続故障が捕まる証明ではない」**を限界の先頭近くに書いた
- 秒に換算せず標本で比べると先に決めた
