# 208. 油圧を除いたパワーステアリングの先行性 — 事前登録

**結果を1つも見る前に書き、単独でコミットする。**

## なぜ絞るか

[docs/207](207_mot_cause_breakdown_results.md) は、パワーステアリングの兆候のみが付いた車両の
翌年不合格率が **33.9倍**であることを示した。しかし**その兆候の74.2%は leak 族**
(`fluid level below minimum` / `leaking` / `has slight seepage`)であった。

**作動油を持つ系の項目であり、電動パワーステアリングには存在しない。**
油圧系の漏れは機械系の推定になるため、**本研究の対象から外す。**

## 対象の定義(実行前に固定)

- **兆候群(非油圧)**: 2024年にパワーステアリングの兆候が付き、**そのどれも leak 族でない**車両。
  leak 族の兆候を1つでも持つ車両は**除外する**(混入を避けるため、群の純度を優先する)
- **不合格(非油圧)**: 2025年のパワーステアリング不合格のうち、**leak 族以外**の族で落ちたもの
- **clean 群**: [docs/206](206_mot_cause_breakdown_protocol.md) と同一(2024年にPSの記録が一切無い)
- 母集団は [docs/150](150_advisory_precedence_verification.md) / [docs/206](206_mot_cause_breakdown_protocol.md) と同一:
  乗用車・通常検査・結果 P/F/PRS・2024と2025の両方で受検・車齢4〜25年

leak 族の判定語は [docs/206](206_mot_cause_breakdown_protocol.md) で固定済み: `leak|seepage|fluid|reservoir`。**変更しない。**

## 判定基準(いま固定する)

| # | 基準 | 閾値 |
|---|---|---|
| **N1 先行性が残るか** | 非油圧の兆候群の、非油圧不合格率が clean 群の何倍か | **3.0倍以上、かつ n ≥ 1,000 で「残る」と判定** |
| **N2 族別** | 非油圧の族ごとに率・倍率・n を報告 | **閾値なし。n < 1,000 の族は倍率を語らない** |
| **N3 量の確認** | 非油圧の兆候群が母集団に占める数 | **報告のみ** |

- **N1が落ちたら、油圧を除くと先行性は残らなかったと書く。**33.9倍は油圧の性質だったことになる
- n が届かない族は**検定不能**と書く。率だけを出して倍率を語らない
- **v2は作らない**

## 事前に認めておくこと

- **非油圧に絞っても、電動EPS固有にはならない。**腐食・損傷・固定不良は油圧式のポンプやホースにも起きる。
  **言えるのは「作動油の漏れではない劣化」までである**
- **検査員の目視所見である。**部品内部の状態ではない
- **機能不全(inoperative/malfunctioning)には兆候の区分が制度上存在しない**([docs/207](207_mot_cause_breakdown_results.md))。
  **したがって本検証も、機能不全の前駆には届かない**
- **兆候は放置され不合格は修理される**非対称が入る
- **選択効果を除去できない**
- **英国市場のデータである**

## Rule Check

- **「非油圧＝電動EPS」ではないことを、結果より先に書いた**
- leak 族の判定語を docs/206 から変更しないと明記した
- N1が落ちた場合に何と書くかを先に決めた
- 機能不全の前駆には本検証も届かないことを先に書いた
