# 165. 前駆指標の検証プロトコル(実行前に固定)

**このドキュメントは、DS015の値を見る前にコミットする。** [docs/140](140_recall_detection_protocol.md) / [docs/142](142_recall_detection_protocol_v2.md) / [docs/161](161_pmsm_model_validation_protocol.md) と同じ作法。

## 何を確かめるか

[docs/164](164_position_summary.md) が残した2つの未証明を、直接に狙う。

| ID | 問い |
|---|---|
| **A** | **部品内部の電気量に、hard failureに先行する情報が乗るか。乗るなら、どれだけ手前から見えるか** |
| **B** | **同一個体の健全時基準は、故障までにどれだけドリフトするか**(個体基準の有効期間) |

## 対象(実行前に固定)

- データ: NASA PCoE MOSFET Thermal Overstress Aging(DS015、パブリックドメイン)
- **解析対象は7 run揃った6デバイス: Test_8 / 9 / 10 / 11 / 12 / 14。** NASA文書の「6個体」と一致する
- run番号を劣化の進行順として扱う(run 1 = 最も健全、run 7 = 最終)
- Test_13(6 run、うち1つが `error setting up this run` と明記)、および run が1〜5個しかないデバイスは**除外**する

## 指標(実行前に固定、3つ)

各 (device, run) について `steadyState` の全レコードから算出する。

1. **R_on_raw** = median( drainSourceVoltage / drainCurrent )
2. **T_pkg** = median( packageTemperature )
3. **R_on_matched** = median( drainSourceVoltage / drainCurrent )、ただし packageTemperature が
   **そのデバイスの run 1 の median packageTemperature ±2°C** に入るレコードのみ

**ベースラインは各デバイス自身の run 1** とする([docs/163](163_per_unit_baselining.md) の個体基準に合わせる。母集団基準は使わない)。

### 交絡の事前宣言

die-attach劣化の機構は「熱伝達の悪化 → 接合温度の上昇 → ON抵抗の上昇」を含む。
したがって **R_on_raw の上昇は温度上昇の結果でもある**。指標3(温度整合版)は、温度に依らない成分が残るかを見るために置く。

**温度整合版で兆候が消えた場合、それを正直に報告する。** 「温度も部品内部の観測量だから問題ない」という後付けの言い換えをしない。

## 判定基準(実行前に固定)

| # | 基準 | 閾値 |
|---|---|---|
| **A1** | **先行性**: 最終run(7)より**前**に、R_on_raw が自デバイスのベースライン比 **+5%** を超える run が存在する | **6デバイス中4以上** |
| **A2** | **単調性**: run順 vs R_on_raw の Spearman ρ | **6デバイス中4以上で ρ ≥ 0.8** |
| **A3** | **温度非依存成分**: R_on_matched でも A1 が成立するか | 成立/不成立をそのまま報告(閾値による合否判定はしない) |
| **B1** | **ベースライン安定性**: 兆候発生前(+5%未満)の run における R_on_raw の変動幅 (max/min − 1) | 閾値を置かず**測定値を報告**。これが個体基準の有効期間の直接の答え |

**不成立の場合の扱い**: 指標を差し替えない。温度窓を変えない。対象デバイスを変えない。
不成立をそのまま記録する([docs/161](161_pmsm_model_validation_protocol.md) と同じ)。

## 成立した場合に言えるようになること

> **部品内部の電気量には、hard failure に先行する情報が乗る。** 実部品・実故障・同一個体の連続追跡で測定された。
> 先行の幅は run 単位で N 段階分である。

これは [docs/150](150_advisory_precedence_verification.md) の24.1倍(**検査員の目視観察**)より、
本研究が主張したい対象(**部品内部の電気信号**)に一段近い。

## 言えないこと(先に固定)

- **これはEPSではない。** ディスクリートパワーMOSFETの熱ストレス試験台である
- したがって言えるのは「**部品内部の電気量に故障先行情報が乗る**」という**機構レベル**まで。
  EPSアシストモータやインバータでも同じ幅で先行するとは言わない
- 故障予測(RUL・交換時期)には使わない。[docs/143](143_recall_detection_results_v2.md) のKillは動かさない。
  run番号は実験で振られた既知の進行であり、予測対象ではない
- 加速試験である。実車の経年劣化と時間軸が対応しない

## 不成立の場合に言えるようになること

> 実部品の連続追跡でも、hard failure に先行する電気的兆候は確認できなかった。
> したがって「閾値未満の兆候に価値がある」という本研究の中心仮説は、部品内部の電気量については支持されない。

これは本研究にとって重い結果になる。**だからこそ先に基準を固定する。**

## Rule Check

- 公開データのみ(NASA = 米国政府著作物・パブリックドメイン)
- 対象デバイス・指標・ベースライン・判定閾値を**値を見る前に**固定した
- 交絡(温度経路)を先に宣言し、温度整合版で消えた場合の扱いも先に決めた
- 不成立時に指標を差し替えないことを明記した
- 転移の限界(EPSではない)を、成立した場合の主張より先に書いた
