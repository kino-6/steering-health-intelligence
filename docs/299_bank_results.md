## 原因 1 — 健全期にも、ゆっくりした漂流がある

[docs/295](295_all_seven_runs.md) の run 中央値は、6 素子とも run 1→4 で −0.05 → −0.24 床と**単調に下がる**。
「run 4 は健全（中央値が 0.24 床以内）」という改訂の前提は**符号付き中央値**では正しいが、
**符号なしの連続平均に 0.2 床の閾値を当てると、この漂流だけで越える。**
3 素子の run 4 誤報はそれである。**精度が上がるほど、健全期の漂流が誤報になる**——閾値が床の 0.2 倍まで下がったせいで、それより小さい漂流が見えてしまった。

> **直線 1 本の指紋は、時間に対する漂流を持たない。**[docs/263](263_temperature_span_results.md) は温度軸の直線性を確かめたが、**時間軸の定常性は確かめていない。**

## 原因 2 — 遅い側が「宣言しない」を実装していない

Test_10 は毎 run の先頭が 3.7〜4.5 床で、run 中央値は ±1 床。**run の開始で温度が中央値より 15〜30 °C 低く、指紋の温度範囲の外**である。
速い側（`element_v2`）は範囲外で「宣言しない」を返すが、**`slow_deviation` は範囲を見ていない。**実装の抜け。
**今は直さない**——結果を見た後に直せば調整になる。次の事前登録で入れる。

## 汎化の見立て（[docs/295](295_all_seven_runs.md)〜本文書の総括）

| 閾値の取り方 | 故障前に鳴った | 但し書き |
|---|---|---|
| 6 素子まとめて較正、N を 6 素子で選ぶ（[295](295_all_seven_runs.md)） | 5/6 | in-sample |
| 5 素子で決めて 1 素子に当てる（[296](296_loo_results.md)） | 4/6 | 1 素子が誤報 1,817 倍 |
| **素子自身の run 1〜3 で較正、N バンク（本文書）** | **形式 6/6、正味 2/6** | 3 素子が漂流で鳴りっぱなし、1 素子が暖機 |

> **ユーザの「汎化していない」は当たっている。**
> 検出の数は閾値の取り方で 2〜5/6 まで動き、**本当に劣化で鳴ったと言い切れるのは 2 素子**である。
> ただし「捕まらない」でもない——run 5 の中央値が +1.4 床を越える 2 素子は、どの取り方でも鳴る。
