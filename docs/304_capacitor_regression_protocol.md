# 304. 事前登録 — コンデンサ 23 個体で、波形から劣化状態（EIS 静電容量）を回帰する

> [docs/303](303_ml_construction_plan.md) の B-1。**手元で唯一、ML の規模（23 個体 × 75,000 波形）と教師（EIS 静電容量 73 時点/個体）を両方持つデータ。**
> 目的は「数件」から脱すること、および記録器共通の事象を**交絡として処理する手順**を確定すること。

**追加取得ゼロ。** NASA Capacitor Electrical Stress、ES10 / ES12 / ES14。

## 教師（実行前に固定）

各個体の EIS 測定（`EIS_Measurement/Data`、列 `Cs/µF`）から、**最低周波数点の Cs** を各測定時刻の静電容量とする（[docs/300](300_eis_sync_results.md) で構造確認済み。73 時点、うち過渡記録の期間内は約 880 の測定時刻の中で個体ごと約 110）。
**目標変数 = 各波形の時刻に線形補間した Cs を、その個体の最初の EIS 値で割った比（1.0 = 新品）。**

## 入力（実行前に固定）

[docs/283](283_method_verification_protocol.md) の 3 特徴（放電の速さ、初期値、終端値）＋ 波形 400 点を 20 点に間引いた 20 次元。計 23 次元。
**時刻・記録器 ID・応力群は入力に入れない。**それらは交絡の検査に使う。

## 分割（実行前に固定）

1. **個体単位 leave-one-out（23 折）**。標準化・回帰の当てはめは学習側 22 個体のみで行う
2. **応力群を丸ごと抜く 3 折**（10 V / 12 V / 14 V）。群をまたぐか
3. 時系列は混ぜない。個体内の分割はしない

## モデル（実行前に固定。この 3 つ。後から足さない）

| | |
|---|---|
| **線形（基準）** | Ridge、α は学習側 22 個体の中だけで 5 折 CV |
| 勾配ブースティング | sklearn HistGradientBoosting、既定値。**調整しない** |
| 1D-CNN | 試さない——本文書では標本を 20 点に間引いており、波形直接の CNN は次の登録に回す |

## 交絡の処理（実行前に固定）

記録器共通の事象（[docs/300](300_eis_sync_results.md)：ES12/ES14 は同一記録器、ES10 は別）。
- **処理 P0**: 何もしない
- **処理 P1**: 各個体の [docs/284](284_method_verification_results.md) の発火点の前後 ±2,000 標本を学習・評価から除く
- **両方を報告し、差を交絡の大きさとする。**

## 判定基準（実行前に固定）

| # | 基準 | 閾値 |
|---|---|---|
| **R1** | 個体 LOO で、線形の予測誤差（MAE、比の単位）の**中央値** | **記述。**併せて「その個体の EIS の隣接測定間のばらつき（MAD）」を出し、**誤差がそれ以内の個体数**を数える |
| **R2** | 群を抜く 3 折で、抜いた群の MAE が個体 LOO の MAE の **2 倍以内** | 群をまたぐ |
| **R3** | 勾配ブースティングが線形の MAE を **10% 以上**下回る個体が過半 | 上回らなければ線形で足りる（[docs/290](290_ml_comparison_results.md) の記憶容量の判断が残る） |
| **R4** | P1 で MAE が P0 より改善する個体数 | 記述。交絡の大きさ |

**R1 で「誤差が EIS のばらつき以内」の個体が過半なら、波形は劣化状態を担っていると書く。半分未満なら、担っていないと書く。**

## 答えないこと
- コンデンサは EPS の部品ではない。**動くのは手法と検証手順**
- EIS の Cs と充放電波形は別の測定。時刻補間の誤差が教師に入る
- 1D-CNN は試していない（次の登録）
