# 350. 第 2 の温度は試験機の操作だった。ただし「劣化兆候が分かるか」の答えは変わらない

[docs/349](349_reference_channel_protocol.md) の事前登録を実行した。**追加取得ゼロ。**

> **R1・R2 とも外れた。**フランジ−パッケージ温度差を基準に足しても、健全期の α は 1.32 → 1.30 でほぼ動かず、
> 発火は **6/6 → 4/6 に悪化した。**
>
> **理由は事前に警戒したとおりだった。**フランジ温度は run ごとに 246.6 → 200 °C と単調に下がる。
> **試験機のヒーター設定そのものである。**加えた項は劣化ではなく操作を写していた。
>
> **そしてこの結果は、「モデルで劣化兆候が分かるか」の答えを変えない。**

実行: `python3 scripts/reference_channel.py` / 数表: [data/reference_channel.tsv](../data/reference_channel.tsv)

**当てはまりは良くなっている**（床が 0.2253 → 0.2085 など、全素子で縮む）。
**事前登録どおり、当てはまりでは判定していない。**

## 「モデルで劣化兆候が分かるか」の答え

**分かる。**この文書はその答えを変えない。変わるのは、**単体素子で自動の警報まで持っていけるか**である。

| | 状態 | 根拠 |
|---|---|---|
| **劣化兆候が量として出るか** | **出る。**能力が 1.000 → 0.892 に下がり、健全期のばらつきの **15 倍** | [docs/334](334_capability_trace.md) |
| **ECU の記録から復元できるか** | **できる。**30 バイトから誤差 0.003、走行中の 2 バイトからでも 0.004 | [docs/333](333_power_module_model_results.md) |
| **自動で警報を出せるか（同種チャネルあり）** | **出せる。**実インバータで検出 8/8、遅い側の誤報 0 | [docs/286](286_common_mode_results.md) |
| **自動で警報を出せるか（同種チャネルなし）** | **出せない。**健全期も傾向を持つため（[docs/348](348_drift_shape_results.md)）。**第 2 の温度では代用できなかった** | 本文書 |

> **EPS は半ブリッジ温度 3 つと相電流 3 つを持つ。同種チャネルがある側である。**
> **単体素子で成立しないことは、EPS には当たらない。**
> **当たるのは、同種チャネルを持たない量（DC バス電圧）だけである。**

## 残る限界

- **同種チャネルの代わりは、この 1 項しか試していない**（事前登録どおり）。他の量は未検討
- **フランジ温度が試験機に従うのは、この試験機の性質である。**別の試験なら使えるかもしれない
- 実インバータの 8/8 は**人為的に導入した故障**であり、劣化ではない
- 6 素子・1 試験機。**EPS ではない**
