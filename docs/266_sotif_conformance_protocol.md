# 266. 事前登録 — 記録器はSOTIFのどこに入るのか

> 「モデル構築とか、Sotifへの適合とか」(2026-09-01)
> [docs/265](265_element_v2_results.md) で記録器は動いた。**次はそれがSOTIFのどこに入るかである。**

**追加取得ゼロ**(規格の公開プレビューのみ)。

---

## 使える一次情報の範囲(先に区切る)

**ISO 21448:2022 の本文は有償である。**したがって**条項の要求文を読んでいない。**

**公開プレビュー**([iTeh 公開サンプル](https://cdn.standards.iteh.ai/samples/77490/d9843a45e11947e0aa79aaf2f00b65a8/ISO-21448-2022.pdf))
から読めるのは次まで。**ここから外に出ない。**

- **目次(全条項の番号と表題)**
- **序文と3章の用語定義のうち 3.1〜3.12 まで**

読めた範囲で、本検定に直接効くもの:

| 箇所 | 内容 |
|---|---|
| **4.4.3** | **SOTIF-related element out of context**(表題のみ) |
| **13** | **Operation phase activities**。13.3 **Topics for observation**、13.4 SOTIF issue evaluation and resolution process(表題のみ) |
| **3.1 acceptance criterion** | 注記が受容基準の例として **「1時間あたりの事象数の上限」**を挙げる。例2が、**運転者が制御できると実証済みの車両レベルの影響(横風の突風)と比べる**やり方を挙げる |
| **3.8 functional insufficiency** | **仕様の不足(3.12) または 性能の不足(3.22)** |
| **3.12 insufficiency of specification** | 不完全な仕様が、**1つ以上の起因条件によって作動したときに**危険な挙動をもたらすもの |

**3.22(性能の不足)と 3.30(起因条件)の定義文はプレビューに含まれない。**表題として参照するに留める。

> **本検定は「ISO 21448に適合している」とは主張しない。**
> 主張できるのは **「公開されている構造のどこに入り、どこに入らないか」**までである。

## 判定基準(実行前に固定)

| # | 基準 | 閾値 |
|---|---|---|
| **S1** | 記録器の出力が、**入力になる条項**と**ならない条項**に、全13条項を漏れなく振り分けられるか | 13/13。**「不明」を残さない** |
| **S2** | EooC仮定シート(54行)に、**実装が出さないものを出すと書いた行**が無いか | **0行。**1行でもあれば FAIL |
| **S3** | 既知の危険なシナリオ(領域2)と未知の危険なシナリオ(領域3)に対し、出力が何をするかを**それぞれ1文で言えるか** | 両方言えること |
| **S4** | **3.1 の受容基準の形**(1時間あたりの事象数、制御可能な車両レベル影響との比較)に、本研究の数値が乗るか | 乗ること |

**S2は機械で検査する。**シート本文に `capability` `能力値` `36バイト` `27バイト` 等、
**実装が出さない語・撤回済みの語が残っていないかを照合する。**

## この検定が答えないこと(先に書く)

- **条項の要求文を読んでいない。**目次の表題と 3.1〜3.12 の定義だけで判断する
- **適合の主張はしない。****「どこに入るか」の対応付けである**
- **第三者の評価を受けていない。**自分で対応付けた結果である
- **EPS実機で動かしていない**([docs/265](265_element_v2_results.md))

## 失敗したときに何を言うか

- **S1が13/13にならなければ**、「振り分けられない条項が残る」と条項番号を挙げて書く
- **S2に該当行があれば**、シートを直し、**成果物が実装より強い主張をしていたと記録する**([TROUBLES.md](../TROUBLES.md) T8)
