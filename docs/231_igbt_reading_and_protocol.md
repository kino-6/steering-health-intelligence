## 2. 事前登録

### 主検証: 新品40個体のばらつき

40個体(MOSFET IRF520Npbf × 20、IGBT IRG4BC30K × 20)の
**しきい値電圧・降伏電圧・漏れ電流**について:

```
個体間ばらつき  S = 40個体の値の 1.4826 × MAD
測定の再現性    R = 同一個体内の測定点のばらつき(同上)
比             S / R
```

**S/R は「新品のばらつきが、測定ノイズの何倍か」である。**
母集団閾値はこの S を跨いで設定せざるを得ないので、**S/R が大きいほど、
母集団閾値では小さな劣化を検出できない。**

| # | 基準 | 閾値 |
|---|---|---|
| **G1** | 3パラメータそれぞれの `S/R` を、MOSFET群・IGBT群それぞれで報告 | **分母(個体数・測定点数)を必ず併記** |
| **G2** | `S/R ≥ 3` となるパラメータがあるか | **あれば「新品ばらつきが測定ノイズの3倍以上ある」と判定** |
| **G3** | 個体基準を使った場合に得られる余裕(= S/R)を報告 | **これが個体基準の量的な利得である** |

### 副次(判定にしない、報告のみ)

**Square Signal at gate の1個体**について、スイッチON区間のコレクタ-エミッタ電圧を
時間に沿って報告する。**n=1 なので判定しない。**
[docs/203](203_cross_machine_replication_results.md) の教訓に従い、**1個体の結果から主張を作らない。**

### 除外するもの(先に決める)

- **Square Signal + SMU の4個体は使わない。**配布元が
  「コレクタ電流が不正確で約600 mAのドリフト」「定常測定のスケールが正しくない」と明記している。
  **測定不良と分かっているデータで検定しない**
- **DC at gate の1個体は使わない。**能動領域であり、既に持っている S8 と同じ動作モードである

## 事前に認めておくこと

- **新品40個体は劣化していない。**測るのは**ばらつき**であって前駆ではない
- **S/R が大きくても、それは「母集団閾値が不利」を意味するだけで、
  「個体基準が劣化を検出できる」ことの証明ではない**
- **スイッチ動作の劣化は1個体しかない。**docs/192〜199 のやり直しは**成立しない**
- 3パラメータの測定条件(温度・バイアス)は Readme に明示が無く、**同一条件と仮定する**
- **これはEPS実機ではない**
