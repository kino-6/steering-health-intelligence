## 私の基準設計の欠陥（[TROUBLES.md](../TROUBLES.md) T34 の続き）

**[docs/307](307_baseline_protocol.md) は T34 を直すために書いたのに、直し方が弱かった。**

**個体単位 leave-one-out では、「時刻」の基準は原理的に「平均的な個体の経年曲線」にしかならない。**
個体ごとの劣化の速さを表す基準を作ろうとすると、**抜いた個体自身の軌跡を使うことになり、漏れる。**

> **これは検定の作り方の問題ではなく、この課題の構造である。**
> **未知の個体に対して「時刻」が持つ情報は、平均的な経年曲線だけである。**
> **だからこそ波形が要る**——というのが、S2 の 16/23 が言っている中身である。

**S2 の 16/23 は、この構造を踏まえて読むべきで、「時刻より波形が良い」という強い主張には使えない。**

## 何が残るか

| **残る** | 波形は、定数よりも平均的な経年曲線よりも良い（15/23、16/23）。勾配ブースティングなら 19/23 |

| **残らない** | 「時刻を使うより波形が良い」という一般的な主張。基準が弱すぎる |
| **残らない** | ES12 での優位。3/8 |
