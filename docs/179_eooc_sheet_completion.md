# 179. EooC仮定シートの欠落 — triggering conditions が無かった

## 判断

**[docs/178](178_sotif_straight_answer.md) で「SOTIFに出せる唯一のもの」と位置づけたEooC仮定シートに、SOTIFの中核概念が丸ごと欠けていた。**

ISO 21448 Clause 4.4.3 が SOTIF-EooC の部品側に文書化を求めるのは**3点セット**である。

| 要求 | 旧シート(19項目) |
|---|---|
| 使われ方の前提(assumptions of use) | **あり**(A節) |
| **部品の triggering conditions(発現条件)と、そこから生じる機能不足** | **triggering conditions が無い** |
| 機能不足の許容発生率(allowed target rate of occurrence) | あり(C節、空欄として) |

そしてこの3つをまとめて **integration requirements** と呼び、**OEMが車両レベルのSOTIF活動で妥当性を確立する**。
旧シートは**片務の監視仕様**であって、EooCの宣言になっていなかった。

**7項目を追加し、26項目にした。** シート: [data/sotif_eooc_assumption_sheet.tsv](../data/sotif_eooc_assumption_sheet.tsv)

## 追加した E節: Triggering conditions

**すべて本研究が既に持っていた公開証拠から埋まった。** 書いていなかっただけである。

| ID | 発現条件 | 公開根拠 |
|---|---|---|
| **EOOC020** | **持続的な高アシスト要求**(低速・大舵角) | 熱余裕を消費し、ディレーティング発動点に近づける([docs/170](170_thermal_headroom_translation.md))。公開リコールが集中する条件と一致(MKT003〜010「Increased steering effort」「risk higher at low speeds」) |
| **EOOC021** | **電源電圧の低下・不安定** | Ford SSM 49530(2021年F-150、始動時8V未満 → 内部故障系code保存 → PSCM交換不要とOEMが説明) |
| **EOOC022** | **依存signalの異常**(通信入力) | GM TSB 17-NA-158(無効な冷却水温signal → 操舵警告 → 「U0401:71でgearを交換するな」という公式警告と誤交換の記録) |
| **EOOC023** | **振動・微摺動**(接点のfretting) | GM 4キャンペーン(16V160/17V382/19V801/20V254)。発現は断続的で再始動により回復・再発(MKT011〜016) |
| **EOOC024** | **路面カント・積載** — **誤発火側の条件** | bias特徴量は最小試験量でも100%発火するため、単発判定では区別できない([docs/144](144_synthetic_sensitivity_results.md))。だから k-of-N が要る([docs/155](155_window_recurrence_verification.md)) |

**EOOC024が重要である。** SOTIFで宣言すべき条件は「機能不足が起きる条件」だけではない。
**観測指標が誤って発火する条件**も宣言しなければ、市場で誤警報になる。
本研究は [docs/144](144_synthetic_sensitivity_results.md) の時点でこれを発見していたが、**シートに書いていなかった**。

## 追加した F節: Integration requirements

EooCは片務ではない。**部品側の仮定の妥当性は、OEMが車両レベルで確立する。** 何を検証してもらうかを書かなければ、仮定は宙に浮く。

**EOOC025 — OEM側が統合時に検証すべきこと(4項目)**

1. 使われ方の前提(EOOC001〜004)が、対象車両の実運用分布と合致するか
2. 発現条件(EOOC020〜024)が車両レベルで実際に生じるか
3. 許容発生率(EOOC011)をOEMが定め、観測粒度(EOOC006/018)でそれが検証可能か
4. 誤発火条件(EOOC024)が車両側の運用で許容できるか

**EOOC026 — 仮定が破れたときの扱い**

部品側が出せるのは「観測値」と「自己の宣言範囲を出たという事実」まで。
そこから先(調査・是正・当局報告)は**OEMのSMSと報告義務**(EU 2022/1426 ISMR、UN ADS GTR)の領域である。
**部品側が是正要否を判断しない。**

## この欠落が意味すること

[docs/178](178_sotif_straight_answer.md) は「シートは19項目のうち大半が埋まっている」と書いた。**その評価は甘かった。**

- 埋まっていたのは **B節(観測能力)** と **A節(使われ方)** であり、これは**監視仕様**である
- 欠けていたのは **E節(発現条件)** と **F節(統合要求)** であり、これが**SOTIF固有の部分**である
- つまり旧シートは「何を観測できるか」の宣言であって、「**どの条件で機能が足りなくなり、それをOEMがどう検証するか**」の宣言ではなかった

**SOTIFに乗るとは、後者を書くことである。**

## それでも埋まらない欄(変わらず)

- **EOOC011 許容発生率の目標値** — OEMが埋める。公開情報では原理的に届かない
- **EOOC013 仮定がRFQへ降りている確認** — 構造は公開で閉じた([docs/177](177_sotif_direction_update.md))。**問いは終了**([AGENTS.md](../AGENTS.md) 0条)
- **EOOC019 物理モデルによる外挿** — 検証失敗([docs/162](162_pmsm_model_validation_results.md))
- **EOOC026 仮定が破れたときの扱い** — OEMの領域

## Rule Check

- **自分が直前に「唯一の成果物」と位置づけたものを叩き、中核の欠落を見つけた**
- 欠落は規格の一次要求(Clause 4.4.3)と照合して特定した。思いつきではない
- 追加したE節は**すべて本研究が既に持っていた公開証拠**で埋めた。新しい主張を足していない
- **誤発火条件(EOOC024)を、機能不足の条件と同じ節に並べて宣言した**——都合の悪い条件を落としていない
- F節でOEMの領域を明示し、部品側が越えない線を書いた
