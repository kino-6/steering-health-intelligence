# 238. 何のデータが要るのか — 落ちた検証から逆算する

> 「結局どんなデータが欲しいの？ 言語化して。」(2026-08-31)

**本研究で落ちた検証は、一つ一つが要件を1行ずつ決めている。**
[docs/225](225_recorder_specification.md) が記録器の仕様だとすれば、**本文書はデータの仕様である。**

---

## 0. なぜ「定番」では足りなかったか

NASA PCoE は定番であり、実際に**本研究で生き残った量的な柱2本は、どちらもNASAである**
([docs/167](167_precursor_results_v2.md) の前駆20〜300倍、[docs/232](232_pristine_unit_spread_results.md) の個体差159〜530倍)。

**足りなかったのは質ではなく、答えられる問いの範囲である。**

| 定番データが答える問い | 答えない問い |
|---|---|
| 前駆はあるか | **断続故障の前駆はあるか** |
| 個体差はどれだけか | **ECU内部信号の観測床はいくらか** |
| どのパラメータが動くか | **検出確率と誤検出率はいくらか** |

## 1. 要件(各行に、それを決めた失敗を付す)

| # | 要件 | これを決めた失敗 |
|---|---|---|
| **R1** | **実機であること。**シミュレーションでない | ボールねじ21.3 GBがSimulinkだった([docs/235](235_pre_acquisition_survey.md)) |
| **R2** | **応用と同じ動作モードで運転されていること。**EPSならインバータがモータを駆動するスイッチ動作 | S8は素子を能動領域のヒーターとして使っていた([docs/199](199_pulse_thermal_results.md)) |
| **R3** | **動作点が記録されていること。**設定値ではなく実測 | S11は `steadyState` が全チャネルNaN([docs/233](233_igbt_exclusion_retracted_protocol.md)) |
| **R4** | **動作点を保持したまま、劣化が進む時間だけ運転された区間があること。****最低1時間**(誤報1件/時を刻むには判定36,000回分が要る。[docs/282](282_igbt_recorder_results.md)) | S11の保持区間は9〜44分で、観測量が分解能の1刻みも動かなかった([docs/237](237_within_condition_results.md)) |
| **R5** | **同型の個体が3つ以上あること。**移植性を検定できる数 | 1機体の結論が別機体で再現しなかった([docs/203](203_cross_machine_replication_results.md)) |
| **R6** | **測定セッション(日付・装置)が記録されていること** | 測定キャンペーンの段差が故障効果を潰した。3機体6セル全部([docs/203](203_cross_machine_replication_results.md)) |
| **R7** | **健全な対照が、故障個体と同じ条件で記録されていること** | 正常クラスだけ非定常だった([docs/215](215_inverter_dataset_acquisition.md)) |
| **R8** | **各個体の劣化前の特性が記録されていること**(個体基準の原資) | 新品の個体差が測定ノイズの159〜530倍あった([docs/232](232_pristine_unit_spread_results.md)) |
| **R9** | **信号が部品の内部量であること。**車両レベルの応答ではない | 横加速度残差は制御器・路面・推定誤差の合成だった([docs/220](220_real_vehicle_granularity_protocol.md)) |
| **R10** | **ECUが実際に持ちうる信号であること。**相電流・DCバス・ゲート駆動・温度1点程度 | 通ったのは加速度計を要する指標だった([docs/205](205_sign_free_deviation_results.md)) |
| **R11** | **スイッチング事象が見える速度で標本化されていること** | インバータデータは10 Hzでスイッチング周期が見えない([docs/215](215_inverter_dataset_acquisition.md)) |
| **R12** | **★ 故障が出たり消えたりすること。**恒久故障でない | 公開データは全部恒久。3回探して無し([docs/175](175_close_contact_question.md), [214](214_dataset_reinventory_2026_08.md), [235](235_pre_acquisition_survey.md)) |
| **R14** | **★★ 部品の機能出力(トルク)が、内部量と同時に測られていること** | **モデルが作れない。**内部量だけでは「いつもと違う」しか言えず、**機能がどれだけ足りないかを言えない**([docs/291](291_model_gap.md))。R12・R13とは独立で、**モデル構築にはこちらが要る** |
| **R13** | **★ 故障が現れた時刻の正解が付いていること** | 正解が無ければ検出確率も誤検出率も測れない([docs/144](144_synthetic_sensitivity_results.md) は合成注入のまま) |

**★ の2件が、他の11件と質的に違う。**R1〜R11は「良い試験設計かどうか」だが、
**R12・R13は「本研究が対象としている現象そのものが入っているか」である。**

## 2. 最小構成(EPSでなくてよい)

**EPS実機である必要はない。**R1〜R13を満たす台があればよい。具体的には:

- **三相インバータ + PMSM**(EPSアシストモータと同出力帯)。**スイッチ動作**(R2)
- **同型3台以上**(R5)、**各台の劣化前特性を取得**(R8)、**健全対照を1台並走**(R7)
- **意図的に不安定な接点を1箇所**——コネクタの接触圧を落とす、はんだにき裂を入れる等。
  **恒久短絡ではなく、熱サイクルで導通が出たり消えたりする状態**(R12)
- **熱サイクルは動作点を保持したまま**行い、**劣化が進む時間だけ運転する**(R4)
- **記録**: 相電流・DCバス電圧電流・ゲート駆動・温度1〜数点。**実測値**(R3, R10)
- **標本化**: スイッチング周期が見える速度(数十〜数百 kHz)(R11)
- **正解**: 導通が途切れた時刻を独立に検出して記録する(R13)

**「独立に」が要である。**同じ信号から正解を作ると循環する。
別系統(たとえば直列に入れた基準抵抗の電圧、あるいは高速カメラ・音響)で事象時刻を取る。

## 3. 何が一番効くか

**R12(断続)とR13(正解時刻)の2つだけである。**

R1〜R11は、程度の差はあれ既存データで近似できている。

| 要件 | 近似できているもの |
|---|---|
| R2 スイッチ動作 | S11(ただしR4で落ちた) |
| R5 個体3つ以上 | KAIST 3機体、NASA 6個体、新品40個体 |
| R8 劣化前特性 | [docs/232](232_pristine_unit_spread_results.md) の40個体 |
| R9 部品内部量 | S8, S11, KAIST |
| **R12 断続** | **機構を持つデータは存在する**(アーク故障、接点開放方式)が、いずれも人為的に作られた故障([docs/239](239_arc_fault_search.md))。**劣化から生じる断続のデータは無い**([docs/242](242_survey_appendix_read.md)) |
| **R13 正解時刻** | **無し。**アークデータは事象でトリガされ、**事象前が記録されない**([docs/239](239_arc_fault_search.md)) |

> **本研究が止まっているのは、R12とR13が公開データに存在しないからである。**
> **他の11件は、不完全ながら手当てがついている。**

## 4. これで何が埋まるか

R12・R13を満たすデータが1件あれば、[docs/225](225_recorder_specification.md) の残る空欄のうち**2件が埋まる。**

| 空欄 | 埋まるか |
|---|---|
| **ECU内部信号の観測床** | **埋まる**(R3, R9, R10, R11) |
| **検出確率・誤検出率** | **埋まる**(R13) |
| 掃引すべき温度範囲 | 部分的(その台の運転範囲まで) |
| 許容できる逸脱の下限 | **埋まらない。**車両レベル安全目標からの配分であり、データの問題ではない |

## 5. 認めておくこと

- **R12を満たす公開データは、目録110件・NASA 21件・アーク4件・個別検索4回のいずれからも見つかっていない**([docs/242](242_survey_appendix_read.md))
- **これは「あればよい」の記述であって、探索の結論ではない。**
  R12・R13を満たす公開データが**将来も存在しない**とは言っていない。
  3回の探索で見つからなかった、までである
- **R12を満たす試験は難しい。**断続は再現性が低く、加速もしにくい。
  **公開データが無いのは偶然ではなく、作るのが難しいからである可能性が高い**
- **最小構成はEPSではない。**同型機構での代替であり、
  EPS実機での確認は[本研究の全期間を通じて]できていない

## Rule Check

- **各要件に、それを決めた失敗を1件ずつ付けた。**要望ではなく逆算である
- **★2件と他11件を質的に分けた。**全部同じ重みで並べない
- **他11件が既存データで近似できていること**を表にした。要求を膨らませない
- 「公開データに無い」を「存在しない」と書いていない
- **R12を満たす試験が難しいこと**を、無い理由の候補として書いた
