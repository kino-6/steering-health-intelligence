# 319. 1 個体の実物。何が書かれ、何が流れるか

[docs/318](318_unit_ledger.md) は層と量を出した。**これは中身である。**
値はすべて実インバータの記録から実際に登録・実行して得たもので、もっともらしく作った例ではない。

実行: `python3 scripts/unit_trace.py`

> **出荷時に 448 バイトを 1 回書き、走行中は 2 バイトを 100 ms ごとに流し、逸脱したときだけ 30 バイトを追記する。**
> **そして同じ走行・同じ個体で、追記が 1,320 バイトになるか 0 バイトになるかは、要求する誤報率だけで決まる。**

## 1. 出荷ラインで 1 回だけ書かれるもの（不揮発 448 B）

チャネル T1（ハーフブリッジ 1 の温度から、同種の T2・T3 を差し引いたもの）の 56 バイト:

| 中身 | 値 |
|---|---|
| 動作点に対する傾き | −0.05964 |
| 基準値 | 52.99 |
| **この個体自身の床** | **12.61**（以後の逸脱はこの単位で数える） |
| 掃引した動作点 下／上 | 488 / 517（**外では宣言しない**） |
| 速い側の閾値 平均／最大 | 0.533 / 3.244 床 |
| 遅い側の閾値 | 0.598 床 |
| **較正できた誤報率 速／遅** | **274.3 / 281.2 件/時** |
| 傾きの基準／そのばらつき | 0.0008745 / 0.0001503（[docs/317](317_changepoint_results.md)） |
| 交差検証のずれ | 0.476 床 |
| 採否 | 1 |

```
0F 4E 74 BD DE F6 53 42 0D C1 49 41 00 00 F4 43 00 40 01 44 33 5D 08 3F B1 9C 4F 40
A7 04 19 3F 92 24 89 43 91 9F F3 3E 00 00 80 3F 00 A0 8C 43 41 3F 65 3A D6 8D 1D 39
```

**8 チャネルで 448 バイト。以後、車両寿命のあいだ書き換えない。**
この個体は 8 本とも採用された（自分の健全を保留区間で再現できた）。

## 2. 同じ走行を 2 通りの要求で流すと

ハーフブリッジ 1 下側の短絡を記録した実データ:

| 要求 | 発火 | 追記量 |
|---|---|---|
| **仕様どおり 1 件/時** | **0 件** | **0 バイト**——較正が 281 件/時 までしか届かず、検出器が動かない |
| 較正できた 281 件/時 | 44 件 | 1,320 バイト |

**これが [docs/318](318_unit_ledger.md) の 274 倍の正体である。**個体も走行も同じで、変わるのは要求だけ。

## 3. 走行中、車内バスに出るもの（2 B、100 ms ごと）

```
   0s   0D 20   逸脱 3.15 床 ／速い側 ／遅い側
   5s   05 1F   逸脱 3.13 床 ／速い側
  10s   05 22   逸脱 3.38 床 ／速い側
  30s   0D 20   逸脱 3.15 床 ／速い側 ／遅い側
```

1 バイト目が状態（宣言可否・どちらの検出器・キーオフまでの持続）、2 バイト目が**自分の床いくつぶん**（0.1 刻み）。
**これで全部である。**あと何 % 出せるか・残り寿命・どこが壊れたかは乗らない
（[docs/183](183_autosar_capability_channel.md) の宛先名 `capability` は禁止語の筆頭）。

## 4. 逸脱したときだけ不揮発に追記されるもの（30 B/件）

```
[    0s] 逸脱 3.15 (粒度 100.4) 事象 5s  速い側 / 遅い側
BB E3 49 40 89 CA C8 42 00 80 FD 43 00 00 00 00 00 00 00 00 00 00 80 3F 00 00 05 00 06 01
```

末尾 6 バイトが「キーオンから 0 秒、事象長 5 秒、旗 0x06（速い側＋遅い側）、有効 1」。
**キーオフ時に累積ストレス カウンタ 4 バイトを 1 回更新して、その走行は終わり。**

## 5. 入庫時に吸い出されるもの（1 回）

指紋 448 B + 記録の全量。**整備側が読むのは「この個体は自分の床の何倍ずれたか」であって、「どの部品が悪いか」ではない。**
部位を名乗らないのは、部位を名乗った DTC がギヤの無駄な交換を繰り返させた公式記録があるため
（[docs/130](130_steering_predictive_diagnostics_comm_validity_public_crosscheck.md)）。

## 残る限界

- **この個体は 281 件/時 までしか較正できていない。**仕様どおり運用すると何も書かない
- 実インバータ 1 台・10 Hz・28 分の記録。**個体差は測っていない**
- 2 バイトのフレーム構成は出せる中身から決めたもので、**バス設計の実測ではない**

## Rule Check
- 値はすべて実データから登録・実行して得た。**例として作っていない**
- **仕様どおりだと 0 バイトになることを、1,320 バイトと同じ表に書いた**
