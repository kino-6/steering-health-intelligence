# Recall Detection Model: Results v2 (確定判定)

## 結論

改訂プロトコル([docs/142](142_recall_detection_protocol_v2.md)、実行前コミット済み)を実行した。

| 指標 | v1 | **v2** | 事前登録基準 |
|---|---|---|---|
| テスト precision | 0.39 | **0.48** | ≥0.5 |
| テスト recall | 0.17 | **0.26** | ≥0.3 |
| テスト PR-AUC | 0.315 | **0.355**(無情報0.110の3.2倍) | - |
| テスト ROC-AUC | 0.783 | **0.796** | - |
| 手作りルール(同条件) | 0.14 / 0.02 | 0.14 / 0.02 | - |

判定: **v2でも事前登録基準に未達(僅差)。** プロトコルの言い方に従い「公開苦情のみによる操舵系リコール前識別は、本アプローチ(v1/v2)では実用シグナルとして不成立」を**確定判定**とする。

**そしてここで止める。** テストeraには既に2回アクセスした。3回目の改良評価は同じテストへの過剰適合(基準を「いつか超える」まで叩く行為)になるため行わない。以後の改良の正しい検証データは、**時間が生む未使用のera(2025年以降のリコール)**である。

## 分かったこと(数字で言えるようになったこと)

1. **信号は実在する**: 公式リコール報告の6ヶ月前時点の公開苦情だけで、後にリコールされるcohortを無情報の3.2倍の効率で並べ替えられる(PR-AUC 0.355)。ROC 0.796
2. **手作りルールとの差は歴然**: docs/136型のルール(0.14/0.02)に対し、学習モデルは同一テストで0.48/0.26
3. **リードと精度のトレードオフを定量化**: 6→24ヶ月前でPR-AUC 0.355→0.145と単調減衰
4. **EPS系限定はさらに難しい**: 陽性42件、PR-AUC 0.180(無情報0.045の4倍のliftだが絶対値は低い)。電動アシスト系の予兆は苦情カテゴリ全体より薄く、部品内部観測(空席(1))の必要性を裏から支持する
5. **適用範囲の明文化**(v1最大の教訓): 苦情ベース監視は消費者苦情が存在する母集団(乗用車系29 make)でのみ定義できる。商用車・バス等はこの方法の圏外
6. 係数は解釈可能なまま: 操舵系比率(+0.64)、苦情量(+0.41)、車齢(−1.25: 新しい車ほどリコールに至る)、アシスト系比率(+0.18)。growthとrel_makeはほぼ寄与せず

## Rule Check

1. v2改訂を実行前にコミット(docs/142)し、2回目のテストアクセスであることを明示した
2. 基準未達(僅差)を「僅差だから成立」と言い換えず、確定判定とした
3. テストの3回目アクセスを自主的に封じ、将来eraを次の検証データに指定した
4. 個車予測・原因断定・OEM批判なし。公開データのみ

## ビジネスモデル(docs/138)への反映

- 第2層(市場シグナル監視=内部投資)の性能限界が数字で確定した: **「リコールの先回りを自動で当てる道具」ではなく、「調査候補を無情報の3倍強の効率で並べる注意配分の道具」**として位置づけるのが誠実な使い方
- 第1層(部品内部観測)の価値は相対的に強まった: EPS系の予兆が苦情から最も見えにくい(発見4)ことは、部品内部でしか取れない観測の希少性の裏付け

## 残る道(実行しない、記録のみ)

1. 将来era(2025年以降のリコール)での再評価 — 時間が経てば汚染なしのテストが自然に生まれる
2. モデルB(波形側の合成劣化感度)— 未着手のまま残存
3. DVSA MOT(分母付き)による相互検証 — 保留のまま
