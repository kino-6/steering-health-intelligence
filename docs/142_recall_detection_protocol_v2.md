# Recall Detection Protocol v2 (Revision)

## 位置づけ

[docs/140](140_recall_detection_protocol.md)(v1、事前登録)の改訂。**本改訂はv2の学習・評価の実行前にコミットする。**
これはテストeraへの**2回目のアクセス**である(多重比較)。以後の再アクセスも都度、改訂の事前コミットを条件とする。

## v1からの変更点(3つだけ。他はv1のまま凍結)

1. **スコープの是正(v1最大の発見への対応)**: v1のマッチ率21%の主因は表記揺れではなく、リコール台帳に含まれる商用車・バス・消防車・RV等が消費者苦情DBにほぼ存在しないことだった(診断: 乗用車系makeに限れば完全一致94%)。v2はユニバースを**consumer make(苦情DB内の総苦情数≥5,000のmake、29社)**に限定する。陽性・陰性の両方に同一適用。苦情ベース監視は消費者が苦情を出す母集団でのみ定義できる、という方法の適用範囲の明文化である。名寄せのfuzzy matchingは導入しない(残る未マッチ6%は警察仕様・中型トラック変種として除外を明記)
2. **rel_make特徴の再設計**: v1で係数の符号が反転(共線性)。`rel_make_v2 = steer_share − 同make中央値share`(比から差へ)
3. **EPS系サブセット評価の実施**: v1で未実施のまま残した補助解析(COMPNAMEにELECTRIC/ASSISTを含むcampaign由来の陽性に限定した場合のテスト性能)を実行する

## 変えないもの

時系列分割(2013-2018学習/2019-2024テスト)、活動下限50、T=event−6ヶ月、特徴量他5種、ロジスティック回帰、凍結操作点の決め方(学習era precision≥0.5で最大recall)、成功基準(**テスト precision≥0.5 ∧ recall≥0.3**)、失敗時の言い方。
