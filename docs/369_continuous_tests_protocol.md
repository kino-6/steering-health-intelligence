# 369. 事前登録 — NASA と同じ量・同じ軸・同じ素子で、劣化式を当て直す

2026-09-14 ユーザ指摘: **「ではどうして NASA は導出できたの？ 何か見落としてないか？」**

見落としが 2 つあった。

| 見落とし | NASA | 私（docs/366、368） |
|---|---|---|
| **量** | transient 波形の on 状態から出す **R_DS(on)**。試験開始時 0.19 Ω（IRF520N の 0.20 Ω と一致） | steadyState の**能動領域の動作点抵抗**（約 1.9、[docs/199](199_pulse_thermal_results.md)） |
| **素子** | **連続 1 run** の試験（図は Test_36、6 時間） | 「7 run 揃った」6 素子 = 0.6 時間 × 7 の階段状の試験 |
| 軸 | 試験機に載っていた aging time | 通電時間（1 分超の空白を除く） |

データには **単一 run で 4.9〜8.0 時間の連続試験が 11 本**ある（Test_26, 29, 30, 31, 32, 33, 35, 36, 37, 38, 41）。
選ぶ段階で全部落としていた（[TROUBLES.md](../TROUBLES.md) T3 の 6 回目）。量の取り違えは T4 の 5 回目。

**追加取得はしない。**同じ zip の、使っていなかった transient と 11 本を使う。

## 量の定義（実行前に固定する）

- transient 記録 1 つ（500 点、dt = 2 µs）につき、**on 状態 = ドレイン電流がその記録の 95 パーセンタイルの 50% を超える点**
- **R_DS(on) = on 状態の V_DS / I_D の中央値**
- 動作点の補正: 試験の最初の 10% を健全とし、R を **I_D（on 状態の中央値）とパッケージ温度の 2 変数で線形回帰**。以後は
  `ΔR/R0(t) = R(t) / R_line(I(t), T(t)) − 1`。docs/199 の「試験機の操作を劣化と読まない」と同じ趣旨
- 50 記録の走行平均を取る
- 軸: **aging time**（試験の最初の記録からの経過時間、休止を含む）を主とし、通電時間も添える

## 対象

上の 11 本。Test_7（2.5 時間）も含めて 12 本を当てる。7 run の 6 素子は含めない（別の試験）。

## 当てはめ（docs/367 と同じ縛り）

- `ΔR/R0 = 0.10` を初めて越えた時刻 `t10` を測り、`a = 0.10 / (exp(b(t10 − t0)) − 1)` で縛る。自由な母数は `b`（格子 0.01〜50 /h、対数）と `t0`（0〜0.98·t10）
- **同定失敗の条件**: `b` か `t0` が格子の端に張り付く。`t10` に達しない試験は「劣化が観測範囲に無い」として別に数える
- **何もしない基準**: 同じデータに直線 `c·(t − t0)` を当てた残差二乗和

## 事前登録する予想（手計算で決まらない量だけ）

| | 予想 | 外れる条件 |
|---|---|---|
| **E1** | 12 本のうち `ΔR/R0 = 0.10` に達するのは **8 本以上** | 7 本以下 |
| **E2** | 達した試験のうち、指数が**同定できる**（端に張り付かない）のは **半分以上** | 半分未満 |
| **E3** | 同定できた試験で、指数の残差二乗和は直線より **20% 以上小さい**（中央値） | 20% 未満。つまり直線で足りる |
| **E4** | 同定できた試験の `b` の最大/最小は **10 倍以内** | 10 倍超 |

**E3 が外れれば「NASA の軸と量でも、この範囲では直線で足りる」が答えになる。**それでも置く。

## 個体群（E2 が成立し、同定が 4 本以上のときだけ）

docs/367 と同じ手順。`b` と `t10 − t0` の対数正規、健全側は 40 テストの σ・S、故障は C = 0.894。
健全個体の走行は連続試験の健全期（最初の 10%）の長さの中央値に合わせる。予想は V3・V4 と同じ（≥ 90%、≤ 2 倍）。

## やらないこと

- 同定できた試験だけを選んで「指数が合う」と言わない。達しない・同定できない本数も書く
- 7 run の 6 素子の結果を、この 12 本の結果で上書きしない。別の試験である
