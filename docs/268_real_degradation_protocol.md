# 268. 事前登録 — 注入をやめ、本物の劣化に記録器を通す

> **本Repoの検出の数値は、すべて注入で測ってある**
> ([docs/244](244_intermittent_injection_results.md), [246](246_internal_signal_injection_results.md),
> [248](248_false_alarm_tradeoff_results.md), [253](253_persistent_event_results.md), [265](265_element_v2_results.md))。
> **記録器を本物の劣化軌跡に通したことが一度も無い。**
>
> [docs/167](167_precursor_results_v2.md) は前駆の**大きさ**を測ったが、**記録器を走らせていない。**
> 「床の20〜300倍ある」と「記録器が鳴る」は別の主張である。

**追加取得ゼロ。** NASA MOSFET(故障まで運転)と KAIST PMSM(実故障重症度)。

---

## 何が違うのか

| これまで | 本検定 |
|---|---|
| 健全な信号に**矩形を足して**検出率を測った | **足さない。**素子が実際に劣化していく記録をそのまま通す |
| 事象の時刻は**こちらが決めた** | **試験機が決めた。**故障は実際に起きた |
| 誤報率は**閾値の設計値** | **健全期間で実際に何回鳴ったかを数える** |

---

## 手順(実行前に固定)

記録器は `scripts/element_v2.py`([docs/265](265_element_v2_results.md))を**そのまま使う。書き換えない。**

**R1・R2・R4(半導体)**
1. 各素子の**最初のrunの前半**を出荷時の指紋とする(素子が最も健全な区間)
2. 残り全部を運用として、記録器を窓ごとに通す
3. **最初に発火した窓**と、**そこから記録の最後(=故障)までの残り**を出す
4. **指紋区間の直後から最初の発火までに鳴った回数**を誤報として数える

**R3(モータ)**
1. 各機体の**重症度0の記録**を指紋とする
2. 重症度を小さい順に通し、**最初に発火する重症度**を出す
3. 1.0 / 1.5 / 3.0 kW の**3機体で一致するか**を見る

**R5(個体基準の価値)**
- 同じ計算を、**指紋をその個体のものから、全個体の中央値に差し替えて**行う
- **発火の早さと誤報の数がどれだけ悪化するか**を測る

---

## 判定基準(実行前に固定)

| # | 基準 | 閾値 |
|---|---|---|
| **R1** | 故障前に発火する素子が6中5以上 | 6中5 |
| **R2** | 指紋後〜初発火までの誤報が、**1件/時の設計値の3倍以内** | 3倍 |
| **R3** | 最初に発火する重症度が、3機体で**2倍以内に収まる** | 2倍 |
| **R4** | 初発火から記録の最後までの残りが、**記録全体の10%以上** | 10% |
| **R5** | 母集団基準にすると、**誤報が2倍以上に増える**か**発火が遅れる** | どちらか |

**R1が落ちれば、記録器は本物の劣化では鳴らない。**
**そのとき [docs/225](225_recorder_specification.md) の全体が、注入でしか成立しない仕様だったことになる。**
**これは本研究で最も重い不成立であり、丸めない。**

## この検定が答えないこと(先に書く)

- **素子は能動領域のヒーターとして使われている**([docs/199](199_pulse_thermal_results.md))。EPSのスイッチ動作ではない
- **故障は加速試験で作られたものであり、市場で起きたものではない**
- **断続故障ではない。**恒久劣化である。R12は依然として未達
- **R4の「残り」は試験機の時間であり、車両の走行時間ではない。**換算しない
