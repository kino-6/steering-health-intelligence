# 198. パルス自己発熱から熱経路を測る — 事前登録

**結果を1つも見る前に書き、単独でコミットする。**

## なぜやり直すか

[docs/197](197_what_limits_the_declaration.md) は、capability 宣言の確度を縛っているのが
**測定ではなく「熱抵抗 Rth が一定」という仮定**であることを示した。
そして [docs/189](189_five_limits_tested.md) ② は Rth の直接測定に失敗したと結論していた。

**その結論は、データの一部しか見ていなかった。**

NASA MOSFET の `.mat` は3つの塊を持つ。docs/165〜197 が使っていたのは `steadyState` だけである。

| 塊 | 中身 | これまで |
|---|---|---|
| `steadyState` | supplyVoltage, packageTemperature, drainSourceVoltage, drainCurrent, flangeTemperature | **使っていた** |
| `transient` | 1 µs刻み1000点の波形: gateSignalVoltage, gateSourceVoltage, drainSourceVoltage, drainCurrent | **未使用** |
| `pwmTempControllerState` | lowTemp, highTemp, gateVoltage, supplyVoltage, switchingFrequency, dutyCycle | **未使用** |

docs/189 ② は `steadyState` の `flangeTemperature` が `packageTemperature` より90〜100°C高いことから、
「試験機がフランジ側から加熱するので素子の熱経路を取り出せない」と結論した。
**これは定常成分についてのみ正しい。**素子自身のパルス発熱に対する応答は、その直流オフセットとは別に取り出せる。

## 探索で既に見たこと(宣言)

事前登録の公正さのため、**この文書を書く前に見たものを全部書く。**

- `pwmTempControllerState`: 温度設定が **run毎に10°Cずつ意図的に下げられている**(250→240→230→220→210→210→210)。
  これまで「素子の温度が下がっていく」と扱っていたものは、**実験計画による操作点の掃引である**
- `steadyState` の `Vds/Id` は **オン抵抗ではない。**素子は能動領域にある
  (供給5.61 V、外部直列抵抗約0.22〜0.28 Ω、素子が約4.9 Vを負担して2.6 Aを流し約13 Wを捨てている)
- **Test_8 run 1 の1個のrunだけ**、パルス内の波形を見た。ゲートON期間400 µsのあいだ、
  ドレイン電流がほぼ一定のまま **Vds が約1.0 V から約2.5 V へ上がって飽和する**
- **run間の比較は一度も見ていない。**下の判定基準はすべてrun間の挙動についてのものである

## 測るもの

ゲートON期間中、電流がほぼ一定のまま Vds が上がるのは**接合部が自己発熱している**からである
(温度上昇で移動度が下がり、同じ電流に必要な Vds が増える)。素子自身が温度計になっている。

- ゲート立ち上がり(gateSignalVoltage が 7 V を超える点)で整列する
- `t0` = 立ち上がり + **10 µs**(スイッチングの落ち着き後)、`t1` = 立ち上がり + **390 µs**(ターンオフ前)
- 各runの先頭 **500波形**(足りなければ全部)を平均する
- `ΔV = Vds(t1) − Vds(t0)`、`P̄ = [t0,t1] における Vds·Id の平均`
- > **Rth_pulse = ΔV / P̄  [V/W]**
- 併せて `ΔV` の63%に達する時間(熱時定数)を報告する

**°C ではなく V/W である。** Vds→Tj の較正値が公開データに無いためで、
**run間の比は較正定数が安定であることを仮定して意味を持つ。**この仮定を宣言する。

## 判定基準(いま固定する)

| # | 基準 | 閾値 |
|---|---|---|
| **T1 単調性** | Rth_pulse が run 1→7 で単調増加(Spearman ρ ≥ 0.8) | **6デバイス中4以上** |
| **T2 先行性** | run 4 の Rth_pulse が run 1〜3 基準を、その基準のばらつきの3倍以上超える | **6デバイス中4以上** |
| **T3 量** | 基準から最終runへの増加率を報告 | **閾値なし。これが docs/197 の k である** |

**T1が落ちたら、熱経路の劣化はこの測定では見えなかったと書く。** v2は作らない。

## 事前に認めておくこと

- **°C に換算できない。**較正が無い。比だけを扱う
- **400 µsのパルスは熱経路の全部を見ない。**素子近傍(ダイとダイアタッチ)までであり、
  ケース〜周囲の経路は含まない。**ダイアタッチはこの範囲にあるので目的には合うが、
  docs/197 の k は定常Rth全体の比なので、ここで出る比をそのまま k とすると過大評価になる**
- **能動領域での測定である。**スイッチとしてのオン抵抗ではない。EPSインバータの動作モードとは異なる
- **run毎に電流も電力も変わる。**P̄ で正規化するが、動作点が同じではない
- **試験機の温度設定がrun毎に下がる。**素子近傍の熱容量・熱抵抗の温度依存性が残差として入る
- **加速試験である。**実車の時間軸に対応しない

- docs/189 ② の結論を「間違い」ではなく「**データの一部しか見ていなかった**」と書いた。訂正の範囲を正確にする
- V/W であって °C/W ではないことを、有利不利にかかわらず先に書いた
