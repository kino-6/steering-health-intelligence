# 215. インバータ故障データを取得した — 断続は入っていない。別の問題が見えた

[docs/214](214_dataset_reinventory_2026_08.md) で見つけたインバータ駆動PMSM故障データセットを取得し、
**「故障は恒久か、時間変化するか」を確かめた。**

> **恒久である。全8つの故障ファイルで、記録の最初から最後まで故障状態が続いている。**
> **断続故障はこのデータセットに入っていない。**

出典: Bacha et al., Data in Brief 58 (2025), CC BY 4.0 → [SOURCES.md](../SOURCES.md) S10

## 中身(全ファイルを列挙してから見た)

`scripts/dataset_coverage.py` で全ファイル・全列を列挙し、**118項目すべてに使用/不使用の判断を付けた**
([CHECKS.md](../CHECKS.md))。

| 条件 | ファイル | サンプル数 | 記録長 |
|---|---|---|---|
| 正常 | NORMAL_OP | 4,295 | 439 s |
| **開放故障** | HB2_HIGH_SIDE_OC | 692 | 71 s |
| **開放故障** | HB3_LOW_SIDE_OC | 1,122 | 115 s |
| 短絡故障 | HB1_LOW_SIDE_SC / HB2_HIGH_SIDE_SC / HB3_HIGH_SIDE_SC | 407 / 340 / 411 | 42 / 35 / 42 s |
| 過熱 | HB1 / HB1&2 / HB3_OVER_TEMP | 853 / 1,734 / 1,033 | 87 / 177 / 105 s |

信号は ADC生値8列(Ia, Ib, Vdc, Idc, T1〜T3, Vd)、10 Hz、タイムスタンプ付き。
装置は三相インバータ(IRF540N) + PMSM(DENSOオルタネータ改造)、10 rad/s 一定。

## 確認1: 故障は恒久だった

各ファイルを時間で5等分し、区間ごとの平均と振幅を比べた。

HB2_HIGH_SIDE_OC(開放故障)の例:

| | 区間1 | 区間2 | 区間3 | 区間4 | 区間5 |
|---|---|---|---|---|---|
| Ia 平均/振幅 | 519.2/166 | 519.1/167 | 519.2/168 | 519.2/167 | 519.3/167 |
| Ib 平均/振幅 | 474.3/96 | 474.2/100 | 473.8/98 | 473.9/98 | 474.0/100 |

**全区間で同じである。**他の7ファイルも同様で、**正常→故障の遷移が記録内に無い。**
`README.md` の手順(「故障を導入し、故障状態で継続記録」)と整合する。

> **[docs/214](214_dataset_reinventory_2026_08.md) が期待した「時間変化する故障」は入っていなかった。**
> **断続故障に届く公開データは、依然として存在しない。**

## 確認2: 正常データの方が非定常だった(こちらの方が重要)

**正常ファイルは439秒のあいだ大きく漂動している。**

| NORMAL_OP | 区間1 | 区間2 | 区間3 | 区間4 | 区間5 |
|---|---|---|---|---|---|
| **Ib 平均** | **393.4** | **457.8** | **504.6** | **509.0** | **511.0** |
| Ia 平均 | 531.0 | 519.9 | 507.3 | 509.3 | 506.3 |

**Ib は118カウント動いている。**一方、故障ファイルはどれも区間間で1カウント以内に収まる。

> **正常クラスだけが非定常で、故障クラスは定常である。**
> **正常と故障を分ける学習器は、「漂動しているか」を分けているだけかもしれない。**

これは本Repoが3回踏んだ構造と同じである——
[docs/162](162_pmsm_model_validation_results.md) / [docs/201](201_motor_second_fault_and_vibration_results.md) /
[docs/203](203_cross_machine_replication_results.md) の測定キャンペーン段差、
[docs/193](193_str_capability_rule_results.md) の母集団閾値による健全個体の誤警報。
**今回は配布データそのものにその構造がある。**

**この漂動が起動時の暖機なのか他の要因かは、配布物からは分からない。**推測しない。

## このデータで何ができて、何ができないか

| | |
|---|---|
| **できる** | インバータのスイッチ故障(開放・短絡・過熱)を、**ハーフブリッジ単位で**識別できるか。本Repo初 |
| **できる** | **どの信号が要るか。**ECUが制御用に必ず持つ相電流だけで足りるか、DCバスや温度が要るか |
| **できない** | 断続故障。**入っていない** |
| **できない** | 前駆の検出。**正常→故障の遷移が記録されていない** |
| **できない** | スイッチング周期の観測。10 Hz では見えない |

**次にやる価値があるのは「どの信号が要るか」である。**
[docs/205](205_sign_free_deviation_results.md) が巻線側で出した答え(相電流だけでは足りず加速度計が要る)の、
**インバータ側の対応物**になる。

## 限界(緩めない)

- **自作の試験装置であり車載品ではない。**PMSMはオルタネータの改造品
- **10 Hz。**スイッチング周期(通常16〜20 kHz)は見えない
- **1条件あたり35〜177秒。**繰り返しが無い
- **9条件それぞれ1回のみ。**個体差・再現性は評価できない
- **ADC生値であり物理単位に換算していない。**校正データは同梱されているが本Repoでは換算しない
- **正常クラスが非定常。**上記のとおり、比較の設計に必ず影響する

## Rule Check

- **期待していた「時間変化する故障」が入っていなかったことを冒頭に書いた**
- **全118項目に使用/不使用を付けてから中身を見た**([CHECKS.md](../CHECKS.md) の棚卸しゲート)
- 正常クラスの非定常を、**故障が恒久だったことより重要だと明記した**
- 漂動の原因を**推測しなかった**
- 「できること/できないこと」を分け、**できないことを先に列挙した**
