# 316. 事前登録 — 大きさではなく、傾きの変化で分ける

> [docs/315](315_boundary_vs_refresh_results.md): 落ちる 3 素子は、**健全期の漂流と劣化の立ち上がりが同じ桁**である。
> **水準に閾値を置くかぎり分けられない。**
>
> **健全期の漂流は 4 run かけて 0.2 床（傾きが一定）。立ち上がりは 1 run で 0.7〜1.5 床（傾きが変わる）。**
> **形が違う。**

**追加取得ゼロ。** NASA MOSFET 6 素子、7 run 全部。**区間は [docs/297](297_bank_protocol.md) 改訂どおり。**

## 統計量（実行前に固定）

指紋・残差の作り方は [docs/315](315_boundary_vs_refresh_results.md) の A（境界）と同一
（指紋は run 1 前半、残差は動作点に対する直線から、床で割る）。**そこから先だけを変える。**

```
較正区間（run 1 後半〜3）で、残差の 累積ストレス に対する傾き a_cal と、その推定のばらつき s_cal を出す
運用中、直近 W 標本で同じ傾き a_now を出す
統計量 = |a_now − a_cal| / s_cal
```

**W は {2000, 5000, 10000} の 3 通り。**バンクとして 3 本すべて走らせ、**OR で束ねる。**
**閾値は較正区間の同じ統計量から、誤報 1 件/時 ÷ 3、clamp して達成率を報告。**

**s_cal の出し方**: 較正区間を W ごとに区切って傾きを出し、その頑健なばらつき（MAD × 1.4826）。

## 判定基準（実行前に固定）

| # | 基準 | 閾値 |
|---|---|---|
| **G1** | run 4 の誤報が設計値の 3 倍以内 かつ run 5〜7 で発火する素子 | **6 中 5** |
| **G2** | [docs/315](315_boundary_vs_refresh_results.md) で落ちた 3 素子（Test_9・11・12）のうち、救えた数 | **2 以上で「形で分けられる」** |
| **G3** | 初発火の run。水準の閾値（[docs/309](309_slow_refusal_results.md)）と比べて早いか遅いか | 記述 |

**G1 が 5 に届かなくても、G2 が 2 以上なら「水準では分けられないものが形では分けられる」と書く。**
**G2 が 1 以下なら、この観測量では漂流と立ち上がりを分けられないと結論し、
[docs/302](302_multivariate_results.md) が見つけた別の量（フランジ−パッケージ温度差）に移る。**

## 答えないこと
- ヒーター動作の 1 試験機・6 素子
- 傾きの変化は線形の当てはめによる。**非線形な立ち上がりの形は見ていない**
- **W の格子は私が決めた仮定である**（[TROUBLES.md](../TROUBLES.md) T2）
