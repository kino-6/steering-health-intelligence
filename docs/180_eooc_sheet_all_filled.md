## 判断

**空欄はゼロになった。ただし「埋まった」の中身は4種類あり、区別して読む必要がある。**

| 状態 | 件数 | 意味 |
|---|---|---|
| 埋まる(実測・検証済み含む) | 21 | 本研究の測定または公開一次文書に基づく |
| 埋まる(不成立の記録) | 3 | **やって成立しなかったことの記録**。これも内容である |
| 制約(仕様として明記) | 1 | 弱点ではなく仕様として宣言する項目 |

シート: [data/sotif_eooc_assumption_sheet.tsv](../data/sotif_eooc_assumption_sheet.tsv)(26項目)

## 埋めた4項目

### EOOC011 — 機能不足の許容発生率

**旧: 「空欄。OEMが埋める。公開情報では原理的に届かない」**
これは **[AGENTS.md](../AGENTS.md) 7条違反**だった。「内部情報がないと分からない」で止めていた。

**新: 導出方法と公開アンカーまでは公開情報で埋まる。**

- **受容原理はISO 21448が挙げている**: GAMAB(Globally At Least As Good) / PRB(Positive Risk Balance) / ALARP / MEM
- **公開アンカーが存在する**: 人間ドライバーの死亡事故率 約1件/1億マイル。GAMABで置けば車両レベル目標は **10⁻⁸ /km オーダー**。文献が引く受容基準も概ね **10⁻⁸ /時間** のオーダー
- **分解の道筋も公開されている**: 全体受容基準 → シナリオクラス別 validation target → 部品の寄与
- **部品側が出せるのは、宣言した粒度での自己の実測発生率まで**

**OEMに残るのは「この program における配分値」だけ**になった。方法も桁感も部品側から提示できる。

> 注意: 10⁻⁸ は**車両レベルの桁感**であり、部品の機能不足に直接あてはめない。配分はOEMの決定である。

### EOOC013 — SOTIF要求が部品側へ降りる経路

**旧: 「空欄・実施条件待ち」** → **新: 構造として確認済み。**

```
規制(EU 2022/1426 ISMR、2022-08発効 / UN ADS GTR、2026-06 WP.29第199回で採択)
  → OEMのライフサイクルSMS + safety case
    → 部品を文脈外要素として組み込む
      → ISO 21448 Clause 4.4.3 の SOTIF-EooC
        → 部品側が仮定(使われ方の前提・発現条件・許容発生率)を差し出す
          → 運用フェーズの市場検証
```

**各段が公開文書で確認できる。** 個別の調達文書に書かれているかは本研究の問いではない([AGENTS.md](../AGENTS.md) 0条)。

### EOOC019 — 物理モデルによる外挿

**旧: 「空欄(検証失敗)」** → **新: 「埋まる(不成立の記録)」。**

**不成立は空欄ではない。** 事前登録した基準に対し不成立であったこと、原因を測定側の2セッション段差と特定したこと、
**モデルを実測に合うまで調整しなかったこと**——これらは全て記録すべき内容である。

そしてこの記録があるから、シート上の他の数値について「モデルではなく実測に基づく」と言える。

### EOOC026 — 仮定が破れたときの扱い

**旧: 「未定義。OEMの領域」** → **新: 部品側の範囲は定義できる。**

- **部品側**: ①事実を記録(時刻・動作点・再発回数・宣言範囲からの逸脱量) ②payloadとして出す ③**自己診断も是正要否の判断もしない**
- **OEM側**: 調査・是正・当局報告(EU 2022/1426 ISMR、UN ADS GTR の SMS が課す義務)

**「OEMの領域」で止めるのと、「部品側の範囲を定義したうえで境界を書く」のは違う。** 後者でなければ引き渡せない。

## 埋めてみて分かったこと

**4つのうち3つは、公開情報が足りなかったのではなく、私が調べていなかっただけだった。**

| 項目 | 止まっていた理由 | 実際 |
|---|---|---|
| EOOC011 | 「配分はOEMが決めるから届かない」 | **導出原理も公開アンカーも公開されていた** |
| EOOC013 | 「RFQを見ないと分からない」 | **構造は公開文書で閉じられた** |
| EOOC026 | 「OEMの領域だから」 | **部品側の半分は定義できた** |
| EOOC019 | 検証して不成立 | これは正当。**不成立の記録として埋まる** |

**「内部情報がないと分からない」は、3回とも調査不足の言い換えだった。**
[AGENTS.md](../AGENTS.md) 7条(ビジネス判断は外から組み立てる。それは判断の放棄であり三流)が、そのまま当たっていた。

## 残る限界(シートの外)

シートは埋まったが、シートが主張できる範囲は変わらない。

- 機能不足の実測(EOOC017の熱余裕13〜50%)は**計算であって測定ではない**([docs/170](170_thermal_headroom_translation.md))
- 実証は**熱・接合部の族**であり、市場で優勢な**接点系の先行時間は測れていない**([docs/175](175_close_contact_question.md))
- 実証データは**代替部品**(NASA MOSFET)であり、EPSそのものではない
- 規制の対象は**ADS搭載車**であり、一般の人間運転車のEPSには及ばない

## Rule Check

- **「原理的に届かない」と自分で書いた欄を、7条違反として撤回し、公開情報で埋めた**
- 埋めた内容の性質(実測 / 不成立の記録 / 仕様 / 境界)を区別して提示した
- 10⁻⁸ を部品レベルに直接あてはめないことを、値の直後に注記した
- シートが埋まっても主張範囲は広がらないことを、最後に明記した
