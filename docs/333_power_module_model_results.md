## 何が「モデル」なのか

**学習していない。**係数は出荷時の指紋そのものである（[TROUBLES.md](../TROUBLES.md) T32）。

```
R_on(t)    = a·T + b + d·g        記録の逸脱 d（床いくつ分）から復元
R_on(健全) = a·T + b              指紋の傾き a と基準値 b
C = √( R_on(健全) / R_on(t) )
```

**`a`・`b`・`g` は既に 56 バイトに入っている。**追加で要るものは無い。

## 復元の精度

| 経路 | 差の中央値 | 最大 | 判定 |
|---|---|---|---|
| **30 バイトの記録から** | **0.0049** | 0.1322 | M1 成立（基準 0.01） |
| **2 バイトのバスから** | **0.0040** | 0.1303 | M2 成立（基準 0.02） |
| 25.5 床の飽和 | — | **0.0%** | M3 飽和なし |

**バスの 0.1 床刻みは、ほとんど何も失わない。**走行中に流れる 2 バイトで、能力の推定には足りている。

**ただし最大誤差 0.13 は 1 素子に集中している。**

## 採否判定の穴

**最大誤差はすべて Test_10 のものである。**[docs/331](331_assist_capability_results.md) で
「run 1 の当てはめが壊れている」と特定した素子である。**出荷時の採否判定はこれを弾けなかった。**

| 素子 | 保留区間のずれ | **指紋の傾き** | 採否（ずれのみ） | 復元の最大誤差 |
|---|---|---|---|---|
| Test_8 | 0.100 床 | +0.00836 | 採用 | 0.0424 |
| Test_9 | 0.122 床 | +0.00823 | 採用 | 0.0110 |
| **Test_10** | **0.148 床** | **−0.00720** | **採用されてしまう** | **0.1322** |
| Test_11 | 0.097 床 | +0.00824 | 採用 | 0.0047 |
| Test_12 | 0.063 床 | +0.00825 | 採用 | 0.0181 |
| Test_14 | 0.043 床 | +0.00831 | 採用 | 0.0057 |

**ずれの列では Test_10 は目立たない。**0.148 床は 2 番目の 0.122 とほとんど変わらない。

> **[docs/280](280_fingerprint_interval_results.md) の採否判定は「自分の健全を再現できるか」を見る。**
> **間違った指紋でも、内部で一貫していれば再現できてしまう。**

**傾きの列では一目である。**R_on は温度とともに上がる。**負の傾きは、当てはめが悪いのではなく物理的にあり得ない。**
これは [docs/325](325_extrapolation_direction_results.md) が仕様に足した規則——**出力を物理範囲に当てる**——を、
**出力ではなく指紋そのものに当てたものである。**

**傾きの符号で弾くと、Test_10 だけが落ちる。**他 5 素子は残り、**差の中央値 0.0034、最大 0.0424** になる。

## 仕様に足すこと

> **出荷時の指紋は、物理に反していないことを確かめてから採用する。**
> **R_on の温度に対する傾きは正である。**負なら採否判定のずれが小さくても**除外する。**
> **保留区間のずれでは見えない**——間違った指紋も内部では一貫しうる。

**この 1 行は無料である。**指紋は既に傾きを持っており、比較は符号を見るだけである。

## SOTIF への参加という観点で何が言えるようになったか

| | |
|---|---|
| **記録** | 30 バイト/事象、448 バイト/個体（[docs/319](319_unit_trace.md)） |
| **走行中の報告** | 2 バイト/フレーム。**この 2 バイトから能力を誤差 0.004 で推定できる** |
| **推定モデル** | 逸脱 → R_on → アシスト能力。**係数は出荷時に固定、学習なし、追加記録なし** |
| **精度** | 採用された素子で中央値 0.003、最大 0.042 |
| **前提** | 導通損のみ。**機能出力の実測ではない**（[docs/331](331_assist_capability_results.md)） |

## 残る限界

- **真値自体が計算である。**ここで確かめたのは「ECU の数字から同じ計算ができるか」であって、**その計算が正しいかではない**
- **導通損しか見ていない。**故障直前でも 11% しか説明できない（[docs/331](331_assist_capability_results.md)）
- **8 ビット電流測定の効きは測れていない。**NASA の記録は別の分解能で取られている
- **傾きの符号という規則は、この 1 素子で見つけたものである。**他にどんな物理違反がありうるかは網羅していない
- 単体 MOSFET・6 素子・1 試験機。**EPS ではない。率ではなく存在証明**
