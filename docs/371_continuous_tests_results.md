## なぜ NASA は導出できたのか（問いへの答え）

1. **量**: transient の on 状態の V_DS / I_D。私は steadyState の別の量で 200 本の文書を書いていた
2. **素子**: 連続試験（Test_36 など）。私は 7 run の階段状の 6 素子だけを選んでいた
3. **形の扱い**: NASA は指数を**仮定**し、Kalman filter / GPR で**追跡**して RUL を出した。**直線と比べて指数を選んだのではない。**
   本件で直線と比べると、死までの 2〜4 時間では区別できない（E3）

つまり「NASA にできて私にできない」のではなく、**NASA は同定していない。**同定を要求したのは私で、その要求にはデータが足りない。

## 答えがどう変わるか

| | 前 | 今 |
