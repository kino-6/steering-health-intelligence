# 170. パラメータのずれを機能不足へ翻訳する(SOTIFのギャップSを埋める)

## 判断

**[docs/169](169_sotif_link_check.md) が残したギャップS(パラメータのずれ ≠ 機能不足)は、熱の経路で埋まった。**

> **兆候が最初に検出できる時点で、持続可能なアシスト熱余裕は既に 13〜50% 失われている**(健全時の接合温度上昇を40°Cと仮定した場合)。
> **このときfaultは立たない。部品は動作している。これが functional insufficiency = SOTIFの主題である。**

実行: `python3 scripts/thermal_headroom_translation.py` / 数表: [data/thermal_headroom_translation.tsv](../data/thermal_headroom_translation.tsv)

## 翻訳の道筋(新しい仮定を1つしか入れない)

1. **[docs/167](167_precursor_results_v2.md) の指標は、熱抵抗の劣化そのものである。**
   指標は「個体ごとの温度係数を除いたON抵抗の残差」である。ON抵抗は接合温度で上がるから、
   **パッケージ温度が同じなのに残差が出る = 同じ消費電力で接合がより熱くなっている = 接合〜パッケージ間の熱抵抗が増えた**
2. **残差を実測の温度係数で割れば、その余分な接合温度上昇が°Cで出る**
3. **熱ディレーティングは持続アシストを制限する。** 熱抵抗が k 倍になれば、同じ温度限界に達する電力は 1/k になる

**新しい仮定は「健全時の接合〜パッケージ温度上昇 ΔTj_0」ひとつだけ**で、これは本データに無いので**掃引**した。

## データ内部の妥当性チェック

翻訳の1段目(「残差は熱抵抗劣化である」)が正しければ、実測の温度係数はシリコンMOSFETの公表値に入るはずである。

- **実測: 0.487 〜 0.636 %/°C**
- 公表される一般値: おおよそ 0.5 〜 0.8 %/°C
- **6デバイス中5デバイスが範囲内。** Test_14 の 0.487 のみわずかに下限を下回る(公表値も概数であり、境界上と見る)

**独立な根拠で解釈が支持された。** これが外れていたら、1段目が間違っているので以降は成立しない。

## なぜこれがSOTIFなのか

| 状態 | fault | 機能 | 規格 |
|---|---|---|---|
| run 1〜4 | なし | 正常 | — |
| **run 5〜6** | **なし。DTCは立たない** | **持続アシスト能力が13〜50%低下** | **ISO 21448 = SOTIF** |
| run 7 | 発生 | 喪失 | ISO 26262 |

**run 5〜6 は「故障していないのに性能が足りない」状態そのものである。** [docs/169](169_sotif_link_check.md) が定義した2層目が、数字で埋まった。

## いつ顕在化するか — 公開の市場ペインと一致する

熱余裕は、**持続的に高いアシスト要求があるときだけ**問題になる。低要求域では制御器が吸収し、何も起きない。

持続的高要求 = **低速・大舵角**(駐車、切り返し)。これは本研究が最初に特定した市場ペインそのものである。

- SCN001 / ULC008: 「低速または低速寄りの操舵でEPS assistが失われる/制限される」
- 公開リコール MKT003〜010: 「**Increased steering effort**」「**risk higher at low speeds**」

**熱余裕の劣化は、公開苦情が集中している運転条件でだけ顕在化する。** 機構と市場現象が同じ場所を指した。

## 言えないこと(先に固定)

1. **これは計算であって、機能損失の測定ではない。** 測ったのは温度係数と残差までで、アシスト損失は3段の推論の先にある
2. **このMOSFETはEPSインバータ素子ではない。** R_on ≈ 1.9 Ω であり、素子自体が負荷になる熱ストレス試験である。EPSインバータのR_DS(on)はmΩ級
3. **ΔTj_0 は仮定である。** 本データに無いので掃引した。実機の値はprogram依存
4. **EPSのディレーティング則の具体は公開されていない。** 「熱ディレーティングが存在する」ことは公開情報(TSB等)で確認できるが、閾値と傾きは不明。1/k の関係は一次近似
5. **EPSインバータでdie-attach型劣化が起きることは示していない。** 同種のパッケージ技術であることからの類推である
6. 車両レベルで危険側に効くかは**OEMの領域**であり、踏み込まない([docs/169](169_sotif_link_check.md))

## Rule Check

- 公開データのみ。新しい仮定を1つ(ΔTj_0)に限定し、それも掃引して単一値に依存させていない
- **データ内部の独立チェック(温度係数が公表値域に入るか)を先に置き、結果を報告した**(6中5が範囲内、1が境界上)
- 計算であって測定ではないことを、結論より先に「言えないこと」で固定した
- 車両レベルの判断はOEMの領域として踏み込んでいない
- 故障予測([docs/143](143_recall_detection_results_v2.md))へ戻っていない。run順は既知の実験進行である
