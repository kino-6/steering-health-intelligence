# 多車種展開と実在変種比較の検証結果

## 検証1: 波形感度は他車種でも成り立つか(多車種展開)

**判断: 質的には4車種すべてで再現した。ただし数値は車種ごとに違い、閾値の使い回しはできない。**

根拠(4車種: Ford Maverick / Genesis G70 / Audi Q3 / Honda CR-V、計3,300セグメント超):

- パターンは全車種で同じ: 定常ずれは最小試験量(0.05m/s²)で全車種100%検出/効きの変化は10〜15%で大半を検出/遅れは0.4〜0.5秒で大半を検出/微小な変化(効き2%、遅れ0.1秒)は全車種で見えない
- 数値は車種で動く: 健全時の誤検出率は3.4%〜10.2%、効き15%の検出率は63%(CR-V)〜99.7%(Audi)。CR-Vは残差のばらつきが大きく、同じ変化が埋もれやすい
- **含意: 「手法は移る、閾値は移らない」。** リコール識別(docs/137のSilverado教訓)と同じ結論が波形側でも出た。実装は車種ごとの母集団較正を前提に設計すべきで、これは欠陥ではなく仕様として明記する

結果ファイル: data/steering_synthetic_sensitivity(_genesis_g70_2018 / _audi_q3_2nd_gen / _honda_cr_v_2016).tsv

## 検証2: 実在する構成の違いを捕まえられるか(変種比較)

**判断: 捕まらなかった、が正しい報告。グループ差は検出できたが、使い方の違い(交絡)と切り分けられない。**

根拠(Audi Q3内の2種類の部品/ソフト識別子: 709本 vs 222本):

- 素の比較では、左右非対称(効果量0.57)と高周波不整合(0.64)に有意差が出た——しかし**使い方の差はそれより大きかった**(平均車速の効果量1.14。B群は明確に低速・低励起の使われ方)
- 使用条件を揃えた層別比較(車速15〜30m/s、励起0.2〜0.8)では、非対称の差は有意でなくなり(p=0.09)、高周波の差も半減(0.64→0.33)。残った差も速度の残り不均衡と切り分けられない
- **含意: 横断比較(違う車同士を比べる)は、公開の観測データでは交絡に埋もれる。** 帰属できる設計は「同じ個体の時間変化」(同一車両の前後比較・再発)だけ——これは①定常ずれが路面でも出る(docs/144)、②届出行動でMY2010が見えない(docs/136)に続き、**3つ目の独立した経路から「個体内の縦断監視が本命」という同じ設計結論に到達した**ことを意味する

結果ファイル: data/steering_fw_group_comparison.tsv(素の比較と層別比較の両方を収録)

## 全体への含意

1. 技術成立性の主張が一段強くなった: 「1車種の実証」→「4車種で質的再現、較正は車種ごと」
2. 「捕まらなかった」検証2は、部品内部実装(個体を特定できる位置)の必要性を、公開データの限界という形でまた裏付けた。外から見える研究として、見えない線を引く仕事がまた一つ済んだ
3. 残る公開検証は、英国車検データ(分母つき)と、学習era内の見逃し構造分析、将来リコールeraの再検証
