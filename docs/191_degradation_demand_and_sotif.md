# 191. 劣化状況を知る需要はどこにあるか、そしてそれはSOTIFか

問い(2026-08-25):

> Assyごと変えるのは組み付け・調整コストから見てそうだと思うんだけど、
> 一方、劣化、疲労状況がその段階でもわかることに需要はあるのでは？
> でそれがSOTIFじゃないの？

**前半は正しい。後半は違う。** 分けて答える。

## 前半 — 需要はある。しかも既に金が払われている

[docs/190](190_assembly_replacement_meaning.md) が示したとおり、**1,346,528台の交換/非交換が、ECU内部に保存された記録だけで決まっている。**
決定点は既に存在し、既に運用され、既に費用が払われている。**需要の存在は証明済みである**——新しく作る必要がない。

ただし、その記録が今答えられるのは2値だけである。

| 記録の答え | 処置 |
|---|---|
| コードあり(既に機能喪失) | Assy交換 |
| コードなし | ソフト更新して返す |

**「どこまで来ているか」という3つ目の答えが無い。**
コードなしで返した車は、「まだ壊れていない」としか言われておらず、
**今後壊れるかどうかは判別されないまま出て行く。**

本研究が測ろうとしているのは、まさにこの3つ目の答えである。
**新しい決定点を作る話ではなく、既にある決定点の答えを増やす話である。**

> **未証明**: 「等級の答えに金を払うか」は証明していない。証明したのは
> 「その決定点が実在し、既に内部記録を経由している」ことまでである。

## 後半 — それはSOTIFではない

**劣化・疲労は故障(fault)である。故障はISO 26262の担当である。**
ISO 21448(SOTIF)が扱うのは「**故障していないのに**性能限界で危険になること」である。
この区別は [docs/178](178_sotif_straight_answer.md) で既に確定している。

したがって、質問の「劣化・疲労状況がその段階でわかる」の需要先は:

| 買い手 | 規格・根拠 | 状態 |
|---|---|---|
| 品質保証・保証費 | 規格外(経済) | **今日金がある**。134万台の決定が実在 |
| 機能安全 | **ISO 26262** | 故障の早期検知。既存業務 |
| SOTIF | ISO 21448 | **後述。今日は客がいない** |

## SOTIFになるのは1箇所だけ

**「コードが出なかったので返した車」である。**

故障はしていない。しかし性能包絡(応答遅れ・ゲイン・オフセット)は動いているかもしれない。
その包絡に**車両側の機能が依存していると、故障が一件も起きないまま前提が崩れる。**
これがEooCの仮定シート([docs/153](153_sotif_eooc_assumption_sheet.md))が宣言する対象である。

**つまりSOTIFは「劣化を知ること」ではなく、「劣化しても故障と呼ばれない領域」の側にある。**

## その形の事例は記録に現れるか — 数えた

米リコール(2010年以降、車両、操舵系)715キャンペーンを、SOTIFの形の目印で数えた。

| 目印 | 操舵系全体 | うちEPS |
|---|---|---|
| 運転支援機能への依存に言及 | 2 | **0** |
| 経時的な劣化・摩耗に言及 | 45 | 3 |
| 故障コードが出ないことに言及 | **0** | **0** |

EPSで劣化に言及した3件も、中身は**製造時の損傷が時間とともに悪化する**話であり
(15V144000 ECU製造時損傷、15V146000 基板接触、20V672000 ヒューズボックス緩み)、
使用による劣化ではない。

**今日まで、EPSリコールが運転支援機能への依存で駆動されたことは一度もない。**

> **飛躍しない。** リコールは**欠陥**を記録する制度である。SOTIFの機能不足は定義上欠陥ではないので、
> **構造上この計器には入らない。**ゼロは「起きていない」ではなく「**この計器では見えない**」である。
> ([docs/176](176_correction_degradation_window.md) と同じ誤りを繰り返さない)
> 言えるのは「**決定と金は今日26262/保証の側にある**」までである。

## 結論 — 測るものは1つ、買い手が2つ

```
        個体基準線上の劣化度(測るもの — 1つ)
                   |
      +------------+------------+
      |                         |
  26262 / 保証              SOTIF (EooC)
  「交換するか」            「機能が前提を満たすか」
  買い手: 販売店・品証        買い手: OEM SOTIF担当
  今日: 134万台で稼働中       今日: 記録上0件
```

**同じ測定である。違うのは誰が読むかだけである。**
[docs/188](188_the_line.md) が「需要の基盤をSOTIF/ADS規制から保証経済へ戻した」のは、この意味で正しかった。
順序は——**保証で入り、EooC仮定シートを持った状態で、SOTIFが来た時に取る。**

## Rule Check

- 質問の前半を肯定し、後半を否定した。**両方を曖昧に肯定しない**
- 「需要がある」の中身を「決定点が実在する」までに限定した。金額・支払意思は未証明と明記
- 0件を「存在しない」と読み替えていない。計器の構造上の盲点として書いた
- [docs/178](178_sotif_straight_answer.md) の既定の結論と矛盾していないことを確認した
