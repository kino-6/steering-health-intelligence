# 248. 実用水準まで下げると、車両レベルは「アシストが完全に抜けた」しか検出できない

[docs/247](247_false_alarm_tradeoff_protocol.md) の事前登録を実行した。**追加取得ゼロ。**

実行: `python3 scripts/false_alarm_tradeoff.py` /
数表: [data/false_alarm_tradeoff.tsv](../data/false_alarm_tradeoff.tsv)

## 結果 — 検出率90%に達する最小振幅(その系列自身の床の倍数)

| 誤検出の水準 | 車両レベル(34,982窓) | 部品内部(NASA、1,003窓) |
|---|---|---|
| **L0 7.2回/時** | **10倍** | **2〜3倍** |
| **L1 1回/時** | **20倍** | **10倍** |
| **L2 0.1回/時** | **20倍** | **標本の外**(7,200窓必要、1,003窓しかない) |
| L3 0.01回/時 | **標本の外**(72,000窓必要) | 標本の外 |

**[docs/247](247_false_alarm_tradeoff_protocol.md) で「標本の外は推定しない」と決めた。推定していない。**

## 実用水準(1回/時)での物理量

| 位置 | 必要な大きさ | 実車換算 |
|---|---|---|
| **車両レベル** | **床の20倍** | **約 4.2 m/s²** |
| **部品内部** | **床の10倍** | (EPS実機の床が不明のため換算できない) |

> **4.2 m/s² の横加速度誤差は、「アシストが完全に抜けた」に相当する大きさである。**
> **実用の誤検出率まで下げると、車両レベルでは断続的な劣化ではなく完全喪失しか捕まらない。**

## 部品内部は余裕が残る

| | 床の倍数 |
|---|---|
| 実用水準(1回/時)での検出限界(部品内部) | **10倍** |
| [docs/167](167_precursor_results_v2.md) が実測した前駆 | **20〜300倍** |

> **余裕は 2倍〜30倍。**[docs/246](246_internal_signal_injection_results.md) の 2〜150倍 からは縮むが、**残る。**

## これが [docs/188](188_the_line.md) の主張の量的な形である

[docs/188](188_the_line.md) は「その瞬間の記録を持てるのは部品の中だけである」と書いた。
**これまでは「外から見えない」という定性的な主張だった**(外部観測6系統、[docs/224](224_current_conclusion.md))。

**いま同じことが、同じ土俵の数値で言える。**

| | 実用水準での検出限界 | 前駆(床の20〜300倍)との関係 |
|---|---|---|
| 車両レベル | 床の20倍 = **約4.2 m/s²** | **完全喪失しか捕まらない** |
| 部品内部 | 床の10倍 | **2〜30倍の余裕が残る** |

**同じ誤検出率で並べたときに、片方だけが前駆に届く。**

## 実用化の代償

| 位置 | L0 → L1 の劣化 |
|---|---|
| 車両レベル | 10倍 → 20倍(**2.0倍悪化**) |
| 部品内部 | 2〜3倍 → 10倍(**3〜5倍悪化**) |

**部品内部の方が代償は大きい**(窓数が少なく閾値の推定が粗いことも効いている)。
**それでも到達点は部品内部の方が良い。**

## 限界(緩めない)

- **部品内部のL2は標本の外である。**1,003窓しかない。**1回/時より厳しい水準は測れていない**
- **部品内部は6デバイスをプールした。**各デバイスの床で正規化してから重ねている
- **車両レベルの4.2 m/s² は、床の中央値0.2083 m/s²からの換算である。**個体差がある
- **EPS実機の床が不明なので、部品内部の10倍を物理量に換算できない**([docs/225](225_recorder_specification.md) の空欄)
- **矩形という波形は仮定である**
- **これは検出器の性能であって現象の実在ではない。**注入した事象は本物ではない
- **1走行時間は制御が有効な時間である。**実走行時間ではない

## Rule Check

- **標本の外の水準を推定しなかった。**2箇所とも「測れない」と書いた
- **部品内部の方が代償が大きい**という不利な事実を、到達点が良いことより先に書いた
- 4.2 m/s² を「アシストが完全に抜けた相当」と**自分で翻訳した。**数字を裸で置かない
- **EPS実機の床が無いので部品内部を物理量に換算できない**と明記した
