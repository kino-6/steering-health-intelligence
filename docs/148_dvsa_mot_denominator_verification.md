# 英国車検データによる分母つき再検証(2025年・1年分)

## 判断

**群レベルの主張「操舵系の不具合リスクは車齢とともに強く増える」は、分母つきの全数検査データで確認できた。**
米国苦情データ(分母なし・自己申告)で引いた曲線の形が、独立の制度・独立の国・分母つきの実測で再現された。検証3は成立。

## 根拠

- 母数: 英国の2025年定期車検、乗用車クラスの通常検査 **約2,800万件**(全数記録=分母がある)。うち操舵系不合格 約67万件
- 率は車齢に対して単調に上がる: 車齢3年 0.11% → 5年 0.46% → 8年 1.4% → 10年 2.3% → 14年 3.4% → 15〜21年で3.5〜4.3%の高原
- 増え方の桁: 車齢3年から20年で**約40倍**。「操舵系は年齢とともに壊れやすくなる」が、感覚ではなく率の曲線として引けた
- 電動パワステ固有項目も同じ形: 率は車齢とともに約10倍に増える(2年0.0014%→18年0.048%)。ただし絶対値は極小——整備現場は故障を汎用の操舵項目で記録しがちで、固有項目の使用は稀(コード化の癖という制度限界)
- 処理は9.2GBのzipを展開せずストリーム2パスで完了。再現は `python3 scripts/dvsa_mot_steering_rates.py`

出力: [data/dvsa_mot_steering_2025.tsv](../data/dvsa_mot_steering_2025.tsv) / [generated/dvsa_mot_steering_2025.html](../generated/dvsa_mot_steering_2025.html)(車齢×不合格率の曲線+メーカー別テーブル)

## 読み方の注意(誤解しやすい点)

- **車齢0〜2年は読まない。** 英国の車検義務は3年目からで、0〜2年の受検は任意・少数のため率が信頼できない。曲線は3年以降で読む
- **22年以降の高原〜微減は生存バイアス。** 古い車で残っているのは手入れされた個体
- **メーカー別の生の率(0.5%〜5.2%)は設計優劣の判定に使わない。** 車齢構成・車種構成・使われ方が混ざったままの数字
- **米国苦情データと比べてよいのは「形」だけ。** 検査不合格と苦情は定義が違う。絶対値の比較は無意味
- 年1回のスナップショットなので、車検間に修理された故障は数えない(率の下振れ方向)
