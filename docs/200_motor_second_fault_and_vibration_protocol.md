# 200. モータ側 第2の故障種と振動チャネル — 事前登録

**結果を1つも見る前に書き、単独でコミットする。**

## なぜこれをやるか

[docs/199](199_pulse_thermal_results.md) で、NASA MOSFET は **EPSパワー段の代役として弱い**ことが分かった。
EPSのインバータはMOSFETをスイッチとして使うが、あの試験機は能動領域のヒーターとして使っている。
残るのは方法の試験台としての価値だけである。

**一方、KAIST PMSM は EPS のアシストモータそのものである。**そしてこのデータセットは
32ファイルのうち **8ファイルしか使っていなかった。**

| 中身 | severity | 状態 |
|---|---|---|
| 層間短絡・電流(3相) | 0.00, 2.26, 2.70, 3.35, 4.41, 6.48, 12.17, 21.69 | 使用済み([docs/195](195_capability_rule_second_mechanism_results.md)) |
| **層間短絡・振動(1ch)** | 同上 | **未使用** |
| **コイル間短絡・電流(3相)** | 0.00, 0.68, 0.81, 1.01, 1.34, 2.00, 3.93, 7.56 | **未使用** |
| **コイル間短絡・振動(1ch)** | 同上 | **未使用** |

**コイル間短絡にも健全記録(0.00)がある。**個体基準の規則がそのまま当たる。

## 探索で既に見たこと(宣言)

- ファイル名一覧と severity。上表のとおり
- 電流は3ch・100 kHz・120秒(単位 A)、振動は **1ch・25.6 kHz・120秒**(単位 g)
- 配布名の不統一: `1000W_1.01_current_intercoil.tdms` だけ小数点がピリオド。他はアンダースコア
- **特徴量の値は一つも見ていない**

## 3つの問い

### W1. 規則は第2の故障種へ転移するか

capability 指標 `C = H(sev)/H(0)`, `H = mean|I| / max|I|` を、**コイル間短絡**に当てる。
[docs/194](194_capability_rule_second_mechanism_protocol.md) と同じ式・同じ手順。

### W2. 振動は電流にない情報を持つか

**これは商品として効く問いである。** EPSのECUは制御のために**相電流を必ず測っている**。
**加速度計は積んでいない。**したがって:

- 電流だけで足りる → **センサ追加ゼロ**で成立する
- 振動が要る → 加速度計の追加が要る

各チャネル・各故障種について、**自身のばらつきの3倍を超える最小のseverity**を出して比べる。

### W3. 電流だけで、2つの故障種を区別できるか

[docs/190](190_assembly_replacement_meaning.md) が示した現場の問題は「どこが悪いか分からないからAssyごと替える」である。
**「劣化している」の次に「どの故障か」まで言えれば、答えの粒度が一段上がる。**

## 特徴量(固定)

各記録の中央20秒。電流は [docs/162](162_pmsm_model_validation_results.md) の極性補正を通す。

| 記号 | チャネル | 定義 |
|---|---|---|
| **C1** | 電流 | `H(sev)/H(0)`、`H = mean|I| / max|I|`(基本波振幅) |
| **C2** | 電流 | 逆相/正相比 `|I2|/|I1|` |
| **V1** | 振動 | 電気周波数の2倍(約400 Hz)における振幅を健全比 |
| **V2** | 振動 | 広帯域RMSを健全比 |

**宣言粒度**: 20秒を2秒×10に分割し、各小窓の値の標準偏差の3倍。全特徴量で同じ定義。

## 判定基準(いま固定する)

| # | 基準 | 閾値 |
|---|---|---|
| **W1 転移** | コイル間短絡で C1 が severity に単調減少 | **Spearman ρ ≤ −0.8** |
| **W2 電流の十分性** | C1 または C2 が分解する最小severityが、V1・V2 のそれ**以下**である | **2つの故障種の両方で成立すること** |
| **W3 故障種の区別** | `(C2) / (1 − C1)` の値域が、2つの故障種で**重ならない** | **重なりゼロ** |

- W1が落ちたら、規則は層間短絡に固有だったと書く
- W2が落ちたら、**振動が要る**と書く。センサ追加が要るという不利な結論でもそう書く
- W3が落ちたら、区別はこの特徴量ではできないと書く。**別の特徴量を後から探さない**

## 事前に認めておくこと

- **機体は1台。**故障は人工的に作られている。自然劣化ではない
- **各severityは1記録ずつ。**繰り返しが無いので、粒度は測定内変動であって個体間変動ではない
- **層間短絡の8点は2つの測定セッションに分かれている**([docs/162](162_pmsm_model_validation_results.md))。
  コイル間短絡が同様かは未確認。**極性を幾何的に検出して報告する**
- **W2は「このデータのこの特徴量で」の比較である。**振動の別の特徴量が勝つ可能性を否定しない
- **振動は1chである。**設置位置による差は評価できない
- **v2は作らない。**落ちたら落ちたと書く

- W2は**不利な結論(振動が要る=センサ追加)になりうる**ことを先に書いた
