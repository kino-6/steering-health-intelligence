# 291. モデルは作れていない。検出器を作った。そして足りないデータが何かは、もう分かっている

> **ユーザ指摘(2026-09-02): 「Sotif意識しているのだから、モデル構築になると思うんだけど。
> で、結局モデル構築できたの?」**
>
> **できていない。**作ったのは**検出器**である。
> **SOTIFが要求するのはモデルであり、両者は別物である。**

---

## 1. 検出器とモデルの違い

| | 検出器(作ったもの) | **モデル(SOTIFが要求するもの)** |
|---|---|---|
| 出す値 | **その個体の基準から3.15床ずれた** | **アシストが何%落ちる。どの条件で。どの危険挙動につながる** |
| 答える問い | いつもと違うか | **機能がどれだけ足りないか** |
| SOTIFの語 | — | **機能不足**(3.8)、**性能の不足**(3.22)、**起因条件**(3.30) |
| 車両側が使えるか | **使えない。**床の倍数は車両にとって意味を持たない | **使える。**配分の対象になる |

**[docs/286](286_common_mode_results.md) が出す「逸脱 3.15」は、SOTIFの語彙に翻訳できない。**
**どれだけ機能が足りないのかを言っていない。**

## 2. モデルは一度作って、取り下げてある

**[docs/192](192_str_capability_rule_protocol.md)〜[docs/195](195_capability_rule_second_mechanism_results.md) で
「能力値」——本来の何%出せるか——を作った。それがモデルだった。**

**取り下げた理由:**

| 文書 | 何が起きたか |
|---|---|
| [docs/199](199_pulse_thermal_results.md) | 使った量がオン抵抗ではなかった。**物理的な導出が壊れた** |
| [docs/203](203_cross_machine_replication_results.md) | **符号が機体をまたがない**(−1.000 / +1.000 / +0.400) |

**以後、本Repoはモデルを作り直していない。検出器に退避した。**
**「予測しない・能力値を出さない」という7つの禁止事項は、その退避の記録である。**

## 3. なぜ作り直せなかったか — データ要件が1つ抜けていた

[docs/238](238_data_requirement.md) の R1〜R13 を読み直した。

> **「機能の出力が同時に測られていること」という要件が無い。**

R9は「信号が部品の内部量であること」、R10は「ECUが持ちうる信号であること」。
**どちらも入力側の要件である。出力側——実際に出たトルク——を要求していない。**

**モデルは、内部量と機能出力を結ぶ写像である。片方しか無ければ作れない。**

| データセット | 内部量 | **機能の出力** |
|---|---|---|
| NASA MOSFET | 素子の電圧・電流 | **無い** |
| NASA IGBT | ゲート波形 | **無い** |
| KAIST PMSM | 三相電流・振動 | **無い** |
| 実インバータ | 相電流・DCバス・温度 | **無い**(位置のみ) |
| commaSteeringControl | **無い** | 車両の応答(部品の出力ではない) |

**5つとも、内部量か機能出力のどちらか一方しか持っていない。**
**だからモデルが作れず、検出器に留まった。**

> **[docs/238](238_data_requirement.md) に R14 を追加する。**
> **R14: 部品の機能出力(トルク)が、内部量と同時に測られていること。**

## 4. そのデータは既に見つけてある

**2026-09-01に評価して、別の理由で保留した**([docs/258](258_kaggle_and_new_candidate_survey.md))。

**産業用電動機 多故障データセット**(Data in Brief、CC BY 4.0、約60 GB、[PMC12361783](https://pmc.ncbi.nlm.nih.gov/articles/PMC12361783/))

| 記録 | 速度 |
|---|---|
| **三相電流** | 100 kHz |
| **トルク** | **25.6 kHz** |
| 回転数 | 100 kHz |
| 振動 | 25.6 kHz |

**内部量(電流)と機能出力(トルク)が、同じ機体で同時に記録されている。**
**本Repoが持つ5つのデータセットで、これを満たすものは1つも無い。**

**保留した理由は「R12(断続)・R13(正解時刻)を満たさないから」だった。**
**モデルを作るのに R12・R13 は要らない。**断続でなくてよい。
**必要なのは、劣化(または故障)の度合いと、そのときの機能出力である。**

| 要件 | この候補 |
|---|---|
| R1 実機 | 満たす |
| R2 スイッチ動作 | 満たす(インバータ駆動) |
| R3 動作点が実測 | 満たす(トルク・回転数) |
| **R14 機能出力が同時** | **満たす。本Repoで初めて** |
| R5 同型3台以上 | **満たさない**(1/3/5/7.5 HP と出力が違う) |
| R12/R13 断続・正解時刻 | 満たさない。**モデル構築には不要** |

## 5. 何が作れるか、何が作れないか

**作れる**: 内部量の逸脱 → 機能出力の低下、の写像。**同じ機体の中で。**

**作れない**:
- **機体をまたぐ写像。**出力が1/3/5/7.5 HP と違い、[docs/203](203_cross_machine_replication_results.md) の
  再現性検定が成立する構成ではない。**1機体限りの結論になる**
- **EPSの数値。**産業用電動機であり、EPSのアシストモータではない
- **断続故障。**R12は未達のまま

## Rule Check

- **「モデルは作れていない」を表題と冒頭に置いた。**検出器と言い換えていない
- **一度作って取り下げた事実と、その2つの理由を書いた**
- **データ要件が1つ抜けていたことを、R1〜R13を読み直して特定した**
- **必要なデータが既に見つかっていて、別の理由で保留していたことを書いた**
- **そのデータで何が作れないかを、作れることと同じ数だけ挙げた**
