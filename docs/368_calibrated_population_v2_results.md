# 368. 標本ごとに当てても指数は同定できない。観測範囲では劣化は直線で、置いていた形がデータで支持された

[docs/367](367_calibrated_population_v2_protocol.md) の事前登録を実行した。**追加取得ゼロ。**

> **V1 外れ（同定 0/6）。事前登録した停止条件により、個体群の段は走らせていない。V2〜V4 は判定しない。**
>
> 全標本に当て、`a` を t10 で縛って `b` と `t0` だけを自由にしても、**6 素子とも `b` が格子の下端 0.001 /h に張り付いた。**
> `b → 0` は指数の直線極限である。つまり**この 6 素子の通電時間 2〜13 時間の範囲では、ΔR/R0 の伸びは直線と区別が付かない。**
> NASA が報告した指数の曲がりは、この軸・この範囲では解像できない。
>
> **裏返すと、これまで「置いた形」だった直線の劣化は、データが支持する形である**（観測範囲の中では）。

実行: `python3 scripts/calibrated_population_v2.py` / 数表: [data/calibrated_population_v2.tsv](../data/calibrated_population_v2.tsv)

## なぜ NASA と違うのか（事前登録していない。候補）

NASA の図の横軸は **aging time（試験機に載っていた時間、0〜250 時間）**で、本件の横軸は**通電時間**（1 分超の空白を除く、2〜13 時間）である。
熱サイクルの休止も劣化に効くなら、指数の曲がりは aging time の軸にだけ現れうる。
[docs/341](341_lifetime_simulation_results.md) で「暦の時間は寿命の通貨にならない」と結論して通電時間を採ったが、
**NASA 自身の形を当てるなら NASA の軸を使うべきだった。**これは候補であって、確かめていない。

## 答えがどう変わるか

| | 前 | 今 |
|---|---|---|
| 仮想モジュールの劣化の形 | 直線（**置いた形**） | 直線（**観測範囲では、データが指数と区別しない形**） |
| NASA の指数モデル | 使えるはず | 7 点でも全標本でも、通電時間の軸では同定できない（docs/366、368） |
| 模型で N を増やす道 | 劣化式から | **劣化式が同定できないので、母数の散らばりが測れず、較正した個体群は作れない**。健全側（σ、S）は 40 テストで測れている |

## 残る限界

- 通電時間ではなく aging time の軸で当て直せば同定できる可能性がある。事前登録していないので、やるなら別に登録する
- Test_10 は出荷時の当てはめが壊れており、どの軸でも使えない
- 6 素子の劣化区間は通電で 2〜13 時間しかなく、指数の曲がりを出すには短い

## Rule Check
- **停止条件どおりに止め、判定しない予想を判定しなかった**
- 同定失敗を「モデルが間違い」とは書かず、「この軸・範囲では区別できない」と書いた
- 置いていた形が支持された、という良い側の結果も書いた
- 軸の候補を「確かめていない」と明記した
