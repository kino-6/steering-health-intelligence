## 新規発見1: インバータ駆動PMSMの故障データセット

| | |
|---|---|
| 出典 | Data in Brief 58 (2025), DOI [10.1016/j.dib.2025.111286](https://doi.org/10.1016/j.dib.2025.111286) |
| 配布 | Zenodo DOI 10.5281/zenodo.13974503 / GitHub `bachaabdelkabir/PMSM-inverter-fault-diagnosis` |
| ライセンス | **CC BY 4.0** |
| 由来 | **実機。**三相インバータ + PMSM + Arduino制御の自作試験装置 |
| 条件 | **9条件**: 正常 / **開放故障2** / **短絡故障3** / **過熱3**——いずれも**インバータのスイッチ側** |
| 信号 | A相電流、B相電流、DCバス電圧、DCバス電流、**ハーフブリッジ3個の温度**、ドライバ電圧(生8信号) |
| 記録 | 10 Hz、1条件あたり約5分、計 10,892 サンプル |

**本研究が一度も持っていなかった種類のデータである。**

- KAIST([docs/195](195_capability_rule_second_mechanism_results.md))は**モータのみ**。インバータは無い
- NASA([docs/199](199_pulse_thermal_results.md))は**単体MOSFETを能動領域のヒーターとして**動かしている
- **これはインバータがモータを実際に駆動している状態でのスイッチ故障である。**EPSのパワー段そのものの構成

そして**開放故障(open-circuit)は、EPSでアシスト喪失が断続的に現れる典型的な機構**である。

**未確認**: 故障が記録中ずっと保持されているか、時間変化するか。配布ページに記載が無い。
**取得して確かめた → [docs/215](215_inverter_dataset_acquisition.md): 恒久であり、断続は入っていなかった。**

**限界(取得前に認める)**: 10 Hz ではスイッチング周期は見えない。1条件5分・全体1万サンプルは小さい。
自作装置であり車載品ではない。

## 新規発見2: OpenLKA — 実車の操舵CANログ

| | |
|---|---|
| 出典 | arXiv [2505.09092](https://arxiv.org/abs/2505.09092)(2025年5月) |
| 配布 | GitHub `OpenLKA/OpenLKA`(暫定的にDropbox配布)。**500 GB超**、部分取得スクリプトあり |
| ライセンス | **MIT**(論文ページはCC0表示) |
| 規模 | **62車種・400時間**、2021〜2024年式 |
| 内容 | CANの生+デコード済(**操舵トルク**、ヨーレート、LKA状態を含む、**100 Hz**)、前方映像1080p/20fps、シーンラベル |
| **事象ラベル** | **有り。**LKAの解除(disengagement)・車線検出失敗などの「failure scenarios」subset |

**commaSteeringControl(既取得)との違い**は事象ラベルの有無である。

既取得のcommaは4車種・3,499ログで、列は
`vEgo, aEgo, steeringAngleDeg, steeringPressed, steer, steerFiltered, latActive, roll, t, latAccelSteeringAngle, latAccelDesired, latAccelLocalizer, epsFwVersion`。
**故障ラベルは無いが、`latAccelDesired` と `latAccelLocalizer` の差は「要求した操舵が実際に出たか」であり、
個体基準法をそのまま当てられる。**

**限界**: LKAの解除はEPSの故障とは限らない(運転者の介入、車線の消失、カーブがきつい等)。
**「異常な操舵事象」であって「EPSの故障」ではない。**
