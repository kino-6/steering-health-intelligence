# 330. 事前登録 — 測った R_on から、アシストが何 % 落ちるかを計算する

## なぜこれを今までやらなかったのか（自分の誤り）

**「アシストが何 % 落ちるか」を、私は 10 回以上「公開データが無いので不可能」と書いてきた。**
**混同していた。**別々の 2 つを 1 つに潰していた。

| | 判断 |
|---|---|
| **ECU が実行時に能力値を名乗るか** | **名乗らない。**7 つの禁止語の筆頭であり、設計判断として閉じている |
| **測った劣化が機能的に何を意味するかを、研究として計算できるか** | **計算できる。**式はこの Repo に既にある |

**後者を前者と一緒に閉じたのが誤りである。**

**式は [docs/192](192_str_capability_rule_protocol.md) が既に置いてある。**

```
導通損で制限されるとき   P = I² R_on = (Tj_max − T_amb) / Rth
  ⇒  I_max = √( (Tj_max − T_amb) / (Rth · R_on) )
  ⇒  実現できるアシストトルク ∝ I_max ∝ 1/√(R_on)
  ⇒  C(t) = √( R_on(base) / R_on(t) )
```

**必要なのは R_on の時間変化だけである。**教師ラベルは要らない。**7 run 分、6 素子、既に手元にある。**

## 温度で汚さないための処理

**試験機は run ごとに温度設定を 10°C ずつ下げている**（250 → 210、[docs/199](199_pulse_thermal_results.md) が特定）。
**R_on は温度に依存するので、生の R_on を run 間で比べると試験機の操作を劣化と読む**（[TROUBLES.md](../TROUBLES.md) T1、過去 5 回）。

> **R_on は、共通の基準動作点に換算してから比べる。**
> 各 run でパッケージ温度に対する直線を当て、**全 run 共通の基準温度における値**を読む。
> 基準温度は**全 run の重なりの中央**とする。

## 手順

データ: NASA MOSFET 熱加速、6 素子 × 7 run（[docs/295](295_all_seven_runs.md) の全 run）。

1. run ごとに `R_on = a · T_package + b` を当てる
2. 全 run のパッケージ温度範囲の**共通部分**を取り、その中央を基準温度 `T_ref` とする
3. 各 run の `R_on(T_ref)` を出す。**run 1 の値を base とする**
4. `C = √( R_on(T_ref, run 1) / R_on(T_ref, run) )` を run ごとに出す
5. **[docs/317](317_changepoint_results.md) が最初に鳴った run での C** を、素子ごとに出す

## 事前に決めて報告すること

| | 何を出すか |
|---|---|
| **A1** | 各素子・各 run の C。**故障直前の run での C が、この試験で失われた能力である** |
| **A2** | **検出器が最初に鳴った run での C。**これが「SOTIF に報告できる時点での機能の残り」である |
| **A3** | A2 と A1 の差。**警告から機能低下までにどれだけ余裕があるか** |

**判定は置かない。数字を出すことが目的である。**ただし読み方は先に固定する:

- **A2 が 0.95 以上なら**「**検出は機能低下に先行する**」と書く
- **A2 が 0.80 未満なら**「**検出時点で既に機能が落ちている**」と書く
- **間なら数字のまま書く**

## この計算が信用できない条件（先に書く）

- **式は導通損だけを考えている。**スイッチング損・ゲート駆動・巻線・機械系は入っていない。
  **実 EPS のアシストが R_on だけで決まるわけではない**
- **Rth が寿命を通じて一定であることを仮定している**（[docs/192](192_str_capability_rule_protocol.md) 仮定B）。
  [docs/199](199_pulse_thermal_results.md) はダイ本体について k ≒ 1 を測ったが、**ダイアタッチは 400 µs の窓では触れていない**
- **Tj_max と T_amb は約分されて消える**ので値は要らないが、**「Tj_max で制限されている」という前提は要る**
- **これは計算であって測定ではない。**[docs/303](303_ml_construction_plan.md) の目標 C（機能出力の実測）は依然として無い。
  **この文書はそれを代替しない**
- 対象は**単体 MOSFET であって EPS ではない**。6 素子・1 試験機。**率ではなく存在証明**
