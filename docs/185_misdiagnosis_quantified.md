# 185. 誤診の痛みを定量した — 全体では無い。標的の族にだけある

## 判断

[docs/184](184_ads_deployment_reality.md) は需要の柱を「OEMの品質・保証の経済性(誤診による無駄な交換)」へ戻した。
**その柱を、苦情160万件で定量した。結果は2つに分かれる。**

**1. 「EPSには誤診の問題がある」は成り立たない。** EPS全体の誤診関連記述は **13.79%**、全苦情の **13.66%** と同じ(**1.01倍**)。
   誤診は業界全体で約14%起きている**普遍的な現象**であり、EPS固有の痛みではない。

**2. ただし「断続的な故障」に絞ると、痛みは実在し、大きい。**
   **断続性を記述したEPS苦情は、原因不明・再現せずと書かれる率が 5.74%。**
   全苦情の基準値 1.15% の **5.0倍**、断続の記述がないEPS苦情(1.28%)の **4.5倍**である。

**本研究が標的にしてきた族こそが、誤診が集中する族だった。**

数表: [data/misdiagnosis_rate_scan.tsv](../data/misdiagnosis_rate_scan.tsv) / 実行: `python3 scripts/misdiagnosis_rate_scan.py`

## 母集団と手順

- NHTSA FLAT_CMPL、222万行。**苦情単位(ODINO)で重複除去**して160万件
- EPS 8,005件 / 操舵全般 140,530件 / 全体 1,604,015件
- 検索語は**結果を見る前に固定**した。消費者が書く言い回しであって、率に合わせて選んでいない

| 語群 | 例 |
|---|---|
| 原因不明・再現せず | no trouble found / could not duplicate / no fault found / no codes |
| 交換したが直らない | replac* かつ (still / again / same problem / did not fix / persist) |
| 繰り返し来店 | multiple times / several times / back to the dealer |

## 結果1: 全体では差が無い

| 語群 | EPS | 操舵全般 | 全体 | EPS/全体 |
|---|---|---|---|---|
| 原因不明・再現せず | 1.50% | 1.32% | 1.15% | 1.31倍 |
| 交換したが直らない | 7.78% | 7.98% | 7.11% | 1.10倍 |
| 繰り返し来店 | 6.48% | 8.02% | 6.85% | **0.95倍** |
| **いずれか** | **13.79%** | 15.60% | **13.66%** | **1.01倍** |

**「繰り返し来店」に至ってはEPSの方が少ない(0.95倍)。**
**EPS全体を「誤診が多い部位」として売り込むことはできない。** これは本研究にとって不利な結果である。

## 結果2: 断続性で層別すると分かれる

| 層 | 原因不明・再現せずの率 | 件数 |
|---|---|---|
| **EPS × 断続的の記述あり** | **5.74%** | 383 |
| EPS × 断続的の記述なし | 1.28% | 7,203 |
| 操舵全般 × 断続的あり | 3.48% | 9,792 |
| 操舵全般 × 断続的なし | 1.15% | 130,738 |

- **EPS内で 4.50倍**(断続あり vs なし)
- 全苦情の基準値 1.15% に対し **5.0倍**
- 操舵全般の断続層(3.48%)よりさらに **1.65倍**。**EPSの断続故障が、操舵系の中でも最も再現しにくい**

## これが本研究の主張とどう噛み合うか

痛みの所在が、標的と一致した。

| 本研究が標的にしてきたもの | 今回の定量 |
|---|---|
| 断続的なアシスト喪失、DTC未満のevent([docs/127](127_steering_predictive_diagnostics_target_case_public_evidence.md), [129](129_steering_predictive_diagnostics_public_case_crosscheck.md)) | **その族で誤診率が5倍** |
| 「部品が観測した事実を、event時点の文脈として説明する」([docs/175](175_close_contact_question.md)) | **販売店で再現できないから、部品側の記録以外に手がかりが無い** |
| GM TSB 17-NA-158「U0401:71でgearを交換するな」という公式警告([docs/130](130_steering_predictive_diagnostics_comm_validity_public_crosscheck.md)) | **誤交換が実際に起きた記録**。今回の統計と同じ現象の個別例 |

**「再現できない」ことこそが痛みであり、部品内部の観測はまさにそこを埋める。**
[docs/175](175_close_contact_question.md) が「fretting系の価値は予告ではなくevent時点の説明」と結論したことと、完全に整合する。

## 限界(小さくない)

1. **絶対数が小さい。** EPS×断続あり は383件、うち原因不明の記述は約22件。**率の差は明確だが、母数は小さい**
2. **消費者が販売店の診断結果を書くとは限らない。** 「原因不明」は**稀にしか書かれない語**(全体で1.15%)であり、
   これは誤診の**発生率ではなく言及率**である。実際の誤診はこれより多いはずだが、**本データからは分からない**
3. 文字列一致であり、否定形("they said it was not a no trouble found")等を区別していない
4. 苦情は自己申告であり、母集団は「苦情を書いた人」に偏る([docs/156](156_train_era_miss_structure.md))

## 事業判断への反映

**売り方の言い方が1つ確定した。**

- ×「EPSは誤診が多いので、監視で減らせます」→ **データが支持しない**(1.01倍)
- ○「**断続的で再現しない故障**では、原因不明で終わる率が5倍になる。**部品側の記録だけがその瞬間を持っている**」→ **データが支持する**

これは [docs/145](145_final_conclusions_and_interpretations.md) が挙げた「誤診による無駄な交換の実費」を、**族を限定する形で裏づけた**ものである。
**限定しない主張は落とす。**

## Rule Check

- 公開データのみ(NHTSA、パブリックドメイン)。検索語は実行前に固定した
- **不利な結果(EPS全体では差が無い、繰り返し来店はむしろ少ない)を先に書いた**
- 単位を苦情(ODINO)にした。行単位で数えない([docs/171](171_eps_wearout_mechanism_scan.md)の教訓)
- 層別(断続性)は**本研究が元から標的にしていた軸**であり、結果を見てから探した軸ではない
- **「言及率であって発生率ではない」**ことを限界に明記した。実際の誤診率を主張していない
