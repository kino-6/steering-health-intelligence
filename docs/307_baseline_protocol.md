# 307. 事前登録 — B に「何もしない基準」を置き直す

> [docs/306](306_capacitor_regression_results.md) は誤差を**教師の測定ばらつき**とだけ比べた。
> **「学習側の平均を予測するだけ」の基準が無く、MAE 0.0130 が単独では読めない**（[TROUBLES.md](../TROUBLES.md) T34）。
> **B が成立かどうかは、この基準との比較で決まる。**

**追加取得ゼロ。** [docs/304](304_capacitor_regression_protocol.md) と同じデータ・同じ分割・同じ特徴。

## 追加する基準（実行前に固定。3 つ）

| 記号なしの名前 | 予測 |
|---|---|
| **平均基準** | 学習側 22 個体の目標変数の平均（定数） |
| **時刻基準** | 目標変数を**時刻だけ**から予測（学習側 22 個体で 1 次回帰）。**波形を一切使わない** |
| **最終値基準** | 常に 1.0（新品）を予測 |

**時刻基準が最も重要である。**コンデンサは時間とともに単調に劣化するので、
**時刻だけで当たるなら、波形は何も足していない。**

## 判定基準（実行前に固定）

| # | 基準 | 閾値 |
|---|---|---|
| **S1** | 線形（Ridge）が**平均基準**を下回る個体 | 過半で「波形は定数より良い」 |
| **S2** | 線形が**時刻基準**を下回る個体 | **過半で「波形が情報を足している」。ここが本命** |
| **S3** | 勾配ブースティングが時刻基準を下回る個体 | 記述 |

**S2 が過半を取らなければ、[docs/306](306_capacitor_regression_results.md) の B は「時刻を当てているだけ」であり、
劣化状態の推定として成立しない。そう書いて B を取り下げる。**

## 答えないこと
- 実運用では「時刻」は使える情報である（キーオン積算時間）。**S2 が落ちても「時刻を使えばよい」という設計上の含意は残る**——ただしそれは波形の主張ではない
