# 問いに答えられるまで回す

**2026-09-01 ユーザ指摘: 「一つの具体的な事例を報告されたが、自分の問いには答えていない。
問いに対して回答できるまで自分でLoop構築するように。」**

**報告の単位を、自分の作業の単位に合わせてはならない。**
検証を1本終えるたびに報告するのは、**問いの粒度ではなく私の作業の粒度で切っている。**

## 手順

```sh
python3 scripts/question_status.py     # 何が開いているか
```

1. **開いている項目を1つ選ぶ。**答えに最も効くものから
2. **[troubles](../troubles/SKILL.md) の28の型を当てる**(特にT14: 「無い」と言い切っていないか)
3. **事前登録を書いてコミットする。**結果より先(`pre-registration order` が強制する)
4. **実行する。**判定は事前登録どおり。閾値を裏返さない
5. **結果を書き、`QUESTION.md` の項目を `[x]` にする。**根拠の文書番号を必ず書く
6. **開いている項目が残っていれば 1 に戻る。ここで報告しない**
7. **全部閉じたら、`QUESTION.md` 先頭の「現在の答え」を書き直す。**
   **恒久的な問いの答えが、今回の結果でどう変わったかを書く。変わらないなら「変わらない」と書く**
8. **そこで初めて報告する。**`scripts/check_report.py` を通す。
   **報告の「答え」節は、恒久的な問いへの答えである。作業項目の合否ではない**([TROUBLES.md](../../../TROUBLES.md) T26)

## 閉じられないときの規則

**「公開データが出れば埋まる」で止めない**([AGENTS.md](../../../AGENTS.md) 0条)。

> **問いを、部品側で決まる形に裏返す。**
>
> - 「ECUの観測床はいくらか」→ **「床がいくらであれば足りるか」**(docs/261)
> - 「運用で訪れる温度範囲は」→ **「直線1本が何度まで持つか」**(docs/263)
> - 「許容できる逸脱の下限は」→ **「部品側では決めない、と決める」**

**裏返しても閉じないなら、それを `C.` の節(閉じないことが答えであるもの)に移す。**
**開いたまま放置しない。**

## 途中でユーザに話すとき

**進捗報告をしない。**聞かれたら答える。それ以外は回す。
**やむを得ず途中で報告するときは、`残り N 件` と何が残っているかを必ず書く**(検査が強制する)。

## 新しい問いが立ったら

`QUESTION.md` の**作業項目**に足す。**恒久的な問いは書き換えない。**

> **恒久的な問いを archive してはならない**([TROUBLES.md](../../../TROUBLES.md) T26)。
> 下位の問いを閉じても、上位の問いは閉じない。**上位の答えを書き直すだけである。**
